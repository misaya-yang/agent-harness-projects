## 容易误用的两个恢复接口

- **缩短会话历史。** 快照移除了 `thread/rollback`。该方法的新请求走未知方法分支，旧 rollout 中的 `ThreadRolledBack` 事件仍可重放。当前 `thread/revert({threadId, beforeTurnId})` 用于已持久化的分页线程，保留指定 Turn 之前的前缀。返回的 Thread 不含历史 Turn，可使用响应里的游标分页补齐。文件改动需要在执行环境中另行处理。 [移除说明](https://github.com/openai/codex/blob/6fd58416e3134633539641d74755b177b0342a5a/codex-rs/app-server/README.md#L609-L618) · [Revert 契约](https://github.com/openai/codex/blob/6fd58416e3134633539641d74755b177b0342a5a/codex-rs/app-server-protocol/src/protocol/v2/thread.rs#L1354-L1383) · [服务端重载保留历史](https://github.com/openai/codex/blob/6fd58416e3134633539641d74755b177b0342a5a/codex-rs/app-server/src/request_processors/thread_processor.rs#L2465-L2505)
- **重试模型请求。** 重试分支用当前工作历史构建请求。启用执行记录捕获且数据仍可用时，可附上执行元数据。这个元数据有自己的生效条件和保留范围。核对工具副作用时，须比较实际操作和写入记录的时序。 [重建请求](https://github.com/openai/codex/blob/6fd58416e3134633539641d74755b177b0342a5a/codex-rs/core/src/session/turn.rs#L2140-L2174) · [执行元数据的开关与保留路径](https://github.com/openai/codex/blob/6fd58416e3134633539641d74755b177b0342a5a/codex-rs/core/src/tools/executed_tool_calls/request_metadata.rs#L111-L173)
