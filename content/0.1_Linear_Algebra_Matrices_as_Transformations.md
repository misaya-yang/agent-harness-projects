# 0.1 线性代数：矩阵即变换

> **一句话核心直觉**：矩阵就是一个线性变换，第 $j$ 列是第 $j$ 个基向量被送到的位置。任何矩阵都能拆成"旋转-拉伸-旋转"：$A = U\Sigma V^\top$。奇异值是各方向的拉伸倍数：最大的那个是谱范数，最大与最小之比是条件数。只保留前 $k$ 个奇异分量，就得到所有秩 $k$ 矩阵里离 $A$ 最近的那一个。LoRA、MLA、Muon 都建立在这几句话上。
> **唤醒标签**：列 = 基向量的去向 · $Av = \lambda v$ · $A = U\Sigma V^\top$ · $\|A\|_2 = \sigma_1$ · $\kappa = \sigma_1/\sigma_{\min}$ · Eckart–Young · 秩 $r$ 存储 $r(m+n)$ · 正交化 $UV^\top$

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

一个 Transformer 层的计算几乎全是矩阵乘法。读这几年的前沿论文，你会反复遇到同一组词：

- **LoRA**：微调时不修改预训练权重 $W$，只训练一个低秩更新量 $\Delta W = BA$。在隐藏维度 $d = k = 4096$、秩 $r = 8$ 时，需要更新的参数量从 1677 万骤降至 6.6 万，仅为原参数量的 0.39%。
- **MLA**（DeepSeek-V2）：避免为每个注意力头单独缓存完整的键（K）和值（V），而是只在显存中缓存低维压缩潜向量，推理时利用矩阵结合律将上投影矩阵直接"吸收"进查询侧矩阵（→ 1.3）。
- **Muon**：把动量矩阵通过奇异值分解写成 $M = U\Sigma V^\top$，随后抹去拉伸奇异值、替换为正交矩阵 $UV^\top$，使得参数空间中每个正交方向的有效更新步长完全对齐（→ 6.3）。
- **条件数**：当损失函数 Hessian 矩阵的条件数过大时，梯度下降会在曲率剧烈变化的狭窄山谷间陷入严重的之字形低效震荡（→ 0.6）。

如果只把矩阵当成一张静态数表，这四个技术就像四个互不相干的工程补丁。但如果将矩阵视作空间变换、用奇异值分解（SVD）将其拆开，它们本质上都在回答同一个几何问题：**一个空间变换究竟在哪几个主方向上拉伸得最多、各自拉伸了多少倍**。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 矩阵的列是基向量的去向

$$
Ax = x_1 a_1 + x_2 a_2 + \cdots + x_n a_n
$$

在几何上，向量 $x$ 在标准基下展开为 $\sum_i x_i e_i$。由线性变换保持加法与数乘的定义，变换后的结果 $Ax = \sum_i x_i A e_i$。这就是说，$Ax$ 本质上是矩阵 $A$ 的各列按照 $x$ 的坐标分量加权求和。标准基向量 $e_1 = (1, 0, \dots)$ 被映射到矩阵第一列 $a_1$，$e_2$ 被映射到第二列 $a_2$。只要掌握了基向量落在何处，整个空间在变换后的朝向与形态就完全确定——这正是"线性"的本质几何含义。

由此引出两个核心推论：

- **矩阵乘法对应复合变换**。式子 $BAx$ 表示先对向量施加变换 $A$，再施加变换 $B$。因为在几何空间中"先旋转再沿坐标轴拉伸"与"先拉伸再旋转"通常导致完全不同的结果，所以矩阵乘法一般不满足交换律（$AB \neq BA$）。
- **行列式对应带符号的面积（体积）缩放倍数**。$\det A$ 刻画了单位超立方体在变换后的体积膨胀或收缩比例。若 $\det A = 0$，说明至少有一个维度被压缩成零厚度的平面，信息永久丢失且变换不可逆；若 $\det A < 0$，说明空间发生了镜像翻转（改变了手性）。

### 2.2 特征向量：方向不变的向量

若非零向量满足 $Av = \lambda v$，则说明 $v$ 经过矩阵 $A$ 变换后并未改变自身所在直线的朝向，仅仅被纯粹拉伸（或缩放）了 $\lambda$ 倍。对于**实对称矩阵**，谱定理保证了极其优良的性质：所有特征值均为实数，且总能找到一组两两正交的特征向量构成完备基，从而分解为 $A = Q\Lambda Q^\top$。我们在后续章节中频繁遇到的协方差矩阵（→ 0.4）与 Hessian 矩阵（→ 0.6）都属于实对称矩阵。

然而现实模型中的一般矩阵（例如非方阵权重）并没有这种对称性保证。普通的二维纯旋转矩阵根本不存在实特征向量（所有非零向量的方向全被旋转改变）；非对称方阵的特征向量之间往往并不垂直；而非方阵更是将向量映射到不同维度的空间中，无从谈起 $Av = \lambda v$。因此，我们需要一种对**任意形状的实矩阵**皆普遍成立的几何分解工具。

### 2.3 SVD：旋转-拉伸-旋转

任意维度为 $m \times n$ 的实矩阵 $A$，都可以精确分解为

$$
A = U \Sigma V^\top
$$

其中 $V$（$n \times n$）与 $U$（$m \times m$）均为正交矩阵（几何上对应保长保角的旋转，可能带有镜像翻转），$\Sigma$（$m \times n$）是对角阵，其主对角线上是按降序排列的非负**奇异值** $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$。

在几何直觉上，任何线性变换对空间的作用都可以拆解为标准三部曲：
1. 先由 $V^\top$ 对输入空间的单位球进行刚体旋转（球体依然是标准圆球）；
2. 再由 $\Sigma$ 沿各个标准坐标轴独立拉伸，将圆球变成半轴长分别为 $\sigma_1, \sigma_2, \dots$ 的超椭球；
3. 最后由 $U$ 将该超椭球在输出空间中旋转到最终目标姿态。

因为正交矩阵满足 $V^\top v_i = e_i$，经过 $\Sigma$ 缩放为 $\sigma_i e_i$，再经 $U$ 映射为 $\sigma_i u_i$，所以**输入空间的右奇异向量 $v_i$ 被直接映射为输出空间的主轴向量 $\sigma_i u_i$**，恰好构成了变形后椭球的各条主半轴。

### 2.4 奇异值读出的三个数

通过 SVD 得到的奇异值谱，能够直接读取矩阵的核心系统特性：

- **谱范数** $\|A\|_2 = \sigma_1 = \max_{\|x\| = 1} \|Ax\|$：表示矩阵 $A$ 能将单位向量拉伸到的理论最长极限长度。在深度学习中，它对应全连接线性层的 Lipschitz 连续常数——输入端若产生微小扰动 $\delta$，输出端的扰动上界严格受控于 $\sigma_1\|\delta\|$。
- **条件数** $\kappa = \sigma_1 / \sigma_{\min}$：最大拉伸倍数与最小拉伸倍数之比，反映了变换的各向异性严重程度。在求解线性方程组 $Ax = b$ 时，输出端观测向量 $b$ 所包含的相对扰动在最坏情况下会被放大 $\kappa$ 倍，传递至解向量 $x$ 中。
- **秩**：非零奇异值的总个数，严格反映输出空间实际占据的有效子空间维度。此外，矩阵行列式的绝对值恰为全部奇异值的连乘积：$|\det A| = \prod_i \sigma_i$。

### 2.5 低秩近似：只留最大的几次拉伸

矩阵的 SVD 也可以等价改写为一系列秩为 1 的外积矩阵之和：

$$
A = \sum_{i=1}^{r} \sigma_i u_i v_i^\top, \qquad A_k = \sum_{i=1}^{k} \sigma_i u_i v_i^\top
$$

**Eckart–Young 定理**指出了截断 SVD 的最优性：在所有秩不超过 $k$ 的候选矩阵中，截取前 $k$ 项得到的 $A_k$ 永远是在几何距离上离原矩阵 $A$ 最近的逼近。其谱范数逼近误差恰好由第一个被丢弃的奇异值决定（$\|A - A_k\|_2 = \sigma_{k+1}$），而 Frobenius 范数逼近误差则严格等于所有被丢弃奇异值的平方和平方根（$\|A - A_k\|_F = \sqrt{\sum_{i > k} \sigma_i^2}$）。

存储与算力效益极其显著：保存原本完整的矩阵 $A$ 需要 $m \times n$ 个浮点数；而保存低秩分解形式 $A_k = (\sum_{i=1}^k \sigma_i u_i) v_i^\top$ 仅需存储两个瘦长矩阵，占用 $k(m + n)$ 个参数。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　复合变换与行列式

由矩阵作用的定义，$(BA)e_j = B(Ae_j) = Ba_j$：复合矩阵 $BA$ 的第 $j$ 列，本质就是"先取 $A$ 的第 $j$ 列向量，再对其施加变换 $B$"。

行列式满足乘法法则 $\det(BA) = \det B \cdot \det A$：几何上这代表空间体积先被 $A$ 缩放 $\det A$ 倍，接着再被 $B$ 缩放 $\det B$ 倍，连续缩放自然相乘。正交矩阵满足 $Q^\top Q = I$，两边取行列式可得 $(\det Q)^2 = 1$，即 $\det Q = \pm 1$：正交变换完全不改变空间体积，纯粹进行刚体旋转（$\det Q = 1$）或带镜像翻转的旋转（$\det Q = -1$）。

### Step 2　从 $A^\top A$ 构造 SVD

对于任意实矩阵 $A$，$A^\top A$ 是实对称半正定方阵（对任意非零向量 $x$，二次型 $x^\top A^\top A x = \|Ax\|^2 \ge 0$）。由实对称矩阵的谱定理，$A^\top A$ 存在正交特征分解 $A^\top A = V \Lambda V^\top$，其中特征值 $\lambda_i \ge 0$，特征向量构成标准正交基 $V = [v_1, \dots, v_n]$。令

$$
\sigma_i = \sqrt{\lambda_i}, \qquad u_i = \frac{A v_i}{\sigma_i} \quad (\sigma_i > 0)
$$

验证向量组 $\{u_i\}$ 的正交性：由特征方程 $A^\top A v_j = \lambda_j v_j$，计算两两内积：

$$
u_i^\top u_j = \frac{v_i^\top A^\top A v_j}{\sigma_i \sigma_j} = \frac{\lambda_j\, v_i^\top v_j}{\sigma_i\sigma_j} = \frac{\lambda_j \delta_{ij}}{\sigma_i \sigma_j} = \delta_{ij}
$$

这证明 $\{u_i\}$ 同样是一组两两正交的单位向量。由 $u_i$ 的定义整理可得 $A v_i = \sigma_i u_i$，写成矩阵分块形式即 $AV = U\Sigma$。两边右乘正交矩阵的逆 $V^\top$，便得到了完整的奇异值分解：$A = U\Sigma V^\top$。

同理计算 $A A^\top = U\Sigma V^\top V \Sigma U^\top = U\Sigma^2 U^\top$：这表明 **$A$ 的非零奇异值恰为 $A^\top A$（或 $AA^\top$）非零特征值的正平方根**。当矩阵本身即为实对称半正定方阵时，SVD 与其特征分解完全重合。

### Step 3　谱范数与条件数

将任意输入向量 $x$ 在标准正交基 $\{v_i\}$ 下线性展开为 $x = \sum_i c_i v_i$，其欧氏长度满足 $\|x\|^2 = \sum_i c_i^2$。代入计算输出长度：

$$
\|Ax\|^2 = x^\top A^\top A x = \sum_i \sigma_i^2 c_i^2 \le \sigma_1^2 \sum_i c_i^2 = \sigma_1^2 \|x\|^2
$$

两边开方可得 $\|Ax\| \le \sigma_1 \|x\|$。当输入取为主轴方向 $x = v_1$ 时等号严格成立，因此由算子范数定义推得谱范数 $\|A\|_2 = \sigma_1$。

对于可逆方阵，$A^{-1} = V\Sigma^{-1}U^\top$，其奇异值为 $1/\sigma_n \ge \cdots \ge 1/\sigma_1$，故 $\|A^{-1}\|_2 = 1/\sigma_n$。求解线性方程组 $Ax = b$ 时，若观测端存在扰动 $\delta b$，解的扰动为 $\delta x = A^{-1}\delta b$。由范数不等式 $\|\delta x\| \le \|A^{-1}\|_2 \|\delta b\| = \|\delta b\| / \sigma_n$；同时由原方程可知 $\|b\| = \|Ax\| \le \sigma_1 \|x\|$，两式相除立即给出相对误差上界：

$$
\frac{\|\delta x\|}{\|x\|} \le \frac{\sigma_1}{\sigma_n} \cdot \frac{\|\delta b\|}{\|b\|} = \kappa \cdot \frac{\|\delta b\|}{\|b\|}
$$

条件数 $\kappa$ 正是扰动放大的最坏恶化倍数。

### Step 4　Eckart–Young（谱范数版）

设 $B$ 是任意一个秩不超过 $k$ 的候选逼近矩阵，根据秩-零度定理，其零空间 $\ker(B) = \{x \mid Bx = 0\}$ 的维度至少为 $n - k$。同时，前 $k+1$ 个右奇异向量张成的子空间 $\mathcal{V}_{k+1} = \mathrm{span}(v_1, \dots, v_{k+1})$ 维度为 $k + 1$。因为这两个子空间的维度之和 $(n - k) + (k + 1) = n + 1 > n$，由维数定理，它们必存在非平凡的交集。

在交集中任取一个单位向量 $x = \sum_{i=1}^{k+1} c_i v_i$（满足 $\|x\|^2 = \sum_{i=1}^{k+1} c_i^2 = 1$）。因为 $x \in \ker(B)$，所以 $Bx = 0$。代入算子范数定义：

$$
\|A - B\|_2 \ge \|(A - B)x\| = \|Ax\| = \sqrt{\sum_{i=1}^{k+1} \sigma_i^2 c_i^2} \ge \sigma_{k+1} \sqrt{\sum_{i=1}^{k+1} c_i^2} = \sigma_{k+1}
$$

另一方面，直接取截断 SVD 矩阵 $A_k = \sum_{i=1}^k \sigma_i u_i v_i^\top$，其逼近残差为 $A - A_k = \sum_{i > k} \sigma_i u_i v_i^\top$，其谱范数恰好精确等于 $\sigma_{k+1}$，完美达到了理论下界。类似的方法可证明在 Frobenius 范数下，最优误差严格为 $\sqrt{\sum_{i>k}\sigma_i^2}$。

### Step 5　离 $A$ 最近的正交矩阵：$UV^\top$

极分解定理指出，任何方阵都可分解为一个正交变换与一个对称半正定拉伸的乘积：$A = (UV^\top)(V\Sigma V^\top)$。在 Frobenius 范数下，寻找与 $A$ 距离最近的正交矩阵 $Q$（经典正交 Procrustes 问题）：

$$
\|A - Q\|_F^2 = \mathrm{tr}\big((A - Q)^\top(A - Q)\big) = \|A\|_F^2 + n - 2\,\mathrm{tr}(Q^\top A)
$$

最小化距离等价于最大化迹项 $\mathrm{tr}(Q^\top A)$。代入 SVD 分解 $A = U\Sigma V^\top$ 并利用迹运算的循环置换性质：

$$
\mathrm{tr}(Q^\top U\Sigma V^\top) = \mathrm{tr}\big((U^\top Q V)^\top \Sigma\big)
$$

由于 $U, Q, V$ 均为正交矩阵，矩阵乘积 $Z = U^\top Q V$ 同样必为正交矩阵，其对角线元素必然满足 $|Z_{ii}| \le 1$。因此对角加权和 $\mathrm{tr}(Z^\top \Sigma) = \sum_i Z_{ii} \sigma_i \le \sum_i \sigma_i$。显然，当且仅当 $Z = I$（即取 $Q = UV^\top$）时，对角元素全部取到最大值 1，等号严格成立。

几何含义十分纯粹：$UV^\top$ 完整保留了原变换 $A$ 的旋转框架，仅仅将各个方向各不相同的拉伸奇异值统一归一化为 1。现代优化器 Muon 正是通过 Newton–Schulz 迭代近似高效计算该正交投影（→ 6.3）。

### Step 6　低秩分解的参数与计算

将高维全连接权重矩阵 $W \in \mathbb{R}^{d \times k}$ 分解为两块低秩矩阵乘积 $BA$（其中 $B \in \mathbb{R}^{d \times r}$、$A \in \mathbb{R}^{r \times k}$，且 $r \ll \min(d, k)$）：参数量从 $dk$ 降至 $r(d + k)$。在前向计算输出向量 $Wx$ 时，根据矩阵乘法结合律，将运算顺序重组为 $B(Ax)$：先将输入 $x$ 投影到紧凑的 $r$ 维低秩瓶颈空间，再映射回 $d$ 维输出空间，计算量由 $dk$ 次乘加减少至 $r(d + k)$ 次。

值得牢记的是，秩不超过 $r$ 是不可逾越的硬性代数约束：如果任务所要求的参数调整在本质上是高秩的，那么即便在微调阶段无论如何精调学习率或训练周期，也无法弥补低秩子空间之外的信息缺失。

## 4. 极简代码锚点（PyTorch）

```python
import torch
torch.manual_seed(0)

# 1. SVD 的几何：右奇异向量 v₁ 被送到 σ₁u₁
A = torch.tensor([[1.4, 0.9], [0.2, 1.0]])
U, S, Vh = torch.linalg.svd(A)              # Vh 的第 i 行是 vᵢᵀ
print(S)                                    # tensor([1.8352, 0.6648])，σ₁σ₂ = |det A| = 1.22
print(A @ Vh[0], S[0] * U[:, 0])            # 两者相等
print(torch.linalg.matrix_norm(A, ord=2), torch.linalg.cond(A))   # 谱范数 = σ₁，条件数 = σ₁/σ₂

# 2. Eckart–Young：截断误差正好是被丢掉的奇异值
W = torch.randn(256, 64) @ torch.randn(64, 256) / 8 + 0.05 * torch.randn(256, 256)   # 秩 64 + 噪声
U, S, Vh = torch.linalg.svd(W)
for k in [8, 32, 64, 128]:
    Wk = U[:, :k] @ torch.diag(S[:k]) @ Vh[:k]
    print(k, torch.linalg.matrix_norm(W - Wk).item(),     # Frobenius 误差
          S[k:].square().sum().sqrt().item())             # √Σᵢ>ₖ σᵢ²，两者相等

# 3. LoRA：用两个瘦矩阵表示更新
d, k, r = 4096, 4096, 8
B = torch.zeros(d, r)                       # B 从 0 开始：训练开始时 ΔW = 0，模型不变
A_ = torch.randn(r, k) * 0.01
x = torch.randn(k)
y = B @ (A_ @ x)                            # 先乘瘦的一边：r(d + k) 次乘加，不必拼出 d×k 的 ΔW
print(r * (d + k), d * k, r * (d + k) / (d * k))   # 65536 16777216 0.0039

# 4. 离 M 最近的正交矩阵 = U Vᵀ（Muon 想要的更新方向）
M = torch.randn(128, 64)
U, S, Vh = torch.linalg.svd(M, full_matrices=False)
O = U @ Vh
print(torch.linalg.svdvals(O)[:3])          # 全是 1
print(torch.dist(O.T @ O, torch.eye(64)))   # ≈ 0
```

### 数值复算 · 丢掉第二个方向，哪一种误差最大？

在同一个 Python 会话中先运行本节上方的实现，再运行以下算例。

```python
import torch
A = torch.diag(torch.tensor([2., 0.5], dtype=torch.float64))
u, sigma, vh = torch.linalg.svd(A)
approx = (u[:, :1] * sigma[:1]) @ vh[:1]
err = A-approx
for x in torch.eye(2, dtype=A.dtype):
    print(f"该方向的输出误差={(err @ x).norm():.3f}")
print(f"相对 Frobenius 误差={err.norm()/A.norm():.3f}")
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **低秩微调仍是最常用的参数高效方法**。LoRA 原论文在 GPT-3 175B 上把可训练参数减少约 1 万倍、显存需求减少约 3 倍，效果与全量微调相当。背后的解释是微调更新的"内在维度"很低：Aghajanyan et al. 只训练 200 个随机投影回全空间的参数，就让 RoBERTa 在 MRPC 上达到全量微调 90% 的效果。
- **KV 缓存用低秩潜变量压缩**。DeepSeek-V2 的 MLA 只缓存每个 token 的一个低维潜向量，相比 DeepSeek 67B 把 KV 缓存减少了 93.3%。推理时利用矩阵结合律把上投影"吸收"进查询，不必把 K 解压出来（→ 1.3）。
- **矩阵优化器把权重当算子**。Muon 对动量做正交化，Moonshot 的扩展实验报告在计算最优设置下，它的计算效率约为 AdamW 的 2 倍（→ 6.3）。谱范数、正交化这些线性代数概念直接变成了优化器设计。

**与工程 / 应用的连接**
- **LoRA 的秩怎么选**：学风格、格式、指令跟随，$r = 8$–$16$ 常常够用；灌入大量新知识或做继续预训练，需要的更新秩更高，LoRA 会明显落后全量微调。可以对全量微调得到的 $\Delta W$ 做 SVD，看奇异值掉得多快，直接判断低秩够不够。
- **合并与量化**：LoRA 训练完可以把 $BA$ 加回 $W$，推理零额外开销。多个 LoRA 相加时，它们的列空间可能互相干扰，这也是模型合并方法要处理的问题。
- **条件数与低精度**：bf16 只有 8 位有效二进制位，相对精度约 $2^{-8} \approx 0.4\%$。条件数大的计算会把舍入误差放大 $\kappa$ 倍，所以归一化、softmax、损失这类操作通常仍在 fp32 下做。
- **看谱做诊断**：跟踪权重或更新矩阵的最大奇异值，能比看 loss 更早发现某一层在失控（→ 5.3）。

**常见误区 / 反直觉点**
1. **"特征值就是奇异值"** ✗：只有对称半正定矩阵才相同。旋转矩阵的特征值是复数 $e^{\pm i\theta}$，奇异值都是 1；$\begin{pmatrix} 0 & 100 \\ 0 & 0 \end{pmatrix}$ 的特征值都是 0，最大奇异值却是 100。
2. **"低秩近似就是删掉一些行或列"** ✗：删掉的是方向（行、列的线性组合），$A_k$ 通常每个元素都非零。
3. **"秩低的矩阵占的存储少"** ✗：一个秩 8 的 4096×4096 矩阵照样有 1677 万个元素。只有按 $B$、$A$ 两个因子存，才省得下来。
4. **"条件数大只是数值精度问题"** ✗：它同样决定优化速度。梯度下降在二次型上大约需要 $\kappa$ 步才能收敛（→ 0.6）。

**高频深挖题**
- **Q1：LoRA 为什么有效？秩 $r$ 怎么选，什么时候不够用？**
  思路：$\Delta W = BA$，参数 $r(d + k)$ → 微调更新的奇异值谱衰减快、内在维度低 → Eckart–Young 保证秩 $r$ 截断是最优近似，误差只取决于被丢掉的 $\sigma_i$ → $B$ 初始化为 0 使训练从原模型出发，缩放 $\alpha / r$ 让不同秩的学习率可比 → 需要高秩更新（继续预训练、新语言）时不够用。
- **Q2：证明线性层 $y = Wx$ 的 Lipschitz 常数是 $\sigma_1(W)$，并说明它和训练稳定性的关系。**
  思路：$\|W(x - x')\| \le \sigma_1 \|x - x'\|$，取 $x - x' \parallel v_1$ 时等号成立 → 深层网络的 Lipschitz 常数不超过各层 $\sigma_1$ 之积 → $\sigma_1$ 过大会放大扰动、导致激活和梯度爆炸 → 谱归一化、Muon 控制更新的谱范数，都是在管这个数。
- **Q3：MLA 怎样用低秩压缩 KV 缓存？推理时为什么不用把 K 解压出来？**
  思路：$c_t = W^{DKV} h_t$，只缓存低维的 $c_t$ → $k_t = W^{UK} c_t$ → $q^\top k = (W^Q h)^\top W^{UK} c = h^\top (W^{Q\top} W^{UK}) c$，把两个矩阵预先乘在一起 → 解压被吸收进查询侧 → 加分项：RoPE 会破坏这种吸收，所以 MLA 单独留了一小段带 RoPE 的 key（→ 1.3）。
