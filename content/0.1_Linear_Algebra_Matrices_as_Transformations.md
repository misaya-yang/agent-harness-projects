# 0.1 线性代数：矩阵即变换

> **一句话核心直觉**：矩阵就是一个线性变换，第 $j$ 列是第 $j$ 个基向量被送到的位置。任何矩阵都能拆成"旋转-拉伸-旋转"：$A = U\Sigma V^\top$。奇异值是各方向的拉伸倍数：最大的那个是谱范数，最大与最小之比是条件数。只保留前 $k$ 个奇异分量，就得到所有秩 $k$ 矩阵里离 $A$ 最近的那一个。LoRA、MLA、Muon 都建立在这几句话上。
> **唤醒标签**：列 = 基向量的去向 · $Av = \lambda v$ · $A = U\Sigma V^\top$ · $\|A\|_2 = \sigma_1$ · $\kappa = \sigma_1/\sigma_{\min}$ · Eckart–Young · 秩 $r$ 存储 $r(m+n)$ · 正交化 $UV^\top$

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

一个 Transformer 层的计算几乎全是矩阵乘法。读这几年的论文，你会反复遇到同一组词：

- **LoRA**：微调时不改 $W$，只学一个秩为 $r$ 的更新 $\Delta W = BA$。$d = k = 4096$、$r = 8$ 时，要学的参数从 1677 万降到 6.6 万，只有 0.39%。
- **MLA**（DeepSeek-V2）：不缓存每个头的 K 和 V，只缓存一个低维的潜向量，推理时再"吸收"进注意力的矩阵里（→ 1.3）。
- **Muon**：把动量矩阵 $M = U\Sigma V^\top$ 换成 $UV^\top$，让每个方向的步长一样大（→ 6.3）。
- **条件数**：Hessian 的条件数大，梯度下降就在山谷里之字形震荡（→ 0.6）。

如果只把矩阵当成一张数表，这是四个互不相干的技巧。把矩阵看成"变换"，再用 SVD 拆开，它们说的是同一件事：**一个变换在哪几个方向上拉伸得最多**。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 矩阵的列是基向量的去向

$$
Ax = x_1 a_1 + x_2 a_2 + \cdots + x_n a_n
$$

$Ax$ 是 $A$ 的各列按 $x$ 的分量加权求和。$e_1 = (1, 0, \dots)$ 被送到第一列 $a_1$，$e_2$ 被送到 $a_2$。知道了基向量去哪，整个空间去哪就定了，这就是"线性"的含义。

两个推论：

- **矩阵乘法 = 复合变换**。$BAx$ 是先做 $A$ 再做 $B$。先旋转再拉伸和先拉伸再旋转结果不同，所以 $AB \neq BA$。
- **行列式 = 带符号的面积（体积）缩放倍数**。$\det A = 0$ 说明某个方向被压扁了，变换不可逆；$\det A < 0$ 说明发生了翻转。

### 2.2 特征向量：方向不变的向量

如果 $Av = \lambda v$，$v$ 经过变换后方向不变，只被拉伸 $\lambda$ 倍。**对称矩阵**有一个很好的性质（谱定理）：特征值都是实数，特征向量可以取成互相垂直的一组，于是 $A = Q\Lambda Q^\top$。协方差矩阵（→ 0.4）和 Hessian（→ 0.6）都是对称矩阵。

但一般矩阵没这么好。旋转矩阵没有实特征向量（每个方向都被转走了）；非对称矩阵的特征向量也不一定互相垂直。我们需要一种对**任何矩阵**都成立的分解。

### 2.3 SVD：旋转-拉伸-旋转

任何 $m \times n$ 的实矩阵都可以写成

$$
A = U \Sigma V^\top
$$

$V$ 和 $U$ 是正交矩阵（旋转，可能带一次翻转），$\Sigma$ 是对角阵，对角线上是非负的**奇异值** $\sigma_1 \ge \sigma_2 \ge \cdots \ge 0$。几何上：单位圆先被 $V^\top$ 转一下（圆还是圆），再被 $\Sigma$ 沿坐标轴拉成椭圆，最后被 $U$ 转到位。**右奇异向量 $v_i$ 被送到 $\sigma_i u_i$**，正好是椭圆的主轴。

拖动四个元素，切换"分解步骤"看圆怎样一步步变成椭圆。初始矩阵 $\sigma_1 = 1.84$、$\sigma_2 = 0.66$；"纯旋转"预设下两个奇异值都是 1，圆还是圆；"带翻转"预设的 $\det A < 0$，翻转会落在 $U$ 里。灰色虚线是 $e_1, e_2$ 的去向，最后一步正是 $A$ 的两列。

### 2.4 奇异值读出的三个数

- **谱范数** $\|A\|_2 = \sigma_1 = \max_{\|x\| = 1} \|Ax\|$：$A$ 能把单位向量拉到的最长长度。它是线性层的 Lipschitz 常数：输入变化 $\delta$，输出变化最多 $\sigma_1\|\delta\|$。
- **条件数** $\kappa = \sigma_1 / \sigma_{\min}$：最长与最短拉伸之比。解 $Ax = b$ 时，$b$ 的相对误差最多被放大 $\kappa$ 倍。
- **秩**：非零奇异值的个数，也就是输出空间实际用到的维数。$|\det A| = \prod_i \sigma_i$。

### 2.5 低秩近似：只留最大的几次拉伸

SVD 也可以写成秩 1 矩阵之和：

$$
A = \sum_{i=1}^{r} \sigma_i u_i v_i^\top, \qquad A_k = \sum_{i=1}^{k} \sigma_i u_i v_i^\top
$$

**Eckart–Young 定理**：在所有秩不超过 $k$ 的矩阵里，$A_k$ 离 $A$ 最近，谱范数误差是 $\sigma_{k+1}$，Frobenius 范数误差是 $\sqrt{\sum_{i > k} \sigma_i^2}$。误差完全由被丢掉的奇异值决定。存储上，$A_k$ 只需要 $k(m + n)$ 个数，而不是 $mn$。

### 丢掉第二个方向，哪一种误差最大？

在[二维 SVD 实验](#lab-0-1)中，将对角元设成 2 和 0.5，其余元素设为 0。满秩变换把单位圆变成半轴为 2 和 0.5 的椭圆。切到秩 1 后，沿长轴的输入完全不受影响，沿短轴的单位输入则损失 0.5。这就是截断后残差的谱范数。相对于整个矩阵的 Frobenius 误差却是 $0.5/\sqrt{4+0.25}$，约为 24.3%。一个是最坏输入的绝对偏差，另一个是所有方向平方能量的相对份额。

**迁移练习。** 若实际输入永远沿第一轴，截断在这批输入上的输出误差是多少？恰好为零。反过来，若下游任务只读第二轴，即使保留能量很高，也可能损失全部有用信号。选择秩时最好同时看谱和任务分布。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　复合变换与行列式

$(BA)e_j = B(Ae_j) = Ba_j$：$BA$ 的第 $j$ 列是"$A$ 的第 $j$ 列再经过 $B$"。行列式满足 $\det(BA) = \det B \cdot \det A$：面积先缩放 $\det A$ 倍，再缩放 $\det B$ 倍。正交矩阵 $Q^\top Q = I$，所以 $\det Q = \pm 1$：不改变面积，只旋转或翻转。

### Step 2　从 $A^\top A$ 构造 SVD

$A^\top A$ 是对称半正定矩阵（$x^\top A^\top A x = \|Ax\|^2 \ge 0$），由谱定理 $A^\top A = V \Lambda V^\top$，$\lambda_i \ge 0$。令

$$
\sigma_i = \sqrt{\lambda_i}, \qquad u_i = \frac{A v_i}{\sigma_i} \quad (\sigma_i > 0)
$$

检查 $u_i$ 两两正交：$u_i^\top u_j = \dfrac{v_i^\top A^\top A v_j}{\sigma_i \sigma_j} = \dfrac{\lambda_j\, v_i^\top v_j}{\sigma_i\sigma_j} = \delta_{ij}$。于是 $AV = U\Sigma$，右乘 $V^\top$ 得 $A = U\Sigma V^\top$。同理 $AA^\top = U\Sigma^2 U^\top$：**$A$ 的奇异值是 $A^\top A$ 特征值的平方根**。对称半正定矩阵的 SVD 就是它的特征分解。

### Step 3　谱范数与条件数

把 $x$ 在 $\{v_i\}$ 下展开，$x = \sum_i c_i v_i$：

$$
\|Ax\|^2 = x^\top A^\top A x = \sum_i \sigma_i^2 c_i^2 \le \sigma_1^2 \sum_i c_i^2 = \sigma_1^2 \|x\|^2
$$

取 $x = v_1$ 时取等号，所以 $\|A\|_2 = \sigma_1$。对可逆方阵，$\|A^{-1}\|_2 = 1/\sigma_n$。解 $Ax = b$ 时 $b$ 有误差 $\delta b$：$\|\delta x\| = \|A^{-1}\delta b\| \le \|\delta b\| / \sigma_n$，又 $\|b\| \le \sigma_1 \|x\|$，两式相乘：

$$
\frac{\|\delta x\|}{\|x\|} \le \frac{\sigma_1}{\sigma_n} \cdot \frac{\|\delta b\|}{\|b\|} = \kappa \cdot \frac{\|\delta b\|}{\|b\|}
$$

### Step 4　Eckart–Young（谱范数版）

设 $B$ 的秩不超过 $k$，它的零空间至少 $n - k$ 维。$\mathrm{span}(v_1, \dots, v_{k+1})$ 是 $k + 1$ 维，两个子空间维数之和超过 $n$，必有公共的单位向量 $x = \sum_{i \le k+1} c_i v_i$。于是

$$
\|A - B\|_2 \ge \|(A - B)x\| = \|Ax\| = \sqrt{\textstyle\sum_{i \le k+1} \sigma_i^2 c_i^2} \ge \sigma_{k+1}
$$

而 $A - A_k = \sum_{i > k} \sigma_i u_i v_i^\top$，谱范数恰好是 $\sigma_{k+1}$，下界取到。Frobenius 版可以类似证明，误差是 $\sqrt{\sum_{i>k}\sigma_i^2}$。

### Step 5　离 $A$ 最近的正交矩阵：$UV^\top$

极分解把任意方阵写成"正交 × 半正定"：$A = (UV^\top)(V\Sigma V^\top)$。在 Frobenius 范数下，离 $A$ 最近的正交矩阵正是 $UV^\top$（正交 Procrustes 问题）：

$$
\|A - Q\|_F^2 = \|A\|_F^2 + n - 2\,\mathrm{tr}(Q^\top A), \qquad \mathrm{tr}(Q^\top U\Sigma V^\top) = \mathrm{tr}\big((U^\top Q V)^\top \Sigma\big) \le \sum_i \sigma_i
$$

$U^\top Q V$ 也是正交矩阵，对角元都不超过 1，取 $Q = UV^\top$ 时等号成立。$UV^\top$ 保留了 $A$ 的所有方向，把每个奇异值都换成 1。Muon 用 Newton–Schulz 迭代近似算的就是它（→ 6.3）。

### Step 6　低秩分解的参数与计算

$W \in \mathbb{R}^{d \times k}$ 写成 $BA$，$B \in \mathbb{R}^{d \times r}$、$A \in \mathbb{R}^{r \times k}$：参数从 $dk$ 降到 $r(d + k)$，计算 $Wx$ 从 $dk$ 次乘加降到 $r(d + k)$ 次。矩阵乘法满足结合律，$(BA)x = B(Ax)$，先乘瘦的那一边永远更省。注意秩不超过 $r$ 是硬约束：如果真正需要的更新是高秩的，$r$ 再怎么调学习率也补不回来。

## 4. 极简代码锚点（PyTorch）

```python
import torch
torch.manual_seed(0)

# 1. SVD 的几何：右奇异向量 v₁ 被送到 σ₁u₁
A = torch.tensor([[1.4, 0.9], [0.2, 1.0]])
U, S, Vh = torch.linalg.svd(A)              # Vh 的第 i 行是 vᵢᵀ
print(S)                                    # tensor([1.8352, 0.6648])，σ₁σ₂ = |det A| = 1.22
print(A @ Vh[0], S[0] * U[:, 0])            # 两者相等
print(torch.linalg.matrix_norm(A, ord=2), torch.linalg.cond(A))   # 谱范数 = σ₁，条件数 = σ₁/σ₂

# 2. Eckart–Young：截断误差正好是被丢掉的奇异值
W = torch.randn(256, 64) @ torch.randn(64, 256) / 8 + 0.05 * torch.randn(256, 256)   # 秩 64 + 噪声
U, S, Vh = torch.linalg.svd(W)
for k in [8, 32, 64, 128]:
    Wk = U[:, :k] @ torch.diag(S[:k]) @ Vh[:k]
    print(k, torch.linalg.matrix_norm(W - Wk).item(),     # Frobenius 误差
          S[k:].square().sum().sqrt().item())             # √Σᵢ>ₖ σᵢ²，两者相等

# 3. LoRA：用两个瘦矩阵表示更新
d, k, r = 4096, 4096, 8
B = torch.zeros(d, r)                       # B 从 0 开始：训练开始时 ΔW = 0，模型不变
A_ = torch.randn(r, k) * 0.01
x = torch.randn(k)
y = B @ (A_ @ x)                            # 先乘瘦的一边：r(d + k) 次乘加，不必拼出 d×k 的 ΔW
print(r * (d + k), d * k, r * (d + k) / (d * k))   # 65536 16777216 0.0039

# 4. 离 M 最近的正交矩阵 = U Vᵀ（Muon 想要的更新方向）
M = torch.randn(128, 64)
U, S, Vh = torch.linalg.svd(M, full_matrices=False)
O = U @ Vh
print(torch.linalg.svdvals(O)[:3])          # 全是 1
print(torch.dist(O.T @ O, torch.eye(64)))   # ≈ 0
```

### 数值复算 · 丢掉第二个方向，哪一种误差最大？

在同一个 Python 会话中先运行本节上方的实现，再运行以下算例。

```python
import torch
A = torch.diag(torch.tensor([2., 0.5], dtype=torch.float64))
u, sigma, vh = torch.linalg.svd(A)
approx = (u[:, :1] * sigma[:1]) @ vh[:1]
err = A-approx
for x in torch.eye(2, dtype=A.dtype):
    print(f"该方向的输出误差={(err @ x).norm():.3f}")
print(f"相对 Frobenius 误差={err.norm()/A.norm():.3f}")
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **低秩微调仍是最常用的参数高效方法**。LoRA 原论文在 GPT-3 175B 上把可训练参数减少约 1 万倍、显存需求减少约 3 倍，效果与全量微调相当。背后的解释是微调更新的"内在维度"很低：Aghajanyan et al. 只训练 200 个随机投影回全空间的参数，就让 RoBERTa 在 MRPC 上达到全量微调 90% 的效果。
- **KV 缓存用低秩潜变量压缩**。DeepSeek-V2 的 MLA 只缓存每个 token 的一个低维潜向量，相比 DeepSeek 67B 把 KV 缓存减少了 93.3%。推理时利用矩阵结合律把上投影"吸收"进查询，不必把 K 解压出来（→ 1.3）。
- **矩阵优化器把权重当算子**。Muon 对动量做正交化，Moonshot 的扩展实验报告在计算最优设置下，它的计算效率约为 AdamW 的 2 倍（→ 6.3）。谱范数、正交化这些线性代数概念直接变成了优化器设计。

**与工程 / 应用的连接**
- **LoRA 的秩怎么选**：学风格、格式、指令跟随，$r = 8$–$16$ 常常够用；灌入大量新知识或做继续预训练，需要的更新秩更高，LoRA 会明显落后全量微调。可以对全量微调得到的 $\Delta W$ 做 SVD，看奇异值掉得多快，直接判断低秩够不够。
- **合并与量化**：LoRA 训练完可以把 $BA$ 加回 $W$，推理零额外开销。多个 LoRA 相加时，它们的列空间可能互相干扰，这也是模型合并方法要处理的问题。
- **条件数与低精度**：bf16 只有 8 位有效二进制位，相对精度约 $2^{-8} \approx 0.4\%$。条件数大的计算会把舍入误差放大 $\kappa$ 倍，所以归一化、softmax、损失这类操作通常仍在 fp32 下做。
- **看谱做诊断**：跟踪权重或更新矩阵的最大奇异值，能比看 loss 更早发现某一层在失控（→ 5.3）。

**常见误区 / 反直觉点**
1. **"特征值就是奇异值"** ✗：只有对称半正定矩阵才相同。旋转矩阵的特征值是复数 $e^{\pm i\theta}$，奇异值都是 1；$\begin{pmatrix} 0 & 100 \\ 0 & 0 \end{pmatrix}$ 的特征值都是 0，最大奇异值却是 100。
2. **"低秩近似就是删掉一些行或列"** ✗：删掉的是方向（行、列的线性组合），$A_k$ 通常每个元素都非零。
3. **"秩低的矩阵占的存储少"** ✗：一个秩 8 的 4096×4096 矩阵照样有 1677 万个元素。只有按 $B$、$A$ 两个因子存，才省得下来。
4. **"条件数大只是数值精度问题"** ✗：它同样决定优化速度。梯度下降在二次型上大约需要 $\kappa$ 步才能收敛（→ 0.6）。

**高频深挖题**
- **Q1：LoRA 为什么有效？秩 $r$ 怎么选，什么时候不够用？**
  思路：$\Delta W = BA$，参数 $r(d + k)$ → 微调更新的奇异值谱衰减快、内在维度低 → Eckart–Young 保证秩 $r$ 截断是最优近似，误差只取决于被丢掉的 $\sigma_i$ → $B$ 初始化为 0 使训练从原模型出发，缩放 $\alpha / r$ 让不同秩的学习率可比 → 需要高秩更新（继续预训练、新语言）时不够用。
- **Q2：证明线性层 $y = Wx$ 的 Lipschitz 常数是 $\sigma_1(W)$，并说明它和训练稳定性的关系。**
  思路：$\|W(x - x')\| \le \sigma_1 \|x - x'\|$，取 $x - x' \parallel v_1$ 时等号成立 → 深层网络的 Lipschitz 常数不超过各层 $\sigma_1$ 之积 → $\sigma_1$ 过大会放大扰动、导致激活和梯度爆炸 → 谱归一化、Muon 控制更新的谱范数，都是在管这个数。
- **Q3：MLA 怎样用低秩压缩 KV 缓存？推理时为什么不用把 K 解压出来？**
  思路：$c_t = W^{DKV} h_t$，只缓存低维的 $c_t$ → $k_t = W^{UK} c_t$ → $q^\top k = (W^Q h)^\top W^{UK} c = h^\top (W^{Q\top} W^{UK}) c$，把两个矩阵预先乘在一起 → 解压被吸收进查询侧 → 加分项：RoPE 会破坏这种吸收，所以 MLA 单独留了一小段带 RoPE 的 key（→ 1.3）。
