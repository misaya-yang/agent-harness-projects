# 0.2 微积分：梯度、链式法则与反向传播

> **一句话核心直觉**：导数不只是"斜率"这个数，它是**函数在一点附近最好的线性近似**。多元函数的线性近似是一个矩阵（Jacobian），复合函数的近似就是把这些矩阵乘起来。反向传播只是选了一个聪明的乘法顺序：从标量 loss 往回乘，一遍就得到全部参数的梯度。
> **唤醒标签**：一阶近似误差 $O(h^2)$ · 梯度垂直于等高线 · Jacobian 连乘 · 向量–Jacobian 积（VJP） · 反向 ≈ 2 倍前向 · 激活缓存 · 梯度消失

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

一个 7B 模型有 70 亿个参数。训练的每一步都要知道：**每个参数往哪边动一点，loss 会下降？**

最朴素的办法是有限差分：把第 $i$ 个参数加一个小量 $h$，重新跑一遍前向，看 loss 变了多少。

$$
\frac{\partial L}{\partial \theta_i} \approx \frac{L(\theta + h\,e_i) - L(\theta)}{h}
$$

70 亿个参数就要跑 70 亿次前向，一步训练要算几百年。而且 $h$ 取大了有截断误差，取小了在 bf16 下全是舍入噪声。

反向传播把这件事的代价降到**大约两次前向**：前向算一遍 loss，反向从 loss 出发再走一遍，所有参数的梯度同时出来。这就是为什么训练一个 token 约要 $6N$ FLOPs：前向 $2N$，反向 $4N$（→ 5.1 §2）。

代价也随之而来：反向时每一层都要用到前向的中间结果，所以这些**激活必须一直留在显存里**。训练比推理吃显存，主要就吃在这里。

| 求梯度的方法 | 代价（N 个参数、1 个标量 loss） | 问题 |
|---|---|---|
| 有限差分 | N + 1 次前向 | 慢到不可用；精度受 h 两头夹击 |
| 符号微分 | 一次推导 | 表达式会指数膨胀，重复子式算很多遍 |
| 前向模式自动微分 | 每个输入方向一次，共 N 次 | 适合输入少、输出多的函数 |
| **反向模式自动微分** | **每个输出一次，loss 是标量，所以 1 次** | 要缓存前向的中间结果 |

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 导数是最好的线性近似

在 $x_0$ 附近，$f$ 可以写成一条直线加一个更小的余项：

$$
f(x_0 + h) = f(x_0) + f'(x_0)\,h + \tfrac12 f''(x_0)\,h^2 + O(h^3)
$$

切线 $f(x_0) + f'(x_0)h$ 的误差主项是 $\tfrac12 f''(x_0)h^2$：**步长缩小 10 倍，误差缩小 100 倍**。曲线弯得越厉害（$|f''|$ 越大），切线越早离开曲线。

这件事对训练的意义是：梯度下降每一步都是在"相信线性近似"。步子迈得太大，近似失效，loss 反而上升。

### 2.2 梯度：上升最快的方向，垂直于等高线

多元函数 $f:\mathbb{R}^n \to \mathbb{R}$ 的线性近似是

$$
f(x + \delta) \approx f(x) + \nabla f(x)^\top \delta
$$

沿单位方向 $u$ 走，变化率是方向导数 $\nabla f^\top u$。由 Cauchy–Schwarz 不等式，$\nabla f^\top u \le \|\nabla f\|$，等号在 $u$ 与 $\nabla f$ 同向时取到。所以：

- 梯度指向**上升最快**的方向，负梯度是下降最快的方向；
- 沿等高线走时 $f$ 不变，方向导数为 0，所以梯度**垂直于等高线**；
- 梯度的长度是最陡方向上的坡度。

"最快"是在欧氏距离下说的。换一种量步长的方式，最陡的方向也会变：Adam 近似是在 $\ell_\infty$ 范数下最陡，Muon 是在谱范数下最陡（→ 6.3 §3）。

### 2.3 链式法则就是矩阵乘法

神经网络是一串函数的复合：$L = \ell(f_K(\cdots f_2(f_1(x))))$。每一层 $f_k$ 在当前点的线性近似是它的 Jacobian $J_k$（输出对输入的偏导排成的矩阵）。复合函数的线性近似，就是这些线性近似的复合：

$$
\frac{\partial L}{\partial x} = \frac{\partial \ell}{\partial h_K}\, J_K\, J_{K-1} \cdots J_1
$$

链式法则没有任何神秘之处：**一串线性映射的复合，就是矩阵连乘。**

### 2.4 在计算图上走一遍

把计算拆成节点，每个节点只做一件简单的事：乘、加、过激活、算 loss。前向从左到右算出每个节点的值；反向从 loss 出发，每经过一条边，就乘上这条边的局部导数。

看三件事：

1. **数值差分和反向传播的结果一致**。反向传播是精确的，不是近似。
2. **每条边的局部导数都要用到前向的值**：$\partial a/\partial z$ 要用 $z$，$\partial m/\partial w$ 要用 $x$。所以前向的中间结果必须缓存。
3. **激活函数饱和时，梯度在这里断掉**。把 tanh 推到饱和区，或者让 ReLU 的输入为负，$\partial a/\partial z$ 接近 0，前面所有参数都拿不到梯度。

### 2.5 为什么从后往前乘

Jacobian 连乘的结果和乘法顺序无关，但**代价和顺序有关**。loss 是标量，最左边的 $\partial \ell/\partial h_K$ 是一个行向量：

- **从左往右乘**（反向模式）：每一步都是"行向量 × 矩阵"，得到的还是行向量，代价和一次前向同阶；
- **从右往左乘**（前向模式）：先算 $J_2 J_1$ 这样的矩阵 × 矩阵，代价随参数量成倍增长。

所以反向传播的本质，是**向量–Jacobian 积（VJP）沿计算图反向流动**。框架从来不显式构造 Jacobian，每个算子只需要实现"给我输出的梯度，我还你输入的梯度"。

### 减小步长，只看一个点可能认错阶数

在[切线实验](#lab-0-2)选择三次函数 $f(x)=x^3-2x$。它的一阶近似误差能精确展开为 $3x_0h^2+h^3$。在普通点 $x_0=1$，将步长减半，主导误差约缩小四倍；在拐点 $x_0=0$，二次项恰好消失，同样的操作会缩小八倍。一次漂亮的数值结果可能来自特定输入上的抵消。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　一元泰勒展开与误差阶

若 $f$ 在 $x_0$ 附近二阶连续可导，带 Lagrange 余项的泰勒公式给出

$$
f(x_0 + h) = f(x_0) + f'(x_0)h + \tfrac12 f''(\xi)h^2, \quad \xi \in (x_0, x_0 + h)
$$

所以一阶近似的误差是 $O(h^2)$。若 $f''(x_0) = 0$（拐点），误差主项变成 $\tfrac16 f'''(x_0)h^3$，上面实验里的"缩小约 1000 倍"就来自这里。

### Step 2　多元函数：梯度与 Jacobian

$f:\mathbb{R}^n \to \mathbb{R}^m$ 在 $x$ 处的 Jacobian 是 $m \times n$ 矩阵 $J_{ij} = \partial f_i / \partial x_j$，满足

$$
f(x + \delta) = f(x) + J\delta + o(\|\delta\|)
$$

$m = 1$ 时 $J$ 是一个行向量，它的转置就是梯度 $\nabla f$。

### Step 3　链式法则与 VJP

设 $h = f(x)$、$L = g(h)$，$L$ 是标量。链式法则：

$$
\frac{\partial L}{\partial x} = \frac{\partial L}{\partial h}\, J_f \quad\Longleftrightarrow\quad \nabla_x L = J_f^\top\, \nabla_h L
$$

右边就是一个 VJP：拿到输出的梯度 $\nabla_h L$，乘上 $J_f^\top$，得到输入的梯度。整张计算图的反向传播，就是对每个节点做一次 VJP；一个节点的输出被多处使用时，把各处传回来的梯度**相加**。

### Step 4　两个最常用的 VJP

**线性层**　$Y = XW$，$X \in \mathbb{R}^{B \times d_{in}}$，$W \in \mathbb{R}^{d_{in} \times d_{out}}$。记 $G = \partial L / \partial Y$，则

$$
\frac{\partial L}{\partial W} = X^\top G, \qquad \frac{\partial L}{\partial X} = G\, W^\top
$$

前向一次矩阵乘，反向两次同样大小的矩阵乘：这就是"反向 ≈ 2 倍前向"的来源。注意 $\partial L/\partial W$ 要用到 $X$：**这一层的输入就是必须缓存的激活**。

**softmax + 交叉熵**　logits $z$，$p = \mathrm{softmax}(z)$，真实类别的 one-hot 为 $y$，$L = -\sum_i y_i \log p_i$。则

$$
\frac{\partial L}{\partial z} = p - y
$$

梯度就是"预测分布减去真实分布"，干净到不需要缓存 softmax 的中间量之外的任何东西（→ 0.5 §3）。

### Step 5　代价与显存

设前向的 FLOPs 为 $F$。矩阵乘占主导时，反向约 $2F$，一步训练约 $3F$。显存方面，反向需要的中间结果在前向时产生、反向时才用掉，峰值显存 ≈ 参数与优化器状态 + 所有层的激活。

激活重算（activation checkpointing）只保存部分层的输入，反向时把中间的前向重跑一遍。$n$ 层网络每隔 $\sqrt{n}$ 层存一个检查点，激活显存从 $O(n)$ 降到 $O(\sqrt{n})$，代价是多算一次前向。

### Step 6　梯度消失与爆炸

深度为 $K$ 的网络，$\nabla_x L = J_1^\top J_2^\top \cdots J_K^\top \nabla_{h_K} L$。粗略地看，梯度的范数被乘了 $K$ 次 $\|J_k\|$：每层都略小于 1，指数衰减；略大于 1，指数爆炸。

残差连接把每层变成 $h_{k+1} = h_k + f_k(h_k)$，Jacobian 变成 $I + J_{f_k}$。连乘里始终有一条"恒等路径"，梯度可以不经衰减地直达浅层（→ 1.1 §2）。

## 4. 极简代码锚点（PyTorch）

```python
import math, torch

class Value:
    """标量反向模式自动微分：每个节点记住父节点和"把梯度传回去"的规则。"""
    def __init__(self, data, parents=(), backward=lambda: None):
        self.data, self.grad, self._parents, self._backward = data, 0.0, parents, backward

    def __mul__(self, other):
        out = Value(self.data * other.data, (self, other))
        def backward():                      # VJP：局部导数 × 输出梯度，累加到输入
            self.grad += other.data * out.grad
            other.grad += self.data * out.grad
        out._backward = backward
        return out

    def __add__(self, other):
        out = Value(self.data + other.data, (self, other))
        def backward():
            self.grad += out.grad
            other.grad += out.grad
        out._backward = backward
        return out

    def tanh(self):
        a = math.tanh(self.data)
        out = Value(a, (self,))
        def backward():
            self.grad += (1 - a * a) * out.grad   # 用到了前向的结果 a：这就是"缓存激活"
        out._backward = backward
        return out

    def backward(self):
        order, seen = [], set()
        def visit(v):                        # 拓扑排序，保证一个节点的梯度收齐后再往回传
            if v not in seen:
                seen.add(v)
                for p in v._parents: visit(p)
                order.append(v)
        visit(self)
        self.grad = 1.0
        for v in reversed(order): v._backward()

# 对拍：一个神经元 L = ½(tanh(w·x + b) − y)²
x, w, b, y = Value(1.5), Value(0.7), Value(-0.2), 0.8
a = (w * x + b).tanh()
diff = a + Value(-y)
loss = diff * diff * Value(0.5)
loss.backward()

wt = torch.tensor(0.7, requires_grad=True); bt = torch.tensor(-0.2, requires_grad=True)
lt = 0.5 * (torch.tanh(wt * 1.5 + bt) - y) ** 2
lt.backward()
print(w.grad, wt.grad.item())               # 两者一致，约 -0.085

# 线性层的 VJP：∂L/∂W = Xᵀ G，∂L/∂X = G Wᵀ
X = torch.randn(4, 3, requires_grad=True); W = torch.randn(3, 5, requires_grad=True)
G = torch.randn(4, 5)
(X @ W).backward(G)
assert torch.allclose(W.grad, X.T @ G) and torch.allclose(X.grad, G @ W.T)
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **反向图在编译期生成**。PyTorch 2 的 `torch.compile` 用 AOTAutograd 在编译时同时捕获前向图和反向图，再一起做算子融合与重算决策。"反向怎么走"不再只在运行时动态决定，编译器可以在两张图之间挪动计算（→ 5.6）。
- **选择性重算成为默认做法**。大模型训练很少整层重算，而是只重算显存大、算力小的那部分。Megatron-LM 的做法是只重算注意力里的 softmax、dropout 等中间结果，矩阵乘的输出仍然保存，用很少的额外算力换回大块显存。
- **低精度训练依赖对梯度幅度的管理**。bf16 和 FP8 训练里，梯度的数值范围决定了能不能用低精度表示。loss scaling、按块缩放因子和梯度裁剪，都是在防止反向链条上的连乘把数值推出可表示范围（→ 5.3）。

**与工程 / 应用的连接**
- **训练显存 ≈ 参数状态 + 激活**。推理只要参数和 KV cache；训练还要存每层的输入以备反向使用，所以同一个模型训练时的显存往往是推理的数倍。显存不够时的三把刀：减小 micro-batch、开激活重算、把序列切到多卡上（→ 5.2）。
- **梯度裁剪是保险丝**。按全局范数裁剪，限制的是一步更新的最大长度，防止一个异常 batch 把参数推出线性近似成立的范围。训练日志里梯度范数的尖峰，往往比 loss spike 更早出现。
- **自定义算子必须写对 VJP**。写融合算子或自定义 attention 时，前向对了不代表反向对了。用数值差分在小尺寸上对拍，是最便宜的检查手段。

**常见误区 / 反直觉点**
1. **"反向传播是一种近似"** ✗：它给出的是精确梯度（在浮点误差范围内），和有限差分不是一回事。
2. **"反向的计算量和前向一样"** ✗：矩阵乘主导时约是 2 倍：要同时算对输入和对权重的梯度。
3. **"梯度就是指向最优解的方向"** ✗：梯度只是局部最陡的方向。病态曲率下它会指向峡谷壁，导致之字形震荡（→ 0.6）。
4. **"激活函数只影响前向表达能力"** ✗：它的导数决定梯度能不能传回去。饱和区和 ReLU 死区里，导数几乎为 0。

**高频深挖题**
- **Q1：为什么训练用反向模式而不是前向模式自动微分？**
  思路：两者都基于链式法则，区别是 Jacobian 连乘的顺序 → loss 是标量，从输出端开始乘，每步都是向量 × 矩阵 → 一次反向得到全部参数梯度，代价约 2 倍前向 → 前向模式每次只能得到一个输入方向的方向导数，要 N 次 → 代价是反向模式要缓存中间结果。
- **Q2：手推线性层 $Y = XW$ 的反向，并说明哪些量必须缓存。**
  思路：$\partial L/\partial W = X^\top G$，$\partial L/\partial X = GW^\top$ → 前者要 $X$，后者要 $W$ → 参数本来就在显存里，额外要存的是这一层的输入激活 $X$ → 由此估算激活显存：每层每 token 若干个 $D$ 维向量，乘以层数、batch 和序列长度。
- **Q3：一个 100 层的网络训不动，梯度范数逐层指数衰减，你怎么排查和修？**
  思路：Jacobian 连乘 → 看各层梯度范数与激活分布，找饱和或死神经元 → 修法：换不饱和的激活、合理初始化（让每层 Jacobian 的尺度接近 1）、加残差连接让 Jacobian 变成 $I + J$、Pre-LN 让恒等路径直通（→ 1.1）。
