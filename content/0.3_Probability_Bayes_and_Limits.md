# 0.3 概率论：条件概率、贝叶斯与大数定律

> **一句话核心直觉**：概率论里最常被用错的两件事，一是把 $P(A \mid B)$ 当成 $P(B \mid A)$，二是把小样本里的波动当成真实差异。贝叶斯公式纠正第一件：看到证据后该信多少，取决于证据的强度**和**事前有多常见。中心极限定理给第二件定量：样本均值的误差按 $1/\sqrt{n}$ 缩小，题目数翻 4 倍，误差棒才缩一半。
> **唤醒标签**：后验 ∝ 似然 × 先验 · 基率谬误 · 似然比 · 链式法则 = 自回归 · 期望的线性性 · 方差按 $1/n$ · 标准误 $\sqrt{p(1-p)/n}$ · 配对比较

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

在人工智能研发与落地中，有两个极其普遍却频繁踩坑的真实场景：

- **场景一（检测与告警）**：一家 AI 文本检测器厂商宣称其算法达到“95% 检出率（真实正例召回率 TPR）与 5% 误报率（假阳性率 FPR）”。某高校将其部署于日常作业抽查，结果发现**所有被系统红牌告警为“AI 代写”的论文中，竟然有超过八成实际上是学生纯手工原创的**。
- **场景二（模型评测与发版）**：团队训练出了新版推理大模型，在著名的 AIME 数学基准（仅 30 道测试题）上测得得分比旧版高出整整 6 分，研发团队随即兴奋地宣布“数学推理能力取得突破性飞跃”。然而将同一模型换一个随机种子再次跑榜，评测得分自身就会上下浮动十余分。

这两个令人困惑的现象，其根源并不在深度学习算法本身，而在于违反了经典概率论的客观法则：场景一忽视了目标事件的**先验基率**（Base Rate），从而掉入了基率谬误；场景二则忽视了**有限抽样波动**（Sampling Error），将纯粹的统计方差误认作系统性的模型能力差异。

从自回归语言模型的序列概率分解、RLHF 对齐中的人类偏好建模，到扩散模型前向加噪的马尔可夫链以及大模型基准消融的置信区间，概率论构成了支撑现代 AI 的隐形骨架（→ 2.2、4.1、5.4）。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 随机变量、期望与方差

随机变量本质上是一种“将实验结果转化为数值的度量映射”：例如单次模型采样生成的回答总 token 长度、一道测试题答对与否（二值量化为 1 或 0）、或者某个特定 token 的预测对数概率（logprob）。概率分布完整刻画了各个可能取值在现实中的出现频次与概率密度。

在算法推导与工程实践中，最重要的两条运算法则是：

- **期望具有绝对的线性性**：$\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]$。**该性质对任意随机变量普遍成立，完全不需要它们相互独立**。这正是机器学习中计算小批量损失平均值、梯度无偏估计时处处通行的理论基石；
- **方差的可加性强依赖独立性**：当且仅当随机变量 $X$ 与 $Y$ 相互独立（或互不相关）时，才满足 $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$。在一般相关情形下，必须额外加上两倍的协方差项 $2\,\mathrm{Cov}(X, Y)$。

由这两条法则可立即严谨推导：对于从同一总体中抽取的 $n$ 个独立同分布（i.i.d.）样本，其样本均值 $\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i$ 的数学期望保持不变（$\mathbb{E}[\bar{X}] = \mu$），而其统计方差收缩至 $1/n$（$\mathrm{Var}(\bar{X}) = \sigma^2/n$），对应的标准差（即均值的标准误）按 $1/\sqrt{n}$ 渐进缩小。

### 2.2 条件概率与贝叶斯公式

条件概率 $P(A \mid B)$ 在语义上读作“在已知事件 $B$ 已经发生的前提下，事件 $A$ 发生的后验概率”，其严谨定义为 $P(A \mid B) = P(A \cap B) / P(B)$。在几何直觉上，它代表将原本全集的样本空间强行压缩收缩到局部子集 $B$ 中，并在新的参考系下重新计算子集 $A$ 所占的测度份额。

通过联合概率的对称展开 $P(A \cap B) = P(B \mid A)P(A) = P(A \mid B)P(B)$，直接整理出贝叶斯公式：

$$
P(\text{AI} \mid \text{报警}) = \frac{P(\text{报警} \mid \text{AI})\, P(\text{AI})}{P(\text{报警})}
$$

厂商向你宣称的往往是条件测试性能：$P(\text{报警} \mid \text{AI})$（检出率 TPR = 95%）和 $P(\text{报警} \mid \text{人写})$（误报率 FPR = 5%）。但在真实业务场景中，用户面对报警提示时真正关心的却是逆条件概率 $P(\text{AI} \mid \text{报警})$——两者之间不可逾越的桥梁，正是**目标先验基率** $P(\text{AI})$。

- **基率极低时的假阳性淹没**：将基率滑块拖动至极低水平（如 1%）。在 1000 篇被检文章中，实际由 AI 撰写的仅有 10 篇；即便检出率高达 95%，系统也只能抓出约 9 或 10 篇真阳性。与此同时，其余 990 篇由人类原创的文章按 5% 的误报率计算，会产生近 50 篇假阳性冤案。最终整个报警池中累计有近 60 篇被拦截，其中真正的 AI 代写仅仅占六分之一左右（约 16.1%）。
- **参数敏感性对比**：尝试分别将检出率提升至 99.5%，或者将误报率压低至 1%。读者会发现：在低基率场景下，即便竭尽全力提升检出率，对提高报警可信度的贡献微乎其微；而唯有大幅压紧误报率，才能立竿见影地提升真正例的占比。

### 2.3 链式法则：联合分布拆成一串条件分布

由条件概率定义递推，任意多元变量的联合概率密度均可严格沿任意指定顺序无损分解为长串条件概率因子的连乘积：

$$
p(x_1, x_2, \dots, x_T) = p(x_1)\, p(x_2 \mid x_1)\, p(x_3 \mid x_1, x_2) \cdots = \prod_{t=1}^{T} p(x_t \mid x_{<t})
$$

这一行恒等式正是自回归大语言模型（如 GPT、LLaMA）的根本数学根基：模型完全不需要强行一次性建模整篇长文本的复杂全局分布，而只需专注学会“给定历史上下文 $x_{<t}$ 之后，下一个候选 token 的条件概率分布”。整段文本的生成概率即为各个位置预测概率的连乘。两边取对数后，乘积整洁地转化为求和，语言模型预训练的极大似然优化目标因此精确化归为每个时间步的条件交叉熵 $\sum_t \log p(x_t \mid x_{<t})$ 之和（→ 0.5 §2）。

### 2.4 独立与条件独立

两个事件 $A, B$ 相互独立，意味着 $P(A \cap B) = P(A)P(B)$，即观察到 $B$ 的状态不会对 $A$ 的概率分布产生任何修正。

在现实系统建模中，更常用且更有威力的概念是**条件独立**：在已知中间状态 $C$ 的前提下，$A$ 与 $B$ 之间不再存在残余的信息关联，记作 $P(A \cap B \mid C) = P(A \mid C)P(B \mid C)$。

经典马尔可夫链正是条件独立性质的集中体现：“给定当前的现在状态，未来的转移概率与过去的演化历史完全无关”。在现代扩散生成模型（DDPM）中，前向加噪过程 $x_0 \to x_1 \to \cdots \to x_T$ 严格构成了马尔可夫链，每一步加噪转移条件仅由上一时刻状态单一决定，使得复杂的联合加噪分布得以优雅地化简为标准高斯转移因子的连乘（→ 0.4 §3、4.1）。

### 2.5 大数定律与中心极限定理

- **大数定律（LLN）**：随着独立抽样样本数量 $n$ 的无限增长，随机变量的样本经验均值以概率 1 严格收敛至其理论期望常数 $\mu$。
- **中心极限定理（CLT）**：不论单个样本底层服从何种复杂的任意概率分布，只要其方差 $\sigma^2$ 是有限非无穷的，当抽样量 $n$ 逐渐增大时，样本均值 $\bar{X}_n$ 的抽样波动分布都将普遍收敛至正态分布 $\mathcal{N}(\mu, \sigma^2/n)$，其抽样标准误为 $\sigma / \sqrt{n}$。

大模型的能力评测本质上就是一次有限抽样实验：模型在全量任务上的真实泛化正确率 $p$ 是未知的理论期望，工程师只能挑选 $n$ 道测试题来估算它。每一道题的答对与否是一个二值伯努利变量，其方差为 $p(1 - p)$。因此，测得正确率的抽样标准误为 $\mathrm{SE} = \sqrt{p(1-p)/n}$。

调整「题目数 n」与「真实正确率 p」滑块，仔细体悟三项关键统计现象：
- **小样本时的离散与偏态**：当题目数量很少时（如 $n = 10 \sim 30$），二项抽样分布呈现显著的阶梯离散性，且在 $p \ne 0.5$ 时明显不对称，此时直接套用高斯正态近似会产生不可忽视的截断偏差；
- **误差棒缩小的边际效益递减（根号律）**：观察置信区间宽度，想要将测试误差棒的宽度缩减一半，测试集的题目数量必须暴力翻整整 4 倍（因为分母依赖 $\sqrt{n}$）；
- **方差在中间最不稳定**：将正确率调整至 $p = 0.5$，误差棒达到最宽峰值；而在 $p$ 极高（如 90% 以上）或极低时，抽样方差 $p(1-p)$ 显著缩小，误差棒自然变窄。

同样的数学物理规律也精准支配着深度学习的小批量随机梯度下降（SGD）：一个包含 $B$ 个样本的小批量平均梯度，是全数据集真实梯度的无偏估计，其随机噪声的标准差严格按 $1/\sqrt{B}$ 缩放。若将 batch size 翻倍，梯度噪声仅仅减小为原来的约 $1/\sqrt{2} \approx 0.707$ 倍（仅降噪 29%），这揭示了为何增大 batch size 时学习率的放大不能盲目超额（→ 6.4）。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　贝叶斯公式与似然比形式

根据条件概率的公理化定义，$P(H \mid E)P(E) = P(E \mid H)P(H) = P(H \cap E)$。利用全概率公式将分母证据项 $P(E)$ 展开：

$$
P(H \mid E) = \frac{P(E \mid H)P(H)}{P(E \mid H)P(H) + P(E \mid \neg H)P(\neg H)}
$$

在工程心算与贝叶斯推断中，更为直观高效的是**几率形式（Odds Form）**。将假设成立的后验概率除以其对立面不成立的后验概率，分母中繁复的归一化常数 $P(E)$ 瞬间完全对消：

$$
\underbrace{\frac{P(H \mid E)}{P(\neg H \mid E)}}_{\text{后验几率}} = \underbrace{\frac{P(H)}{P(\neg H)}}_{\text{先验几率}} \times \underbrace{\frac{P(E \mid H)}{P(E \mid \neg H)}}_{\text{似然比（贝叶斯因子）}}
$$

以 AI 检测器为例：测试证据的似然比为 TPR / FPR = 0.95 / 0.05 = 19。在基率为 1% 的场景下，先验几率是 $0.01 / 0.99 = 1 : 99$。乘以似然比 19 后，后验几率更新为 $19 : 99$。将其换算回概率值：

$$
P(\text{AI} \mid \text{报警}) = \frac{19}{19 + 99} = \frac{19}{118} \approx 16.1\%
$$

若要使报警后的后验可信度达到过半（即后验几率突破 $1 : 1$），似然比必须强行超越 $99$ 倍，这意味着必须在保持高检出的同时，将误报率硬性压缩到 $0.95 / 99 \approx 0.96\%$ 以下。

### Step 2　链式法则与对数似然

设预训练数据集包含多个独立文档样本 $\mathcal{D} = \{x^{(i)}\}$。基于样本独立假设，全数据集的整体联合似然等于各个文档概率的连乘积。将每个文档内部的长序列再次运用概率链式法则展开：

$$
\log p_\theta(\mathcal{D}) = \sum_i \sum_t \log p_\theta\big(x^{(i)}_t \mid x^{(i)}_{<t}\big)
$$

在模型训练阶段，每个时间步 $t$ 输入的上下文历史 $x_{<t}$ 始终直接取自真实数据集中的标准答案（Teacher Forcing 机制）。因此，所有序列位置的预测条件概率可以完全摆脱时序自回归循环，在 GPU 上实现高度并行的矩阵乘运算。

需要特别警惕的是，“样本独立同分布”往往只是理想化的建模假设：从同一篇长文档切分出的不同上下文片段并非统计独立，评测基准中源自同一主题的测试题也往往高度相关。这种内在相关性会导致朴素公式算出的置信区间偏窄、低估实际风险（详见 Step 5）。

### Step 3　期望与方差的运算规则

- 线性缩放与平移：$\mathbb{E}[aX + b] = a\,\mathbb{E}[X] + b$，$\mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X)$；
- 方差的矩表示形式：$\mathrm{Var}(X) = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$；
- 独立变量和的方差可加性：当 $X_i$ 相互独立时，$\mathrm{Var}\big(\sum_i X_i\big) = \sum_i \mathrm{Var}(X_i)$。代入样本均值定义 $\bar{X} = \frac{1}{n}\sum_i X_i$，即有 $\mathrm{Var}(\bar{X}) = \frac{1}{n^2} \cdot n\sigma^2 = \sigma^2 / n$。

对于评测二值命中与否的伯努利随机变量（答对为 1，概率为 $p$；答错为 0，概率为 $1-p$），其方差严格为 $p(1 - p)$，且在 $p = 0.5$（胜负不可预测）时达到最大值 0.25。

### Step 4　中心极限定理与置信区间

设样本 $X_1, \dots, X_n$ 独立同分布，总体均值为 $\mu$，有限总体方差为 $\sigma^2$。随着样本容量 $n$ 逐步增大，标准化后的统计量依分布收敛到标准正态分布：

$$
\frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} \mathcal{N}(0, 1)
$$

在标准正态分布的双侧分位数下，$P(-1.96 \le Z \le 1.96) \approx 0.95$。因此，总体均值 $\mu$ 的渐进 95% 置信区间由 $\bar{X}_n \pm 1.96\,\sigma/\sqrt{n}$ 给出。在模型评测任务中，总体标准差 $\sigma$ 直接代入样本无偏估计 $\sqrt{\hat{p}(1-\hat{p})}$。

以 AIME 数学竞赛基准为例（共 30 道测试题，设测得样本正确率 $\hat{p} = 0.70$）：其标准误为 $\mathrm{SE} = \sqrt{0.70 \times 0.30 / 30} = \sqrt{0.007} \approx 0.0837 \approx 0.084$。95% 置信半宽为 $1.96 \times 0.0837 \approx 0.164$（即 $\pm 16.4$ 个百分点）。这意味着该测试测出的 70% 得分，其真实能力区间仅仅被框在 $[53.6\%, 86.4\%]$ 的宽泛范围中。

### Step 5　比较两个模型：独立与配对

当比较模型 A 与模型 B 的性能优劣时，有两种截然不同的实验设计：

**独立样本评测**：若模型 A 与模型 B 分别在**两批各自独立**的测试题集上评测，其正确率差值 $\hat{p}_A - \hat{p}_B$ 的统计方差等于两者方差直接相加：

$$
\mathrm{Var}(\hat{p}_A - \hat{p}_B) = \frac{p_A(1-p_A) + p_B(1-p_B)}{n}
$$

若要以 95% 的统计显著性把握断定幅度为 $d$ 的性能优势，测试样本量大致需要满足 $n \ge 2p(1-p)(1.96/d)^2$。在 $p = 0.70$、希望分辨 $d = 2$ 个百分点的小幅优势时，需要 $n \ge 2 \times 0.21 \times (1.96 / 0.02)^2 \approx 4034$ 道题目。

**配对样本评测（Paired Evals）**：若让两个模型在**完全相同的一套题目**上运行，可直接对每道题目计算两者的答题表现差值 $D_i = X_{A,i} - X_{B,i}$。此时差值均值 $\bar{D}$ 的方差为：

$$
\mathrm{Var}(\bar{D}) = \frac{\mathrm{Var}(X_A) + \mathrm{Var}(X_B) - 2\,\mathrm{Cov}(X_A, X_B)}{n}
$$

由于同属于能力强弱相近的大模型，两个模型在面对同一道具体题目时，其答对与否存在显著的正相关性（容易的送分题大家都答对，困难的边界题大家都答错，即 $\mathrm{Cov}(X_A, X_B) > 0$）。这一正协方差项能够直接抵消绝大部分题目本身的难度波动方差，使得配对比较的有效误差棒显著缩窄。

反之，若测试用例具有群体成簇结构（例如同一篇长阅读材料下挂靠多道阅读理解题），组内题目答对与否的正相关会让朴素公式严重低估方差，此时必须改用聚类稳健标准误（Clustered Standard Errors）进行校正。

```python
import numpy as np

def posterior(base_rate, tpr, fpr):
    """贝叶斯公式：报警时真是阳性的概率。"""
    hit = base_rate * tpr
    return hit / (hit + (1 - base_rate) * fpr)

print(posterior(0.01, 0.95, 0.05))   # ≈ 0.161：基率 1% 时，报警六次只对一次
print(posterior(0.01, 0.95, 0.01))   # ≈ 0.490：压误报率比提检出率有效得多

def eval_error_bar(correct):
    """CLT 标准误与 95% 区间；correct 是逐题 0/1 数组。"""
    p, n = correct.mean(), len(correct)
    se = np.sqrt(p * (1 - p) / n)
    return p, 1.96 * se

def paired_diff(correct_a, correct_b):
    """同一套题上的配对比较：逐题求差，再算差值均值的标准误。"""
    d = correct_a.astype(float) - correct_b.astype(float)
    return d.mean(), 1.96 * d.std(ddof=1) / np.sqrt(len(d))

rng = np.random.default_rng(0)
difficulty = rng.uniform(0, 1, 500)                  # 题目难度：两个模型共享
a = rng.uniform(0, 1, 500) > difficulty * 0.9        # 模型 A
b = rng.uniform(0, 1, 500) > difficulty * 0.95       # 模型 B 略弱
print(eval_error_bar(a), eval_error_bar(b))
print(paired_diff(a, b))   # 区间比"两个独立误差棒相减"窄：同一道题上的对错相关
```

### 数值复算 · 把后验概率还原为可清点的人数

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **给评测加误差棒正在成为规范**。Evan Miller 的《Adding Error Bars to Evals》系统地把中心极限定理用到大模型评测上：报告标准误；题目成组时用聚类标准误；比较两个模型时在同一套题上做配对差；对每道题多次采样，压低模型自身采样带来的方差。
- **小基准靠重复采样稳住数字**。推理模型的技术报告普遍对 AIME 这类只有几十道题的基准，每题采样多次（如 16 或 64 次）再取平均。这只能压住"模型采样"这一层随机性，题目本身只有 30 道的抽样误差仍然在。
- **AI 文本检测依然受基率约束**。OpenAI 在 2023 年下线了自己的 AI 文本分类器，理由是准确率低。今天的检测器指标更好，但只要实际场景里 AI 文本占比低，误报就会占报警的大头。

**与工程 / 应用的连接**
- **看 A/B 结果先算标准误**。线上对比两个提示词或两个模型版本时，先算差值的置信区间，再决定要不要上线。样本量不够时，"提升 3%"可能完全是噪声（→ 5.4）。
- **告警阈值要按基率调**。内容审核、异常检测、幻觉检测都是同一个结构。真实事件越稀有，越要牺牲一些检出率去换更低的误报率，否则值班的人会被误报淹没。
- **把自回归当成链式法则来理解**。生成长文本时整体概率是条件概率的乘积，任何一步的小偏差都会通过条件传给后面所有步：这是曝光偏差和长程漂移的概率论根源。

**常见误区 / 反直觉点**
1. **"检出率 95% 的检测器，报警就有 95% 可信"** ✗：那是 $P(\text{报警} \mid \text{AI})$，你需要的是 $P(\text{AI} \mid \text{报警})$，中间差一个基率。
2. **"期望的线性性要求变量独立"** ✗：期望永远线性可加，只有方差的可加性需要独立（或不相关）。
3. **"多换几个随机种子，基准的误差棒就能缩到很小"** ✗：种子只改变模型采样的随机性；题目只有 30 道，题目抽样的误差一分不少。
4. **"95% 置信区间是说真值有 95% 的概率落在这个区间里"** ✗：频率学派的说法是，按这个方法反复构造区间，95% 的区间会覆盖真值。对单个已经算出来的区间，真值要么在里面，要么不在。

**高频深挖题**
- **Q1：一个检测器检出率 99%、误报率 1%，用在基率 0.1% 的场景，报警时有多大概率是真的？怎么改进？**
  思路：似然比 99，先验几率 1 : 999，后验几率 99 : 999，约 9% → 改进方向：两级检测（第二级在第一级报警的样本上跑，基率已经提到约 9%）、提高阈值换更低误报率、引入额外独立证据让似然比相乘。
- **Q2：新模型在 500 道题上比旧模型高 3 个百分点，这个提升可信吗？你怎么判断？**
  思路：独立误差棒：$p \approx 0.7$ 时每个约 ±4 个百分点，3 个百分点不显著 → 但两者在同一套题上评测，应该做配对比较，逐题求差算标准误 → 再检查题目有无分组结构、是否多次采样、是否看了很多基准后只挑了这一个（多重比较）。
- **Q3：为什么 batch size 翻倍，学习率常常不能也翻倍？**
  思路：小批量梯度是全量梯度的无偏估计，噪声标准差按 $1/\sqrt{B}$ 缩小 → batch 小时噪声主导，增大 batch 近似等价于降噪，线性放大学习率可行 → 超过临界 batch size 后噪声已经不是瓶颈，再放大 batch 只是浪费算力，学习率也不能继续线性放大（→ 6.4）。
