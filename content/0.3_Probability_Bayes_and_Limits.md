# 0.3 概率论：条件概率、贝叶斯与大数定律

> **一句话核心直觉**：概率论里最常被用错的两件事，一是把 $P(A \mid B)$ 当成 $P(B \mid A)$，二是把小样本里的波动当成真实差异。贝叶斯公式纠正第一件：看到证据后该信多少，取决于证据的强度**和**事前有多常见。中心极限定理给第二件定量：样本均值的误差按 $1/\sqrt{n}$ 缩小，题目数翻 4 倍，误差棒才缩一半。
> **唤醒标签**：后验 ∝ 似然 × 先验 · 基率谬误 · 似然比 · 链式法则 = 自回归 · 期望的线性性 · 方差按 $1/n$ · 标准误 $\sqrt{p(1-p)/n}$ · 配对比较

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

两个真实的场景：

- 一个 AI 文本检测器宣称"检出率 95%、误报率 5%"。学校拿它抽查论文，报警的文章里，**有八成以上其实是学生自己写的**。
- 新模型在 AIME（30 道题）上比旧模型高 6 分，于是宣布"推理能力显著提升"。可同一个模型换个随机种子重跑，分数本身就能上下浮动十几分。

两者的错误都不在模型，而在概率：前者忽略了基率，后者忽略了抽样误差。这一篇把这两件事讲透，后面读 RLHF 的偏好模型、扩散的马尔可夫链、评测与消融时都会用到（→ 2.2、4.1、5.4）。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 随机变量、期望与方差

随机变量是"结果的数值化"：一次采样生成的回答长度、一道题对或错（记为 1 或 0）、一个 token 的 logprob。它的分布告诉你每个取值有多常见。

两条最常用的性质：

- **期望是线性的**：$\mathbb{E}[aX + bY] = a\,\mathbb{E}[X] + b\,\mathbb{E}[Y]$。这一条**不需要独立**。
- **方差要独立才可加**：$X, Y$ 独立时 $\mathrm{Var}(X + Y) = \mathrm{Var}(X) + \mathrm{Var}(Y)$。一般情形要加上 $2\,\mathrm{Cov}(X, Y)$。

由此立刻得到：$n$ 个独立同分布样本的均值，期望不变，方差缩小到 $1/n$，标准差缩小到 $1/\sqrt{n}$。

### 2.2 条件概率与贝叶斯公式

$P(A \mid B)$ 读作"已知 $B$ 发生，$A$ 发生的概率"，定义为 $P(A \cap B) / P(B)$：把样本空间缩到 $B$ 里，再看 $A$ 占多少。把同一个联合概率从两边写，就得到贝叶斯公式：

$$
P(\text{AI} \mid \text{报警}) = \frac{P(\text{报警} \mid \text{AI})\, P(\text{AI})}{P(\text{报警})}
$$

检测器厂商告诉你的是 $P(\text{报警} \mid \text{AI})$（检出率）和 $P(\text{报警} \mid \text{人写})$（误报率）。你真正关心的是反过来的 $P(\text{AI} \mid \text{报警})$，中间隔着一个**基率** $P(\text{AI})$。

```academy-lab
0.3
```

把基率拖到 1%：1000 篇里只有 10 篇是 AI 写的，抓到 9 或 10 篇；而 990 篇人写的文章按 5% 误报，会有约 50 篇被冤枉。报警的约 60 篇里，真阳性只占六分之一。**基率越低，误报越会淹没真阳性**，这就是基率谬误。

### 2.3 链式法则：联合分布拆成一串条件分布

任何联合分布都可以按顺序拆开：

$$
p(x_1, x_2, \dots, x_T) = p(x_1)\, p(x_2 \mid x_1)\, p(x_3 \mid x_1, x_2) \cdots = \prod_{t=1}^{T} p(x_t \mid x_{<t})
$$

这一行就是自回归语言模型的全部数学：模型只需要学会"给定前文，下一个 token 的分布"，整段文本的概率就是这些条件概率的乘积。取对数后乘积变求和，训练目标就是每个位置的 $\log p(x_t \mid x_{<t})$ 之和（→ 0.5 §2）。

### 2.4 独立与条件独立

$A, B$ 独立，是指 $P(A \cap B) = P(A)P(B)$，知道一个不改变对另一个的判断。**条件独立**更常用：给定 $C$ 之后 $A, B$ 独立。

马尔可夫链就是一种条件独立：给定现在，未来与过去无关。DDPM 的前向加噪链 $x_0 \to x_1 \to \cdots \to x_T$ 正是这样，每一步只依赖上一步，所以联合分布可以拆成一串简单的高斯转移（→ 0.4 §3、4.1）。

### 2.5 大数定律与中心极限定理

**大数定律**：样本均值收敛到期望。**中心极限定理**：不管单个样本是什么分布，只要方差有限，样本均值的分布都趋向高斯，标准差是 $\sigma / \sqrt{n}$。

评测正是一次抽样：真实正确率 $p$ 未知，用 $n$ 道题去估。每道题是一个 0/1 随机变量，方差 $p(1 - p)$，所以测得分数的标准误是 $\sqrt{p(1-p)/n}$。

```academy-lab
0.3-clt
```

三个观察：题目很少时分布是离散的、不对称的，正态近似变差；$n$ 翻 4 倍，误差棒才缩一半；$p$ 接近 50% 时误差棒最宽。

同一个道理也解释了小批量梯度为什么能用：一个 batch 的平均梯度是全量梯度的无偏估计，噪声的标准差按 $1/\sqrt{B}$ 缩小。batch 翻倍，噪声只降到约 0.71 倍，这也是学习率和 batch size 要一起调的原因（→ 6.4）。

### 把后验概率还原为可清点的人数

在[贝叶斯检测器](#lab-0-3)固定检出率 95%、误报率 5%。假设检测 10,000 份文本，基率只有 1%。真实正例只有 100 份，从中报出 95 份；其余 9,900 份贡献 495 个误报。读者眼前的报警池有 590 份，其中真正例只占 95/590。搬到另一个基率为 10% 的场景，即使同一检测器的两个条件概率完全不变，报警后的可信度也会变。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　贝叶斯公式与似然比形式

由条件概率的定义，$P(H \mid E)P(E) = P(E \mid H)P(H)$。用全概率公式展开分母：

$$
P(H \mid E) = \frac{P(E \mid H)P(H)}{P(E \mid H)P(H) + P(E \mid \neg H)P(\neg H)}
$$

更好记的是**几率形式**：

$$
\underbrace{\frac{P(H \mid E)}{P(\neg H \mid E)}}_{\text{后验几率}} = \underbrace{\frac{P(H)}{P(\neg H)}}_{\text{先验几率}} \times \underbrace{\frac{P(E \mid H)}{P(E \mid \neg H)}}_{\text{似然比}}
$$

检测器的似然比是 TPR / FPR = 0.95 / 0.05 = 19。基率 1% 的先验几率是 1 : 99，乘以 19 得 19 : 99，后验约 16.1%。要让后验过半，需要似然比超过 99，也就是把误报率压到 1% 以下。

### Step 2　链式法则与对数似然

对数据集 $\{x^{(i)}\}$，假设样本独立，整体似然是各样本概率的乘积；每个样本再按链式法则拆开：

$$
\log p_\theta(\mathcal{D}) = \sum_i \sum_t \log p_\theta\big(x^{(i)}_t \mid x^{(i)}_{<t}\big)
$$

训练时每个位置的条件都用真实前文（teacher forcing），所有位置可以并行计算。注意"样本独立"是一个假设：同一篇文档切出来的片段并不独立，评测时同一主题的题目也不独立，这会让朴素的误差棒偏窄（见 Step 5）。

### Step 3　期望与方差的运算规则

- $\mathbb{E}[aX + b] = a\,\mathbb{E}[X] + b$，$\mathrm{Var}(aX + b) = a^2\,\mathrm{Var}(X)$；
- $\mathrm{Var}(X) = \mathbb{E}[X^2] - \mathbb{E}[X]^2$；
- 独立时 $\mathrm{Var}\big(\sum_i X_i\big) = \sum_i \mathrm{Var}(X_i)$，所以 $\mathrm{Var}(\bar{X}) = \sigma^2 / n$。

伯努利变量（答对为 1）的方差是 $p(1 - p)$，在 $p = 0.5$ 时最大。

### Step 4　中心极限定理与置信区间

独立同分布、方差 $\sigma^2$ 有限时：

$$
\frac{\bar{X}_n - \mu}{\sigma / \sqrt{n}} \xrightarrow{d} \mathcal{N}(0, 1)
$$

于是 $\bar{X}_n \pm 1.96\,\sigma/\sqrt{n}$ 是 $\mu$ 的近似 95% 置信区间。评测里 $\sigma$ 用 $\sqrt{\hat{p}(1-\hat{p})}$ 代入。

AIME 30 题、正确率 70%：标准误 $\sqrt{0.21/30} \approx 0.084$，95% 区间约 ±16 个百分点。

### Step 5　比较两个模型：独立与配对

两个模型在**各自独立**的题集上评测，差值的方差是两者方差之和：

$$
\mathrm{Var}(\hat{p}_A - \hat{p}_B) = \frac{p_A(1-p_A) + p_B(1-p_B)}{n}
$$

要以 95% 的把握分辨差距 $d$，大约需要 $n \ge 2p(1-p)(1.96/d)^2$。$p = 0.7$、$d = 2$ 个百分点时，$n \approx 4000$。

在**同一套题**上比较时，可以逐题求差 $D_i = X_{A,i} - X_{B,i}$：

$$
\mathrm{Var}(\bar{D}) = \frac{\mathrm{Var}(X_A) + \mathrm{Var}(X_B) - 2\,\mathrm{Cov}(X_A, X_B)}{n}
$$

两个模型在同一道题上的对错是正相关的（难题大家都错），协方差项让配对比较的方差明显更小。反过来，题目成组出现时（同一篇阅读材料的多道题），组内相关会让误差棒变宽，要用聚类标准误。

## 4. 极简代码锚点（NumPy）

```python
import numpy as np

def posterior(base_rate, tpr, fpr):
    """贝叶斯公式：报警时真是阳性的概率。"""
    hit = base_rate * tpr
    return hit / (hit + (1 - base_rate) * fpr)

print(posterior(0.01, 0.95, 0.05))   # ≈ 0.161：基率 1% 时，报警六次只对一次
print(posterior(0.01, 0.95, 0.01))   # ≈ 0.490：压误报率比提检出率有效得多

def eval_error_bar(correct):
    """CLT 标准误与 95% 区间；correct 是逐题 0/1 数组。"""
    p, n = correct.mean(), len(correct)
    se = np.sqrt(p * (1 - p) / n)
    return p, 1.96 * se

def paired_diff(correct_a, correct_b):
    """同一套题上的配对比较：逐题求差，再算差值均值的标准误。"""
    d = correct_a.astype(float) - correct_b.astype(float)
    return d.mean(), 1.96 * d.std(ddof=1) / np.sqrt(len(d))

rng = np.random.default_rng(0)
difficulty = rng.uniform(0, 1, 500)                  # 题目难度：两个模型共享
a = rng.uniform(0, 1, 500) > difficulty * 0.9        # 模型 A
b = rng.uniform(0, 1, 500) > difficulty * 0.95       # 模型 B 略弱
print(eval_error_bar(a), eval_error_bar(b))
print(paired_diff(a, b))   # 区间比"两个独立误差棒相减"窄：同一道题上的对错相关
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **给评测加误差棒正在成为规范**。Evan Miller 的《Adding Error Bars to Evals》系统地把中心极限定理用到大模型评测上：报告标准误；题目成组时用聚类标准误；比较两个模型时在同一套题上做配对差；对每道题多次采样，压低模型自身采样带来的方差。
- **小基准靠重复采样稳住数字**。推理模型的技术报告普遍对 AIME 这类只有几十道题的基准，每题采样多次（如 16 或 64 次）再取平均。这只能压住"模型采样"这一层随机性，题目本身只有 30 道的抽样误差仍然在。
- **AI 文本检测依然受基率约束**。OpenAI 在 2023 年下线了自己的 AI 文本分类器，理由是准确率低。今天的检测器指标更好，但只要实际场景里 AI 文本占比低，误报就会占报警的大头。

**与工程 / 应用的连接**
- **看 A/B 结果先算标准误**。线上对比两个提示词或两个模型版本时，先算差值的置信区间，再决定要不要上线。样本量不够时，"提升 3%"可能完全是噪声（→ 5.4）。
- **告警阈值要按基率调**。内容审核、异常检测、幻觉检测都是同一个结构。真实事件越稀有，越要牺牲一些检出率去换更低的误报率，否则值班的人会被误报淹没。
- **把自回归当成链式法则来理解**。生成长文本时整体概率是条件概率的乘积，任何一步的小偏差都会通过条件传给后面所有步：这是曝光偏差和长程漂移的概率论根源。

**常见误区 / 反直觉点**
1. **"检出率 95% 的检测器，报警就有 95% 可信"** ✗：那是 $P(\text{报警} \mid \text{AI})$，你需要的是 $P(\text{AI} \mid \text{报警})$，中间差一个基率。
2. **"期望的线性性要求变量独立"** ✗：期望永远线性可加，只有方差的可加性需要独立（或不相关）。
3. **"多换几个随机种子，基准的误差棒就能缩到很小"** ✗：种子只改变模型采样的随机性；题目只有 30 道，题目抽样的误差一分不少。
4. **"95% 置信区间是说真值有 95% 的概率落在这个区间里"** ✗：频率学派的说法是，按这个方法反复构造区间，95% 的区间会覆盖真值。对单个已经算出来的区间，真值要么在里面，要么不在。

**高频深挖题**
- **Q1：一个检测器检出率 99%、误报率 1%，用在基率 0.1% 的场景，报警时有多大概率是真的？怎么改进？**
  思路：似然比 99，先验几率 1 : 999，后验几率 99 : 999，约 9% → 改进方向：两级检测（第二级在第一级报警的样本上跑，基率已经提到约 9%）、提高阈值换更低误报率、引入额外独立证据让似然比相乘。
- **Q2：新模型在 500 道题上比旧模型高 3 个百分点，这个提升可信吗？你怎么判断？**
  思路：独立误差棒：$p \approx 0.7$ 时每个约 ±4 个百分点，3 个百分点不显著 → 但两者在同一套题上评测，应该做配对比较，逐题求差算标准误 → 再检查题目有无分组结构、是否多次采样、是否看了很多基准后只挑了这一个（多重比较）。
- **Q3：为什么 batch size 翻倍，学习率常常不能也翻倍？**
  思路：小批量梯度是全量梯度的无偏估计，噪声标准差按 $1/\sqrt{B}$ 缩小 → batch 小时噪声主导，增大 batch 近似等价于降噪，线性放大学习率可行 → 超过临界 batch size 后噪声已经不是瓶颈，再放大 batch 只是浪费算力，学习率也不能继续线性放大（→ 6.4）。
