# 0.4 高斯分布：协方差几何与重参数化

> **一句话核心直觉**：多元高斯就是"把标准正态拉伸、旋转、再平移"：$x = \mu + L\varepsilon$。协方差 $\Sigma = LL^\top$ 决定了等高线椭圆：特征向量是主轴，特征值是半轴长的平方。高斯经过线性变换、取边缘、取条件之后都还是高斯，这种封闭性让 VAE 和扩散模型的数学几乎可以手算。
> **唤醒标签**：$x = \mu + L\varepsilon$ · $\Sigma = LL^\top$ · 特征向量 = 主轴 · 马氏距离 · 条件均值 $\mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2)$ · 重参数化 · $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon$ · 信噪比

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

生成模型里到处是高斯：VAE 的潜变量是高斯，扩散模型往数据里加的是高斯噪声，Flow Matching 从高斯出发搬运到数据（→ 4.1、4.2）。为什么偏偏是它？

- **中心极限定理**：许多独立小扰动之和趋向高斯，噪声天然长这样（→ 0.3 §2）。
- **最大熵**：给定均值和方差，高斯是最"不做额外假设"的分布（→ 0.5）。
- **封闭性**：线性变换、相加、取边缘、取条件，结果还是高斯，均值和协方差可以直接写出来。

如果没有第三条，扩散模型训练时要从 $x_0$ 一步步加噪到 $x_t$，每个样本都要跑 $t$ 步；有了它，$q(x_t \mid x_0)$ 一步写出，训练时随机抽一个 $t$ 就行。如果没有"重参数化"，VAE 的编码器就无法通过采样这一步拿到梯度。这一篇把这两件事讲清楚。

---

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 从一维到多元

一维高斯 $\mathcal{N}(\mu, \sigma^2)$ 的密度只依赖"离均值几个标准差"：$(x - \mu)^2 / \sigma^2$。多元高斯把它推广成马氏距离：

$$
p(x) = \frac{1}{\sqrt{(2\pi)^d \det \Sigma}} \exp\!\Big(-\tfrac12 (x - \mu)^\top \Sigma^{-1} (x - \mu)\Big)
$$

密度相同的点满足 $(x - \mu)^\top \Sigma^{-1} (x - \mu) = c$，这是一个椭球。

### 2.2 协方差就是一个椭圆

把 $\Sigma$ 做特征分解 $\Sigma = Q \Lambda Q^\top$：$Q$ 的列是互相垂直的方向，$\Lambda$ 是每个方向上的方差。等高线椭圆的**主轴就是特征向量，半轴长是 $\sqrt{\lambda_i}$**。

生成样本的方法正好反过来：先采标准正态 $\varepsilon$（一个圆形的云），再乘一个满足 $LL^\top = \Sigma$ 的矩阵 $L$（拉伸加旋转），最后平移 $\mu$。

```academy-lab
0.4
```

观察：$\rho = 0$ 时主轴沿坐标轴；$\rho$ 一变，主轴就转开；$\rho \to \pm 1$ 时 $\lambda_2 \to 0$，椭圆压扁成一条线，$\Sigma$ 接近奇异。打开"固定 $x_1 = 1$"，红色竖线上的区间就是条件分布：均值移到 $\rho\sigma_2/\sigma_1$，宽度缩小。知道 $x_1$ 让你对 $x_2$ 更有把握。

### 2.3 线性变换仍是高斯

若 $x \sim \mathcal{N}(\mu, \Sigma)$，则

$$
Ax + b \sim \mathcal{N}(A\mu + b,\; A\Sigma A^\top)
$$

一个直接的应用是初始化。线性层 $y = Wx$，若 $W$ 的元素独立、方差为 $v$，输入各维独立、方差为 1，则每个输出的方差是 $d_{in} \cdot v$。要让方差逐层保持不变，就取 $v = 1/d_{in}$：这就是按 $1/\sqrt{\text{fan\_in}}$ 缩放初始化的由来。

### 2.4 重参数化：让采样可以求导

VAE 的编码器输出 $\mu_\phi(x)$ 和 $\sigma_\phi(x)$，然后从 $\mathcal{N}(\mu_\phi, \sigma_\phi^2)$ 里采一个 $z$。"采样"这个操作对 $\phi$ 没有梯度。重参数化把随机性挪到一个与参数无关的噪声上：

$$
z = \mu_\phi(x) + \sigma_\phi(x) \odot \varepsilon, \qquad \varepsilon \sim \mathcal{N}(0, I)
$$

现在 $z$ 是 $\phi$ 的确定性可导函数，梯度可以穿过它流回编码器。随机性只在 $\varepsilon$ 里，而 $\varepsilon$ 不需要梯度。

### 2.5 前向加噪：一步写出 $q(x_t \mid x_0)$

DDPM 每一步往数据里混一点噪声：$x_t = \sqrt{1 - \beta_t}\,x_{t-1} + \sqrt{\beta_t}\,\varepsilon_t$。因为每一步都是高斯的线性组合，$t$ 步之后仍是高斯，可以一步写出：

$$
x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \varepsilon, \qquad \bar\alpha_t = \prod_{s=1}^{t} (1 - \beta_s)
$$

$\bar\alpha_t / (1 - \bar\alpha_t)$ 是信噪比：信号能量与噪声能量之比。噪声调度决定信噪比随时间怎么下降。

```academy-lab
0.4-noise
```

把两种调度拖到 $t = 0.5$ 对比：线性调度的信噪比已经降到约 0.09，两个峰几乎合成一个；余弦调度的信噪比还接近 1，数据结构仍然清晰。Improved DDPM 改用余弦调度，就是嫌线性调度在后半段"浪费"了太多步：那时的样本几乎已经是纯噪声。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　仿射变换的均值与协方差

$y = Ax + b$。由期望的线性性，$\mathbb{E}[y] = A\mu + b$。协方差：

$$
\mathrm{Cov}(y) = \mathbb{E}\big[(y - \mathbb{E}y)(y - \mathbb{E}y)^\top\big] = A\,\mathbb{E}\big[(x - \mu)(x - \mu)^\top\big]A^\top = A\Sigma A^\top
$$

高斯的特征函数在仿射变换下保持指数二次型的形式，所以 $y$ 仍是高斯。特别地，取 $x = \varepsilon \sim \mathcal{N}(0, I)$、$A = L$，得 $\mathrm{Cov}(L\varepsilon) = LL^\top$。Cholesky 分解给出一个下三角的 $L$，计算最便宜。

### Step 2　特征分解与椭圆

$\Sigma = Q\Lambda Q^\top$，令 $u = Q^\top(x - \mu)$（旋转到主轴坐标）：

$$
(x - \mu)^\top \Sigma^{-1} (x - \mu) = u^\top \Lambda^{-1} u = \sum_i \frac{u_i^2}{\lambda_i}
$$

等于 $c^2$ 的点构成主轴半长为 $c\sqrt{\lambda_i}$ 的椭球。二维时主轴的转角满足 $\tan 2\theta = \dfrac{2\Sigma_{12}}{\Sigma_{11} - \Sigma_{22}}$。

### Step 3　条件分布

把 $x$ 分成两块，$\mu = (\mu_1, \mu_2)$，$\Sigma = \begin{pmatrix} \Sigma_{11} & \Sigma_{12} \\ \Sigma_{21} & \Sigma_{22} \end{pmatrix}$，则

$$
x_1 \mid x_2 \sim \mathcal{N}\big(\mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2),\;\; \Sigma_{11} - \Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}\big)
$$

条件均值随观测值线性移动；条件协方差（Schur 补）与观测值无关，而且总是比 $\Sigma_{11}$ 小。二维情形里，$x_2 \mid x_1$ 的均值是 $\mu_2 + \rho\frac{\sigma_2}{\sigma_1}(x_1 - \mu_1)$，方差是 $\sigma_2^2(1 - \rho^2)$，正是实验里那条红色区间。

DDPM 反向过程要用的 $q(x_{t-1} \mid x_t, x_0)$，也是用这条公式算出来的高斯。

### Step 4　一步写出 $q(x_t \mid x_0)$

记 $\alpha_t = 1 - \beta_t$。归纳假设 $x_{t-1} = \sqrt{\bar\alpha_{t-1}}\,x_0 + \sqrt{1 - \bar\alpha_{t-1}}\,\varepsilon'$，代入一步加噪：

$$
x_t = \sqrt{\alpha_t \bar\alpha_{t-1}}\,x_0 + \underbrace{\sqrt{\alpha_t(1 - \bar\alpha_{t-1})}\,\varepsilon' + \sqrt{1 - \alpha_t}\,\varepsilon_t}_{\text{两个独立高斯之和}}
$$

两个独立零均值高斯相加，方差相加：$\alpha_t(1 - \bar\alpha_{t-1}) + (1 - \alpha_t) = 1 - \alpha_t\bar\alpha_{t-1} = 1 - \bar\alpha_t$。于是 $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1 - \bar\alpha_t}\,\varepsilon$，归纳完成。

### Step 5　重参数化梯度与 score-function 梯度

要对 $\mathbb{E}_{z \sim q_\phi}[f(z)]$ 求 $\nabla_\phi$，有两条路：

$$
\underbrace{\mathbb{E}_{\varepsilon}\big[\nabla_\phi f(\mu_\phi + \sigma_\phi \varepsilon)\big]}_{\text{重参数化：要求 } f \text{ 可导}} \qquad \underbrace{\mathbb{E}_{z \sim q_\phi}\big[f(z)\,\nabla_\phi \log q_\phi(z)\big]}_{\text{score function / REINFORCE：只要能算 } \log q}
$$

重参数化用到了 $f$ 的梯度信息，方差通常低得多；score-function 估计量只用 $f$ 的值，方差大，但对离散变量也成立。语言模型输出的 token 是离散的，无法重参数化，所以策略梯度走的是第二条路（→ 2.3 §3）。

### Step 6　两个高斯之间的 KL

VAE 损失里的正则项有闭式解：

$$
\mathrm{KL}\big(\mathcal{N}(\mu, \sigma^2)\,\|\,\mathcal{N}(0, 1)\big) = \tfrac12\big(\sigma^2 + \mu^2 - 1 - \log \sigma^2\big)
$$

$\mu = 0, \sigma = 1$ 时为 0；$\sigma \to 0$ 时 $-\log\sigma^2$ 趋向无穷，这一项阻止编码器把每个样本编码成一个点（→ 0.8）。

## 4. 极简代码锚点（PyTorch）

```python
import torch

# 1. 用 Cholesky 因子生成相关高斯：x = μ + Lε
mu = torch.tensor([0.0, 0.0])
s1, s2, rho = 1.4, 0.7, 0.6
Sigma = torch.tensor([[s1 * s1, rho * s1 * s2], [rho * s1 * s2, s2 * s2]])
L = torch.linalg.cholesky(Sigma)
x = mu + torch.randn(100_000, 2) @ L.T
print(torch.cov(x.T))                        # ≈ Sigma
evals, evecs = torch.linalg.eigh(Sigma)      # 特征向量 = 椭圆主轴，√特征值 = 半轴长

# 2. 重参数化 vs score-function：同一个梯度，方差差多少？
mu_q = torch.tensor(0.5, requires_grad=True)
f = lambda z: (z - 2.0) ** 2                 # 目标：∇_μ E[f(z)] = 2(μ − 2) = −3
eps = torch.randn(10_000)
z = mu_q + eps                               # σ 固定为 1
g_rep = torch.autograd.grad(f(z).mean(), mu_q)[0]
g_sf = (f(z.detach()) * (z.detach() - mu_q.detach())).mean()   # ∇μ log N(z; μ, 1) = z − μ
per_sample_rep = 2 * (z.detach() - 2.0)
per_sample_sf = f(z.detach()) * (z.detach() - mu_q.detach())
print(g_rep.item(), g_sf.item())             # 都 ≈ −3
print(per_sample_rep.var().item(), per_sample_sf.var().item())  # score-function 的方差大得多

# 3. 扩散前向加噪：一步造出任意 t 的样本
betas = torch.linspace(1e-4, 0.02, 1000)
alpha_bar = torch.cumprod(1 - betas, dim=0)
def q_sample(x0, t, noise):
    a = alpha_bar[t].sqrt().view(-1, *[1] * (x0.dim() - 1))
    s = (1 - alpha_bar[t]).sqrt().view(-1, *[1] * (x0.dim() - 1))
    return a * x0 + s * noise                # x_t = √ᾱ x0 + √(1 − ᾱ) ε

# 4. VAE 的 KL 正则：KL(N(μ, σ²) ‖ N(0, 1)) 的闭式解
def kl_to_standard(mu, logvar):
    return 0.5 * (logvar.exp() + mu ** 2 - 1 - logvar).sum(-1)
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **高斯仍是生成模型的起点**。Stable Diffusion 3 一类的 rectified flow 模型从标准高斯出发，沿直线插值 $x_t = (1 - t)x_0 + t\varepsilon$ 去学速度场，并用 logit-normal 分布对时间 $t$ 采样，把训练集中到中间的噪声水平（→ 4.2）。"在哪些信噪比上多花训练"已经和"用什么网络"同样重要。
- **潜空间扩散依赖带 KL 正则的 VAE**。主流图像与视频生成模型先用一个 VAE 把像素压到潜空间，KL 项把潜变量拉向标准高斯附近，让后面的扩散模型有一个尺度稳定的工作空间（→ 4.5）。
- **初始化与参数化按方差设计**。从 $1/\sqrt{\text{fan\_in}}$ 初始化到 μP，核心都是"让每层输出的方差不随宽度漂移"，这样小模型上调好的超参才能迁移到大模型（→ 6.4）。

**与工程 / 应用的连接**
- **噪声调度要看信噪比，而不是步数**。换分辨率时，同一个调度下的信噪比会变：分辨率越高，相邻像素越相关，同样的噪声破坏的信息越少。很多高分辨率模型因此会平移时间步分布。
- **采样温度对应缩放噪声**。扩散采样时把初始噪声乘一个小于 1 的系数，相当于只在高斯的中心区域采样，结果更"稳"但多样性下降，和语言模型降温度是同一类取舍（→ 0.5）。
- **协方差接近奇异是数值问题的信号**。做 Cholesky 失败、马氏距离爆炸，通常是某些维度几乎线性相关。加一个小的对角项（$\Sigma + \epsilon I$）是标准做法。

**常见误区 / 反直觉点**
1. **"不相关就是独立"** ✗：只有**联合高斯**时，不相关才等价于独立。一般分布里，协方差为 0 的两个变量仍可能强相关。
2. **"任何对称矩阵都能当协方差"** ✗：协方差必须半正定，所有特征值 ≥ 0，否则"方差"会是负的。
3. **"两个高斯的混合还是高斯"** ✗：两个高斯**随机变量之和**是高斯；两个高斯**密度的加权混合**是多峰分布，不是高斯（→ 0.5 的双峰实验）。
4. **"重参数化对离散变量也能用"** ✗：离散采样不可导。Gumbel-softmax 只是可导的近似，语言模型的 RL 训练仍用 score-function 梯度。

**高频深挖题**
- **Q1：为什么 DDPM 训练时可以随机抽 $t$，而不必从 $x_0$ 一步步加噪？**
  思路：每步是高斯的线性组合 → 两个独立高斯之和仍是高斯，方差相加 → 归纳得 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\varepsilon$ → 训练时一步造样本，网络学习从 $x_t$ 预测 $\varepsilon$ → 加分项：$q(x_{t-1} \mid x_t, x_0)$ 也是高斯，由条件高斯公式给出，这是反向过程的监督信号。
- **Q2：重参数化技巧解决了什么问题？为什么语言模型的 RLHF 用不上它？**
  思路：采样不可导 → 把随机性移到与参数无关的 $\varepsilon$，$z = \mu + \sigma\varepsilon$ 对参数可导 → 梯度方差低 → token 是离散的，没有 $\varepsilon \mapsto z$ 的可导映射 → 只能用 $f \cdot \nabla \log \pi$ 的 score-function 梯度，所以需要 baseline、优势函数来降方差（→ 2.3）。
- **Q3：二维高斯 $\sigma_1 = \sigma_2 = 1$、$\rho = 0.9$，画出它的等高线，并写出 $x_2 \mid x_1 = 1$ 的分布。**
  思路：特征值 $1 \pm \rho$ = 1.9 和 0.1，主轴沿 45° 方向，椭圆细长 → 条件均值 $\rho \cdot 1 = 0.9$，条件方差 $1 - \rho^2 = 0.19$，标准差约 0.44 → 相关越强，观测一个变量后另一个越确定。
