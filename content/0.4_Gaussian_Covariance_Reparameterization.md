# 0.4 高斯分布：协方差几何与重参数化

> **一句话核心直觉**：多元高斯就是"把标准正态拉伸、旋转、再平移"：$x = \mu + L\varepsilon$。协方差 $\Sigma = LL^\top$ 决定了等高线椭圆：特征向量是主轴，特征值是半轴长的平方。高斯经过线性变换、取边缘、取条件之后都还是高斯，这种封闭性让 VAE 和扩散模型的数学几乎可以手算。
> **唤醒标签**：$x = \mu + L\varepsilon$ · $\Sigma = LL^\top$ · 特征向量 = 主轴 · 马氏距离 · 条件均值 $\mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2)$ · 重参数化 · $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon$ · 信噪比

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

在现代生成式人工智能中，高斯分布几乎无处不在：变分自编码器（VAE）将高维输入压缩进高斯潜空间，扩散模型（DDPM）向图像注入高斯白噪声，流匹配（Flow Matching）以标准高斯为源分布构建概率速度场（→ 4.1、4.2）。为什么现代生成算法不约而同地选择高斯分布作为核心地基？

- **中心极限定理的普遍性**：自然界中大量相互独立的微小随机扰动叠加，其极限分布普遍收敛为高斯分布。真实世界中的传感器噪声与成像噪点天然具备高斯形态（→ 0.3 §2）；
- **最大熵性质**：在已知均值与协方差的全部可能分布中，高斯分布拥有最大的信息熵。这意味着除了一阶与二阶矩之外，高斯分布对数据形态“不做任何额外的主观假设”（→ 0.5）；
- **代数运算法则的完美封闭性**：高斯变量经过仿射线性变换、两个独立高斯变量相加、对高维联合分布取边缘分布，或者给定部分观测后计算条件分布——其输出结果**依然严格是高斯分布**，且新分布的均值与协方差矩阵均能用简单的解析式直接写出。

如果高斯分布缺乏这种封闭性，扩散模型的预训练将陷入灾难：为了获得第 $t$ 步的加噪图像，工程师必须从第 0 步开始串行迭代加噪 $t$ 次，每个样本的加噪开销都正比于步数；而正是凭借高斯可加性，$q(x_t \mid x_0)$ 可以跳过所有中间步一步解析写出，训练时对时间步 $t$ 进行随机单点采样即可。

类似地，如果没有将高斯采样解耦的“重参数化技巧”，VAE 的编码器就无法将反向传播的梯度流穿过随机采样节点。本篇将系统阐明这两大机制背后的几何直觉与代数推导。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 从一维到多元

一维正态分布 $\mathcal{N}(\mu, \sigma^2)$ 的概率密度，在几何上仅取决于样本点离均值中心的相对标准化距离：$(x - \mu)^2 / \sigma^2$。

多元高斯分布将这一概念从单一标量轴自然推广至多维向量空间，其核心距离度量由欧氏距离升级为**马氏距离（Mahalanobis Distance）**：

$$
p(x) = \frac{1}{\sqrt{(2\pi)^d \det \Sigma}} \exp\!\Big(-\tfrac12 (x - \mu)^\top \Sigma^{-1} (x - \mu)\Big)
$$

在几何空间中，概率密度相等的点集满足二次型方程 $(x - \mu)^\top \Sigma^{-1} (x - \mu) = c^2$，它在 $d$ 维几何空间中严格描绘出一个以 $\mu$ 为中心、形态由协方差逆矩阵 $\Sigma^{-1}$ 决定的超椭球面。

### 2.2 协方差就是一个椭圆

协方差矩阵 $\Sigma$ 必定是实对称半正定方阵。由谱定理对其进行正交特征分解 $\Sigma = Q \Lambda Q^\top$：正交矩阵 $Q$ 的各列给出了空间中一组两两正交的主方向，对角阵 $\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_d)$ 则给出了沿这些主方向的真实方差。

这一分解揭示了等高线椭球的精巧几何结构：**椭球的主轴方向恰好与特征向量完全重合，而对应主半轴的几何长度严格等于方差的平方根 $\sqrt{\lambda_i}$**。

计算机生成相关高斯样本的过程，在几何上恰恰是上述分解的逆向工程：
1. 首先从标准正态分布采样一团各向同性的球形白噪声 $\varepsilon \sim \mathcal{N}(0, I)$；
2. 寻找满足 $LL^\top = \Sigma$ 的变换矩阵 $L$（如 Cholesky 下三角分解），通过矩阵乘法 $L\varepsilon$ 对球形点云施加定向旋转与主轴拉伸；
3. 最后叠加均值向量 $\mu$ 完成空间平移，得到目标样本 $x = \mu + L\varepsilon$。

- **切片条件分布的方差收缩**：打开「条件分布」开关（固定观测 $x_1 = 1$），画面中红色竖线上截出的区间即为条件高斯分布 $p(x_2 \mid x_1 = 1)$。读者会发现，条件均值沿回归线线性移动至 $\mu_2 + \rho\frac{\sigma_2}{\sigma_1}(x_1 - \mu_1)$，同时区间的置信半宽显著收缩至 $\sigma_2\sqrt{1 - \rho^2}$。相关性越强，已知 $x_1$ 后对 $x_2$ 的推断确定性就越高。

### 2.3 线性变换仍是高斯

设随机向量服从多元高斯分布 $x \sim \mathcal{N}(\mu, \Sigma)$，对其施加任意确定性的仿射线性映射 $Ax + b$（其中矩阵 $A$ 形状为 $m \times d$），输出向量依然严格保持高斯分布形态：

$$
Ax + b \sim \mathcal{N}(A\mu + b,\; A\Sigma A^\top)
$$

这一封闭性质在深度网络权重初始化中有着至关重要的应用。考虑全连接线性层的前向计算 $y = Wx$。假设权重矩阵 $W$ 的各元素独立同分布、方差为 $v$，输入向量各维度独立、方差归一化为 1。根据仿射方差法则，每个输出神经元的边际方差严格等于输入神经元数量乘以权重方差（即 $d_{in} \cdot v$）。为了确保信号在前向深层传递中方差既不爆炸也不衰减（保持为 1），必须强制设定权重初始方差 $v = 1/d_{in}$——这正是深度学习经典权重初始化（按 $1/\sqrt{\text{fan\_in}}$ 缩放，如 LeCun / He 初始化）的数学本源。

### 2.4 重参数化：让采样可以求导

在变分自编码器（VAE）中，编码器神经网络负责预测潜变量的后验参数 $\mu_\phi(x)$ 与 $\sigma_\phi(x)$，随后模型需要从高斯分布 $\mathcal{N}(\mu_\phi(x), \sigma_\phi^2(x)I)$ 中抽取一个潜变量样本 $z$，交给解码器重构输入。

然而，传统的“从分布中随机摇号抽样”是一个纯粹的随机离散化黑盒操作，无法针对编码器参数 $\phi$ 定义反向求导链条。

**重参数化技巧（Reparameterization Trick）**的突破在于将随机性从计算流中完全解耦剥离出来：将不可导的分布采样，等价改写为一个由确定性参数与无参数纯噪声复合构成的可微计算图：

$$
z = \mu_\phi(x) + \sigma_\phi(x) \odot \varepsilon, \qquad \varepsilon \sim \mathcal{N}(0, I)
$$

此时，潜变量 $z$ 成为了关于编码器网络参数 $\phi$ 的纯确定性、处处可微的显式函数。解码器传回的重构梯度能够长驱直入、无损穿透 $z$ 回传至编码器 $\mu_\phi$ 和 $\sigma_\phi$。所有随机性被完整隔离在外部的标准高斯白噪声 $\varepsilon$ 中，而白噪声本身不含任何可学习参数、不需要计算梯度。

### 2.5 前向加噪：一步写出 $q(x_t \mid x_0)$

在去噪扩散概率模型（DDPM）中，前向加噪过程被设计为单步向数据注入微量高斯白噪声：$x_t = \sqrt{1 - \beta_t}\,x_{t-1} + \sqrt{\beta_t}\,\varepsilon_t$。

因为每一步加噪本质上都是两个相互独立的高斯变量的线性组合，根据高斯分布的相加封闭性，哪怕经历 $t$ 次级联加噪，其累积结果 $x_t$ 相对于原始干净数据 $x_0$ 的条件分布依然严格是一个单高斯分布。其解析表达式可以直接跨越中间所有步骤一步写出：

$$
x_t = \sqrt{\bar\alpha_t}\, x_0 + \sqrt{1 - \bar\alpha_t}\, \varepsilon, \qquad \bar\alpha_t = \prod_{s=1}^{t} (1 - \beta_s)
$$

其中比值 $\bar\alpha_t / (1 - \bar\alpha_t)$ 具有明确的物理意义——**信噪比（Signal-to-Noise Ratio，SNR）**，即干净信号成分的功率与叠加噪声成分的功率之比。所谓的“噪声调度（Noise Schedule）”，本质上就是在定义信噪比随着加噪时间步 $t$ 如何平滑衰减。

拖动「时间 t」滑块并在「线性调度」与「余弦调度」之间切换，对比两者的信噪比演变规律：

## 3. 承重墙推导：重新捡起核心数学

### Step 1　仿射变换的均值与协方差

设 $y = Ax + b$，其中 $x \sim \mathcal{N}(\mu, \Sigma)$。由数学期望的线性性质，输出均值为 $\mathbb{E}[y] = A\,\mathbb{E}[x] + b = A\mu + b$。计算输出协方差矩阵：

$$
\mathrm{Cov}(y) = \mathbb{E}\big[(y - \mathbb{E}[y])(y - \mathbb{E}[y])^\top\big] = A\,\mathbb{E}\big[(x - \mu)(x - \mu)^\top\big]A^\top = A\Sigma A^\top
$$

由于多元高斯的特征函数（傅里叶变换）在仿射变换下依然保持指数二次型结构，根据特征函数的唯一性定理，$y$ 必然严格服从高斯分布 $\mathcal{N}(A\mu + b, A\Sigma A^\top)$。

在样本生成实践中，取标准白噪声 $x = \varepsilon \sim \mathcal{N}(0, I)$，平移项取均值向量 $b = \mu$，变换矩阵取满足 $LL^\top = \Sigma$ 的下三角矩阵 $L$。输出随机变量 $x = \mu + L\varepsilon$ 的协方差严格为 $L I L^\top = LL^\top = \Sigma$。在数值计算上，Cholesky 分解仅需 $O(d^3/3)$ 次乘加操作，比完整的特征分解更为经济高效。

### Step 2　特征分解与椭圆

对实对称协方差矩阵进行正交对角化 $\Sigma = Q\Lambda Q^\top$（其中 $Q^\top Q = I$，$\Lambda = \mathrm{diag}(\lambda_1, \dots, \lambda_d)$）。引入正交旋转坐标系 $u = Q^\top(x - \mu)$，将原二次型马氏距离展开：

$$
(x - \mu)^\top \Sigma^{-1} (x - \mu) = u^\top Q^\top (Q\Lambda Q^\top)^{-1} Q u = u^\top \Lambda^{-1} u = \sum_{i=1}^d \frac{u_i^2}{\lambda_i}
$$

当二次型等于常数 $c^2$ 时，方程 $\sum_i u_i^2 / (c^2\lambda_i) = 1$ 正是解析几何中标准超椭球的标准方程。椭球在各个特征轴向上的半轴长度精确为 $c\sqrt{\lambda_i}$。

在二维情形下，设协方差矩阵为 $\begin{pmatrix} \Sigma_{11} & \Sigma_{12} \\ \Sigma_{12} & \Sigma_{22} \end{pmatrix}$。利用平面旋转变换消去非对角项，可直接导出椭圆长轴相对于水平坐标轴的旋转偏角满足经典关系：$\tan 2\theta = \dfrac{2\Sigma_{12}}{\Sigma_{11} - \Sigma_{22}}$。

### Step 3　条件分布与 Schur 补

将高维联合高斯向量及其参数按分块结构展开：$x = \begin{pmatrix} x_1 \\ x_2 \end{pmatrix}$，均值 $\mu = \begin{pmatrix} \mu_1 \\ \mu_2 \end{pmatrix}$，协方差矩阵分块为 $\Sigma = \begin{pmatrix} \Sigma_{11} & \Sigma_{12} \\ \Sigma_{21} & \Sigma_{22} \end{pmatrix}$。

在联合高斯指数二次型中通过关于 $x_1$ 进行配方整理，可解析求得在给定观测 $x_2$ 的条件下，$x_1$ 的后验条件分布依然严格服从高斯分布：

$$
x_1 \mid x_2 \sim \mathcal{N}\big(\mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2),\;\; \Sigma_{11} - \Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}\big)
$$

这组公式蕴含着极为深刻的几何与信息论意义：
1. **条件均值随观测线性移动**：$\mu_1 + \Sigma_{12}\Sigma_{22}^{-1}(x_2 - \mu_2)$ 本质上是最优线性最小均方误差估计（LMMSE），增益矩阵 $\Sigma_{12}\Sigma_{22}^{-1}$ 将观测残差线性映射为均值修正量；
2. **条件协方差独立且严格收缩**：条件协方差矩阵 $\Sigma_{11 \mid 2} = \Sigma_{11} - \Sigma_{12}\Sigma_{22}^{-1}\Sigma_{21}$ 在代数上对应协方差矩阵的 Schur 补。它完全与具体观测到的数值 $x_2$ 无关，且减去了一个半正定矩阵，证明**引入额外变量的观测永远只会减少（或维持）不确定性，绝不会让方差膨胀**。

在二维特例中，若已知 $x_1$，则 $x_2 \mid x_1$ 的条件均值为 $\mu_2 + \rho\frac{\sigma_2}{\sigma_1}(x_1 - \mu_1)$，条件方差精确收缩为 $\sigma_2^2(1 - \rho^2)$。扩散模型（DDPM）反向转移核心公式 $q(x_{t-1} \mid x_t, x_0)$ 的闭式高斯解，正是应用这一分块条件推导得出的。

### Step 4　一步写出 $q(x_t \mid x_0)$

记单步保留系数为 $\alpha_t = 1 - \beta_t$。设归纳假设在 $t-1$ 步成立：$x_{t-1} = \sqrt{\bar\alpha_{t-1}}\,x_0 + \sqrt{1 - \bar\alpha_{t-1}}\,\varepsilon'$（其中 $\varepsilon' \sim \mathcal{N}(0, I)$）。将其代入第 $t$ 步的加噪递推式：

$$
x_t = \sqrt{\alpha_t}\,x_{t-1} + \sqrt{1 - \alpha_t}\,\varepsilon_t = \sqrt{\alpha_t \bar\alpha_{t-1}}\,x_0 + \underbrace{\sqrt{\alpha_t(1 - \bar\alpha_{t-1})}\,\varepsilon' + \sqrt{1 - \alpha_t}\,\varepsilon_t}_{\text{两独立零均值高斯变量之和}}
$$

根据两个独立零均值高斯变量相加依然为高斯变量且方差直接相加的法则：

$$
\mathrm{Var} = \alpha_t(1 - \bar\alpha_{t-1}) + (1 - \alpha_t) = \alpha_t - \alpha_t\bar\alpha_{t-1} + 1 - \alpha_t = 1 - \alpha_t\bar\alpha_{t-1} = 1 - \bar\alpha_t
$$

因此，这两个独立噪声项的线性组合等价于单一标准高斯变量 $\varepsilon \sim \mathcal{N}(0, I)$ 乘以合振幅 $\sqrt{1 - \bar\alpha_t}$。数学归纳法完成，直接得出封闭解 $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1 - \bar\alpha_t}\,\varepsilon$。

### Step 5　重参数化梯度与 score-function 梯度

当目标优化损失为分布期望 $\nabla_\phi \mathbb{E}_{z \sim q_\phi}[f(z)]$ 时，数学上有两条截然不同的梯度估计路径：

$$
\underbrace{\mathbb{E}_{\varepsilon \sim \mathcal{N}(0, I)}\big[\nabla_z f(\mu_\phi + \sigma_\phi \varepsilon)\,\nabla_\phi(\mu_\phi + \sigma_\phi \varepsilon)\big]}_{\text{重参数化梯度（Reparameterization Trick）：要求 } f \text{ 平滑可导}} \qquad \underbrace{\mathbb{E}_{z \sim q_\phi}\big[f(z)\,\nabla_\phi \log q_\phi(z)\big]}_{\text{Score-function 估计器（REINFORCE）：仅需 } f \text{ 可计算标量值}}
$$

两者的核心差异在于方差尺度与适用边界：
- **重参数化估计器**深入利用了目标函数本身的切线导数信息 $\nabla_z f$。采样点只要稍有移动，导数便能直接指示参数优化的正确倾斜方向，因此其单样本蒙特卡洛方差极低、优化极其稳定平滑；
- **Score-function 估计器**将 $f(z)$ 纯粹当成无导数的标量奖励黑盒，仅依靠调整对数似然 $\nabla_\phi \log q$ 尝试提高高分样本的出现概率。这种方法方差极大，在实际应用中必须借助基线网络（Baseline）和优势函数进行强力方差缩减（→ 2.3 §3）。但其决定性优势在于不要求被积函数可导，因而能够通吃离散 token 采样的强化学习对齐。

### Step 6　两个高斯之间的 KL

在 VAE 优化目标中，潜变量分布 $q_\phi(z \mid x) = \mathcal{N}(\mu, \sigma^2)$ 与标准正态先验 $p(z) = \mathcal{N}(0, 1)$ 之间的 KL 散度拥有极其简洁的闭式积分表达式：

$$
\mathrm{KL}\big(\mathcal{N}(\mu, \sigma^2)\,\|\,\mathcal{N}(0, 1)\big) = \int q(z) \log \frac{q(z)}{p(z)}\, dz = \tfrac12\big(\sigma^2 + \mu^2 - 1 - \log \sigma^2\big)
$$

检查函数的极值行为：当且仅当后验均值 $\mu = 0$ 且后验方差 $\sigma^2 = 1$ 时，KL 散度达到最小值 0。若模型试图让方差坍塌为零（$\sigma^2 \to 0$，即将潜变量退化为确定性点映射），对数项 $-\log \sigma^2$ 会迅猛趋向正无穷大。这一屏障从数学上强制阻止了编码器将潜空间坍缩为孤立离散点的冲动，保证了生成潜空间的连续性与平滑插值能力（→ 0.8）。

## 4. 极简代码锚点（PyTorch）

```python
import torch

# 1. 用 Cholesky 因子生成相关高斯：x = μ + Lε
mu = torch.tensor([0.0, 0.0])
s1, s2, rho = 1.4, 0.7, 0.6
Sigma = torch.tensor([[s1 * s1, rho * s1 * s2], [rho * s1 * s2, s2 * s2]])
L = torch.linalg.cholesky(Sigma)
x = mu + torch.randn(100_000, 2) @ L.T
print(torch.cov(x.T))                        # ≈ Sigma
evals, evecs = torch.linalg.eigh(Sigma)      # 特征向量 = 椭圆主轴，√特征值 = 半轴长

# 2. 重参数化 vs score-function：同一个梯度，方差差多少？
mu_q = torch.tensor(0.5, requires_grad=True)
f = lambda z: (z - 2.0) ** 2                 # 目标：∇_μ E[f(z)] = 2(μ − 2) = −3
eps = torch.randn(10_000)
z = mu_q + eps                               # σ 固定为 1
g_rep = torch.autograd.grad(f(z).mean(), mu_q)[0]
g_sf = (f(z.detach()) * (z.detach() - mu_q.detach())).mean()   # ∇μ log N(z; μ, 1) = z − μ
per_sample_rep = 2 * (z.detach() - 2.0)
per_sample_sf = f(z.detach()) * (z.detach() - mu_q.detach())
print(g_rep.item(), g_sf.item())             # 都 ≈ −3
print(per_sample_rep.var().item(), per_sample_sf.var().item())  # score-function 的方差大得多

# 3. 扩散前向加噪：一步造出任意 t 的样本
betas = torch.linspace(1e-4, 0.02, 1000)
alpha_bar = torch.cumprod(1 - betas, dim=0)
def q_sample(x0, t, noise):
    a = alpha_bar[t].sqrt().view(-1, *[1] * (x0.dim() - 1))
    s = (1 - alpha_bar[t]).sqrt().view(-1, *[1] * (x0.dim() - 1))
    return a * x0 + s * noise                # x_t = √ᾱ x0 + √(1 − ᾱ) ε

# 4. VAE 的 KL 正则：KL(N(μ, σ²) ‖ N(0, 1)) 的闭式解
def kl_to_standard(mu, logvar):
    return 0.5 * (logvar.exp() + mu ** 2 - 1 - logvar).sum(-1)
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **高斯仍是生成模型的起点**。Stable Diffusion 3 一类的 rectified flow 模型从标准高斯出发，沿直线插值 $x_t = (1 - t)x_0 + t\varepsilon$ 去学速度场，并用 logit-normal 分布对时间 $t$ 采样，把训练集中到中间的噪声水平（→ 4.2）。"在哪些信噪比上多花训练"已经和"用什么网络"同样重要。
- **潜空间扩散依赖带 KL 正则的 VAE**。主流图像与视频生成模型先用一个 VAE 把像素压到潜空间，KL 项把潜变量拉向标准高斯附近，让后面的扩散模型有一个尺度稳定的工作空间（→ 4.5）。
- **初始化与参数化按方差设计**。从 $1/\sqrt{\text{fan\_in}}$ 初始化到 μP，核心都是"让每层输出的方差不随宽度漂移"，这样小模型上调好的超参才能迁移到大模型（→ 6.4）。

**与工程 / 应用的连接**
- **噪声调度要看信噪比，而不是步数**。换分辨率时，同一个调度下的信噪比会变：分辨率越高，相邻像素越相关，同样的噪声破坏的信息越少。很多高分辨率模型因此会平移时间步分布。
- **采样温度对应缩放噪声**。扩散采样时把初始噪声乘一个小于 1 的系数，相当于只在高斯的中心区域采样，结果更"稳"但多样性下降，和语言模型降温度是同一类取舍（→ 0.5）。
- **协方差接近奇异是数值问题的信号**。做 Cholesky 失败、马氏距离爆炸，通常是某些维度几乎线性相关。加一个小的对角项（$\Sigma + \epsilon I$）是标准做法。

**常见误区 / 反直觉点**
1. **"不相关就是独立"** ✗：只有**联合高斯**时，不相关才等价于独立。一般分布里，协方差为 0 的两个变量仍可能强相关。
2. **"任何对称矩阵都能当协方差"** ✗：协方差必须半正定，所有特征值 ≥ 0，否则"方差"会是负的。
3. **"两个高斯的混合还是高斯"** ✗：两个高斯**随机变量之和**是高斯；两个高斯**密度的加权混合**是多峰分布，不是高斯（→ 0.5 的双峰实验）。
4. **"重参数化对离散变量也能用"** ✗：离散采样不可导。Gumbel-softmax 只是可导的近似，语言模型的 RL 训练仍用 score-function 梯度。

**高频深挖题**
- **Q1：为什么 DDPM 训练时可以随机抽 $t$，而不必从 $x_0$ 一步步加噪？**
  思路：每步是高斯的线性组合 → 两个独立高斯之和仍是高斯，方差相加 → 归纳得 $x_t = \sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\varepsilon$ → 训练时一步造样本，网络学习从 $x_t$ 预测 $\varepsilon$ → 加分项：$q(x_{t-1} \mid x_t, x_0)$ 也是高斯，由条件高斯公式给出，这是反向过程的监督信号。
- **Q2：重参数化技巧解决了什么问题？为什么语言模型的 RLHF 用不上它？**
  思路：采样不可导 → 把随机性移到与参数无关的 $\varepsilon$，$z = \mu + \sigma\varepsilon$ 对参数可导 → 梯度方差低 → token 是离散的，没有 $\varepsilon \mapsto z$ 的可导映射 → 只能用 $f \cdot \nabla \log \pi$ 的 score-function 梯度，所以需要 baseline、优势函数来降方差（→ 2.3）。
- **Q3：二维高斯 $\sigma_1 = \sigma_2 = 1$、$\rho = 0.9$，画出它的等高线，并写出 $x_2 \mid x_1 = 1$ 的分布。**
  思路：特征值 $1 \pm \rho$ = 1.9 和 0.1，主轴沿 45° 方向，椭圆细长 → 条件均值 $\rho \cdot 1 = 0.9$，条件方差 $1 - \rho^2 = 0.19$，标准差约 0.44 → 相关越强，观测一个变量后另一个越确定。
