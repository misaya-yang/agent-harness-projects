# 0.5 信息论：熵、交叉熵、KL 与极大似然

> **一句话核心直觉**：交叉熵 $H(p, q) = H(p) + \mathrm{KL}(p \,\|\, q)$。训练语言模型就是在最小化它：数据的熵 $H(p)$ 是改不掉的底线，你能压下去的只有 KL。极大似然等价于最小化前向 $\mathrm{KL}(\text{数据} \,\|\, \text{模型})$，它逼模型"处处都要覆盖"；反过来最小化 $\mathrm{KL}(\text{模型} \,\|\, \text{目标})$，模型会"挑一个峰钻进去"。这一个不对称，解释了 SFT 与 RLHF 行为上的很多差异。
> **唤醒标签**：$H = -\sum p\log p$ · 交叉熵 = 熵 + KL · MLE ⇔ 最小化前向 KL · 覆盖模式 vs 寻找模式 · 困惑度 $e^{H}$ · 温度改熵 · $p - y$ · bits per byte

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

在大语言模型的预训练、后训练与评测实践中，工程师每天都会直面四类核心困惑：

- **困惑一（损失瓶颈）**：模型在海量语料上预训练，交叉熵损失（Loss）一路下降到 1.8 之后逐渐趋于平缓、停滞不前。这究竟是因为模型架构容量不够、还是已经触碰到了自然语言内在不确定性的理论极限？
- **困惑二（指标陷阱）**：两个候选大模型在测试集上的困惑度（Perplexity）分别为 6.1 和 7.3，能草率断定前者一定更优秀吗？若两者的词表大小与分词切分规则（Tokenizer）完全不同，直接对比每 token 困惑度在统计学上毫无意义；
- **困惑三（行为分化）**：为什么监督微调（SFT）之后的模型“有求必应、样样略懂，却偶尔胡言乱语”，而经过强化学习对齐（RLHF）之后，模型回答风格显著更稳健聚焦，但输出的多样性却肉眼可见地大幅萎缩？
- **困惑四（采样调优）**：推理采样时调高温度参数（Temperature），模型天马行空、更有“创意”；调低温度，生成内容保守确定。温度在底层究竟改变了分布的什么物理量？

这些看似分散的工程现象，在底层共享同一套数学语言：**信息熵（Entropy）、交叉熵（Cross Entropy）与 KL 散度（Kullback–Leibler Divergence）**。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 熵：平均的意外程度

在信息论奠基人香农（Claude Shannon）的视角中，一个离散随机事件发生的概率为 $p$，当它真实发生时带给观察者的“信息量”（或意外程度 Surprisal）严格定义为负对数：$I(x) = -\log p(x)$。

越是司空见惯、必然发生的大概率事件，发生时带来的信息增量越趋近于 0；越是百年一遇、极度罕见的极端事件，一旦真实降临，其带来的信息冲击就越剧烈。

**信息熵（Entropy）**正是随机系统意外程度的数学期望——即平均而言，该系统内部包含多少不可预测的不确定性：

$$
H(p) = -\sum_x p(x) \log p(x)
$$

若对数底数取 2，熵的物理单位是**比特（bit）**。根据香农无失真源编码定理，它代表对该分布生成的离散符号进行最优无损压缩编码时，每个符号在理论上平均至少需要消耗的二进制比特数。当 $K$ 个可能结果服从等概率均匀分布时，不确定性达到最大峰值，熵为 $\log_2 K$；当系统完全确定性地发生某一特定结果时，熵彻底归零。

### 2.2 交叉熵与 KL：用错的分布要多花多少比特

假设自然界客观真实的底层数据分布为 $p$，但工程师却只能基于手头的神经网络预测模型 $q$ 去对数据进行编码或概率推断。此时，观察者面对真实数据所感受到的平均意外程度（即平均编码码长）被称为**交叉熵（Cross Entropy）**：

$$
H(p, q) = -\sum_x p(x) \log q(x) = H(p) + \underbrace{\sum_x p(x) \log \frac{p(x)}{q(x)}}_{\mathrm{KL}(p \,\|\, q)\ \ge\ 0}
$$

这一定理将交叉熵严谨拆解为两项之和：
1. **数据本身的固有信息熵 $H(p)$**：由现实世界客观语言与物理规律决定，是不可消除的理论下界；
2. **KL 散度 $\mathrm{KL}(p \,\|\, q)$**：**因为我们主观采用了不完美的拟合模型 $q$ 来逼近真实分布 $p$，而额外付出的冗余代价**。

根据 Jensen 不等式，KL 散度永远非负（$\mathrm{KL} \ge 0$），当且仅当模型预测分布 $q$ 与真实数据分布 $p$ 在几乎处处完全重合时，散度才等于 0。因此，训练语言模型时的交叉熵损失下界是数据内在的信息熵，永远不可能降到 0：自然语言在语境“今天天气真”后面究竟接“好”、“热”还是“晴朗”，在现实中原本就存在多元客观可能性。

### 2.3 极大似然就是最小化前向 KL

在自回归大模型预训练中，核心算法目标是最大化训练语料库在模型参数 $\theta$ 下的平均对数似然。当训练语料充分庞大时，根据大数定律，经验样本均值依概率收敛至在真实数据分布 $p$ 下的数学期望：

$$
\frac{1}{N}\sum_{i=1}^N \log q_\theta(x^{(i)}) \;\xrightarrow{N \to \infty}\; \mathbb{E}_{x \sim p}[\log q_\theta(x)] = -H(p, q_\theta) = -H(p) - \mathrm{KL}(p \,\|\, q_\theta)
$$

由于数据的固有熵 $H(p)$ 是客观恒量、与模型参数 $\theta$ 完全无关，因此：**最大化数据对数似然 ⇔ 最小化预测交叉熵 ⇔ 最小化前向 KL 散度 $\mathrm{KL}(p \,\|\, q_\theta)$**。这三者在数学上是完全同构的同一件事。

### 2.4 KL 的方向：覆盖模式 vs 寻找模式

KL 散度在数学上不是度量距离：它严格不满足对称性，即 $\mathrm{KL}(p \,\|\, q) \ne \mathrm{KL}(q \,\|\, p)$。当拟合模型 $q$（例如单高斯）的表达能力受限、无法完美复现复杂的真实多峰分布 $p$ 时，选择不同的优化方向将导致截然相反的收敛行为：

在上方实验中，读者可调节「两峰间距 d」与「右峰权重」，对比单高斯模型在两种优化目标下的拟合轮廓差异：
- **前向 KL $\mathrm{KL}(p \,\|\, q)$（模式覆盖，Mode-Covering）**：积分在真实数据分布 $p$ 有概率质量的地方进行加权。一旦在真实数据存在样本的区域（$p(x) > 0$）模型预测值 $q(x) \to 0$，被积项 $\log(p/q) \to +\infty$，模型将遭受极其沉重的无穷大惩罚。因此，前向 KL 强迫模型宁可过度放宽方差、将大量概率质量浪费在两个峰之间的低谷空白地带，也必须强行张开臂膀“同时盖住每一个数据峰”。
- **反向 KL $\mathrm{KL}(q \,\|\, p)$（模式寻找，Mode-Seeking）**：积分在模型自身分布 $q$ 产生质量的地方进行加权。模型为了避免在目标稀薄区（$p(x) \to 0$）犯错，会主动将自身收缩，死死钻进其中某一个最具主导性的单峰之中，对另一个峰视而不见。

这一方向性差异直接解释了大模型后训练的行为分化：**预训练与 SFT 最小化的是前向 KL**，因此模型会全盘接纳人类语料库中的所有表达模式（包括罕见、低质或偶发的幻觉长尾）；而 **RLHF 的策略优化行为更接近反向 KL**，策略模型在奖励函数驱动下迅速缩聚在最高奖励的局部模式中，使得回答高度稳定聚焦，但代价是输出多样性的显著收窄（→ 2.1、2.2）。

### 2.5 温度、熵与困惑度

语言模型在线性分类头输出每个 token 的未归一化 logits 分数 $z \in \mathbb{R}^V$。在加入采样温度参数 $T > 0$ 之后，其预测概率向量通过缩放 softmax 计算：$p_i = \mathrm{softmax}(z_i / T)$。

温度参数 $T$ 在代数上完全不改变候选词的相对大小排序，它唯一调控的是概率分布的“尖锐程度”，即**分布的瞬时信息熵**。困惑度（Perplexity，定义为 $\mathrm{PPL} = e^{H(p)}$）在物理直觉上可形象解读为**等效候选词数**：若模型在当前位置的困惑度为 4.6，意味着模型当前的不确定性程度，严格等价于在一个包含 4.6 个词的均匀候选池中进行随机猜测。

```academy-lab

```

在上方实验中，通过拖动「温度 T」滑块并在不同标准答案词（如「热」）之间切换，读者可细致观察两个极限状态：
- **低温坍缩（$T \to 0$）**：分布被无限锐化，极速退化为单点 argmax 决定性状态，分布熵 $H \to 0$，等效候选词数 $e^H \to 1$。然而，一旦真实数据中出现的目标词恰好不是模型判定为最高分的那个词，其交叉熵损失将按 $O(1/T)$ 发生灾难性暴涨！
- **高温摊平（$T \to \infty$）**：所有候选词的 logits 差异被彻底抹平，概率分布渐进趋近于全词表的均匀分布，信息熵逼近最大值 $\ln V$，困惑度直接等价于词表全量候选词总数。

### 困惑度是等效词数，不能当作目标词的排名

打开[温度实验](#lab-0-5-temperature)，固定 logits 再改变温度。温度升高，概率质量通常摊到更多词上，分布熵 $H$ 增大；$e^H$ 是具有同样熵的**均匀**分布所需的候选数。若交换两个词的标签，熵完全相同，可它们作为标准答案的负 log 概率会互换。

**迁移练习。** 模型对两个词给出 0.9 和 0.1。把正确答案从前者换成后者，分布困惑度会变吗？不会。单个目标的 NLL 却相差 $\ln9$。这也说明评估语料困惑度时应先对真实目标的 NLL 取平均，再取指数。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　交叉熵分解与 KL 非负

将对数商恒等变形 $\log q(x) = \log p(x) - \log\frac{p(x)}{q(x)}$ 直接代入交叉熵的定义式：

$$
H(p, q) = -\sum_x p(x) \log q(x) = -\sum_x p(x)\log p(x) + \sum_x p(x) \log\frac{p(x)}{q(x)} = H(p) + \mathrm{KL}(p \,\|\, q)
$$

KL 散度的非负性（吉布斯不等式）由琴生（Jensen）不等式严谨保证。因为对数函数 $f(u) = \log u$ 严格为凹函数（二阶导数 $-1/u^2 < 0$），对凹函数取期望满足 $\mathbb{E}[\log U] \le \log \mathbb{E}[U]$。令随机变量为密度比 $U = \frac{q(x)}{p(x)}$，并在真实分布 $p$ 下求期望：

$$
-\mathrm{KL}(p \,\|\, q) = \sum_x p(x) \log\frac{q(x)}{p(x)} \le \log\left(\sum_x p(x) \cdot \frac{q(x)}{p(x)}\right) = \log\left(\sum_x q(x)\right) = \log 1 = 0
$$

两边反号即得 $\mathrm{KL}(p \,\|\, q) \ge 0$。根据琴生不等式的等号取值条件，等号当且仅当随机变量 $U = q(x)/p(x)$ 几乎处处为常数时成立。结合两者均为合法的归一化概率分布，该常数只能为 1，即 $q(x) = p(x)$。

### Step 2　softmax 交叉熵的梯度

设网络最终分类头输出的 logits 分数为 $z$，softmax 预测概率为 $q_i = e^{z_i} / \sum_j e^{z_j}$。真实目标分布记为 $p$（在单标签硬分类时为 one-hot 编码）。将其代入负对数似然损失：

$$
L = -\sum_i p_i \log q_i = -\sum_i p_i \left( z_i - \log\sum_j e^{z_j} \right) = -\sum_i p_i z_i + \left(\sum_i p_i\right) \log\sum_j e^{z_j} = -\sum_i p_i z_i + \log\sum_j e^{z_j}
$$

对第 $k$ 个未归一化分量 $z_k$ 直接求偏导：

$$
\frac{\partial L}{\partial z_k} = -p_k + \frac{e^{z_k}}{\sum_j e^{z_j}} = -p_k + q_k = q_k - p_k
$$

损失对网络 logits 的反向梯度展现出惊人的纯粹性与对称美：“预测概率向量直接减去真实标签分布”。在知识蒸馏任务中，只要把硬 one-hot 标签 $p$ 替换为教师模型预测的平滑软概率分布，上述公式形式完全保持不变。

### Step 3　为什么前向与反向 KL 行为不同

在连续空间中写出两种散度的显式积分：

- **前向 KL**：$\mathrm{KL}(p \,\|\, q) = \int p(x) \big(\log p(x) - \log q(x)\big)\, dx$。其权重由真实分布 $p(x)$ 主导。在真实数据密集（$p(x) > 0$）而模型未覆盖（$q(x) \to 0$）的区域，被积项 $-\log q(x) \to +\infty$，产生趋向无穷的爆炸级惩罚。因此，**漏掉任何一个真实模式（False Negative）都会受到严厉制裁**。这迫使模型在近似能力受限时宁可摊宽方差、覆盖所有模式。特别地，在多元高斯族里最小化前向 KL 的理论解恰为矩匹配（Moment Matching）：$q$ 的均值和协方差精确对齐 $p$ 的样本均值和样本协方差；
- **反向 KL**：$\mathrm{KL}(q \,\|\, p) = \int q(x) \big(\log q(x) - \log p(x)\big)\, dx$。其权重由模型自身分布 $q(x)$ 主导。在模型自身产生采样（$q(x) > 0$）但目标稀薄（$p(x) \to 0$）的区域，被积项 $-\log p(x) \to +\infty$。因此，**模型把概率质量投放在目标不存在的虚空区域（False Positive）会受到严厉惩罚**；反之，若模型主动缩减到局部、遗漏了目标分布的某些模式，只要在未被遗漏的区域模型自身采样为 0（$q(x) = 0$），则被积项为 0，几乎完全不受惩罚。

### Step 4　KL 正则下的最优策略

大模型强化学习对齐（RLHF）的核心优化目标为：

$$
\max_\pi\; \mathcal{J}(\pi) = \mathbb{E}_{y \sim \pi}[r(y)] - \beta\, \mathrm{KL}(\pi \,\|\, \pi_{\text{ref}})
$$

将期望与 KL 展开为求和式并提取公因子 $-\beta$：

$$
\mathcal{J}(\pi) = \sum_y \pi(y) r(y) - \beta \sum_y \pi(y) \log\frac{\pi(y)}{\pi_{\text{ref}}(y)} = -\beta \sum_y \pi(y) \left[ \log\frac{\pi(y)}{\pi_{\text{ref}}(y)} - \frac{r(y)}{\beta} \right]
$$

将中括号内的减法合并为对数内部的除法：

$$
\mathcal{J}(\pi) = -\beta \sum_y \pi(y) \log\frac{\pi(y)}{\pi_{\text{ref}}(y) e^{r(y)/\beta}}
$$

定义未归一化因子的配分函数 $Z = \sum_y \pi_{\text{ref}}(y) e^{r(y)/\beta}$，并定义理论最优分布 $\pi^*(y) = \frac{1}{Z}\, \pi_{\text{ref}}(y)\, e^{r(y)/\beta}$。将 $\pi^*(y) Z$ 代入上式分母：

$$
\mathcal{J}(\pi) = -\beta \sum_y \pi(y) \left[ \log\frac{\pi(y)}{\pi^*(y)} - \log Z \right] = -\beta\, \mathrm{KL}\big(\pi \,\|\, \pi^*\big) + \beta \log Z
$$

由于 $\beta > 0$ 且 $\mathrm{KL}(\pi \,\|\, \pi^*) \ge 0$，当且仅当策略策略分布与目标完全重合（$\mathrm{KL} = 0$）时目标函数达到全局极值。因此其无约束最优解析解为：

$$
\pi^*(y) = \frac{1}{Z}\, \pi_{\text{ref}}(y)\, e^{r(y)/\beta}
$$

这表明基础策略分布在奖励函数指数加权下被重构，超参数 $\beta$ 精确对应热力学温度。直接偏好优化（DPO）正是反向解耦该等式，用策略的对数比值直接代换隐式奖励模型（→ 2.4）。

### Step 5　困惑度与跨 tokenizer 比较

困惑度定义为测试集上每个 token 的平均交叉熵对数损失取指数：$\mathrm{PPL} = \exp(\text{每 token 平均 NLL})$。

当且仅当两个模型使用完全相同的分词字典（Tokenizer）时，困惑度数值才具有可比性。若词表大小不同，大词表往往将较长子词切分为单个 token，每个 token 蕴含的字节信息量更大，对应的每 token 预测难度天然增加。跨模型评估信息压缩能力的公正物理标尺是**每字节比特数（Bits Per Byte, BPB）**：

$$
\text{bits per byte} = \frac{\text{全文本总交叉熵损失（nats）}}{\text{全文本 UTF-8 编码总字节数} \times \ln 2}
$$

分母中的 $\ln 2$ 将自然对数单位（nats）换算为香农信息比特（bits）。它衡量的是将目标文本无损压缩至极限时，平均每个字节所需消耗的物理比特数，彻底脱钩了分词器切分粒度的干扰。

## 4. 极简代码锚点（PyTorch）

```python
import torch, torch.nn.functional as F

def entropy(logits):
    logp = F.log_softmax(logits, -1)
    return -(logp.exp() * logp).sum(-1)

# 1. 交叉熵 = 熵 + KL
p = torch.tensor([0.5, 0.3, 0.2])                     # "数据分布"
z = torch.tensor([1.0, 0.2, -0.5], requires_grad=True)
logq = F.log_softmax(z, -1)
H_p = -(p * p.log()).sum()
CE = -(p * logq).sum()
KL = (p * (p.log() - logq)).sum()
assert torch.allclose(CE, H_p + KL)

# 2. softmax 交叉熵的梯度就是 q − p
CE.backward()
assert torch.allclose(z.grad, logq.exp() - p)

# 3. 用策略自己的样本估计 KL(π ‖ π_ref)：k1 无偏但可能为负，k3 无偏且非负
def kl_estimators(logp_pi, logp_ref):
    log_ratio = logp_ref - logp_pi                     # log(π_ref / π)，在 y ~ π 上计算
    k1 = -log_ratio
    k3 = log_ratio.exp() - 1 - log_ratio               # GRPO 使用的形式
    return k1.mean(), k3.mean()

# 4. 温度只缩放 logits：排序不变，熵变
logits = torch.tensor([3.2, 2.6, 2.1, 1.7, 1.2, 0.4, -0.5, -1.8])
for T in (0.3, 1.0, 3.0):
    H = entropy(logits / T)
    print(T, H.item(), H.exp().item())                 # 熵与困惑度（等效候选数）

# 5. 每字节比特数：跨 tokenizer 可比
def bits_per_byte(total_loss_nats, text):
    return total_loss_nats / (len(text.encode("utf-8")) * torch.log(torch.tensor(2.0)))
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **RL 训练里的 KL 都是采样估计的**。完整计算 $\mathrm{KL}(\pi \,\|\, \pi_{\text{ref}})$ 要对所有可能的回答求和，做不到。实际做法是在策略自己采出的 token 上估计。GRPO（DeepSeekMath）用 $\frac{\pi_{\text{ref}}}{\pi} - \log\frac{\pi_{\text{ref}}}{\pi} - 1$ 这个无偏、非负的估计量，把它直接加进损失，而不是像 PPO 那样塞进奖励里（→ 2.5）。
- **蒸馏开始讲究 KL 的方向**。传统知识蒸馏最小化前向 KL（学生覆盖老师的全部分布）；MiniLLM 等工作发现，对生成任务改用反向 KL、并在学生自己采出的序列上计算（on-policy 蒸馏），学生不会把概率浪费在老师分布的长尾上，生成更稳（→ 2.1）。
- **跨模型比较压缩能力用每字节比特数**。不同模型的 tokenizer、词表大小差别很大，每 token 困惑度已经不能直接比较。比较基座模型的"语言建模能力"时，越来越多地报告 bits per byte。

**与工程 / 应用的连接**
- **loss 降不下去时先估数据熵**。用更大的模型或更长的训练在同一份数据上跑，loss 下降趋缓的位置大致就是数据熵加上模型容量带来的残余 KL。Scaling Law 里那个不可约的常数项，就是数据熵（→ 6.1）。
- **logprob 能当置信度，但要校准**。预训练模型的 token 概率通常校准得不错；RLHF 之后分布被推向寻找模式，模型往往过度自信，用 logprob 判断"它确定吗"之前要先在验证集上校准（→ 9.3）。
- **温度、top-p 都在改熵**。温度对整个分布做缩放；top-p 截掉长尾再重新归一化。两者都会降低熵、减少胡言乱语，代价是多样性下降（→ 7.1）。

**常见误区 / 反直觉点**
1. **"训练 loss 应该能降到 0"** ✗：交叉熵的下界是数据熵。loss 接近 0 通常意味着模型背下了训练集。
2. **"KL 是一种距离"** ✗：它不对称，也不满足三角不等式。方向选错，模型行为会完全不同。
3. **"困惑度低的模型一定更好"** ✗：要在同一个 tokenizer、同一份测试集上比较；跨 tokenizer 时用 bits per byte。
4. **"温度越高越有创造力"** ✗：温度只是把分布压平，低质量的候选也被抬高。高温带来的多样性里，很大一部分是噪声。

**高频深挖题**
- **Q1：为什么说极大似然训练等价于最小化 KL 散度？是哪个方向的 KL？这带来什么行为？**
  思路：平均对数似然 → 期望 → $-H(p) - \mathrm{KL}(p \,\|\, q_\theta)$ → 前向 KL → 漏掉数据的任何模式都会被重罚 → 覆盖模式：模型会把概率分给数据里所有出现过的说法，包括低质量的 → 这就是 SFT 之后模型"什么都学一点"、需要偏好对齐去收窄的原因。
- **Q2：RLHF 里 KL 正则的作用是什么？如果 β 设成 0 会怎样？**
  思路：最优解 $\pi^* \propto \pi_{\text{ref}} e^{r/\beta}$ → β 控制离参考模型多远 → β → 0 时策略把全部概率压到奖励模型给分最高的回答上，奖励模型的漏洞被放大，出现 reward hacking 与语言退化（→ 2.2）→ β 太大则学不到东西。
- **Q3：同一份测试集上，模型 A 困惑度 6.1、B 困惑度 7.3，但 B 的词表是 A 的两倍。哪个模型语言建模能力更强？**
  思路：困惑度按 token 计，词表更大的 tokenizer 每个 token 覆盖更多字节，每 token 的预测更难 → 不能直接比 → 换算成 bits per byte：总 loss（nats）÷（字节数 × ln 2）→ 比较这个数。
