# 0.8 变分推断：Jensen 不等式与 ELBO

> **一句话核心直觉**：潜变量模型的似然 $p(x) = \int p(x \mid z)p(z)\,dz$ 里有一个积分，算不动。挑一个好算的分布 $q(z)$，用 Jensen 不等式得到下界 ELBO $= \mathbb{E}_q[\log p(x \mid z)] - \mathrm{KL}(q \,\|\, p(z))$。它与真实对数似然的差距恰好是 $\mathrm{KL}(q \,\|\, p(z \mid x))$，所以提高 ELBO 就是在拟合数据的同时逼近后验。VAE 用重参数化优化它；扩散模型是一个很深的层次 VAE，它的 ELBO 化简后就是加权的去噪损失。
> **唤醒标签**：$\log p(x) = \text{ELBO} + \mathrm{KL}(q\|p(z \mid x))$ · Jensen：$\log\mathbb{E} \ge \mathbb{E}\log$ · 重建 − KL · 摊销推断 $q_\phi(z \mid x)$ · 重参数化 · 后验坍缩 · 阈值 $\beta\sigma^2$ · 扩散 = 层次 VAE

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

想用一个潜变量 $z$ 来解释数据：先从简单的先验 $p(z) = \mathcal{N}(0, I)$ 采一个 $z$，再用神经网络解码成 $x$。训练要做极大似然（→ 0.5），可是

$$
p_\theta(x) = \int p_\theta(x \mid z)\, p(z)\, dz
$$

是对高维 $z$ 的积分，被积函数里还套着一个神经网络，没有闭式解。后验 $p(z \mid x) = p(x \mid z)p(z)/p(x)$ 也要用到这个积分。

最朴素的办法是蒙特卡洛：从先验采 $z_i$，算 $\frac1N\sum_i p(x \mid z_i)$。但对一张具体的图，绝大多数随机 $z$ 解码出来都和它毫不相干，估计的方差大到没法用（→ 0.7 的重要性采样：提议分布离目标太远）。我们需要一个"看了 $x$ 之后再决定往哪采"的分布 $q(z \mid x)$。

没有这一步，就没有 VAE，没有 Stable Diffusion 里那个把图像压进潜空间的自编码器，扩散模型的去噪损失也只是一个"看起来合理"的经验公式。

---

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 换个分布去积分

任取一个 $q(z)$（只要在 $p(x, z) > 0$ 的地方 $q(z) > 0$），

$$
p(x) = \int q(z)\,\frac{p(x, z)}{q(z)}\,dz = \mathbb{E}_{z \sim q}\!\left[\frac{p(x, z)}{q(z)}\right]
$$

这就是重要性采样的式子。$q$ 越像后验 $p(z \mid x)$，比值 $p(x,z)/q(z)$ 越接近常数，估计越准。

### 2.2 Jensen：对数的平均 ≤ 平均的对数

$\log$ 是凹函数，所以 $\log \mathbb{E}[W] \ge \mathbb{E}[\log W]$。把它用在上式：

$$
\log p(x) \ge \mathbb{E}_{q}\big[\log p(x, z) - \log q(z)\big] \equiv \text{ELBO}(q)
$$

ELBO 是 evidence lower bound（证据下界），这里的"证据"就是 $\log p(x)$。只要能从 $q$ 采样、能算 $\log p(x, z)$ 和 $\log q(z)$，就能用样本估计它。

### 2.3 差距恰好是 KL(q‖后验)

$$
\log p(x) = \text{ELBO}(q) + \mathrm{KL}\big(q(z) \,\|\, p(z \mid x)\big)
$$

左边与 $q$ 无关，所以**把 ELBO 推高，就是把 $q$ 推向真实后验**；KL 为 0 时下界取等号。这把"算不动的推断"变成了"可以用梯度做的优化"。

```academy-lab

```

"线性模型的最优 q"预设下差距是 0.00：线性高斯模型的后验本身就是高斯。换到 $z^2$ 模型、$x = 2$，后验在 $\pm 1.41$ 附近各有一个峰；把 $q$ 调到最好（"抓住一个峰"），差距停在 0.73，接近 $\log 2$。"硬盖两个峰"让 $q$ 把大量概率放在两峰之间的低谷，差距涨到 9.11。每一个状态下，差距都和直接数值积分得到的 KL 相等。最大化 ELBO 等于最小化**反向** KL，所以 $q$ 倾向于抓住一个峰（→ 0.5）。

### 2.4 另一种写法：重建 − 正则

把 $\log p(x, z) = \log p(x \mid z) + \log p(z)$ 拆开：

$$
\text{ELBO} = \underbrace{\mathbb{E}_{q}\big[\log p(x \mid z)\big]}_{\text{重建：从 } z \text{ 解码回 } x \text{ 有多准}} - \underbrace{\mathrm{KL}\big(q(z) \,\|\, p(z)\big)}_{\text{正则：} q \text{ 别离先验太远}}
$$

重建项要 $q$ 把不同的 $x$ 编码到能区分的位置；KL 项把每个 $q$ 拉回先验附近，生成时才能直接从 $\mathcal{N}(0, I)$ 采样，落到解码器认识的区域。

### 2.5 VAE：摊销推断 + 重参数化

为每个数据点单独优化一个 $q$ 太贵。VAE 用一个编码器网络一次性输出 $q_\phi(z \mid x) = \mathcal{N}(\mu_\phi(x), \mathrm{diag}\,\sigma_\phi^2(x))$，这叫**摊销推断**。采样用重参数化 $z = \mu_\phi + \sigma_\phi \odot \varepsilon$（→ 0.4 §2.4），梯度可以穿过采样流回编码器。解码器取 $p_\theta(x \mid z) = \mathcal{N}(f_\theta(z), \sigma^2 I)$，重建项就是 $-\|x - f_\theta(z)\|^2/(2\sigma^2)$ 加常数，KL 项有闭式解（→ 0.4 Step 6）。编码器和解码器一起用 SGD 最大化 ELBO。

### 2.6 VAE 为什么糊

线性 VAE 的最优解可以直接写出来（Step 4）。数据沿每个主方向的方差是 $\lambda_k$：

- $\lambda_k \le \beta\sigma^2$ 的方向，编码它的收益抵不过 KL 代价，后验坍缩回先验，解码器把它整个丢掉；
- $\lambda_k > \beta\sigma^2$ 的方向被保留，但重建被缩小到 $1 - \beta\sigma^2/\lambda_k$ 倍。

自然图像的高频细节方差小，最先被牺牲。

```academy-lab
0.8-vae
```

$\sigma^2 = 0.01$ 时 16 个分量里保留 9 个，重建保留 91.5% 的方差；$\beta = 4$ 只剩 4 个，79.8%；$\sigma^2 = 1$ 时全部坍缩，重建是一条直线。$\beta$ 和 $\sigma^2$ 只以乘积出现：调大解码器的噪声方差，等于告诉模型"像素误差不要紧"，效果和调大 $\beta$ 一样。

另一个原因是高斯解码器本身：同一个 $z$ 可能对应几种合理的细节，L2 重建的最优输出是它们的平均，平均出来就是模糊的。

### 2.7 扩散模型：一个很深的层次 VAE

把 $x_1, \dots, x_T$ 都看成潜变量。编码器是固定的加噪过程 $q(x_t \mid x_{t-1})$，不需要学；解码器是学出来的去噪过程 $p_\theta(x_{t-1} \mid x_t)$。写出这个模型的 ELBO，每一项都是两个高斯之间的 KL，化简后正是"预测加进去的噪声"的加权平方误差（Step 5）。DDPM 去掉权重，得到 $\|\varepsilon - \varepsilon_\theta(x_t, t)\|^2$。

### 用可解的后验检查 ELBO 的差距

在[ELBO 实验](#lab-0-8)里切到线性观测。取先验 $z\sim N(0,1)$、观测噪声标准差 0.6、观测 $x=2$。将联合密度中含 $z$ 的平方项配方，可得后验方差 $v=0.36/1.36$、后验均值 $m=2/1.36$。若变分分布取到这个高斯，ELBO 与真实 log 似然重合。

现在只把变分均值移走 $\delta$，保留正确方差。KL 差距恰为 $\delta^2/(2v)$。预测这个差距随偏移加倍会怎样变化，再去切换双峰模型：在线性例中，单高斯族能包含真实后验；双峰情形连最优单高斯也通常留有差距。界的松弛既可能来自参数没调好，也可能来自分布族受限。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　Jensen 不等式

$f$ 凹，则 $f(\mathbb{E}[W]) \ge \mathbb{E}[f(W)]$，当且仅当 $W$ 几乎处处为常数时取等号。取 $f = \log$、$W = p(x, z)/q(z)$、$z \sim q$：

$$
\log p(x) = \log \mathbb{E}_q\!\left[\frac{p(x, z)}{q(z)}\right] \ge \mathbb{E}_q\!\left[\log \frac{p(x, z)}{q(z)}\right]
$$

取等号要求 $p(x, z)/q(z)$ 与 $z$ 无关，即 $q(z) \propto p(x, z)$，也就是 $q = p(z \mid x)$。

### Step 2　ELBO 与 KL 的恒等式

用 $p(x, z) = p(z \mid x)\,p(x)$：

$$
\log p(x) - \text{ELBO} = \mathbb{E}_q\big[\log p(x) - \log p(z \mid x) - \log p(x) + \log q(z)\big] = \mathbb{E}_q\!\left[\log \frac{q(z)}{p(z \mid x)}\right] = \mathrm{KL}\big(q \,\|\, p(z \mid x)\big)
$$

EM 算法正是交替使用这个恒等式：E 步令 $q = p(z \mid x)$，让下界贴紧；M 步固定 $q$，对模型参数 $\theta$ 最大化下界。VAE 做不到精确的 E 步，于是用编码器近似它，两步合成一次梯度更新。

### Step 3　重建项、KL 项与 $\sigma^2$

高斯解码器下，

$$
\text{ELBO} = -\frac{1}{2\sigma^2}\,\mathbb{E}_q\|x - f_\theta(z)\|^2 - \frac{D}{2}\log(2\pi\sigma^2) - \beta\,\mathrm{KL}\big(q \,\|\, p(z)\big)
$$

（标准 ELBO 是 $\beta = 1$。）乘以 $\sigma^2$ 不改变最优解，目标等价于 $-\tfrac12\mathbb{E}\|x - f_\theta(z)\|^2 - \beta\sigma^2\,\mathrm{KL}$：**真正决定"重建还是压缩"的是 $\beta\sigma^2$**。把 $\sigma^2$ 随手设成 1，等于给 KL 加了很大的权重。

### Step 4　线性 VAE 的闭式解

沿一个主方向，数据 $x \sim \mathcal{N}(0, \lambda)$，编码器 $q(z \mid x) = \mathcal{N}(vx, s^2)$，解码器 $p(x \mid z) = \mathcal{N}(wz, \sigma^2)$。代入 Step 3，记 $\tau = \beta\sigma^2$，对数据取期望后（乘以 $\sigma^2$）：

$$
J = -\tfrac12\big[(1 - wv)^2\lambda + w^2 s^2\big] - \tfrac{\tau}{2}\big[v^2\lambda + s^2 - 1 - \log s^2\big]
$$

对 $s^2$、$v$ 求导置零得 $s^2 = \tau/c$、$v = w/c$，其中 $c = w^2 + \tau$。代回去，$J = -\tfrac{\tau}{2}\big[\lambda/c + \log c\big] + \text{const}$，对 $c \ge \tau$ 最小化 $\lambda/c + \log c$：

$$
c^* = \max(\lambda, \tau) \;\Rightarrow\; w^2 = (\lambda - \tau)_+, \qquad \mathbb{E}[\hat x \mid x] = wv\,x = \Big(1 - \frac{\tau}{\lambda}\Big)_{\!+} x, \qquad \mathrm{KL} = \tfrac12 \log\frac{\lambda}{\tau}\ \ (\lambda > \tau)
$$

$\lambda \le \tau$ 时 $w = 0$：解码器不用 $z$，编码器输出先验，这就是后验坍缩。Lucas et al. 由此指出，坍缩往往不是 ELBO 的错，而是解码器噪声方差 $\sigma^2$ 设得太大。

### Step 5　扩散模型的 ELBO 化成去噪损失

层次 VAE 的负 ELBO 分解为

$$
\mathbb{E}_q\Big[\underbrace{\mathrm{KL}\big(q(x_T \mid x_0)\,\|\,p(x_T)\big)}_{\approx 0} + \sum_{t > 1}\mathrm{KL}\big(q(x_{t-1} \mid x_t, x_0)\,\|\,p_\theta(x_{t-1} \mid x_t)\big) - \log p_\theta(x_0 \mid x_1)\Big]
$$

$q(x_{t-1} \mid x_t, x_0) = \mathcal{N}(\tilde\mu_t, \tilde\beta_t I)$ 由条件高斯公式给出（→ 0.4 Step 3）。把 $p_\theta$ 的均值参数化成 $\mu_\theta = \frac{1}{\sqrt{\alpha_t}}\big(x_t - \frac{\beta_t}{\sqrt{1 - \bar\alpha_t}}\,\varepsilon_\theta(x_t, t)\big)$，方差取 $\sigma_t^2$，两个高斯的 KL 只剩均值差：

$$
\mathrm{KL}_t = \frac{\|\tilde\mu_t - \mu_\theta\|^2}{2\sigma_t^2} = \frac{\beta_t^2}{2\sigma_t^2\,\alpha_t(1 - \bar\alpha_t)}\,\big\|\varepsilon - \varepsilon_\theta(x_t, t)\big\|^2
$$

DDPM 发现去掉前面的权重、对 $t$ 均匀采样，样本质量反而更好。Variational Diffusion Models 进一步证明，连续时间极限下 ELBO 是按信噪比变化率加权的去噪误差，而且除了两端的信噪比，与噪声调度的形状无关。

### Step 6　KL 的方向

ELBO 最小化的是 $\mathrm{KL}(q \,\|\, p(z \mid x))$：在 $q$ 有质量而后验没有的地方惩罚极重，在后验有质量而 $q$ 没有的地方几乎不罚。所以近似族不够灵活时，$q$ 会缩在后验的一个峰里，方差偏小（→ 0.5 的反向 KL）。这也是 VAE 的潜空间里会出现"空洞"的原因之一：先验认为有概率的区域，未必有哪个 $q(z \mid x)$ 覆盖过。

## 4. 极简代码锚点（PyTorch）

```python
import math
import torch
import torch.nn as nn
torch.manual_seed(0)

# 1. 验证 log p(x) = ELBO + KL(q‖p(z|x))：一维 z² 模型，网格积分
def log_normal(x, m, s):
    return -0.5 * math.log(2 * math.pi) - math.log(s) - 0.5 * ((x - m) / s) ** 2

x, sx = 2.0, 0.6
z = torch.linspace(-6, 6, 24001, dtype=torch.float64)
dz = z[1] - z[0]
log_joint = log_normal(x, z ** 2, sx) + log_normal(z, 0.0, 1.0)      # log p(x, z)
log_px = torch.logsumexp(log_joint, 0) + torch.log(dz)
mu, s = 1.4, 0.2                                                     # q 贴住右边的峰
log_q = log_normal(z, mu, s)
q = log_q.exp()
elbo = (q * (log_joint - log_q)).sum() * dz
kl_post = (q * (log_q - (log_joint - log_px))).sum() * dz
print(log_px.item(), elbo.item(), (log_px - elbo).item(), kl_post.item())   # 后两个相等（≈ 0.84）

# 2. 最小 VAE：重参数化 + 闭式 KL，sigma2 和 beta 一起决定取舍
class VAE(nn.Module):
    def __init__(self, d=784, h=256, k=16):
        super().__init__()
        self.enc = nn.Sequential(nn.Linear(d, h), nn.ReLU(), nn.Linear(h, 2 * k))
        self.dec = nn.Sequential(nn.Linear(k, h), nn.ReLU(), nn.Linear(h, d))

    def forward(self, x, beta=1.0, sigma2=0.01):
        mu, logvar = self.enc(x).chunk(2, dim=-1)
        z = mu + (0.5 * logvar).exp() * torch.randn_like(mu)        # 重参数化
        rec = -((x - self.dec(z)) ** 2).sum(-1) / (2 * sigma2)      # log p(x|z)，省略常数
        kl = 0.5 * (logvar.exp() + mu ** 2 - 1 - logvar)            # 每个潜维度的 KL
        loss = -(rec - beta * kl.sum(-1)).mean()                    # 最小化 −ELBO
        return loss, kl.mean(0)

vae = VAE()
opt = torch.optim.Adam(vae.parameters(), lr=1e-3)
# 合成数据：4 个强方向（每个方差 λ ≈ 7.8）+ 各向同性弱噪声（方差 0.0025 < βσ² = 0.01）
W = torch.randn(4, 784) * 0.1
for step in range(5000):
    x = torch.randn(64, 4) @ W + 0.05 * torch.randn(64, 784)    # 每步新采样，避免背下训练集里的噪声
    loss, kl_per_dim = vae(x)
    opt.zero_grad(); loss.backward(); opt.step()
print(kl_per_dim.detach().sort(descending=True).values[:6])
# 4 个维度的 KL ≈ 3.4，接近闭式解 ½ln(λ/βσ²) = ½ln(7.8/0.01) ≈ 3.3；其余 12 个坍缩到先验，KL ≈ 0

# 3. 线性 VAE 的闭式解：方差低于 βσ² 的方向整个坍缩，其余按 1 − βσ²/λ 缩小
lam = torch.tensor([1.0, 0.3, 0.05, 0.01, 0.002])            # 数据各主方向的方差
for tau in [1e-3, 1e-2, 1e-1]:                               # tau = βσ²
    shrink = (1 - tau / lam).clamp(min=0)
    rate = 0.5 * torch.log((lam / tau).clamp(min=1)).sum()
    print(tau, shrink.numpy().round(3), round(rate.item(), 2))
```

### 数值复算 · 用可解的后验检查 ELBO 的差距

在同一个 Python 会话中先运行本节上方的实现，再运行以下算例。

```python
import torch
from torch.distributions import Normal, kl_divergence
v, m = 0.36/1.36, 2/1.36
post = Normal(torch.tensor(m, dtype=torch.float64), v**0.5)
for offset in [0., 0.25, 0.5]:
    approx = Normal(post.loc + offset, post.scale)
    gap = kl_divergence(approx, post)
    assert abs(gap.item() - offset**2/(2*v)) < 1e-10
    print(f"均值偏移={offset:.2f}  ELBO 差距={gap:.3f} nat")
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **潜空间生成依赖自编码器，但 KL 只是配角**。潜扩散模型先用自编码器把图像压到低维潜空间，再在潜空间里做扩散。它的自编码器只带很弱的 KL 惩罚，作用是把潜变量的尺度管住；重建的清晰度主要来自感知损失和基于图像块的对抗损失，正是为了绕开 §2.6 说的模糊。
- **扩散训练目标被理解成"加权的 ELBO"**。VDM 把不同的损失写法统一成对信噪比的加权积分。今天调扩散和流模型，很大一部分工作是在选这个权重，以及在哪些噪声水平上多采样（→ 0.4、4.2）。
- **变分视角也出现在后训练里**。带 KL 正则的奖励最大化 $\max_\pi \mathbb{E}_\pi[r] - \beta\,\mathrm{KL}(\pi \,\|\, \pi_{\text{ref}})$，等价于最小化 $\mathrm{KL}(\pi \,\|\, \pi^*)$，其中 $\pi^* \propto \pi_{\text{ref}}\, e^{r/\beta}$ 扮演"后验"的角色。DPO 的推导就是从这个最优解出发的（→ 2.4）。

**与工程 / 应用的连接**
- **监控每个潜维度的 KL**：KL 接近 0 的维度已经坍缩、不传任何信息。"活跃维度数"比总 loss 更能说明编码器有没有在工作。
- **强解码器的后验坍缩**：解码器是自回归模型（例如一个语言模型）时，它不看 $z$ 也能把 $x$ 建模得很好，KL 项会把 $z$ 整个推回先验。常见对策是 KL 退火（训练初期 $\beta$ 从 0 慢慢升到 1）和 free bits（每个维度的 KL 低于某个值时不罚）。
- **$\beta$ 的两个方向**：$\beta > 1$ 压缩更狠，潜变量更容易对应可解释的因素（β-VAE），代价是更糊；$\beta < 1$ 重建更清晰，但先验采样的质量变差，因为 $q$ 离先验更远了。
- **解码器方差别随手设成 1**：图像像素归一化到 $[0, 1]$ 时，$\sigma^2 = 1$ 意味着 KL 的相对权重非常大，几乎所有细节都会坍缩（实验里 $\sigma^2 = 1$ 的预设）。

**常见误区 / 反直觉点**
1. **"ELBO 涨了，说明 $q$ 更接近后验"** ✗：只有固定模型参数 $\theta$ 时才成立。联合训练时，ELBO 上涨也可能来自模型把自己的后验"掰"得更像高斯，好让 $q$ 贴上去，而真实似然未必变好。
2. **"VAE 糊全是 KL 项的错"** ✗：高斯解码器对多种合理细节取平均，同样会糊；而且决定取舍的是 $\beta\sigma^2$，不只是 $\beta$。
3. **"后验坍缩一定是 bug"** ✗：方差低于 $\beta\sigma^2$ 的方向，坍缩正是 ELBO 的最优解。真正的问题是 $\beta\sigma^2$ 设得太大，或者解码器强到不需要 $z$。
4. **"扩散模型的训练目标就是 ELBO"** ✗：DDPM 的 $L_{\text{simple}}$ 去掉了 ELBO 的权重，是一个重新加权的版本。按 ELBO 的权重训练似然更好，按简化权重训练样本质量更好。

**高频深挖题**
- **Q1：推导 ELBO，并说明它和 $\log p(x)$ 差在哪里。**
  思路：$p(x) = \mathbb{E}_q[p(x,z)/q(z)]$ → Jensen 得下界 → 用 $p(x, z) = p(z \mid x)p(x)$ 证明差距是 $\mathrm{KL}(q\|p(z \mid x))$ → 取等号当且仅当 $q$ 是真实后验 → 加分项：差距来自近似族不够灵活和摊销误差两部分；最小化的是反向 KL，$q$ 倾向于抓住一个峰。
- **Q2：VAE 生成的图像为什么模糊？怎么缓解？**
  思路：高斯解码器 + L2 重建，对不确定的细节取平均 → KL 代价让方差低于 $\beta\sigma^2$ 的方向坍缩，高频细节最先被丢（线性 VAE 闭式解）→ 缓解：减小 $\beta\sigma^2$、更灵活的后验和先验、感知损失与对抗损失（潜扩散的自编码器）、或者把细节交给后面的扩散模型去生成。
- **Q3：扩散模型的训练损失 $\|\varepsilon - \varepsilon_\theta\|^2$ 是怎么从 ELBO 来的？**
  思路：把 $x_{1:T}$ 当潜变量，加噪过程是固定的编码器 → 负 ELBO 拆成每一步两个高斯的 KL → $q(x_{t-1} \mid x_t, x_0)$ 由条件高斯给出 → 用 $\varepsilon$ 参数化均值，KL 化成加权的 $\|\varepsilon - \varepsilon_\theta\|^2$ → DDPM 去掉权重得到 $L_{\text{simple}}$ → 加分项：VDM 证明连续时间 ELBO 只依赖两端信噪比。
