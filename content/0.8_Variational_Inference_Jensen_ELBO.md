# 0.8 变分推断：Jensen 不等式与 ELBO

> **一句话核心直觉**：潜变量模型的似然 $p(x) = \int p(x \mid z)p(z)\,dz$ 里有一个积分，算不动。挑一个好算的分布 $q(z)$，用 Jensen 不等式得到下界 ELBO $= \mathbb{E}_q[\log p(x \mid z)] - \mathrm{KL}(q \,\|\, p(z))$。它与真实对数似然的差距恰好是 $\mathrm{KL}(q \,\|\, p(z \mid x))$，所以提高 ELBO 就是在拟合数据的同时逼近后验。VAE 用重参数化优化它；扩散模型是一个很深的层次 VAE，它的 ELBO 化简后就是加权的去噪损失。
> **唤醒标签**：$\log p(x) = \text{ELBO} + \mathrm{KL}(q\|p(z \mid x))$ · Jensen：$\log\mathbb{E} \ge \mathbb{E}\log$ · 重建 − KL · 摊销推断 $q_\phi(z \mid x)$ · 重参数化 · 后验坍缩 · 阈值 $\beta\sigma^2$ · 扩散 = 层次 VAE

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

在概率生成模型中，最经典的假设是用低维连续潜变量 $z$ 来解释高维观测数据 $x$ 的生成机制：算法首先从极简的先验分布 $p(z) = \mathcal{N}(0, I)$ 中抽取一个潜编码 $z$，随后交由复杂的非线性深度神经网络（解码器）将其渲染映射为真实的高维图像或文本数据 $x \sim p_\theta(x \mid z)$。

为了训练解码器参数 $\theta$，最标准的统计学习法则是极大似然估计（→ 0.5）。然而，计算观测数据 $x$ 的边际似然概率需要对全量潜空间进行连续积分：

$$
p_\theta(x) = \int p_\theta(x \mid z)\, p(z)\, dz
$$

这构成了阻碍生成模型落地的第一道不可逾越的高墙：潜变量 $z$ 的维度通常高达数十甚至数百维，而被积函数内部深嵌着高度非线性的深度神经网络，全空间微积分根本不存在闭式解析解。更棘手的是，若想推断某张具体图像 $x$ 背后的潜在成因分布（即真实后验概率 $p_\theta(z \mid x) = p_\theta(x \mid z)p(z)/p_\theta(x)$），其分母依然强依赖这个无法计算的边际似然积分。

若诉诸于朴素蒙特卡洛积分：从先验高斯分布中盲目随机抽取海量 $z_i \sim \mathcal{N}(0, I)$，并计算平均解码似然 $\frac1N\sum_i p_\theta(x \mid z_i)$。对于一张特定的真实图像（如一张特定的猫脸），在广袤无垠的高维潜空间中，绝大多数随机构造的白噪声潜向量解码出来的内容与其毫无瓜葛，其观测似然几乎全部精确为 0。这种重要性提议分布与真实目标后验严重脱靶的现象，会导致抽样方差大到彻底不可用（→ 0.7）。

算法迫切需要一个“在审视了具体输入 $x$ 之后、能够精准指示应当在潜空间哪个局部区域进行针对性采样的推断向导”——变分推断分布 $q(z \mid x)$。

**没有变分推断与证据下界（ELBO），就没有经典的变分自编码器（VAE），没有 Stable Diffusion 中将像素图像无损压入紧凑潜空间的自编码压缩器，而现代扩散模型的去噪损失也将沦为一个缺乏统计解释力的启发式经验公式。**

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 换个分布去积分

引入任意一个定义在潜空间上的辅助概率分布 $q(z)$（仅要求在联合密度 $p(x, z) > 0$ 的区域满足 $q(z) > 0$），将无法直接计算的边际似然积分在分子与分母上同时乘以 $q(z)$：

$$
p(x) = \int q(z)\,\frac{p(x, z)}{q(z)}\,dz = \mathbb{E}_{z \sim q}\!\left[\frac{p(x, z)}{q(z)}\right]
$$

这一代数变形在形式上严格对应重要性采样：我们将难以下手的先验积分，等价转化为在任意推断分布 $q(z)$ 下对似然比值 $p(x, z)/q(z)$ 的数学期望。若我们精心设计的辅助分布 $q(z)$ 能够极其逼真地拟合真实后验分布 $p(z \mid x)$，则似然比值 $p(x, z)/q(z) = p(z \mid x)p(x)/q(z) \approx p(x)$ 将趋于平稳常数，其估计方差降至极低。

### 2.2 Jensen：对数的平均 ≤ 平均的对数

由于对数函数 $f(u) = \log u$ 在定义域上严格为凹函数，根据经典琴生（Jensen）不等式，对随机变量求对数后的数学期望，永远小于或等于先求数学期望再取对数：$\mathbb{E}[\log W] \le \log \mathbb{E}[W]$。

将琴生不等式直接施加于上述边际似然的期望表达式（取 $W = p(x, z)/q(z)$）：

$$
\log p(x) = \log \mathbb{E}_{q}\!\left[\frac{p(x, z)}{q(z)}\right] \ge \mathbb{E}_{q}\left[\log \frac{p(x, z)}{q(z)}\right] = \mathbb{E}_{q}\big[\log p(x, z) - \log q(z)\big] \equiv \text{ELBO}(q)
$$

不等式右侧的泛函被称为**证据下界（Evidence Lower Bound, ELBO）**。在贝叶斯统计中，观测数据的对数似然 $\log p(x)$ 被通称为“证据（Evidence）”。

这一不等式带来了决定性的计算突破：只要我们所选择的变分分布 $q(z)$ 易于采样（例如对角高斯分布），且深度网络能够容易地计算联合对数概率 $\log p(x, z)$ 与变分熵 $\log q(z)$，我们便能通过单次或数次随机采样，毫无障碍地构建出证据下界的高效、无偏蒙特卡洛梯度估计！

### 2.3 差距恰好是 KL(q‖后验)

变分下界与真实对数似然之间的误差间隙（Gap），在数学上拥有极其严谨的恒等闭式解：

$$
\log p(x) = \text{ELBO}(q) + \mathrm{KL}\big(q(z) \,\|\, p(z \mid x)\big)
$$

这一恒等式揭示了变分推断的全部奥秘：
- 等式左侧的真实证据 $\log p(x)$ 纯粹由客观数据与生成模型参数决定，与辅助分布 $q$ 毫无关联；
- 因此，当我们在固定生成模型的前提下努力调整变分参数以推高 $\text{ELBO}(q)$ 时，**在代数上完全等价于最小化变分分布 $q(z)$ 与真实后验分布 $p(z \mid x)$ 之间的反向 KL 散度**！

当且仅当变分分布与真实后验完全吻合时，KL 散度归零，证据下界与真实似然完美贴紧重合。这巧妙地将原本无法解析求解的“后验推断微积分难题”，完全化归为一个“可以通过连续梯度反向传播直接求解的凸/非凸优化问题”。

在上方实验中，读者可深入探索变分分布逼近真实后验时的几何行为：
- **线性高斯下的零间隙贴合**：选择「线性模型」预设。由于线性高斯系统的真实后验本身严格是一个单峰高斯分布，当读者将变分高斯分布 $q$ 的均值 $\mu$ 与方差 $\sigma$ 调节至最优解时，$\text{ELBO}$ 与真实对数似然精确重合，二者的数值差距精确为 0.00 nat。
- **非线性 $z^2$ 双峰后验下的模式寻找（Mode-Seeking）**：切换为非线性观测模型 $x = z^2$（观测值 $x = 2$）。由于 $(\pm\sqrt{2})^2 = 2$，真实后验在对称位置 $\pm 1.41$ 各自拥有一个尖锐波峰。
  - 若将单高斯变分分布调节至「抓住一个峰」预设（$\mu \approx 1.41, \sigma \approx 0.2$），变分分布紧紧贴合其中一个模式，其逼近差距稳定在约 0.73 nat（极其接近丢失半数概率质量所带来的理论熵损失 $\ln 2 \approx 0.693$）；
  - 若读者尝试将变分分布强行横跨两侧（「硬盖两个峰」，$\mu = 0$ 且增大 $\sigma$），变分高斯会被迫把海量概率质量抛洒在两峰之间的近零概率谷底深渊中。由于变分推断最小化的是**反向 KL 散度 $\mathrm{KL}(q \,\|\, p)$**，在真实概率稀薄区产生采样会招致无穷大惩罚（→ 0.5 §2.4），导致逼近差距剧烈暴涨至 9.11 nat！这生动证明了单峰变分族在面对多峰后验时，必然展现出极端的单模式聚焦特性。

### 2.4 另一种写法：重建 − 正则

将联合对数概率按条件概率法则展开：$\log p(x, z) = \log p(x \mid z) + \log p(z)$。代入证据下界中重新分组：

$$
\text{ELBO} = \mathbb{E}_{q}\big[\log p(x \mid z) + \log p(z) - \log q(z)\big] = \underbrace{\mathbb{E}_{q}\big[\log p(x \mid z)\big]}_{\text{重构项：解码保真度}} - \underbrace{\mathrm{KL}\big(q(z) \,\|\, p(z)\big)}_{\text{正则化项：潜空间先验规整度}}
$$

这一分解将生成模型的优化目标清晰地重构为两股相互博弈的对立力量：
1. **重构项（Reconstruction Loss）**：要求编码器 $q(z \mid x)$ 提炼出的潜变量 $z$ 必须尽可能保留输入 $x$ 的全部判别特征，使得解码器能够以极高的概率精度将原始样本无损重构还原；
2. **正则项（KL Regularization）**：要求针对每个样本预测出的后验分布 $q(z \mid x)$，不能肆无忌惮地离散漂移，必须受到先验基准分布 $p(z) = \mathcal{N}(0, I)$ 的强力回拉。这保证了在推理生成阶段，我们直接从先验高斯白噪声中采出的任意随机向量，都能准确落在解码器熟悉的有效特征流形内，不至于解码出破碎的乱码。

### 2.5 VAE：摊销推断 + 重参数化

在传统变分推断中，为训练集里的每一个样本单独迭代优化一组专属的变分参数极其低效。**变分自编码器（VAE）**提出了革命性的**摊销推断（Amortized Inference）**架构：使用一个参数共享的深度神经网络（编码器 Encoder）直接预测条件高斯的均值与对数方差：$q_\phi(z \mid x) = \mathcal{N}(\mu_\phi(x), \mathrm{diag}(\sigma_\phi^2(x)))$。

随后，模型利用**重参数化技巧（Reparameterization Trick）**将随机采样重构为 $z = \mu_\phi(x) + \sigma_\phi(x) \odot \varepsilon$（其中 $\varepsilon \sim \mathcal{N}(0, I)$，→ 0.4 §2.4）。重构项在高斯解码器假设下转化为像素级的均方误差 $-\|x - f_\theta(z)\|^2 / (2\sigma^2)$，而对角高斯变分分布与标准高斯先验之间的 KL 散度拥有直接的解析闭式解（→ 0.4 Step 6）。编码器参数 $\phi$ 与解码器参数 $\theta$ 由此得以组装在同一个端到端计算图中，直接利用标准 SGD / Adam 联合最大化 ELBO。

### 2.6 VAE 为什么糊

早期使用 VAE 生成的图像普遍存在肉眼可见的“朦胧塑料感”，其背后存在两个致命的数学机理：

**机理一（后验坍缩与方差阈值截断）**：在线性高斯 VAE 的理论闭式解中（详见 Step 4），数据沿各个正交主方向的真实方差记为 $\lambda_k$。编码该特征方向的收益由数据方差决定，而代价由正则权重 $\beta$ 与解码器方差 $\sigma^2$ 的乘积 $\tau = \beta\sigma^2$ 约束：
- 对于方差微弱的高频特征方向（$\lambda_k \le \beta\sigma^2$），模型判定编码这些维度的微小重建收益根本无法抵偿必须付出的 KL 正则罚分。最优策略是**后验完全坍缩回先验**（$q(z \mid x) \to \mathcal{N}(0, I)$），编码器与解码器将这些高频信息彻底遗弃；
- 仅有方差显著的大尺度低频方向（$\lambda_k > \beta\sigma^2$）得以幸存保留，但其重构幅度依然被系统性收缩为 $(1 - \beta\sigma^2/\lambda_k)$ 倍。

由于自然图像的高频精细纹理（如发丝、毛孔、织物编织纹路）在正交分解中能量极小，它们在训练初期便被 ELBO 判决机制首先无情扼杀。

在上方实验中，调节「解码器噪声方差 σ²」与「β（KL 项权重）」两项关键超参数：
- **方差与权重的乘积支配**：在基准状态（$\sigma^2 = 0.01, \beta = 1$），16 个特征分量中保留了 9 个有效维度，系统保留了 91.5% 的数据方差；将 $\beta$ 调高至 4，活跃特征数骤减至 4 个，保留方差降至 79.8%；若随手将解码器方差设为 $\sigma^2 = 1.0$（许多初学者的默认写法），所有 16 个潜维度将瞬间发生灾难性全量坍缩，重构图像彻底退化为毫无辨识度的平均灰度直线！
- **超参数耦合本质**：$\beta$ 与 $\sigma^2$ 始终以乘积形式出现。随手将 $\sigma^2$ 设大，在数学上等价于为 KL 正则项施加了天文数字般的惩罚系数，强制逼迫整个潜空间全面坍缩。

**机理二（L2 均方误差的平均模糊效应）**：高斯解码器本质上假定像素误差服从独立高斯分布，其极大似然训练等价于最小化 L2 均方重建误差。对于复杂的纹理细节，给定一个模糊的低维编码 $z$，现实中往往存在成百上千种合理但相位微异的高频纹理可能。为了使全局 L2 均方误差最小化，解码器输出的最优解必然是所有可能清晰纹理的加权像素级平均——多张清晰图像在像素级取平均，呈现出来的必然是一团模糊的色块。现代潜扩散模型（Latent Diffusion）正是改用感知损失（Perceptual Loss）与块级判别器（PatchGAN），才彻底打破了这一模糊魔咒。

### 2.7 扩散模型：一个很深的层次 VAE

去噪扩散概率模型（DDPM）在统计物理架构上，可以严谨地视作一个拥有 $T$ 级超深层次结构的特殊马尔可夫 VAE：
- **固定且无参的编码器**：从干净数据 $x_0$ 到纯噪声 $x_T$ 的加噪链条 $q(x_{1:T} \mid x_0)$ 是一个完全确定、无需学习的高斯马尔可夫过程；
- **可学习的参数化解码器**：从纯白噪声 $x_T$ 逐步逆向降噪重构出样本 $x_0$ 的过程 $p_\theta(x_{0:T})$ 是由深度神经网络参数化的去噪链条。

写出该超深层 VAE 的完整变分下界（负 ELBO），由于每一步的状态转移均严格服从条件高斯分布，展开式中的每一项都可以严谨化简为两个已知高斯分布之间的 KL 散度闭式解（Step 5）。最终整个庞大的 ELBO 极其优美地化简为在所有时间步加权累加的“预测注入噪声与真实噪声之间的均方误差”！DDPM 去掉复杂的加权系数并对时间步 $t$ 进行均匀采样，直接诞生了风靡世界的简洁去噪损失 $\|\varepsilon - \varepsilon_\theta(x_t, t)\|^2$。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　Jensen 不等式与下界构造

若实函数 $f$ 在区间上严格为凹函数（例如对数函数 $f(u) = \log u$），对于任意离散或连续随机变量 $W$，其数学期望的函数值永远不小于函数值的数学期望：

$$
f(\mathbb{E}[W]) \ge \mathbb{E}[f(W)]
$$

当且仅当随机变量 $W$ 在概率测度下几乎处处为退化的常数时，等号严格成立。

在边际似然积分中，选取任意合法的提议密度 $q(z)$，定义随机变量比值 $W = \frac{p(x, z)}{q(z)}$，并在变分分布 $z \sim q$ 下求期望：

$$
\log p(x) = \log \mathbb{E}_{z \sim q}\!\left[\frac{p(x, z)}{q(z)}\right] \ge \mathbb{E}_{z \sim q}\left[\log \frac{p(x, z)}{q(z)}\right] \equiv \text{ELBO}(q)
$$

下界取等号的充要条件是比值 $\frac{p(x, z)}{q(z)}$ 与潜变量 $z$ 无关（恒为常数 $C$）。结合归一化条件，这等价于 $q(z) = \frac{p(x, z)}{\int p(x, z')dz'} = p(z \mid x)$，即变分分布必须与真实后验完全一致。

### Step 2　ELBO 与 KL 的恒等式推导

利用联合概率与条件概率的基本代数关系 $p(x, z) = p(z \mid x)\,p(x)$，将真实证据对数 $\log p(x)$ 减去证据下界 $\text{ELBO}(q)$：

$$
\begin{aligned}
\log p(x) - \text{ELBO}(q) &= \log p(x) - \mathbb{E}_{z \sim q}\big[\log p(x, z) - \log q(z)\big] \\
&= \mathbb{E}_{z \sim q}\big[\log p(x) - \log\big(p(z \mid x)\,p(x)\big) + \log q(z)\big] \\
&= \mathbb{E}_{z \sim q}\big[\log p(x) - \log p(z \mid x) - \log p(x) + \log q(z)\big] \\
&= \mathbb{E}_{z \sim q}\left[\log \frac{q(z)}{p(z \mid x)}\right] \\
&= \mathrm{KL}\big(q(z) \,\|\, p(z \mid x)\big)
\end{aligned}
$$

上式中 $\log p(x)$ 完美对消。该恒等式构成了变分推断的最深底层基石：
- 经典的期望最大化算法（EM 算法）正是严格交替应用该恒等式：**E 步**令 $q(z) = p(z \mid x)$，使得 KL 项归零、下界贴紧真实似然；**M 步**固定 $q(z)$，针对模型生成参数 $\theta$ 最大化下界；
- 变分自编码器（VAE）由于深度解码器的复杂性无法在 E 步求出精确后验，因而改用带参编码器网络 $q_\phi(z \mid x)$ 进行近似，通过反向传播将 E 步与 M 步熔接为单次联合端到端梯度更新。

### Step 3　重建项、KL 项与超参 $\sigma^2$ 的耦合

在高斯解码器假设下（假定观测噪声方差为各项同性的 $\sigma^2 I$），单个样本的解码对数似然为：

$$
\log p_\theta(x \mid z) = -\frac{1}{2\sigma^2}\|x - f_\theta(z)\|^2 - \frac{D}{2}\log(2\pi\sigma^2)
$$

代入引入超参数 $\beta$ 的广义变分下界（$\beta$-VAE，标准 ELBO 对应 $\beta = 1$）：

$$
\text{ELBO} = -\frac{1}{2\sigma^2}\,\mathbb{E}_q\big[\|x - f_\theta(z)\|^2\big] - \frac{D}{2}\log(2\pi\sigma^2) - \beta\,\mathrm{KL}\big(q(z \mid x) \,\|\, p(z)\big)
$$

由于常数项与缩放不影响梯度的极值点，将整个优化目标两边同乘常数 $\sigma^2$，等价的目标函数重组为：

$$
-\tfrac12\,\mathbb{E}_q\big[\|x - f_\theta(z)\|^2\big] - \beta\sigma^2\,\mathrm{KL}\big(q(z \mid x) \,\|\, p(z)\big)
$$

该公式揭示了一个在工程实践中极易被忽视的关键规律：**真正决定“重构精度与潜空间压缩度”博弈天平的，是乘积项 $\tau = \beta\sigma^2$**。若工程师在代码实现中随手将解码器方差设为默认的 $\sigma^2 = 1.0$（而非匹配像素真实噪声方差的 $0.01$ 左右），无形中便给正则项施加了百倍量级的超强惩罚，诱发大面积后验坍缩。

### Step 4　线性 VAE 的闭式解与后验坍缩相变

Lucas et al. (2019) 针对一维高斯系统给出了线性 VAE 的全局最优解析解：设数据分布为 $x \sim \mathcal{N}(0, \lambda)$（其中 $\lambda$ 为数据方差），线性编码器为 $q(z \mid x) = \mathcal{N}(vx, s^2)$，线性解码器为 $p(x \mid z) = \mathcal{N}(wz, \sigma^2)$。

记综合有效正则系数 $\tau = \beta\sigma^2$。将各分布代入 Step 3 的目标泛函，对真实数据分布求数学期望，得到关于标量参数 $(w, v, s^2)$ 的优化目标：

$$
J = -\tfrac12\big[(1 - wv)^2\lambda + w^2 s^2\big] - \tfrac{\tau}{2}\big[v^2\lambda + s^2 - 1 - \log s^2\big]
$$

令偏导 $\partial J / \partial s^2 = 0$ 和 $\partial J / \partial v = 0$，解得稳态关系 $s^2 = \tau/c$ 以及 $v = w/c$（其中定义复合方差 $c = w^2 + \tau \ge \tau$）。将该关系代回消元，目标函数化简为仅关于 $c$ 的单一标量函数：$J(c) = -\tfrac{\tau}{2}\big[\lambda/c + \log c\big] + \text{const}$。

在约束区间 $c \ge \tau$ 上求使 $\lambda/c + \log c$ 极小化的全局最优点：
- 当数据方差充足（$\lambda > \tau$）时，极值点在导数为零处取得：$c^* = \lambda$。由此直接反解出非零参数：$w^2 = \lambda - \tau$，$wv = 1 - \tau/\lambda$，潜变量的正则 KL 散度严格等于 $\tfrac12 \log(\lambda / \tau) > 0$；
- 当数据方差微弱（$\lambda \le \tau$）时，函数在定义域边界单调，最优点被迫截断在边界：$c^* = \tau$。此时 $w^2 = 0$（即解码器权重 $w = 0$）。

当 $w = 0$ 时，解码器完全切断了与潜编码 $z$ 的联系，同时编码器输出 $v = 0, s^2 = 1$，退化为固定的先验分布 $\mathcal{N}(0, 1)$。这就是经典的**后验坍缩（Posterior Collapse）**。这一解析解铁证了：坍缩在数学本质上并非优化器的局部陷入 Bug，而是当特征方差低于临界阈值 $\beta\sigma^2$ 时，变分目标函数的全局数学最优解。

### Step 5　扩散模型的 ELBO 化成去噪损失

将扩散模型包含 $T$ 个时间步的完整轨迹 $x_{1:T}$ 视作深度层次潜变量。根据马尔可夫分解，模型的变分负下界可精准展开为各时间步的相对熵之和：

$$
-\text{ELBO} = \mathbb{E}_q\Big[\underbrace{\mathrm{KL}\big(q(x_T \mid x_0)\,\|\,p(x_T)\big)}_{\approx 0 \text{（终态纯高斯先验匹配）}} + \sum_{t > 1}\mathrm{KL}\big(q(x_{t-1} \mid x_t, x_0)\,\|\,p_\theta(x_{t-1} \mid x_t)\big) - \log p_\theta(x_0 \mid x_1)\Big]
$$

根据条件高斯定理（→ 0.4 Step 3），前向高斯马尔可夫链在已知起点 $x_0$ 时的逆向后验分布 $q(x_{t-1} \mid x_t, x_0) = \mathcal{N}(\tilde\mu_t(x_t, x_0), \tilde\beta_t I)$ 具有确切的闭式解析均值：$\tilde\mu_t = \frac{\sqrt{\bar\alpha_{t-1}}\beta_t}{1 - \bar\alpha_t}x_0 + \frac{\sqrt{\alpha_t}(1 - \bar\alpha_{t-1})}{1 - \bar\alpha_t}x_t$。

参数化神经网络解码器 $p_\theta(x_{t-1} \mid x_t) = \mathcal{N}(\mu_\theta(x_t, t), \sigma_t^2 I)$。当两个多元高斯分布的协方差矩阵设定相同时，它们之间的 KL 散度直接化简为两分布均值向量差值的平方欧氏范数：

$$
\mathrm{KL}_t = \frac{\|\tilde\mu_t - \mu_\theta\|^2}{2\sigma_t^2}
$$

将 $x_0 = \frac{1}{\sqrt{\bar\alpha_t}}(x_t - \sqrt{1 - \bar\alpha_t}\varepsilon)$ 代入整理，均值差异整齐地化简为真实注入噪声与网络预测噪声之间的差值：

$$
\mathrm{KL}_t = \frac{\beta_t^2}{2\sigma_t^2\,\alpha_t(1 - \bar\alpha_t)}\,\big\|\varepsilon - \varepsilon_\theta(x_t, t)\big\|^2
$$

DDPM (Ho et al., 2020) 的巨大突破在于：大胆丢弃分母中前置的复杂加权因子，直接采用简化后的等权重均方误差，不仅极大稳定了多步训练动态，反而大幅跃升了生成图像的主观视觉清晰度。

### Step 6　KL 的方向性与潜空间空洞

在变分自编码器中，ELBO 所优化的目标在数学上是**反向 KL 散度 $\mathrm{KL}\big(q_\phi(z \mid x) \,\|\, p(z \mid x)\big)$**。

回顾信息论中的核心结论（→ 0.5 §2.4）：反向 KL 具有强烈的模式寻找（Mode-Seeking）倾向。当预设的单高斯变分族不足以拟合真实复杂的高维多峰后验时，编码器 $q_\phi(z \mid x)$ 会主动收缩其方差，死死收敛并锚定在其中某一个局部主峰周围，而把其余可能的潜在解释完全置空。

这种局部的方差低估带来了 VAE 领域著名的“潜空间空洞（Latent Space Holes）”问题：训练集所有样本通过编码器聚合出的整体聚合后验 $q(z) = \frac{1}{N}\sum_i q_\phi(z \mid x_i)$，在先验空间 $\mathcal{N}(0, I)$ 中留下大量未被任何真实样本后验覆盖过的空洞盲区。当生成阶段直接从标准高斯先验中随机采样到这些空洞区域时，解码器便会输出失真或模糊的非真实假样本。现代潜扩散模型（Latent Diffusion）正是利用后续强大的连续扩散过程在潜空间上重新建模，才彻底弥合了这些由变分推断留下的拓扑空洞。

ELBO 最小化的是 $\mathrm{KL}(q \,\|\, p(z \mid x))$：在 $q$ 有质量而后验没有的地方惩罚极重，在后验有质量而 $q$ 没有的地方几乎不罚。所以近似族不够灵活时，$q$ 会缩在后验的一个峰里，方差偏小（→ 0.5 的反向 KL）。这也是 VAE 的潜空间里会出现"空洞"的原因之一：先验认为有概率的区域，未必有哪个 $q(z \mid x)$ 覆盖过。

## 4. 极简代码锚点（PyTorch）

```python
import math
import torch
import torch.nn as nn
torch.manual_seed(0)

# 1. 验证 log p(x) = ELBO + KL(q‖p(z|x))：一维 z² 模型，网格积分
def log_normal(x, m, s):
    return -0.5 * math.log(2 * math.pi) - math.log(s) - 0.5 * ((x - m) / s) ** 2

x, sx = 2.0, 0.6
z = torch.linspace(-6, 6, 24001, dtype=torch.float64)
dz = z[1] - z[0]
log_joint = log_normal(x, z ** 2, sx) + log_normal(z, 0.0, 1.0)      # log p(x, z)
log_px = torch.logsumexp(log_joint, 0) + torch.log(dz)
mu, s = 1.4, 0.2                                                     # q 贴住右边的峰
log_q = log_normal(z, mu, s)
q = log_q.exp()
elbo = (q * (log_joint - log_q)).sum() * dz
kl_post = (q * (log_q - (log_joint - log_px))).sum() * dz
print(log_px.item(), elbo.item(), (log_px - elbo).item(), kl_post.item())   # 后两个相等（≈ 0.84）

# 2. 最小 VAE：重参数化 + 闭式 KL，sigma2 和 beta 一起决定取舍
class VAE(nn.Module):
    def __init__(self, d=784, h=256, k=16):
        super().__init__()
        self.enc = nn.Sequential(nn.Linear(d, h), nn.ReLU(), nn.Linear(h, 2 * k))
        self.dec = nn.Sequential(nn.Linear(k, h), nn.ReLU(), nn.Linear(h, d))

    def forward(self, x, beta=1.0, sigma2=0.01):
        mu, logvar = self.enc(x).chunk(2, dim=-1)
        z = mu + (0.5 * logvar).exp() * torch.randn_like(mu)        # 重参数化
        rec = -((x - self.dec(z)) ** 2).sum(-1) / (2 * sigma2)      # log p(x|z)，省略常数
        kl = 0.5 * (logvar.exp() + mu ** 2 - 1 - logvar)            # 每个潜维度的 KL
        loss = -(rec - beta * kl.sum(-1)).mean()                    # 最小化 −ELBO
        return loss, kl.mean(0)

vae = VAE()
opt = torch.optim.Adam(vae.parameters(), lr=1e-3)
# 合成数据：4 个强方向（每个方差 λ ≈ 7.8）+ 各向同性弱噪声（方差 0.0025 < βσ² = 0.01）
W = torch.randn(4, 784) * 0.1
for step in range(5000):
    x = torch.randn(64, 4) @ W + 0.05 * torch.randn(64, 784)    # 每步新采样，避免背下训练集里的噪声
    loss, kl_per_dim = vae(x)
    opt.zero_grad(); loss.backward(); opt.step()
print(kl_per_dim.detach().sort(descending=True).values[:6])
# 4 个维度的 KL ≈ 3.4，接近闭式解 ½ln(λ/βσ²) = ½ln(7.8/0.01) ≈ 3.3；其余 12 个坍缩到先验，KL ≈ 0

# 3. 线性 VAE 的闭式解：方差低于 βσ² 的方向整个坍缩，其余按 1 − βσ²/λ 缩小
lam = torch.tensor([1.0, 0.3, 0.05, 0.01, 0.002])            # 数据各主方向的方差
for tau in [1e-3, 1e-2, 1e-1]:                               # tau = βσ²
    shrink = (1 - tau / lam).clamp(min=0)
    rate = 0.5 * torch.log((lam / tau).clamp(min=1)).sum()
    print(tau, shrink.numpy().round(3), round(rate.item(), 2))
```

### 数值复算 · 用可解的后验检查 ELBO 的差距

在同一个 Python 会话中先运行本节上方的实现，再运行以下算例。

```python
import torch
from torch.distributions import Normal, kl_divergence
v, m = 0.36/1.36, 2/1.36
post = Normal(torch.tensor(m, dtype=torch.float64), v**0.5)
for offset in [0., 0.25, 0.5]:
    approx = Normal(post.loc + offset, post.scale)
    gap = kl_divergence(approx, post)
    assert abs(gap.item() - offset**2/(2*v)) < 1e-10
    print(f"均值偏移={offset:.2f}  ELBO 差距={gap:.3f} nat")
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **潜空间生成依赖自编码器，但 KL 只是配角**。潜扩散模型先用自编码器把图像压到低维潜空间，再在潜空间里做扩散。它的自编码器只带很弱的 KL 惩罚，作用是把潜变量的尺度管住；重建的清晰度主要来自感知损失和基于图像块的对抗损失，正是为了绕开 §2.6 说的模糊。
- **扩散训练目标被理解成"加权的 ELBO"**。VDM 把不同的损失写法统一成对信噪比的加权积分。今天调扩散和流模型，很大一部分工作是在选这个权重，以及在哪些噪声水平上多采样（→ 0.4、4.2）。
- **变分视角也出现在后训练里**。带 KL 正则的奖励最大化 $\max_\pi \mathbb{E}_\pi[r] - \beta\,\mathrm{KL}(\pi \,\|\, \pi_{\text{ref}})$，等价于最小化 $\mathrm{KL}(\pi \,\|\, \pi^*)$，其中 $\pi^* \propto \pi_{\text{ref}}\, e^{r/\beta}$ 扮演"后验"的角色。DPO 的推导就是从这个最优解出发的（→ 2.4）。

**与工程 / 应用的连接**
- **监控每个潜维度的 KL**：KL 接近 0 的维度已经坍缩、不传任何信息。"活跃维度数"比总 loss 更能说明编码器有没有在工作。
- **强解码器的后验坍缩**：解码器是自回归模型（例如一个语言模型）时，它不看 $z$ 也能把 $x$ 建模得很好，KL 项会把 $z$ 整个推回先验。常见对策是 KL 退火（训练初期 $\beta$ 从 0 慢慢升到 1）和 free bits（每个维度的 KL 低于某个值时不罚）。
- **$\beta$ 的两个方向**：$\beta > 1$ 压缩更狠，潜变量更容易对应可解释的因素（β-VAE），代价是更糊；$\beta < 1$ 重建更清晰，但先验采样的质量变差，因为 $q$ 离先验更远了。
- **解码器方差别随手设成 1**：图像像素归一化到 $[0, 1]$ 时，$\sigma^2 = 1$ 意味着 KL 的相对权重非常大，几乎所有细节都会坍缩（实验里 $\sigma^2 = 1$ 的预设）。

**常见误区 / 反直觉点**
1. **"ELBO 涨了，说明 $q$ 更接近后验"** ✗：只有固定模型参数 $\theta$ 时才成立。联合训练时，ELBO 上涨也可能来自模型把自己的后验"掰"得更像高斯，好让 $q$ 贴上去，而真实似然未必变好。
2. **"VAE 糊全是 KL 项的错"** ✗：高斯解码器对多种合理细节取平均，同样会糊；而且决定取舍的是 $\beta\sigma^2$，不只是 $\beta$。
3. **"后验坍缩一定是 bug"** ✗：方差低于 $\beta\sigma^2$ 的方向，坍缩正是 ELBO 的最优解。真正的问题是 $\beta\sigma^2$ 设得太大，或者解码器强到不需要 $z$。
4. **"扩散模型的训练目标就是 ELBO"** ✗：DDPM 的 $L_{\text{simple}}$ 去掉了 ELBO 的权重，是一个重新加权的版本。按 ELBO 的权重训练似然更好，按简化权重训练样本质量更好。

**高频深挖题**
- **Q1：推导 ELBO，并说明它和 $\log p(x)$ 差在哪里。**
  思路：$p(x) = \mathbb{E}_q[p(x,z)/q(z)]$ → Jensen 得下界 → 用 $p(x, z) = p(z \mid x)p(x)$ 证明差距是 $\mathrm{KL}(q\|p(z \mid x))$ → 取等号当且仅当 $q$ 是真实后验 → 加分项：差距来自近似族不够灵活和摊销误差两部分；最小化的是反向 KL，$q$ 倾向于抓住一个峰。
- **Q2：VAE 生成的图像为什么模糊？怎么缓解？**
  思路：高斯解码器 + L2 重建，对不确定的细节取平均 → KL 代价让方差低于 $\beta\sigma^2$ 的方向坍缩，高频细节最先被丢（线性 VAE 闭式解）→ 缓解：减小 $\beta\sigma^2$、更灵活的后验和先验、感知损失与对抗损失（潜扩散的自编码器）、或者把细节交给后面的扩散模型去生成。
- **Q3：扩散模型的训练损失 $\|\varepsilon - \varepsilon_\theta\|^2$ 是怎么从 ELBO 来的？**
  思路：把 $x_{1:T}$ 当潜变量，加噪过程是固定的编码器 → 负 ELBO 拆成每一步两个高斯的 KL → $q(x_{t-1} \mid x_t, x_0)$ 由条件高斯给出 → 用 $\varepsilon$ 参数化均值，KL 化成加权的 $\|\varepsilon - \varepsilon_\theta\|^2$ → DDPM 去掉权重得到 $L_{\text{simple}}$ → 加分项：VDM 证明连续时间 ELBO 只依赖两端信噪比。
