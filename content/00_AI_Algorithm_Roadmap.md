## 2. 全局约定

**记号（全部篇目统一）**

| 符号 | 含义 | 符号 | 含义 |
|---|---|---|---|
| B, L, D | batch、序列长度、模型宽度 | N, T | 参数量、训练 token 数 |
| H, H_kv, d_h | Q 头数、KV 头数、每头维度 | E, k | 专家总数、每 token 激活专家数 |

**写作口径**
- 每篇按六段模板输出；跨篇引用写成 `→ 2.3 §3`。
- 代码锚点只负责把公式落到张量维度上，不追求可复现组件。每篇真正的产出是第 5 节里**能扛住三层追问的判断**。
- 每篇第 5 节增加 **「2026 前沿现状」**：这项技术在当前一线模型里的真实落地形态。所有篇目生成前都先查一手材料（技术报告、模型卡、官方规格）；1.6、2.5–2.7、3.3 变化最快，查得最细。
- **DeepSeek-V4 的统一口径**：各篇引用的 V4 架构、训练与后训练细节均取自其 preview 版技术报告（arXiv 2606.19348）。正式版的后训练流程与 preview 不同，涉及后训练和评测数字时以正式版说明为准。

**优先级口径**
- P0 / P1 按「LLM + 后训练 + Agent」算法岗主线判定。
- 目标若是后训练 / RL 岗：2.7 升 P0。
- 目标若是 AIGC / 多模态生成岗：M4 全部与 3.1、3.3 升 P0，1.6、2.7 降为选读。
- **[熟区]**：你已有一线深度的部分。不做唤醒，只做面试表达化，读速 ×2。
- **[Agent]**：与 Agent 工程经验强耦合，读时优先建立映射。

## 3. 模块详解

### M1 · LLM 现代架构与底层几何直觉（6 篇 · ≈10h）

**学完能做出的判断**
- 任一架构改动，都能从两个视角说出动机：**残差流上信息和梯度怎么走**、**显存带宽被谁吃掉**。
- 能用数字回答"为什么这个模型选 GQA / MLA / MoE"：KV cache 压缩比、激活参数比、通信代价。

| # | 篇目 | 核心闭环（这一篇要打通的那条链） | 应用侧锚点 | 级别 | 时长 |
|---|---|---|---|---|---|
| 1.1 | 残差流、Pre-LN 与 RMSNorm | 残差流是共享总线，Attention / FFN 是读写它的模块 → Post-LN 把归一化挡在梯度高速公路上，深了就训不动 → Pre-LN 让恒等路径直通，代价是深层贡献被稀释 → RMSNorm 只去掉"减均值"，为什么几乎无损 | 为什么中间层能拿来做 embedding / early-exit / 层剪枝 | P0 | 2h |
| 1.2 | RoPE 频率谱与外推 **[熟区]** | 旋转把绝对位置变成相对相位差 → 每对维度是一只转速不同的钟 → 低频钟在训练长度内没转完一圈，是外推崩的根因 → PI / NTK-aware / YaRN 各改了谱的哪一段 | 标称 128K、实际可用长度短；长上下文"中段遗忘" | P0 | 1h |
| 1.3 | KV Cache、GQA 与 MLA | decode 每步把整份 KV 搬一遍 → 带宽受限而非算力受限 → MQA / GQA 砍 KV 头数 → MLA 压成低秩 latent + 推理时矩阵吸收 → RoPE 与吸收冲突，所以要 decoupled RoPE | prefix cache 命中率、单卡并发上限、每 token 成本 | P0 | 2h |
| 1.4 | MoE 路由与负载均衡 | 参数量与计算量解耦 → 路由正反馈导致专家坍塌 → 辅助损失 vs 无辅助损失的 bias 调节 → 细粒度 + 共享专家 → 专家并行的 all-to-all 代价 | 显存按总参数算、吞吐按激活参数算；小 batch 时负载不均引起延迟抖动 | P0 | 2h |
| 1.5 | FlashAttention 与 IO 感知 | 注意力的瓶颈是 L² 中间矩阵在 HBM 上的读写，不是 FLOPs → 分块 + online softmax 让 softmax 可拆 → 反向用重算换显存 → 结果精确，只改访存 | 长 prompt 的 prefill 延迟；为什么 FA 不影响输出质量 | P0 | 1.5h |
| 1.6 | 稀疏 / 线性 / 混合注意力 | 线性注意力 = 把 KV cache 压成固定大小状态（RNN 化）→ 代价是精确召回 → 稀疏选择 vs 状态压缩两条路 → 为什么出现"少量全注意力层 + 大量线性 / 稀疏层"的混合架构 | 超长上下文 Agent 的成本曲线；大海捞针 vs 状态压缩 | P1 | 1.5h |

### M2 · 大模型后训练与强化学习 ★ 核心（7 篇 · ≈17.5h）

**学完能做出的判断**
- 能在一张图里画出 KL 正则 RL 目标 $\max_\pi \mathbb{E}[r] - \beta\,\mathrm{KL}(\pi\,\|\,\pi_{\text{ref}})$，并指出 SFT / PPO / DPO / GRPO 各是它的哪种近似、退化或工程替代。
- 能手推 PPO-clip 与 DPO 闭式解，说出每一步省掉了什么、付出了什么。
- 看到 RL 训练曲线异常（reward ↑ 但评测 ↓、熵骤降、长度爆炸）能给出前三个嫌疑。
- 能把 Agent 工程里的决定（上下文、工具、harness、评测）翻译成 RL 语言：状态表示、动作空间、环境、奖励、信用分配。

| # | 篇目 | 核心闭环 | 应用侧锚点 | 级别 | 时长 |
|---|---|---|---|---|---|
| 2.1 | SFT 与蒸馏的本质 | SFT = 最小化对示范分布的 forward KL（mode-covering，"每种示范都学一点"）→ 格式与幻觉风格一并学走 → loss mask、数据配比与遗忘 → off-policy 蒸馏 vs on-policy 蒸馏（学生在自己的分布上被老师逐 token 纠正） | 微调后"变笨"、格式漂移；蒸馏小模型推理强但泛化窄 | P0 | 2h |
| 2.2 | RLHF 全链路与 Reward Hacking | Bradley-Terry 把偏好变标量 → RM 只是人类偏好的有偏代理 → 优化越狠偏离越大（过优化曲线）→ KL 惩罚是拴住策略的绳 | 谄媚、冗长、"看起来很有帮助"：都是 RM 被钻空子的症状 | P0 | 2h |
| 2.3 | 从策略梯度到 PPO | log-derivative trick → REINFORCE 方差大 → baseline / advantage / GAE 降方差 → 重要性采样复用数据 → ratio 失控 → clip 当信任域的廉价替代 → LLM 里的 token 级 MDP 与四个模型 | 为什么 RLHF 的显存账是 SFT 的数倍 | P0 | 3h |
| 2.4 | DPO：推导与局限 | KL 正则 RL 有闭式最优解 → 反解出"奖励 = β·log 概率比" → 代入 BT，配分函数相消 → 一个二分类 loss；局限：离线分布外、chosen 概率也下降、长度偏置；IPO / SimPO / KTO 各修哪一处 | 为什么偏好 / 风格对齐常用 DPO，推理能力仍靠在线 RL | P0 | 2.5h |
| 2.5 | GRPO、RLVR 与推理模型 | 去掉 critic，用同题多采样的组内相对分作 baseline → 可验证奖励压缩 hacking 空间 → R1-Zero 的长度增长与"aha" → DAPO / Dr.GRPO / GSPO 分别修了 GRPO 的哪个偏差 | 思考 token 消耗、overthinking；推理模型在开放任务上未必更好 | P0 | 3h |
| 2.6 | Agentic RL **[Agent]** | 单轮 bandit → 多轮 POMDP：工具 / 环境返回作 observation 且不计 loss → 长轨迹信用分配、稀疏结果奖励 vs 过程奖励 → rollout 成本由环境延迟主导 → 与 2.5 的逐项差异 | 你在 harness / 工具 / 上下文上做的每个决定，在这里都变成环境设计或状态表示 | P0 | 3h |
| 2.7 | RL 系统与训练稳定性 **[Agent]** | rollout 占大头 → 训推分离与异步 off-policy → 推理引擎与训练框架的 logprob 不一致 → 重要性修正 → 熵坍塌 / 熵爆炸的监控与干预 → 为什么 MoE 上 RL 更难稳 | 推理引擎的精度、采样参数、批处理不确定性如何污染训练信号 | P1 | 2h |

### M3 · 多模态表征与视觉-语言对齐（3 篇 · ≈5.5h）

- 画出主流 VLM 的数据流，说清分辨率、视觉 token 数、各训练阶段解冻什么的取舍。
- 判断"拼接式 VLM"与"原生多模态"的根本分歧在哪。

| # | 篇目 | 核心闭环 | 应用侧锚点 | 级别 | 时长 |
|---|---|---|---|---|---|
| 3.1 | 视觉表征三条路：CLIP / DINO / MAE **[熟区：DINO 部分]** | InfoNCE = batch 内 N 选 1 分类（温度与 batch size 为何关键）→ DINO 用自蒸馏 + centering / sharpening 防坍塌，patch 特征天然可分割 → MAE 学低层重建，需微调才好用 | 为什么 VLM 选 CLIP / SigLIP 系编码器，以图搜图 / 密集预测常选 DINO 系 | P1 | 2h |

| 3.3 | 原生多模态与统一理解生成 | 早融合离散 token vs 自回归 + 扩散混合 vs 理解 / 生成解耦编码器 → 理解要语义、生成要像素细节，这对矛盾决定了架构分歧 | 同一模型"看图准、画图一般"或反之 | P1 | 1.5h |

### M4 · AIGC 生成模型核心范式（4 篇 · ≈8h）

**学完能做出的判断**
- 用"把噪声分布搬运成数据分布"一个画面，统一 DDPM、score SDE、Flow Matching。
- 手推 ε 预测与 score 的等价、CFG 的贝叶斯来源。
- 解释 DiT / MM-DiT 为什么取代 U-Net，adaLN 在干什么。

| # | 篇目 | 核心闭环 | 应用侧锚点 | 级别 | 时长 |
|---|---|---|---|---|---|
| 4.1 | DDPM → DDIM → SDE / ODE | 前向加噪有闭式 → 预测噪声 ≈ 学 score → DDIM 把随机采样变成确定性 ODE，所以能跳步 → SDE 视角下两者是同一件事的不同离散化 | 采样步数 ↔ 质量 ↔ 延迟 | P1 | 2.5h |
| 4.2 | Flow Matching / Rectified Flow | 直接回归"从噪声指向数据"的速度场 → 条件 FM 把算不了的边际目标换成算得了的条件目标 → 路径越直、步数越少 → **可跳过 4.1 直接读**：先懂 FM 再回看 DDPM 是更短的路 | SD3 / Flux 级图像模型、语音与机器人动作生成头 | P0 | 2.5h |
| 4.3 | CFG 与少步采样 | CFG = 沿"条件 − 无条件"方向外推（放大 ∇log p(c\|x)）→ guidance scale 是多样性 ↔ 贴合度旋钮 → 训练时条件 dropout 一模两用 → 蒸馏 / 一致性模型压步数 | 调 guidance 时的过饱和；提示跟随 vs 画面崩 | P1 | 1.5h |
| 4.4 | DiT 与 MM-DiT | 在 VAE latent 上 patchify + Transformer → adaLN-Zero：条件注入为逐层缩放平移，零初始化 = 恒等起步 → MM-DiT：文本 / 图像各一套权重、联合注意力 → 视频 = 时空 patch | 分辨率 / 时长与 token 数、注意力成本的关系 → 视频生成为何贵 | P1 | 1.5h |

|---|---|---|---|---|---|
| 5.1 | 显存与算力手算 | 训练显存 = 权重 + 梯度 + 优化器（混合精度 Adam ≈ 16 B/参数）+ 激活 → 训练 ≈ 6NT、推理 ≈ 2N / token → KV cache 公式 → 算术强度与 roofline：prefill 算力受限、decode 带宽受限 | 一张卡能跑多大模型、多少并发 | P0 | 2h |

| 5.3 | 训练诊断：Loss 曲线与数值稳定 | spike / 平台 / 发散 / 下游不涨各自的前三嫌疑（学习率与 warmup、坏数据批次、数值溢出、attention logit 增长）→ 对应干预（QK-norm、z-loss、梯度裁剪、跳批回滚）→ BF16 / FP8 的坑、WSD 调度 | 排查 Agent trace 的方法论如何迁移到读 loss 曲线 | P0 | 2h |

| 5.5 | 应用岗 → 算法岗的面试桥梁 | 应用经验到算法语言的映射表（上下文管理 ↔ 长上下文 / KV 架构；工具与 harness ↔ RL 环境与动作空间；评测与 trace ↔ RM / verifier 与数据飞轮）→ 算法面试的三层追问结构 → 把追问引向强项 | 本篇就是全套资料"应用侧锚点"一列的汇总 | P0 | 1h |

## 5. 推荐切入顺序：重燃路径

**设计逻辑**：不从 1.1 开始。先从你在推理侧已有体感的地方切入，第一阶段就让"症状 → 根因"接上；带着这股势能进入最核心的后训练线；最后补训练者视角与生成 / 多模态。

| 阶段 | 顺序 | 这一阶段只回答一个问题 | 为什么这样排 | 时长 |
|---|---|---|---|---|
| **A** 约第 1 周 | 5.1 → 1.3 → 1.5 → 1.2 | 推理为什么慢、为什么贵？答案几乎都是**搬数据**，不是算 | prefix cache、并发上限这些你在应用侧已经碰过，这里只补根因，正反馈最快；5.1 的公式后面每篇都复用；1.2 排在 1.3 后面，因为 MLA 的 decoupled RoPE 正好是你熟区和新知识的接口 | 6.5h |
| **B** 约第 2–3 周 | 2.3 → 2.5 → 2.6 → 2.2 → 2.4 → 2.1 →（2.7） | 后训练的脊柱是什么？KL 正则 RL 目标 | 先立脊柱（PPO），紧接着读最热、也离你 Agent 工作最近的 GRPO 与 Agentic RL；再回头读 RLHF / DPO / SFT，此时它们都是"已知目标的某种近似"，读得很快 | 17.5h |
| **C** 约第 4 周 | 5.4 → 5.3 → 1.1 → 1.4 → 1.6 → 5.2 | 怎么知道训对了、挂了怎么查、怎么切到多卡上？ | 5.4 紧跟 RL 线，因为 RL 实验最容易被噪声骗；1.1 与诊断、1.4 与分布式天然成对 | 12h |
