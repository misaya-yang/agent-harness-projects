## 3. 模块详解

### M0 · 数学基础：AIGC 与后训练的公式从哪来（9 篇 · ≈20.5h）

**学完能做出的判断**
- 看到一个矩阵运算，能说出它在几何上做了什么：哪些方向被拉伸、哪些被压扁，低秩近似丢掉了什么。
- 看到任何一个 loss，都能说出它在最大化谁的似然、最小化哪个方向的 KL，以及梯度怎样沿计算图流回每个参数。
- 能用高斯分布、score 与随机微分方程，一口气讲清扩散模型从加噪、训练到采样的每一步为什么成立。

| # | 篇目 | 核心闭环 | 应用侧锚点 | 级别 | 时长 |
|---|---|---|---|---|---|
| 0.1 | 线性代数：矩阵即变换 | 矩阵 = 线性变换，列是基向量的去向 → 特征分解给出不变方向，SVD 把任意矩阵拆成"旋转-拉伸-旋转" → 奇异值决定谱范数与条件数 → 截断 SVD 是最优低秩近似 → 低秩、正交化与谱范数贯穿 LoRA、MLA、Muon | LoRA 为什么只要很小的秩；MLA 怎么压 KV；Muon 为什么要正交化 | P0 | 2.5h |
| 0.2 | 微积分：梯度、链式法则与反向传播 | 导数 = 最好的局部线性近似 → 梯度指向上升最快的方向，与等高线垂直 → 多元链式法则 = Jacobian 相乘 → 反向模式从标量 loss 出发，一次求出全部参数的梯度，代价约为前向的 2 倍 → 反向要用前向的中间结果，所以训练时要缓存激活 | 训练显存为什么是推理的数倍；梯度消失与爆炸从哪来；activation checkpointing 的取舍 | P0 | 2.5h |
| 0.3 | 概率论：条件概率、贝叶斯与大数定律 | 随机变量与分布 → 期望的线性性与方差 → 条件概率与贝叶斯公式：后验 ∝ 似然 × 先验 → 链式法则把联合分布拆成条件分布的乘积，这就是自回归 → 大数定律与中心极限定理：误差按 1/√n 缩小 | 评测分数的误差棒；AI 文本检测器为什么误报多；小批量梯度为什么能用 | P0 | 2.5h |
| 0.4 | 高斯分布：协方差几何与重参数化 | 一维高斯 → 多元高斯：协方差的特征向量是等高线椭圆的主轴 → 线性变换后仍是高斯：x = μ + Lε → 边缘与条件分布仍是高斯 → 重参数化让采样可以求导 → 扩散前向加噪 q(x_t∣x_0) 一步写出 | VAE 和扩散为什么离不开高斯；噪声调度为什么要看信噪比 | P0 | 2h |
| 0.5 | 信息论：熵、交叉熵、KL 与极大似然 | 熵 = 平均意外程度 → 交叉熵 = 熵 + KL，所以 loss 的下界是数据熵而不是 0 → 极大似然 ⇔ 最小化前向 KL → 前向 KL 覆盖所有模式、反向 KL 只抓一个模式 → 困惑度 = e^loss，温度改的是分布的熵 | 困惑度怎么读；SFT 与 RLHF 的 KL 为什么方向相反；温度为什么改变"创造力" | P0 | 2h |
| 0.6 | 优化：条件数、动量与 AdamW | 梯度下降 = 在某种范数下走最陡的一步 → 条件数大时 SGD 之字形震荡，步长被最大曲率卡住 → 动量是梯度的指数滑动平均 → Adam 逐元素归一化 ≈ 符号下降 → AdamW 把权重衰减从梯度里解耦 | 学习率与 batch size 怎么一起调；为什么权重衰减不能直接加进 Adam 的梯度 | P0 | 2h |
| 0.7 | 采样：蒙特卡洛、score 与 Langevin | 用样本均值估期望，误差按 1/√n 下降 → 重要性采样换一个提议分布，方差取决于两者重叠得多好 → score = ∇log p 与归一化常数无关 → Langevin 动力学沿 score 走一步再加噪声，从任意起点采到目标分布 → 多个噪声级别的 score 就是扩散模型要学的东西 | 扩散模型为什么学 score 而不是密度；off-policy 修正的方差从哪来 | P1 | 2.5h |
| 0.8 | 变分推断：Jensen 不等式与 ELBO | 边缘似然里有积分，算不动 → Jensen 不等式给出下界 ELBO → ELBO = 重建项 − KL(q‖p)，与真实对数似然的差距正好是 KL(q‖后验) → VAE 用重参数化优化 ELBO → 扩散模型是一个很深的层次 VAE | VAE 为什么糊；扩散的训练目标为什么是加权去噪损失 | P1 | 2h |
| 0.9 | 随机微分方程：布朗运动与概率流 ODE | 随机游走的极限是布朗运动，方差随时间线性增长 → SDE = 漂移 + 扩散 → 前向加噪 SDE 有对应的反向去噪 SDE，只差一个 score 项 → Fokker–Planck 方程描述密度怎么演化 → 同一族边缘分布对应一条确定性的概率流 ODE，这是 DDIM 与 Flow Matching 的出发点 | 采样器为什么能"跳步"；ODE 采样与 SDE 采样怎么选 | P1 | 2.5h |

### M1 · LLM 现代架构与底层几何直觉（9 篇 · ≈15.5h）

**学完能做出的判断**
- 任一架构改动，都能从两个视角说出动机：**残差流上信息和梯度怎么走**、**显存带宽被谁吃掉**。
- 能用数字回答"为什么这个模型选 GQA / MLA / MoE"：KV cache 压缩比、激活参数比、通信代价。

| # | 篇目 | 核心闭环（这一篇要打通的那条链） | 应用侧锚点 | 级别 | 时长 |
|---|---|---|---|---|---|
| 1.0 | 注意力与 Transformer Block 从零推导 | 用 query 对一组 key 做软寻址 → 除以 √d 防止 softmax 饱和 → 多头 = 多个子空间并行寻址 → 因果掩码让训练可以并行 → Block = 注意力 + FFN + 残差 + 归一化 → 参数量 ≈ 12·L·D² | 手写 MHA；参数量估算题；为什么上下文越长越贵 | P0 | 2.5h |
| 1.1 | 残差流、Pre-LN 与 RMSNorm | 残差流是共享总线，Attention / FFN 是读写它的模块 → Post-LN 把归一化挡在梯度高速公路上，深了就训不动 → Pre-LN 让恒等路径直通，代价是深层贡献被稀释 → RMSNorm 只去掉"减均值"，为什么几乎无损 | 为什么中间层能拿来做 embedding / early-exit / 层剪枝 | P0 | 2h |
| 1.2 | RoPE 频率谱与外推 **[熟区]** | 旋转把绝对位置变成相对相位差 → 每对维度是一只转速不同的钟 → 低频钟在训练长度内没转完一圈，是外推崩的根因 → PI / NTK-aware / YaRN 各改了谱的哪一段 | 标称 128K、实际可用长度短；长上下文"中段遗忘" | P0 | 1h |
| 1.3 | KV Cache、GQA 与 MLA | decode 每步把整份 KV 搬一遍 → 带宽受限而非算力受限 → MQA / GQA 砍 KV 头数 → MLA 压成低秩 latent + 推理时矩阵吸收 → RoPE 与吸收冲突，所以要 decoupled RoPE | prefix cache 命中率、单卡并发上限、每 token 成本 | P0 | 2h |
| 1.4 | MoE 路由与负载均衡 | 参数量与计算量解耦 → 路由正反馈导致专家坍塌 → 辅助损失 vs 无辅助损失的 bias 调节 → 细粒度 + 共享专家 → 专家并行的 all-to-all 代价 | 显存按总参数算、吞吐按激活参数算；小 batch 时负载不均引起延迟抖动 | P0 | 2h |
| 1.5 | FlashAttention 与 IO 感知 | 注意力的瓶颈是 L² 中间矩阵在 HBM 上的读写，不是 FLOPs → 分块 + online softmax 让 softmax 可拆 → 反向用重算换显存 → 结果精确，只改访存 | 长 prompt 的 prefill 延迟；为什么 FA 不影响输出质量 | P0 | 1.5h |

### M8 · 检索、记忆与 Agent 系统（4 篇 · ≈6.5h）

**学完能做出的判断**
- 定位一个 RAG 系统答错时，错在召回、重排、上下文利用还是生成。
- 说清向量索引的召回率、延迟和内存三者怎么权衡。
- 把 Agent 的上下文管理和记忆设计，翻译成信息论和检索问题来讨论。

**学完能做出的判断**
