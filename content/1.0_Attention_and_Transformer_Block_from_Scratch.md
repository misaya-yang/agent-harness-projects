# 1.0 注意力与 Transformer Block 从零推导

> **一句话核心直觉**：注意力让每个位置用一个 query 去给所有位置的 key 打分，再按 softmax 权重把 value 加权平均：这是一本可以求导的"软字典"。除以 $\sqrt{d}$ 是为了让分数的尺度不随维度变大，否则 softmax 退化成 one-hot，只有排第一的 key 能拿到梯度。多头 = 多个低秩的"关系"并行查询；因果掩码让一次前向同时训练 $T$ 个预测，也正是它让 KV cache 成立。一个块 = 注意力负责 token 之间交流 + FFN 负责每个 token 各自计算；参数量约 $12LD^2$，上下文超过几万 token 后，注意力的 FLOPs 反超所有矩阵乘。
> **唤醒标签**：$\mathrm{softmax}(QK^\top/\sqrt{d})V$ · $\partial L/\partial s_j = p_j\, g^\top(v_j - \bar y)$ · $\mathrm{Var}(q\cdot k) = d$ · $W_Q^\top W_K$ 秩 $\le d_{\text{head}}$ · 因果掩码 ⇒ KV cache · $12LD^2$ · Llama-3-8B = 8,030,261,248 · 每 token 注意力 $4LtD$ · 归纳头

## 1. 问题：一组向量怎样互相读取信息？

一句话进入模型后，先变成 $T$ 个向量 $x_1, \dots, x_T \in \mathbb{R}^D$（→ 1.8）。但单个 token 的含义取决于上下文：

> The animal didn't cross the street because **it** was too tired.

处理 "it" 时，模型需要从 "animal" 那里取信息；把 tired 换成 wide，"it" 就该指向 "street"。所以我们要一种运算，让每个位置去别的位置取信息，并满足四个条件：

1. **长度可变**：同一组参数要能处理 10 个 token，也要能处理 10 万个。
2. **按内容寻址**：去哪儿取，取决于两个位置的内容，而不是固定的距离。"it" 和 "animal" 之间可能隔 3 个词，也可能隔 300 个。
3. **能并行**：训练时 $T$ 个位置要能同时算，GPU 才吃得饱。
4. **可求导**：寻址本身要能被梯度训练。

先看三个自然的尝试，各自卡在哪里：

| 尝试 | 做法 | 卡在哪里 |
|---|---|---|
| 全连接 | 把 $T$ 个向量拼成一个长向量，过 MLP | 输入长度固定；"第 3 个位置"和"第 300 个位置"各用一套权重，学到的规律不能平移 |
| 卷积 | 每个位置只看左右 $k$ 个邻居，权重共享 | 权重与内容无关；距离为 $n$ 的两个词要堆 $n/k$ 层才能见面 |
| RNN | 从左到右把历史压进一个固定大小的状态 $h_t$ | 必须串行算 $T$ 步；所有历史挤过同一个瓶颈；远距离的梯度要连乘 $T$ 个雅可比（→ 0.2） |

我们想要的是这样的形式：

$$
y_i = \sum_{j} a_{ij}\, v_j, \qquad a_{ij} \text{ 由 } x_i, x_j \text{ 的内容算出，} \sum_j a_{ij} = 1
$$

求和形式对任意序列长度 $T$ 均天然成立（满足条件 1）；权重由两者的特征内容动态决定（满足条件 2）；所有查询位置 $i$ 可以并行矩阵化求解，紧凑写为 $Y = AV$（满足条件 3）；只要权重函数 $a_{ij}$ 保持平滑可导，就能端到端反向传播梯度（满足条件 4）。剩下的核心问题只有一个：**注意力权重 $a_{ij}$ 究竟该如何计算**？本课将从这一基本问题出发，推导软寻址的数学本质、方差缩放的必要性，并逐步搭建起现代 Transformer Block 的完整因果架构与算力账本。

## 2. 从字典查找到软寻址

### 2.1 硬查找不可导

Python 字典的逻辑是“输入 query，检索严格匹配的 key，返回对应 value”。如果将其放宽为几何最近邻检索（“寻找点积最相似的 key”）：

$$
y = v_{j^*}, \qquad j^* = \arg\max_j\; q \cdot k_j
$$

硬寻址的核心缺陷在于**不可导**：当 query 向量 $q$ 发生微小连续变动时，argmax 选出的最优索引 $j^*$ 通常保持恒定，输出 $y$ 也毫无变化；而一旦变动幅度越过临界点导致 $j^*$ 跃迁至另一个 key，输出向量 $y$ 又会发生阶跃断裂。这意味着输出 $y$ 对 $q$ 的导数几乎处处为 0，反向传播的梯度无法向模型传递“应该把注意力转向哪一个 key”的学习信号。

### 2.2 softmax：带熵正则的 argmax

为了实现连续可导，必须将“硬选一个索引”平滑为“按概率分布分配权重”。令匹配分数为内积 $s_j = q \cdot k_j$，归一化权重为：

$$
p_j = \frac{e^{s_j}}{\sum_l e^{s_l}}, \qquad y = \sum_j p_j v_j
$$

为什么权重分配偏偏选取指数形式？在优化与信息论视角下有一个坚实的结论：softmax 分布是下列受约束凸优化问题的**唯一全局最优解**：

$$
\max_{p \in \Delta}\; \sum_j p_j s_j + \tau H(p), \qquad H(p) = -\sum_j p_j \log p_j
$$

第一项要求尽可能将概率权重集中在分数高的 key 上（当温度 $\tau \to 0$ 时退化为 argmax）；第二项香农熵 $H(p)$ 则构成正则化项，惩罚过于极端的集中分布，要求保持一定的探索不确定性。构建拉格朗日函数 $\sum_j p_j s_j - \tau\sum_j p_j\log p_j - \lambda(\sum_j p_j - 1)$ 并对各个分量 $p_j$ 求偏导置零：得到 $s_j - \tau(\log p_j + 1) - \lambda = 0$，由此推导出最优解必然满足 $p_j \propto e^{s_j/\tau}$。该问题的对偶最优值正是 $\tau\log\sum_j e^{s_j/\tau}$（即 log-sum-exp，亦称光滑最大值函数 Smooth Max），而 softmax 恰好是该光滑对偶函数的解析梯度。

因此，softmax 绝非经验设定的启发式公式，而是“在匹配分数高处下注、同时保留熵不确定性”的最优折中解，温度参数 $\tau$ 精确控制着确定性与平滑度的平衡。在标准注意力中设定 $\tau = 1$，但后文将会证明：内积分数的统计方差在数值行为上直接充当着有效温度的角色。

由此引出两个关键推论：

- **平移不变性与分数差**：若所有分数加上同一个标量常数 $c$，softmax 概率分布 $p$ 保持严格不变。工程实现时必须先减去当前行最大值 $\max_j s_j$ 再进行指数运算，彻底消除上溢隐患；FlashAttention 依赖的在线 softmax 算法正是建立在此性质之上（→ 1.5）。
- **核平滑器等价性**：输出展开为 $y = \sum_j K(q, k_j)\, v_j / \sum_j K(q, k_j)$，其中核函数为指数点积核 $K(q,k) = e^{q\cdot k}$。该形式与非参数统计中的 Nadaraya–Watson 核回归完全等价：注意力机制本质上是一个核函数由神经网络投影参数动态学习的核平滑回归器。若将核函数近似解耦为特征映射内积 $\phi(q)^\top\phi(k)$，求和顺序便可利用结合律转置重排，将计算复杂度从平方降为线性，这构成了线性注意力的演化起点（→ 1.6）。

### 2.3 梯度流向哪里：每个 key 拿到的梯度正比于它的权重

根据微分链式法则，softmax 函数的雅可比矩阵为 $\partial p_i/\partial s_j = p_i(\delta_{ij} - p_j)$。设上游损失函数回传的梯度为 $g = \partial L/\partial y$，记当前加权平均输出为 $\bar y = \sum_i p_i v_i$：

$$
\frac{\partial y}{\partial s_j} = \sum_i p_i(\delta_{ij} - p_j)\, v_i = p_j(v_j - \bar y)
\quad\Longrightarrow\quad
\boxed{\frac{\partial L}{\partial s_j} = p_j\; g^\top (v_j - \bar y)}
$$

这一解析梯度公式揭示了注意力学习的核心动态：

- **方向修正项** $g^\top(v_j - \bar y)$：若将当前输出 $\bar y$ 沿候选向量 $v_j$ 方向微调能够降低损失函数 $L$（即点积为负），梯度下降便会**增加**该位置的分数 $s_j$。这是指导模型“该向哪个 key 转移注意力”的精准纠偏信号。
- **幅度门控因子** $p_j$：**当前分配权重 $p_j$ 接近 0 的 key，其梯度回传信号被严重截断**。哪怕候选向量 $v_j$ 正好包含解决任务所需的核心语义，只要由于初始分数偏差导致 $p_j \approx 0$，模型也几乎无法从梯度中获得反馈来将其召回。

由此可见，softmax 输出分布的锐度直接决定了有多少候选 key 能够同时获得有效的梯度更新信号。这就引出了下一节关于数值缩放的深层推导。

## 3. 为什么要除以 $\sqrt{d}$

### 3.1 点积的方差随维度线性增长

设 $q, k \in \mathbb{R}^d$ 各分量独立、均值 0、方差 1（初始化时大致如此，归一化层也会把激活拉到这个尺度）。那么

$$
\mathbb{E}[q\cdot k] = \sum_{i=1}^d \mathbb{E}[q_i]\mathbb{E}[k_i] = 0, \qquad
\mathrm{Var}(q\cdot k) = \sum_{i=1}^d \mathbb{E}[q_i^2]\,\mathbb{E}[k_i^2] = d
$$

$d_{\text{head}} = 128$ 时，分数的标准差是 $\sqrt{128} \approx 11.3$。

### 3.2 标准差 11 的 softmax 长什么样

$T$ 个独立高斯分数里最大的那个约为 $\sigma\sqrt{2\ln T}$，第一名和第二名的间隔约为 $\sigma/\sqrt{2\ln T}$。$T = 1024$、$\sigma = 11.3$ 时，间隔约 3.0，第一名的权重是第二名的 $e^{3} \approx 20$ 倍。下面是 256 个随机 query、每个对 1024 个随机 key 打分的实测（代码见 §9.2）：

| $d$ | 是否除以 $\sqrt d$ | 分数标准差 | 平均最大权重 | 有效候选数 $e^{H}$ |
|---|---|---|---|---|
| 16 | 否 | 3.97 | 0.396 | 20.9 |
| 64 | 否 | 7.97 | 0.703 | 3.2 |
| 128 | 否 | 11.33 | 0.796 | 2.1 |
| 512 | 否 | 22.56 | 0.896 | 1.4 |
| 任意 | 是 | 1.00 | 0.016 | ≈ 625 |

不缩放时，$d = 128$ 的注意力在初始化时就只盯着约 2 个 key，而且是**随机**的 2 个（key 是随机生成的，排在第一纯属高维采样的偶然波动）。按 §2.3 的梯度公式，其余 1000 多个候选 key 的权重 $p_j \approx 0$，无法获得梯度更新：真正包含核心语义的 key 只要未能在初始化时碰巧排在前列，就几乎永远失去被梯度发现的机会。除以 $\sqrt d$ 后，内积分数的方差被严格归一化回 1，每个 query 在初始化时能够将注意力概率较为均匀地铺展在约 625 个候选 key 上，确保每个候选 key 都能分得一份基础学习信号。

需要辨明两项关键机制原理：

1. **缩放不改变相对排序**，只改变概率分布的平滑锐度。内积同除以 $\sqrt{d}$ 在数学上完全等价于将 softmax 的温度设定为 $\tau = \sqrt d$。如果模型在后续训练中确实需要高度集中的尖锐注意力，优化器完全可以通过增大权重矩阵范数、拉大 $q$ 与 $k$ 的模长来主动提高分数的动态范围。
2. **缩放因子解决的是“初始化阶段激活方差不随特征维度 $d$ 漂移”**，从而保证扩大网络超参数时超参数（如学习率）具有良好的可移植性。但在长期训练中，$q\cdot k$ 的数值幅度依然可能持续膨胀，造成注意力 logit 过大而诱发训练崩溃或 loss 尖刺，工程上需配合 QK-norm 或 QK-Clip 等机制加以约束（→ 5.3、→ 6.3）。在 Maximal Update Parametrization（μP）理论中，更进一步主张采用 $1/d$ 而非 $1/\sqrt d$：因为随着模型训练成熟，$q$ 与 $k$ 的神经元激活逐渐形成强相关模式，点积的期望幅度将按照 $d$（而非无偏随机假设下的 $\sqrt d$）阶数膨胀。

## 4. Q、K、V：为什么要三个投影

### 4.1 直接用 $x$ 做点积行不通

在自注意力设定中，query、key、value 均派生自同一组输入序列 $x$。最简化的直觉尝试是直接令 $s_{ij} = x_i\cdot x_j$ 且 $v_j = x_j$。但这会遭遇两大致命缺陷：

- **对称性锁定**：点积满足交换律 $s_{ij} = s_{ji}$。但在自然语言语法中，“代词 it 检索先行词 animal”绝不意味着“先行词 animal 也必须同等关注代词 it”，语义依赖具有天然的方向性。
- **自环能量主导**：向量自身的模长平方 $x_i\cdot x_i = \|x_i\|^2$ 在几何上往往显著大于与异构向量的点积，导致注意力矩阵的对角线过度膨胀，每个 token 沦为主要关注自身，阻碍跨位置特征融合。

### 4.2 QK 是一个低秩双线性形式

引入可学习投影矩阵 $q_i = W_Q x_i$、$k_j = W_K x_j$（其中 $W_Q, W_K \in \mathbb{R}^{d_{\text{head}}\times D}$）：

$$
s_{ij} = (W_Q x_i)^\top (W_K x_j) = x_i^\top \underbrace{W_Q^\top W_K}_{M \,\in\, \mathbb{R}^{D\times D}} x_j
$$

- 双线性矩阵 $M = W_Q^\top W_K$ 一般不对称，从而彻底打破点积对称性约束（$s_{ij} \ne s_{ji}$），赋予语义依赖以明确的方向性。
- 由于内层特征维度为 $d_{\text{head}}$，矩阵乘积的秩严格受限于瓶颈维度，即 $\mathrm{rank}(M) \le d_{\text{head}}$。这意味着单个注意力头只能在最高 $d_{\text{head}}$ 维的线性子空间中度量 token 之间的关联：每个注意力头本质上是一个**低秩的关系探测器**。
- 最终注意力得分完全由乘积矩阵 $M$ 决定：对任意可逆变换矩阵 $R$，若执行规范重整化 $W_Q \to RW_Q$ 且 $W_K \to R^{-\top}W_K$，数学输出严格等价。因此孤立分析 $W_Q$ 或 $W_K$ 单一权重的绝对数值并无物理意义，机制可解释性分析的重心始终聚焦于耦合矩阵 $W_Q^\top W_K$。

### 4.3 V 和 O：匹配用的信息 ≠ 传递的信息

在语言理解中，决定“关注哪个位置”的辨别特征与“从中提取何种信息”的语义表征往往高度正交。例如代词 "it" 依据“名词性、单数、有生命实体”等句法线索匹配先行词 "animal"，但最终需要抽取并传递的则是 "animal" 的具象语义实体。因此，特征提取端必须采用独立的 Value 投影 $v_j = W_V x_j$，各头的抽取结果汇聚后由输出投影 $W_O$ 统一映射并累加写回残差流（→ 1.1）。将单个注意力头展开为显式回路：

$$
\text{head}(x)_i = \sum_j \underbrace{\mathrm{softmax}_j\big(x_i^\top W_Q^\top W_K x_j/\sqrt{d}\big)}_{\text{QK 回路：去哪儿读}}\;\underbrace{W_O W_V}_{\text{OV 回路：读到什么、写回什么}}\, x_j
$$

在 Anthropic 提出的 Transformer Circuits 机制可解释性框架中，注意力被精确解耦为两条正交机制回路：**QK 回路**（决定注意力寻址模式，即控制信息流动的路由路径），以及 **OV 回路**（决定被读取的 token 经历何种线性语义变换后写回目标位置的残差流）。§9.4 训练演示的归纳头，正是两层网络中 QK 与 OV 回路精妙跨层组合的直接体现。

## 5. 多头：一个头只能表达一种关系

### 5.1 一个分布只能做一次加权平均

单一注意力头对每个 query 只能生成一个一维概率分布，其输出本质上是所有候选 value 向量的**单次凸组合（加权平均）**。假设当前位置的代词 "it" 需要同时捕获两种截然不同的上下文信息：一方面从位置 3 汲取“代词所指代的主体实体概念”，另一方面从位置 9 汲取“紧邻前驱词的定语修饰语”。单个头只能被迫将两处的 value 向量按照单一标量权重线性混叠，而在同一向量空间内线性叠加后的异构特征极难在后续网络层中被无损逆向分离。

多头注意力（Multi-Head Attention）的核心思想是分治：配置 $h$ 组相互独立的投影参数 $W_Q^{(m)}, W_K^{(m)}, W_V^{(m)} \in \mathbb{R}^{d_{\text{head}}\times D}$（其中 $d_{\text{head}} = D/h$）。各头独立计算各自的注意力分布并执行独立的加权平均；所得的多路输出特征拼接后，经统一的输出矩阵 $W_O$ 执行线性融合：

$$
y_i = W_O\,[\text{head}_1; \dots; \text{head}_h] = \sum_{m=1}^{h} W_O^{(m)}\sum_j a^{(m)}_{ij}\, W_V^{(m)} x_j
$$

其中 $W_O^{(m)}$ 对应投影矩阵 $W_O$ 中划分给第 $m$ 个头的对应列切片。等式右侧的求和形式明确揭示了其物理图像：**将各头输出拼接后乘以 $W_O$，在代数上完全等价于各头经各自的 $W_O^{(m)}$ 投影后在残差流上直接执行矢量累加**。各个注意力头得以在各自的低维子空间中并行、独立地向全局残差流写入专属特征。

### 5.2 多头不增加参数和算力

| | 一个大头（$d = D$） | $h$ 个头（$d_{\text{head}} = D/h$） |
|---|---|---|
| $W_Q, W_K, W_V$ 参数 | $3D^2$ | $h \times 3 \times D \times D/h = 3D^2$ |
| $W_O$ 参数 | $D^2$ | $D^2$ |
| 打分 FLOPs（每对 token） | $2D$ | $h\times 2D/h = 2D$ |
| 能表达的关系 | 1 个秩 $\le D$ 的关系 | $h$ 个秩 $\le D/h$ 的关系 |

代价也有：每个头的 $M^{(m)}$ 秩只有 $D/h$。Bhojanapalli et al. 指出，$d_{\text{head}}$ 小于序列长度时，单个头无法表示任意的注意力模式（低秩瓶颈）。实践中 $d_{\text{head}}$ 基本固定在 64–128，宽度增加时加头数而不是加头维度。另一方面，训练好的模型里很多头是冗余的：Michel et al. 发现大多数层剪到只剩一个头，性能下降很小。GQA 让多个 query 头共享一组 K、V 头，省的是 KV cache（→ 1.3）。

## 6. 因果掩码：一次前向训练 $T$ 个预测

### 6.1 掩码把"预测下一个 token"变成并行任务

语言模型按概率链式法则进行联合分布自回归分解：$p(x_1,\dots,x_T) = \prod_t p(x_t\mid x_{<t})$（→ 0.3）。如果网络结构能够严格保证位置 $t$ 的输出仅依赖于当前及历史输入 $x_{\le t}$，那么**仅需一次模型前向传播**，即可同步输出全部 $T$ 个时间步的条件概率分布；将这 $T$ 个预测的交叉熵损失累加求和，即可在单次迭代中完成全序列的有监督训练（Teacher Forcing 并行机制）。

在底层实现上，这一因果约束通过在 softmax 归一化之前将所有来自“未来”位置的注意力打分强行置为负无穷大实现：

$$
s_{ij} \leftarrow -\infty \quad (j > i) \qquad\Longrightarrow\qquad p_{ij} = 0
$$

这一掩码操作使得未归一化的分数矩阵呈现严格的下三角形式，经过 softmax 变换后每一行依然构成合法的离散概率分布。

### 6.2 因果掩码让 KV cache 成立

利用数学归纳法可以严格证明：**在因果掩码的约束下，网络中任意第 $l$ 层、任意位置 $i$ 的激活表示，仅严格依赖于原始输入序列的前缀 $x_1,\dots,x_i$**。
- 基础步：第 0 层输入为词嵌入与位置嵌入的逐位置求和，该依赖显然严格成立。
- 归纳步：假设第 $l$ 层各位置均满足此前缀依赖；在第 $l+1$ 层中，位置 $i$ 的注意力模块仅读取索引 $j\le i$ 处的 Key 与 Value 向量，而这些向量均由第 $l$ 层位置 $\le i$ 的表示线性投影得出；后续的 FFN 与归一化层均为单 token 的逐点运算，不引入跨位置连接。故第 $l+1$ 层位置 $i$ 同样仅依赖 $x_{\le i}$。归纳成立。

核心推论：在自回归解码生成第 $t+1$ 个 token 时，历史前 $t$ 个位置在每一层计算得到的 Key 与 Value 向量，**与历史时间步计算出的数值完全恒定一致**。因此推理引擎完全不需要重新计算历史 token 的线性投影，只需将其缓存在显存中（KV Cache），每一步解码只需为当前新生成的单一 token 投射一行 query，并与历史缓存执行增量注意力打分。因果掩码正是 KV Cache 成立的理论基石；若去掉因果掩码（例如 BERT 架构的双向全注意力），新输入的 token 会反向更新并改变所有历史位置的深层隐藏状态，导致历史计算无法复用，缓存机制彻底瓦解。

### 6.3 没有位置信息，注意力把序列当集合

去掉因果掩码后，设 $P$ 为任意置换矩阵，若将输入矩阵 $X$ 的行打乱为 $PX$。则未缩放打分矩阵变为 $(PX)(PX)^\top = PXX^\top P^\top = PSP^\top$；由于 softmax 操作独立逐行执行，所得权重矩阵严格满足变换为 $PAP^\top$。此时注意力层的输出为：

$$
PAP^\top \cdot PV = P(AV)
$$

（利用了正交置换矩阵的性质 $P^\top P = I$）。这表明打乱输入序列的 token 顺序，只会导致输出向量产生完全同构的置换：标准自注意力运算具有严格的**置换等变性（Permutation Equivariance）**。在没有额外结构先验的情况下，模型完全无法分辨“猫吃鱼”与“鱼吃猫”的语法差异。因此，必须向模型中显式注入位置信息，现代大语言模型普遍采用旋转位置编码 RoPE（→ 1.2）。

但这里存在一个深刻的反直觉细节：带因果掩码的解码器模型，即使完全不注入任何显式位置编码（NoPE），网络依然能够学到有效的序列顺序并正常执行生成任务。原因在于**因果下三角掩码本身破坏了置换对称性，暗中泄露了绝对位置信息**：位置 $i$ 处若执行对历史 token 的均匀退化关注，其分配给每个历史 key 的归一化权重恒为 $1/i$，该标量倒数精确标记了当前 token 所处的绝对深度索引。Kazemnejad et al. 的实证研究进一步表明，无位置编码的因果解码器在特定长度外推评测中的泛化能力甚至不逊于部分经典显式位置编码。

## 7. Transformer Block：注意力负责交流，FFN 负责计算

### 7.1 结构

现代大模型几乎都用 Pre-Norm 结构（→ 1.1）：

$$
h = x + \mathrm{Attn}(\mathrm{Norm}(x)), \qquad y = h + \mathrm{FFN}(\mathrm{Norm}(h))
$$

两个子层分工明确：

- **注意力是唯一在 token 之间搬运信息的地方**。给定权重 $a_{ij}$ 时，它对 value 是线性的：只是加权平均。
- **FFN 逐个 token 独立计算**，不看别的位置，但提供了主要的非线性和大部分参数（→ 1.7）。

一个常用的比喻：注意力是"开会交换信息"，FFN 是"各自回去思考"。残差把每一层的输出累加到同一条"残差流"上，后面的层可以读到前面任意层写入的东西。

### 7.2 参数量：从 $12LD^2$ 到 Llama-3-8B 的 8,030,261,248

每层参数（忽略偏置和归一化增益）：

| 部件 | 经典 GPT（MHA，FFN 宽 $4D$） | Llama 3（GQA，SwiGLU） |
|---|---|---|
| $W_Q$、$W_O$ | $2D^2$ | $2D^2$ |
| $W_K$、$W_V$ | $2D^2$ | $2D\cdot n_{kv}d_{\text{head}}$ |
| FFN | $2\times D\times 4D = 8D^2$ | $3\times D\times F$（三个矩阵） |
| 合计 | $12D^2$ | — |

再加上 embedding $VD$，若输出头不共享权重，再加 $VD$。

**检验 1：GPT-3 175B**。$L = 96$、$D = 12288$：$12 \times 96 \times 12288^2 = 173.9\text{B}$，加上 embedding $50257\times 12288 = 0.62\text{B}$，共 174.6B，对得上。

**检验 2：Llama-3-8B**。$D = 4096$、$L = 32$、32 个 query 头、8 个 KV 头（$d_{\text{head}} = 128$）、$F = 14336$、$V = 128256$，输出头不共享：

| 项 | 计算 | 参数 |
|---|---|---|

| $W_K + W_V$ | $2\times 4096\times 1024$ | 8,388,608 |
| SwiGLU | $3\times 4096\times 14336$ | 176,160,768 |
| 两个 RMSNorm | $2\times 4096$ | 8,192 |

## 8. 算力账：上下文为什么越来越贵

### 8.1 每个 token 的两部分 FLOPs

前向时，每个参数对每个 token 做一次乘加，即 2 FLOPs。对 Llama-3-8B，参与矩阵乘的参数是 32 层的 6.98B 加上输出头的 0.53B（embedding 只是查表），约 7.5B，所以

$$
\text{矩阵乘} \approx 2 \times 7.5\text{B} = 15.0 \text{ GFLOP / token，与上下文长度无关}
$$

注意力打分和加权不对应任何参数。位置 $t$ 的 query 要和 $t$ 个 key 做点积，再对 $t$ 个 value 加权；每层所有头合起来，query 的总维度是 $n_{\text{heads}}d_{\text{head}} = D$：

$$
QK^\top: 2tD, \qquad AV: 2tD \qquad\Longrightarrow\qquad \text{注意力} \approx 4LtD \text{ FLOPs / token}
$$

GQA 不改变这一项：它减少的是 K、V 的个数，每个 query 头仍然要和 $t$ 个 key 做点积。

### 8.2 交叉点：约 3 万 token

两项相等时 $4LtD = 2N_{\text{matmul}}$。Llama-3-8B：$4\times 32\times 4096 = 524{,}288$，所以 $t \approx 15.0\times 10^9 / 524{,}288 \approx 28{,}600$。Llama-3-70B 的交叉点约为 53,000（§11 练习 3）。

- 上下文 4K 时，注意力只占每 token 算力的 13%：这时"模型有多大"决定成本。
- 上下文 128K 时，注意力是矩阵乘的 4.6 倍：这时"上下文多长"决定成本。

整段 prefill 阶段处理 $T$ 个 token 的注意力总 FLOPs 是各步累加：$\sum_t 4LtD \approx 2LDT^2$，计算量随上下文序列长度呈现**严格的二次方膨胀**。这正是长文本场景下算力与时延成本曲线陡峭上扬的根本物理原因，也是 FlashAttention 的 IO 感知分块（→ 1.5）、稀疏与线性注意力架构（→ 1.6）竭力攻克的焦点。而在自回归 decode 阶段，每步单 token 计算量虽小，但每生成一个新 token 都必须从高带宽显存（HBM）中将全部历史 $t$ 个位置的 Key 和 Value 完整吞吐一遍，使得生成瓶颈彻底从算力受限（Compute-bound）转变为内存带宽受限（Memory-bound）（→ 1.3、→ 5.1）。

在下方互动实验中，你可以切换不同的模型架构（如 Llama-3-8B 与 70B）并拖动【上下文长度 t】滑块：
- 观察代表矩阵乘算力的水平基线（$2N_{\text{matmul}}$，恒定不变）与代表注意力算力的倾斜直线（$4LtD$，随上下文长度 $t$ 线性爬升）；
- 垂直虚线标记了两者的算力【交叉点】。在交叉点左侧（常规短上下文），模型的矩阵乘参数量主导推理计算成本；一旦滑块滑向右侧长上下文区域（如 128K），注意力打分与加权的 FLOPs 急剧升高，成为主导单 token 耗时的主要算力开销。

## 9. 从零实现：从注意力函数到会"复制"的小模型

下面每段代码都可以直接运行（PyTorch 2.x，CPU 即可），注释里的数字是实际运行的输出。

### 9.1 因果注意力与多头

```python
import math, torch, torch.nn as nn, torch.nn.functional as F
torch.manual_seed(0)

def attention(q, k, v, causal=True):
    # q, k, v: [batch, heads, T, d_head]
    d = q.shape[-1]
    scores = q @ k.transpose(-2, -1) / math.sqrt(d)          # [B, H, T, T]
    if causal:
        T = q.shape[-2]
        mask = torch.ones(T, T, dtype=torch.bool).triu(1)     # 对角线以上 = 未来位置
        scores = scores.masked_fill(mask, float("-inf"))
    weights = scores.softmax(dim=-1)                          # 每一行是一个概率分布
    return weights @ v, weights

q, k, v = (torch.randn(2, 4, 16, 32) for _ in range(3))
out, w = attention(q, k, v)
ref = F.scaled_dot_product_attention(q, k, v, is_causal=True)
print((out - ref).abs().max().item())        # 2.98e-07：和 PyTorch 的实现一致
print(w.triu(1).abs().max().item())          # 0.0：未来位置的权重严格为 0

class MHA(nn.Module):
    def __init__(self, D, n_heads):
        super().__init__()
        self.h, self.dh = n_heads, D // n_heads
        self.wq, self.wk, self.wv, self.wo = (nn.Linear(D, D, bias=False) for _ in range(4))
    def forward(self, x, causal=True):
        B, T, D = x.shape
        split = lambda t: t.view(B, T, self.h, self.dh).transpose(1, 2)   # [B, H, T, dh]
        y, _ = attention(split(self.wq(x)), split(self.wk(x)), split(self.wv(x)), causal)
        return self.wo(y.transpose(1, 2).reshape(B, T, D))               # 拼接各头，再乘 W_O

mha = MHA(64, 4)
x = torch.randn(1, 10, 64)
perm = torch.randperm(10)
# §6.3：无掩码时，打乱输入 = 同样地打乱输出
print(torch.allclose(mha(x[:, perm], causal=False), mha(x, causal=False)[:, perm], atol=1e-6))   # True
# §6.2：只改第 6 个位置之后的输入，前 6 个位置的输出不变，所以它们的 K、V 可以缓存
x2 = x.clone(); x2[:, 6:] = torch.randn(1, 4, 64)
print(torch.allclose(mha(x)[:, :6], mha(x2)[:, :6], atol=1e-6))                                  # True
```

### 9.3 一个 Llama 式的完整模型，并数清参数

```python
class RMSNorm(nn.Module):
    def __init__(self, D, eps=1e-5):
        super().__init__(); self.g, self.eps = nn.Parameter(torch.ones(D)), eps
    def forward(self, x):
        return self.g * x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)

class Block(nn.Module):
    """Pre-Norm 块：GQA 注意力 + SwiGLU FFN（位置编码见 1.2，这里省略）。"""
    def __init__(self, D, n_heads, n_kv, F_dim):
        super().__init__()
        self.h, self.kv, self.dh = n_heads, n_kv, D // n_heads
        self.wq = nn.Linear(D, n_heads * self.dh, bias=False)
        self.wk = nn.Linear(D, n_kv * self.dh, bias=False)       # GQA：K、V 头数少于 Q 头数（→ 1.3）
        self.wv = nn.Linear(D, n_kv * self.dh, bias=False)
        self.wo = nn.Linear(n_heads * self.dh, D, bias=False)
        self.w1, self.w3 = nn.Linear(D, F_dim, bias=False), nn.Linear(D, F_dim, bias=False)
        self.w2 = nn.Linear(F_dim, D, bias=False)
        self.n1, self.n2 = RMSNorm(D), RMSNorm(D)
    def forward(self, x):
        B, T, D = x.shape
        h = self.n1(x)
        q = self.wq(h).view(B, T, self.h, self.dh).transpose(1, 2)
        k = self.wk(h).view(B, T, self.kv, self.dh).transpose(1, 2).repeat_interleave(self.h // self.kv, 1)
        v = self.wv(h).view(B, T, self.kv, self.dh).transpose(1, 2).repeat_interleave(self.h // self.kv, 1)
        a = F.scaled_dot_product_attention(q, k, v, is_causal=True)
        x = x + self.wo(a.transpose(1, 2).reshape(B, T, -1))     # 注意力：token 之间交流
        h = self.n2(x)
        return x + self.w2(F.silu(self.w1(h)) * self.w3(h))     # FFN：每个 token 各自计算

class LM(nn.Module):
    def __init__(self, V, D, L, n_heads, n_kv, F_dim):
        super().__init__()
        self.emb = nn.Embedding(V, D)
        self.blocks = nn.ModuleList(Block(D, n_heads, n_kv, F_dim) for _ in range(L))
        self.norm, self.head = RMSNorm(D), nn.Linear(D, V, bias=False)
    def forward(self, idx):
        x = self.emb(idx)
        for b in self.blocks: x = b(x)
        return self.head(self.norm(x))

for name, cfg in {"Llama-3-8B": (128256, 4096, 32, 32, 8, 14336),
                  "Llama-3-70B": (128256, 8192, 80, 64, 8, 28672)}.items():
    with torch.device("meta"):                     # 只建形状、不分配内存，8B 模型也能瞬间"搭"出来
        model = LM(*cfg)
    print(name, f"{sum(p.numel() for p in model.parameters()):,}")
# Llama-3-8B 8,030,261,248
# Llama-3-70B 70,553,706,496
```

### 9.4 训练一个两层小模型，看归纳头自己长出来

最后用一个只有注意力（没有 FFN）的两层模型做一个任务：一段随机 token 重复两遍，第一遍无法预测，第二遍完全可以照抄。重复段的长度每个样本都不同（8–31），所以模型不能靠"看固定距离之前的位置"作弊，只能**按内容**去找"当前 token 上次出现在哪，它后面跟的是什么"。

```python
V, T, D, H = 64, 64, 64, 4

def batch(n):
    x = torch.randint(V, (n, T))
    L = torch.randint(8, 32, (n,))                            # 重复段长度，每个样本不同
    pos = torch.arange(T)
    src = torch.where((pos >= L[:, None]) & (pos < 2 * L[:, None]), pos - L[:, None], pos)
    x = x.gather(1, src)                                       # 第 L..2L-1 位抄第 0..L-1 位
    second = (pos[:-1] >= L[:, None]) & (pos[:-1] < 2 * L[:, None] - 1)   # 目标落在第二遍里
    first = pos[:-1] < L[:, None] - 1
    return x, first, second, L

class AttnLayer(nn.Module):
    def __init__(self):
        super().__init__()
        self.norm, self.qkv, self.o = nn.LayerNorm(D), nn.Linear(D, 3 * D, bias=False), nn.Linear(D, D, bias=False)
    def forward(self, x):
        B = x.shape[0]
        q, k, v = self.qkv(self.norm(x)).view(B, T, 3, H, D // H).permute(2, 0, 3, 1, 4)
        s = q @ k.transpose(-1, -2) / math.sqrt(D // H)
        s = s.masked_fill(torch.ones(T, T, dtype=torch.bool).triu(1), float("-inf"))
        self.att = s.softmax(-1)                               # 留着，训练完拿出来看
        return x + self.o((self.att @ v).transpose(1, 2).reshape(B, T, D))

class Tiny(nn.Module):
    def __init__(self):
        super().__init__()
        self.tok, self.pos = nn.Embedding(V, D), nn.Embedding(T, D)   # 可学习的绝对位置
        self.layers = nn.ModuleList([AttnLayer(), AttnLayer()])
        self.head = nn.Linear(D, V, bias=False)
    def forward(self, idx):
        x = self.tok(idx) + self.pos(torch.arange(T))
        for layer in self.layers: x = layer(x)
        return self.head(x)

torch.manual_seed(0)
model = Tiny()
opt = torch.optim.AdamW(model.parameters(), lr=3e-3)
for step in range(3001):
    x, first, second, L = batch(64)
    lt = F.cross_entropy(model(x)[:, :-1].reshape(-1, V), x[:, 1:].reshape(-1), reduction="none").view(64, T - 1)
    opt.zero_grad(); lt.mean().backward(); opt.step()
    if step % 500 == 0:
        print(step, round(lt[first].mean().item(), 2), round(lt[second].mean().item(), 3))
# step    第一遍  第二遍
#    0     4.47   4.449
#  500     4.34   0.754
# 1000     4.30   0.510
# 3000     4.34   0.267      ← 第一遍停在 ln 64 ≈ 4.16 附近（无法预测），第二遍几乎全对

with torch.no_grad():
    x, first, second, L = batch(512); model(x)
    b, t = second.nonzero(as_tuple=True)
    a1, a2 = model.layers[0].att, model.layers[1].att          # [B, H, T, T]
    t1 = torch.arange(1, T)
    print(a1[:, :, t1, t1 - 1].mean(dim=(0, 2)))               # 第 1 层各头看"前一个位置"：[0.01, 0.04, 0.47, 0.40]
    print(a2[b, :, t, t - L[b] + 1].mean(0))                   # 第 2 层各头看"上次出现处的下一个"：[0.65, 0.64, 0.64, 0.59]
```

训练完打开注意力矩阵，能看到一个两步的回路，没有人教过它：

1. **第 1 层**有两个头（第 3、4 个）把约一半的权重放在"前一个位置"上：它们通过 OV 回路把"我前面是谁"写进每个位置的残差流（previous-token head）。
2. **第 2 层**的头在第二遍的位置 $t$ 上，把约 60% 的权重放在位置 $t - L + 1$：那里的残差流里写着"我前面是 $x_t$"，正好和当前 token 匹配（QK 回路用的是第 1 层写入的信息），而它自己的 token 就是答案（OV 回路把它复制过来）。

这就是 Olsson et al. 描述的**归纳头**（induction head）：用 "[A][B] … [A] → [B]" 的模式补全序列。它被认为是大模型上下文学习（in-context learning）的重要机制之一。单层注意力做不到这件事：位置 $t$ 的 query 需要知道"哪个位置的**前一个** token 是 $x_t$"，这个信息必须先由一层注意力搬过去。

## 10. 实战直觉、避坑与面试深挖

**与工程 / 应用的连接**
- **prompt 长度的成本是两段式的**：上下文几千 token 时，成本主要由模型大小决定；超过约 3 万（8B）到 5 万（70B）token 后，注意力的平方项开始主导 prefill 算力。长文档问答、Agent 的长轨迹，贵就贵在这里。
- **attention sink**：softmax 的权重必须加起来等于 1，一个头"没什么可看"时，也得把权重放在某处。训练好的模型普遍把多余的权重堆在第一个 token 上。StreamingLLM 发现，做滑动窗口时把开头几个 token 的 KV 永久保留，模型就不会崩；把它们逐出缓存，困惑度会飙升。给注意力输出加一个逐头的 sigmoid 门（Qwen 团队的 gated attention）可以消除这种现象。
- **批量推理的 padding**：decoder 做批量推理通常左填充，并且要把 padding 位置同时从 key 一侧屏蔽掉；只用 `is_causal=True` 不会屏蔽 padding。位置编号也要从真实 token 开始算。
- **数值**：fp16 下 $e^{s}$ 在 $s > 11$ 时就会溢出，所以一定要先减去行最大值；分数矩阵和 softmax 通常在 fp32 下累加。

**常见误区 / 反直觉点**
1. **"注意力权重就是模型的解释"** ✗：Jain & Wallace 发现，可以构造出差异很大、预测却几乎不变的注意力分布。权重说明"读了哪里"，不说明"读到的东西是否被用上"：OV 回路可能把它写进一个后面没人读的子空间。
2. **"多头比单头参数多、算得多"** ✗：参数和打分 FLOPs 都一样（§5.2），多头只是把一个大关系拆成多个低秩关系。
3. **"除以 $\sqrt d$ 是为了防止数值溢出"** ✗：溢出靠减最大值解决。缩放的作用是让初始化时分数的尺度不随 $d$ 变，避免 softmax 退化成 one-hot、其余 key 拿不到梯度（§2.3、§3.2）。
4. **"注意力对输入是线性的"** ✗：给定权重时它对 $V$ 线性，但权重本身经过 softmax、依赖 $Q$ 和 $K$，整体是关于 $x$ 的三次项再过 softmax 的高度非线性函数。
5. **"没有位置编码，模型就完全不知道顺序"** ✗：对双向注意力成立（置换等变）；带因果掩码的解码器可以从掩码本身推断位置（§6.3）。

**高频深挖题**
- **Q1：推导 softmax 注意力对分数的梯度，并据此解释为什么要除以 $\sqrt d$。**
  思路：$\partial p_i/\partial s_j = p_i(\delta_{ij} - p_j)$ → $\partial L/\partial s_j = p_j\,g^\top(v_j - \bar y)$，权重为 0 的 key 拿不到梯度 → $\mathrm{Var}(q\cdot k) = d$，不缩放时 $d=128$ 的分数标准差 11.3、有效候选数只有 2 → 缩放后标准差 1 → 加分项：缩放不改排名；μP 用 $1/d$；训练中 logit 增长要靠 QK-norm。
- **Q2：手算 Llama-3-8B 的参数量。**
  思路：每层 $2D^2 + 2D\cdot n_{kv}d_{\text{head}} + 3DF + 2D$ = 218,112,000 → ×32 → 加 embedding 和不共享的输出头 $2VD$ → 8.03B → 加分项：FFN 占每层 81%；对比经典 $12LD^2$。
- **Q3：为什么因果掩码让训练可以并行，又让推理可以用 KV cache？**
  思路：位置 $i$ 只依赖 $x_{\le i}$（逐层归纳）→ 训练时一次前向得到 $T$ 个条件分布 → 推理时旧位置的 K、V 不会因新 token 改变 → 双向注意力两样都做不到。
- **Q4：上下文从 4K 增加到 128K，每个 token 的算力怎么变？**
  思路：矩阵乘 $2N$ 不变，注意力 $4LtD$ 线性增长 → 8B 模型交叉点约 2.9 万 → 128K 时注意力约为矩阵乘的 4.6 倍 → prefill 总量 $\propto T^2$ → decode 主要受 KV 读取带宽限制（→ 1.3）。

## 11. 练习（附解答）

**练习 1**　$d_{\text{head}} = 64$、不除以 $\sqrt d$ 时，随机初始化下分数的标准差是多少？要让它回到 1，softmax 的温度应该设成多少？

> **解答**：$\mathrm{Var}(q\cdot k) = 64$，标准差 8。除以 $\sqrt{64} = 8$，即温度 $\tau = 8$。§3.2 的表里 $d = 64$ 不缩放时有效候选数只有 3.2。

**练习 2**　计算 Llama-3-70B 的参数量：$D = 8192$、$L = 80$、64 个 query 头、8 个 KV 头、$F = 28672$、$V = 128256$，输出头不共享。

> **解答**：$d_{\text{head}} = 128$，$n_{kv}d_{\text{head}} = 1024$。每层：$2\times 8192^2 + 2\times 8192\times 1024 = 150{,}994{,}944$（注意力），$3\times 8192\times 28672 = 704{,}643{,}072$（FFN），归一化 16,384，合计 855,654,400；×80 = 68,452,352,000。embedding 加输出头 $2\times 128256\times 8192 = 2{,}101{,}346{,}304$，最后的归一化 8,192。总计 **70,553,706,496**，与 §9.3 的代码一致。

**练习 3**　Llama-3-70B 在多长的上下文处，每个 token 的注意力 FLOPs 追上矩阵乘？

> **解答**：矩阵乘参数 = 68.45B（层）+ 1.05B（输出头）= 69.5B，每 token $2\times 69.5 = 139.0$ GFLOP。注意力 $4\times 80\times 8192\times t = 2{,}621{,}440\,t$。相等时 $t \approx 53{,}000$。比 8B 的 2.9 万长，因为矩阵乘随 $D^2$ 增长，注意力只随 $D$ 增长。

**练习 4**　在 §9.4 的代码里，把头数改成 $H = 1$（$d_{\text{head}} = 64$），分别在除以 $\sqrt d$ 和不除两种情况下训练，比较第 500 步第二遍的 loss。你预期会看到什么？

> **解答**：一次运行（种子 0）的结果：缩放版第 500 步第二遍 loss 已降到 0.75；不缩放版还停在 4.01，几乎没学到东西，到第 1000 步才降到 0.70。两者最终都能学会，但不缩放时初始注意力过于尖锐，模型要先把 $q$、$k$ 调到合适的尺度才能开始找对的 key，起步被拖慢了。单次运行有随机性，自己跑时可以换几个种子看看。

**练习 5**　证明：去掉因果掩码后，如果只给位置 1 加一个与其他位置不同的固定向量（比如一个"开头标记"），注意力仍然不知道其他位置的顺序。

> **解答**：设 $P$ 是只打乱位置 2 到 $T$ 的置换（固定位置 1）。输入 $PX$ 时，位置 1 的标记仍在位置 1，§6.3 的推导照样成立：$\mathrm{Attn}(PX) = P\,\mathrm{Attn}(X)$。所以位置 2 到 $T$ 之间的任何顺序信息都无法被区分。一个开头标记只能告诉模型"谁是开头"，要编码顺序，每个位置都需要各自的位置信息。
