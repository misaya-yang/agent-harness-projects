# 1.1 残差流、Pre-LN 与 RMSNorm：一条共享总线

> **一句话核心直觉**：Transformer 的主干不是"一层层堆叠"，而是一条**残差流**：每一层从这条总线上读、算、再把结果加回去。Post-LN 把归一化放在总线上，层数一深，梯度就要连闯 L 道关卡；Pre-LN 把归一化挪到支路上，恒等路径直通，训练稳了，代价是总线越来越"粗"，深层写进去的东西被稀释。2026 年的前沿开始对"总线怎么聚合"本身动刀。
> **唤醒标签**：残差流 · Post-LN vs Pre-LN · RMSNorm · 深度诅咒 · 门控注意力与注意力汇 · mHC / Attention Residuals

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

原始 Transformer 用的是 Post-LN。它在浅层模型上效果很好，层数一多就必须仔细设计学习率 warmup，否则训练直接发散。Pre-LN 解决了稳定性，成为几乎所有 LLM 的默认选择，但它带来了一个更隐蔽的问题。

2025 年的《The Curse of Depth》系统描述了这个问题：**现代 LLM 中有将近一半的层，效果远不如预期**。剪枝实验也印证了这一点：用 Pre-LN 的 LLM 删掉深层几乎不掉点，而用 Post-LN 的 BERT 恰好相反。你花钱训练的后半截网络，很大程度上在"空转"。

本篇代码的模拟（48 层，随机初始化）：

```
                第 1 层    第 24 层   第 48 层
Pre-LN 隐状态范数   7.8       11.0       13.5    ← 总线越来越粗
加 LayerNorm Scaling 8.2       8.7        8.9    ← 按 1/√层号 缩放后基本持平
```

总线越粗，后面每一层的输出在总和里占的比例就越小。这就是深层"空转"的直观原因。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 残差流是一条总线

```
token 嵌入 ──►══════════════════════════════════════════════► 输出头
               ║ 读   ▲ 写     ║ 读   ▲ 写     ║ 读   ▲ 写
               ▼      ║        ▼      ║        ▼      ║
             [Attn 1]─┘      [FFN 1]──┘      [Attn 2]─┘   ……

  每个模块：从总线读出当前状态 → 计算 → 把"增量"加回总线
  Attention：在 token 之间搬运信息（"谁该看谁"）
  FFN：     在每个 token 内部做变换（"知道什么"，常被看作键值记忆）
```

把模型看成"一条总线 + 一组读写模块"，很多现象就好解释了：中间层的隐状态本身就是有意义的表示（所以能拿来做 embedding、做 early-exit）；删掉某些层不会让模型彻底崩溃（其他模块还在读写同一条总线）。

### 2.2 归一化放在哪里

```
Post-LN：  x ──►(+)──► LN ──► 下一层          归一化在总线上：每层都要穿过 LN 的雅可比
             └─ f(x) ─┘

Pre-LN：   x ──────►(+)──► 下一层              归一化在支路上：总线上有一条纯恒等路径
           └► LN ► f ┘
```

- **Post-LN**：梯度从输出流回输入，要连续穿过 L 个 LN。每个 LN 都会按当前的标准差重新缩放，L 次连乘之后，靠近输出和靠近输入的梯度尺度差距很大，所以需要 warmup 把早期的大梯度压住。
- **Pre-LN**：总线上存在一条不经过任何归一化的恒等路径，梯度可以直达任意一层，训练稳定。

本篇代码在 48 层随机网络上测了各层第一个线性层的梯度范数：Post-LN 越靠近输出越大（0.30 → 0.39），Pre-LN 越深越小（0.32 → 0.23）。后者正对应"深层学得少"。

### 2.3 Pre-LN 的代价：总线越来越粗

Pre-LN 下每层都往总线上**加**东西，而总线本身从不被归一化，所以隐状态的方差随深度增长。第 l 层的输出要在一个越来越大的总和里"发声"，相对贡献越来越小，深层模块的雅可比趋近于恒等，几乎不改变总线。

### 2.4 RMSNorm：只保留真正有用的那部分

LayerNorm 做两件事：减均值（去中心化）、除标准差（去尺度）。RMSNorm 只做第二件，也不要偏置。实践表明，起稳定作用的主要是**尺度归一化**，去中心化几乎没贡献。去掉它，少一次规约，计算更快，效果基本不变。

### 2.5 注意力汇：softmax 必须"交出"概率

softmax 的输出必须加起来等于 1。当一个头在某个位置"没什么可看"时，它也得把概率放到某处，于是大量注意力被倾倒在第一个 token（BOS）上，形成**注意力汇**（attention sink），同时伴随某些维度上数值巨大的**巨量激活**（massive activations）。Qwen 团队的门控注意力（NeurIPS 2025）在注意力输出后加一个逐头的 sigmoid 门，给了每个头"什么都不输出"的选项：**BOS 上的注意力从 46.7% 降到 4.8%**，巨量激活和注意力汇都被缓解，长上下文外推也变好了。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　残差的展开与恒等梯度路径

$$
h_L = h_0 + \sum_{l=0}^{L-1} f_l(h_l),\qquad
\frac{\partial h_L}{\partial h_l} = I + \sum_{j\ge l}\frac{\partial f_j}{\partial h_l}
$$

**物理含义**：梯度里永远有一个 $I$，不会因为层数多而衰减到零。残差不只是梯度技巧，它同时规定了信息在深度方向**怎么聚合**：每一层的输出都以固定权重 1 被加进总线。2026 年的结构创新正是从"固定权重 1"这一点切入的（Step 5）。

### Step 2　Post-LN 的连乘

$$
h_{l+1} = \mathrm{LN}\big(h_l + f_l(h_l)\big)
\quad\Rightarrow\quad
\frac{\partial h_L}{\partial h_l} = \prod_{j=l}^{L-1} J_{\mathrm{LN}}^{(j)}\big(I + \partial f_j\big)
$$

每一项都含有 LN 的雅可比（大致按 $1/\sigma$ 缩放），L 次连乘后梯度尺度沿深度剧烈变化。这正是 Post-LN 需要 warmup、层数一深就容易发散的原因。

### Step 3　Pre-LN 的方差增长与 LayerNorm Scaling

$$
h_{l+1} = h_l + f_l\big(\mathrm{LN}(h_l)\big)
\quad\Rightarrow\quad
\mathrm{Var}(h_l) \approx \mathrm{Var}(h_0) + \sum_{j<l}\mathrm{Var}(f_j) \quad\text{随深度增长}
$$

- 由于 $f_j$ 的输入已被归一化，每层的输出方差大致是同一量级，而总线方差持续累加。《The Curse of Depth》从理论上分析了 Pre-LN 输出方差随深度的增长，指出这使深层模块的导数趋近于单位矩阵、几乎不参与训练。
- **LayerNorm Scaling**：把第 l 层 LN 的输出乘以 $1/\sqrt{l}$，抑制深层写入总线的方差。不加参数、不需调参，在 130M 到 7B 的模型上都优于 Pre-LN。

### Step 4　RMSNorm 与门控注意力

$$
\mathrm{RMSNorm}(x) = \frac{x}{\sqrt{\frac1d\sum_i x_i^2 + \epsilon}} \odot g,\qquad
\mathrm{LN}(x) = \frac{x - \mu}{\sigma}\odot g + b
$$

$$
Y' = \mathrm{SDPA}(Q,K,V)\ \odot\ \sigma(X W_\theta)
$$

- 门控的输入是该层归一化后的隐状态 X，按头、按元素作用在注意力输出上。门值高度稀疏，相当于给注意力加了一层**输入依赖的非线性开关**。
- **设计巧妙之处**：注意力汇的根源是"softmax 必须输出点什么"，门控在 softmax **之后**提供了关闭输出的能力，从根上去掉了倾倒概率的需求，而不是去修补 BOS token。

### Step 5　前沿：把"固定权重 1"换掉

- **mHC**（DeepSeek-V4）：把残差流加宽为 4 条并行通道，通道之间用一个约束在双随机矩阵上的混合矩阵交换信息，谱范数不超过 1，保证混合是非扩张的、数值稳定。
- **Attention Residuals**（Kimi，2026 年 3 月）：标准残差可以看作"深度方向上权重全为 1 的线性注意力"，AttnRes 把它升级为深度方向上的 softmax 注意力：每层用一个学到的 query，对之前各层的输出做加权选择

$$
h_l = \sum_{i<l} \alpha_{i\to l}\, v_i,\qquad \sum_i \alpha_{i\to l} = 1
$$

  为降低大规模训练时对所有前层输出做注意力的显存和通信开销，又提出了 **Block AttnRes**：块内仍用普通残差相加，块之间对块级表示做注意力。

**一句话串起来**：Post-LN → Pre-LN 解决的是"梯度怎么流"，LayerNorm Scaling 解决的是"深层写多大声"，mHC 和 AttnRes 解决的是"总线怎么聚合"。

## 4. 极简代码锚点（PyTorch）

一个 Pre-LN 块：RMSNorm、门控注意力、SwiGLU，外加可选的 LayerNorm Scaling。已跑通。

```python
import math, torch, torch.nn as nn, torch.nn.functional as F

class RMSNorm(nn.Module):
    def __init__(self, D, eps=1e-6):
        super().__init__(); self.g = nn.Parameter(torch.ones(D)); self.eps = eps
    def forward(self, x):                                       # 只除 RMS，不减均值、无偏置
        return self.g * x * torch.rsqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)

class PreLNBlock(nn.Module):
    def __init__(self, D, H, layer_idx=None):
        super().__init__(); self.H, self.dh = H, D // H
        self.n1, self.n2 = RMSNorm(D), RMSNorm(D)
        self.qkv, self.o = nn.Linear(D, 3 * D, bias=False), nn.Linear(D, D, bias=False)
        self.gate = nn.Linear(D, D, bias=False)                 # 门控注意力：逐头逐元素的 sigmoid 门
        self.w1, self.w3 = nn.Linear(D, 4 * D, bias=False), nn.Linear(D, 4 * D, bias=False)
        self.w2 = nn.Linear(4 * D, D, bias=False)
        self.lns = 1 / math.sqrt(layer_idx + 1) if layer_idx is not None else 1.0   # LayerNorm Scaling

    def forward(self, x):                                       # x: (B, L, D) —— 残差流
        B, L, D = x.shape
        h = self.n1(x) * self.lns                               # 从总线"读"：归一化只在支路上
        q, k, v = self.qkv(h).view(B, L, 3, self.H, self.dh).permute(2, 0, 3, 1, 4)
        a = F.scaled_dot_product_attention(q, k, v, is_causal=True)          # (B, H, L, dh)
        a = a.transpose(1, 2).reshape(B, L, D) * torch.sigmoid(self.gate(h)) # 允许"什么都不输出"
        x = x + self.o(a)                                       # 往总线"写"：恒等路径不经过任何归一化
        h = self.n2(x) * self.lns
        return x + self.w2(F.silu(self.w1(h)) * self.w3(h))     # SwiGLU FFN，同样只写增量
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **残差结构成为新的创新点**：Kimi K3 以 KDA 和 Attention Residuals 为基础；DeepSeek-V4 用 mHC 加宽残差流，报告其墙钟开销只占重叠后 1F1B 流水线阶段的 6.7%。两家走了两条不同的路，一个"加宽"，一个"按注意力选择"。
- **归一化的位置还在演化**：Peri-LN（在模块的输入和输出两侧都做归一化）在 2025 年的研究中被认为特别有效，并据报道用于 Gemma 3。Qwen3-Next 的全注意力层组合了输出门、零中心化的 QK-Norm 变体和 partial RoPE。

**与工程 / 应用的连接**
- **中间层可用、深层可剪**：Pre-LN 让中间层隐状态有意义，所以能拿来做 embedding、early-exit、推测解码的草稿模型；深层贡献小，所以层剪枝和 logit lens 类的分析工具都有效。
- **注意力汇影响 KV cache 压缩策略**：很多长上下文的 KV 淘汰方法（例如保留开头几个 token + 滑窗）依赖"BOS 是注意力汇"这一事实。换成门控注意力的模型后，这个假设可能不再成立，压缩策略要重新验证。

**常见误区 / 反直觉点**
1. **"残差连接只是为了让梯度流过去"** ✗：它同时规定了信息在深度方向的聚合方式（固定权重 1 的累加），这正是深度诅咒和 AttnRes 讨论的对象。
2. **"Pre-LN 全面优于 Post-LN"** ✗：Pre-LN 换来了稳定性，代价是深层效率低。Peri-LN、LayerNorm Scaling、混合方案都在找两者之间的平衡。
3. **"RMSNorm 去掉减均值会损失表达力"** ✗：起作用的主要是尺度归一化，去中心化几乎没有贡献，去掉它还能省计算。

**高频深挖题**
- **Q1：Post-LN 和 Pre-LN 的梯度有什么区别？为什么 Post-LN 需要 warmup，而 Pre-LN 深层效果差？**
  思路：写出两种结构的雅可比 → Post-LN 每层都穿过 LN，梯度尺度沿深度连乘、初期靠近输出的梯度大，所以要 warmup → Pre-LN 有恒等路径、稳定，但总线方差随深度增长，深层输出被稀释、雅可比趋近恒等 → 补救：LayerNorm Scaling、Peri-LN，以及 mHC / AttnRes 这类改写聚合方式的结构。
- **Q2：什么是注意力汇？它从哪来？门控注意力为什么能去掉它？这对推理侧有什么影响？**
  思路：softmax 必须归一，没东西可看的头只能把概率倒在 BOS 上，伴随巨量激活 → 门控在 softmax 之后给了"不输出"的选项，从根上消除需求（BOS 注意力 46.7% → 4.8%）→ 推理侧：依赖 sink token 的 KV 淘汰策略要重新评估；巨量激活的减少也有利于低精度量化。
