# 1.2 RoPE 频率谱与外推 [熟区]

> **一句话核心直觉**：RoPE 把位置写成一组转速各不相同的钟（每对维度一只），$q \cdot k$ 只读得出两只钟的相位差。低频钟在训练长度内没转满一圈，延长上下文会遇到训练没覆盖的相位。
> **唤醒标签**：$R_m^\top R_n = R_{n-m}$ · $\theta_i = b^{-2i/d}$ 与波长 · 临界维度 · PI / NTK-aware / YaRN · partial RoPE / NoPE

**本篇定位**：熟区，不做唤醒。三个目标：① 一套 3 分钟能讲完、扛得住追问的表达骨架；② 和 1.3（MLA decoupled RoPE）、1.6（混合架构）打通；③ 2026 年前沿模型位置编码的真实配置。

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

假设一个使用 RoPE 的模型只在 4K 窗口内训练。拿 8K 的文本测试时，困惑度可能明显上升。位置插值（PI）把位置映回训练时的范围，再用较长文本续训；能恢复多少，要看具体模型和评测。

**2026 年的反直觉现象**：位置编码越用越少，上下文却越来越长。
- DeepSeek 只在 64 维子空间上加 RoPE；
- Kimi Linear / K3 的全注意力层干脆不用 RoPE（NoPE），位置交给线性注意力层；
- 在使用 RoPE 的开源模型里，partial RoPE 在 2026 年已经成为多数。

面试官问"为什么"，答案就是本篇的主线：**位置信息正在从"每层每维都写"变成"集中写在少数便宜的地方"**。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 钟表画面

固定训练窗口为 4,096 token，先选原频率再拉长目标窗口。每对维度对应一只钟，纵轴的 0 代表刚好转满一圈。换成位置插值或 YaRN，看哪些钟减速、哪些仍以原速度转。图里测的是相位覆盖；要知道模型的困惑度，还要实际跑评测。

```academy-lab
1.2
```

- b=10⁴、d=128 时最长波长约 **5.4 万 token**；Llama 3 式 b=5×10⁵ 时约 **256 万 token**。
- **临界维度** $i_c$：波长恰好等于训练长度的频率对序号。$i > i_c$ 的钟在训练中**从没转满一圈**。沿用原频率向外推时，它们会进入训练未覆盖的相位，转满一圈后相位再折回。
- 低频钟在训练长度内几乎不转，近似"位置无关"，常被模型当作语义通道使用；高频钟负责精确的相对位置。

### 2.2 三个旋钮（面试时先把问题归到旋钮上）

| 旋钮 | 什么时候定 | 代表做法 |
|---|---|---|
| **算子形式**：哪些层、哪些维度用 RoPE | 架构设计 | 全量 RoPE / partial（DeepSeek 64 维，MiniMax-M3 一半维度）/ NoPE 层（Kimi K3、RNoPE） |
| **训练时频谱**：base 与各频率怎么分配 | 预训练 / 长上下文阶段 | b 从 10⁴ 到 5×10⁵ 再往上；长上下文阶段调大 base |
| **推理时范围**：把没见过的长度映射回见过的相位 | 部署 / 少量续训 | PI、NTK-aware、YaRN、LongRoPE |

这三个旋钮常被混为一谈。"外推方法比较"这类问题几乎都只在第三个旋钮上，"为什么去掉 RoPE"在第一个旋钮上。先归类，回答就有了骨架。

### 2.3 PI / NTK / YaRN：按波长分区处理

| 方法 | 高频区 | 中频区 | 低频区 |
|---|---|---|---|
| PI | 转速降为 $1/s$，局部相位差变小 | 转速降为 $1/s$ | 转速降为 $1/s$ |
| NTK-aware | 最高频不动 | 随频率逐渐减速 | 最低频转速降为 $1/s$ |
| YaRN | 训练转满 32 圈的频率不动 | 按训练圈数插值 | 转不满一圈的频率降为 $1/s$ |

YaRN 的思想：高频钟在训练里已经转了很多圈，优先保留它们编码局部距离的分辨率；低频钟没转满一圈，必须插值；中间平滑过渡。另外，上下文变长后 softmax 的熵会被稀释，所以再加一个温度把注意力"收紧"回来。

### 用两个位置验证相对相位

把一个二维特征写成单位向量 $(1,0)$。query 放在位置 $m$、key 放在位置 $n$，各自旋转后，点积是 $\cos(m\theta)\cos(n\theta)+\sin(m\theta)\sin(n\theta)=\cos((n-m)\theta)$。若把提示词整体向右挪 100 个位置，两个绝对角度都变了，它们的差却相同。这条恒等式对任意固定的 query、key 都成立，所需条件是两端使用同一套旋转频率。

先拿单一频率 $\theta=0.25$ 验算。两位置相距 2 时点积约为 0.878；只把 key 再挪 4 个位置，点积变成 $\cos(1.5)$，约为 0.071。把每个频率对的这类贡献加起来才是完整分数。一个低频对的相位覆盖不足能提示外推风险，却不能直接换算为困惑度。


**迁移练习。** 若把两端的位置都除以 4，平移不变性还在吗？相对角变为 $(n-m)\theta/4$，所以仍然成立。但相邻词的转角缩小了，区分局部距离的能力可能受到影响。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　相对性

把 q 的第 i 对维度看成复数 $q^{(i)}$，位置 m 处乘以 $e^{\mathrm{i} m\theta_i}$：

$$
\langle R_m q,\ R_n k \rangle = \mathrm{Re}\sum_i q^{(i)}\, \overline{k^{(i)}}\, e^{\mathrm{i}(m-n)\theta_i} = q^\top R_{n-m}\, k
$$

**直觉**：旋转是正交变换，两个向量各转各的角度，内积只看角度差。绝对位置被"消掉"了。

### Step 2　波长与临界维度

$$
\lambda_i = \frac{2\pi}{\theta_i} = 2\pi\, b^{2i/d},\qquad
i_c = \frac{d}{2}\log_b\frac{L_{\text{train}}}{2\pi}
$$

b=10⁴、d=128、L_train=4K：**64 对里有 18 对**在训练中没转满一圈（约 28%）。MLA 的 decoupled RoPE 只有 64 维、32 对，同样设置下有 9 对。

### Step 3　三种推理时缩放（缩放因子 $s = L_{\text{target}}/L_{\text{train}}$）

$$
\text{PI:}\ \ \theta_i' = \theta_i / s
\qquad\qquad
\text{NTK-aware:}\ \ b' = b \cdot s^{\,d/(d-2)}
$$

NTK 的设计巧妙在于：改 base 后，最高频 $\theta_0 = 1$ 不变，最低频恰好缩小 s 倍。例如 s=8、d=128 时 $b' \approx 8.3\times10^4$。

**YaRN 的频率混合。** 先按训练窗口内的圈数找两端，再沿频率对序号线性过渡。取 $D=d/2$，令 $j(r)=D\log_b(L_{\rm train}/(2\pi r))$。采用常见的取整实现，快端 $a=\lfloor j(32)\rfloor$，慢端 $c=\lceil j(1)\rceil$。定义 $w_i=\mathrm{clip}((i-a)/(c-a),0,1)$，则

$$
\theta'_i=(1-w_i)\theta_i+w_i\theta_i/s.
$$

- $d=128$、$b=10000$、训练长度 4096 时，两端是第 20、46 对（从 0 计数）。21 对保留原频率，18 对全插值，中间 25 对混合。原论文按圈数描述分区，常见模型实现沿维度序号做线性 ramp；两条中间曲线有差别。
- 这一常用配置把幅度因子乘在 q 和 k 上；对全部参与旋转的维度，logits 放大 $(0.1\ln s+1)^2$（s=8 时约 1.46 倍），补偿长序列下注意力熵的稀释。

### Step 4　MLA 为什么必须 decoupled，以及 YaRN 只作用在哪

1.3 §3 Step 4：RoPE 的 $R_{s-t}$ 夹在 q 与 $W_{UK}$ 之间，会让吸收失效，所以位置被隔离到 64 维共享的 $k^R$ 上。推论：**长上下文扩展也只需要动这 64 维**。DeepSeek-V2 在解耦 RoPE 的子空间用 YaRN（s=40、α=1、β=32），并按自己的注意力结构调整了长度缩放因子来调节注意力熵。[DeepSeek-V2 技术报告](https://arxiv.org/abs/2405.04434)

### Step 5　NoPE 为什么能行

- 因果掩码本身就打破了排列对称：第 t 个位置只能看到 t 个 token，模型可以从注意力的分布里"数"出位置。所以纯 NoPE 也能学到位置，只是可能训练不稳。2026 年的 partial RoPE 系统研究发现，NoPE 的不稳定可以靠极少量 RoPE 或 QK-Norm 缓解，但 QK-Norm 方案收敛到的 loss 更高。
- 在这类混合架构中，门控衰减 $\alpha_t$ 让历史信息的影响随位置和内容变化。全注意力层可以不加 RoPE；这些层不会遇到 RoPE 相位超出训练范围的问题，模型仍然需要在更长的序列中找准相关信息。

## 4. 极简代码锚点（PyTorch）

```python
import math, torch

def rope_inv_freq(d, base=10000.0):
    return base ** (-torch.arange(0, d, 2, dtype=torch.float64) / d)   # (d/2,) θ_i

def yarn_inv_freq(d, base, L_train, s, alpha=1.0, beta=32.0):
    theta = rope_inv_freq(d, base)
    def pair_index(turns):
        return d / 2 * math.log(L_train / (2 * math.pi * turns), base)
    fast, slow = math.floor(pair_index(beta)), math.ceil(pair_index(alpha))
    mix = ((torch.arange(d // 2, dtype=theta.dtype) - fast) / max(1, slow-fast)).clamp(0, 1)
    theta_new = (1 - mix) * theta + mix * theta / s
    mscale = 0.1 * math.log(s) + 1.0                     # √(1/t)，乘在 q 和 k 上
    return theta_new, mscale

def apply_rope(x, pos, theta):
    """x: (B, H, L, d)，相邻两维一组（HF 的 rotate_half 是前后两半一组，差一个维度置换）"""
    ang = pos[:, None].to(torch.float64) * theta[None]  # (L, d/2)
    cos, sin = ang.cos().to(x.dtype), ang.sin().to(x.dtype)
    x1, x2 = x[..., 0::2], x[..., 1::2]                  # (B, H, L, d/2)
    return torch.stack([x1 * cos - x2 * sin, x1 * sin + x2 * cos], -1).flatten(-2)

# 临界维度：哪些频率对在训练长度内没转满一圈
theta = rope_inv_freq(128, 1e4)
print(((2 * math.pi / theta) > 4096).sum().item())       # → 18（共 64 对）
# 相对性自检：位置 (3, 10) 与 (103, 110) 的 q·k 相同，误差 ~1e-15
```

### 数值复算 · 用两个位置验证相对相位

在同一个 Python 会话中先运行本节上方的实现，再运行以下算例。

```python
import math
import torch

theta = torch.tensor([0.25], dtype=torch.float64)
unit = torch.tensor([1., 0.], dtype=torch.float64).reshape(1, 1, 1, 2)
def dot_at(m, n):
    q_rot = apply_rope(unit, torch.tensor([m]), theta)
    k_rot = apply_rope(unit, torch.tensor([n]), theta)
    return (q_rot * k_rot).sum().item()

for shift in [0, 4, 100]:
    both = dot_at(3 + shift, 5 + shift)
    key_only = dot_at(3, 5 + shift)
    assert math.isclose(both, math.cos(0.5), abs_tol=1e-12)
    print(f"{shift:3d}  {both:.3f}  {key_only:.3f}")
```

**运行结果**

```text
  4  0.878  0.071
100  0.878  0.933
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **"用 RoPE" 已经不是一个完整的配置描述**。2026 年的综述把开源模型的位置编码分成几类：DeepSeek、LongCat、GLM-5 按 RoPE / NoPE 子空间拆分，以适配 MLA 或稀疏注意力；Kimi K3 转向 NoPE，由 KDA 隐式提供位置。
- **趋势数字**：在每层 softmax 注意力都用全量 RoPE 仍是最常见的做法，但比例从 2025 年到 2026 年下降了；使用 RoPE 的模型里，partial RoPE 从 2025 年的少数变成了 2026 年的多数（MiniMax-M3 只旋转 128 维中的 64 维）。在 1B–8B 的实验里，每个头只旋转约 10% 的维度，训练 loss 和基准常常与全量 RoPE 持平，全量 RoPE 在部分评测上更好。
- **DeepSeek-V4**：K、V 共用一个条目，RoPE 只加在最后 64 维，并对注意力输出施加位置 −i 的逆旋转（→ 1.3）。按照第三方依据 config 整理的报告，V4 的 1M 上下文靠 YaRN 扩展得到，而不是原生在 1M 上训练。
- **层间分工**：RNoPE 交替使用 NoPE 层和只在滑窗内用 RoPE 的层，在极长上下文的检索上明显更好，并影响了 Llama 4 的设计。2026 年的机制研究发现，把全局层的 RoPE 去掉，会让模型的检索机制转向语义匹配，位置信息的质量也随之下降。**NoPE 换来了外推，也付出了位置精度的代价。**

**与工程 / 应用的连接**
- **标称长度 ≠ 可用长度**。YaRN 扩出来的 1M 是"相位不越界"，不等于"1M 处还能精确检索"。看 MRCR、RULER 这类长程检索指标：在 MRCR 1M 上，DeepSeek-V4-Pro 为 83.5%，Claude Opus 4.6 为 92.9%，同样标称 1M，差距是实打实的。
- **静态 YaRN 有短文本代价**。部署时把 `rope_scaling` 固定打开，等于对所有请求都用了插值后的频率，短 prompt 也被"压缩"。所以一些模型卡建议只在确实需要长上下文时才开启。
- **Agent 的"中段遗忘"**不只是位置编码的锅：注意力熵稀释、训练数据里长距离依赖稀少、以及 1.6 的压缩/稀疏机制都有份。排查时先分清是相位越界（换 rope_scaling 能改善）还是检索能力（换不了）。

**常见误区 / 反直觉点**
1. **"RoPE 有长程衰减，所以远处 token 天然不重要"** ✗：衰减的是随机或常向量内积的上界，学到的 q、k 完全可以关注很远的位置；低频维度在训练长度内几乎不转，常被当成近似位置无关的语义通道。
2. **"PI / YaRN 是外推方法"** ✗：它们本质是**插值**，把没见过的长度映射回见过的相位范围。真正"外推"的只有那些在训练中已经转满很多圈的高频维度，YaRN 正是保留它们不动。
3. **"partial RoPE / NoPE 是在偷工减料"** ✗：在 MLA 里它是吸收的前提（→ 1.3），在混合架构里位置由别的层提供；代价是位置精度和训练稳定性，需要 QK-Norm 或保留少量 RoPE 兜底。

**高频深挖题（附 3 分钟表达骨架）**
- **Q1：为什么 RoPE 外推会崩？PI、NTK、YaRN 各解决了什么？**
  1. 结论先行：崩在低频维度，因为它们在训练中没转满一圈，推理时出现了没见过的相位。
  2. 机制：钟表画面 + 临界维度公式，给一个数（b=10⁴、4K 训练时约 28% 的维度越界）。
  3. 方法按波长分区：PI 全压（伤高频）→ NTK 改 base（高频不动、低频压缩）→ YaRN 分段 ramp + 温度。
  4. 收尾钩子：这三种方法都只动"推理时范围"这一个旋钮；训练时频率表怎么分配，是独立的另一维。这里是你把自己研究接进来的位置。
- **Q2：为什么前沿模型开始在部分层或部分维度上去掉 RoPE？**
  思路：三个动机，各配一个例子。① 结构约束：MLA 吸收与 RoPE 冲突 → decoupled / partial（DeepSeek）；② 外推：NoPE 层没有越界相位 → 全局层 NoPE（Kimi Linear / K3、RNoPE）；③ 分工：线性层或局部层负责语序，全局层负责检索。最后补代价：训练稳定性（需 QK-Norm 或保留少量 RoPE）和位置精度（检索机制会转向语义匹配）。
