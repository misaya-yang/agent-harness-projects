# 1.7 FFN、SwiGLU 与知识存储

> **一句话核心直觉**：FFN 是逐 token 的两层网络，可以读成一张键值表：$W_{\text{in}}$ 的每一行是一个"键"，检测输入里的某种模式；$W_{\text{out}}$ 的每一列是一个"值"，模式命中就把它写回残差流。在 $D$ 维输入中，线性映射最多能对 $D$ 个线性无关的键任意指定输出，中间加一层非线性后，容量随隐藏宽度和参数量增长，训练充分的模型约为 2 bit/参数。SwiGLU 把隐藏单元写成两路投影相乘，乘法本身带来二次交互：连激活函数都不要的 Bilinear 也比 ReLU 好。8/3 来自参数对齐。ROME 把一层 FFN 当成线性联想记忆，用带约束的最小二乘写入一条新事实，闭式解是一个秩一更新；它比直接微调好，是因为更新方向用 $C^{-1}k^*$ 而不是 $k^*$。
> **唤醒标签**：$\mathrm{FFN}(x) = \sum_i \sigma(k_i\cdot x)\, v_i$ · 线性记忆容量 $= D$ · 2 bit/参数 · $W_2(\mathrm{SiLU}(W_1x)\odot W_3x)$ · Bilinear 1.960 < ReLU 1.997 · $3DF = 8D^2 \Rightarrow F = \tfrac{8}{3}D$ · 11008 / 14336 · $\hat W = W + \Lambda (C^{-1}k^*)^\top$ · 微调 = 朴素秩一更新

## 1. 问题：三分之二的参数在做什么？

1.0 里算过，Llama-3-8B 每层 2.18 亿参数，FFN 占 1.76 亿（81%）；32 层 FFN 加起来 56.4 亿，占全部 80.3 亿参数的 70%。前向时 FFN 也贡献了每个 token 约四分之三的矩阵乘 FLOPs。

可 FFN 从不看别的 token。在 token 之间搬信息的只有注意力（→ 1.0 §7）。那么，问模型"埃菲尔铁塔位于哪座城市"，"巴黎"这个答案不在上下文里，它只能来自权重。这一课回答三个问题：

1. FFN 到底在算什么？有没有一种读法，让它的权重有意义？
2. 现代模型为什么都换成了 SwiGLU？8/3 这个奇怪的比例从哪来？
3. 一条事实存在模型的哪里？能不能只改这一条、不碰别的？

## 2. FFN 是逐 token 的两层网络

### 2.1 定义

$$
\mathrm{FFN}(x) = W_{\text{out}}\,\sigma(W_{\text{in}}x), \qquad W_{\text{in}} \in \mathbb{R}^{F\times D},\; W_{\text{out}} \in \mathbb{R}^{D\times F}
$$

$F$ 是隐藏宽度，经典取 $4D$。同一个函数作用在每个位置上：对整段序列 $X \in \mathbb{R}^{T\times D}$，就是 $\sigma(XW_{\text{in}}^\top)W_{\text{out}}^\top$，两次大矩阵乘。prefill 时 $T$ 个 token 共用同一份权重，算术强度高，GPU 吃得饱（→ 5.1）。

### 2.2 没有 FFN 会怎样

去掉 FFN，一层只剩 $x + \sum_h A^{(h)} X W_V^{(h)}W_O^{(h)}$。**给定注意力模式 $A$，这对 $X$ 是线性的**：模型能做的只是把各位置的向量线性地混来混去，非线性只来自 softmax 对"看哪里"的选择。Dong et al. 证明，纯注意力网络（没有残差和 MLP）随深度增加，输出会以双指数速度坍缩成秩 1，所有位置变得一样。FFN 提供逐 token 的非线性特征计算，残差防止坍缩；两者缺一不可。

## 3. 键值记忆：把 FFN 读成一张查找表

### 3.1 换一种写法

记 $W_{\text{in}}$ 的第 $i$ 行为 $k_i$，$W_{\text{out}}$ 的第 $i$ 列为 $v_i$：

$$
\mathrm{FFN}(x) = \sum_{i=1}^{F} \underbrace{\sigma(k_i\cdot x)}_{\text{键 } i \text{ 命中多少}}\; v_i
$$

和注意力并排放：

| | 注意力 | FFN |
|---|---|---|
| 键从哪来 | 上下文里的 token，随输入变化 | $F$ 个学出来的固定向量 |
| 匹配后怎么归一化 | softmax，权重和为 1 | 逐个过 $\sigma$，不归一化，可以同时命中很多个 |
| 值从哪来 | 上下文 token 的 $W_V x_j$ | $F$ 个学出来的固定向量 |
| 本质 | 对上下文的软查找 | 对参数里的"记忆"的软查找 |

这个对应不只是形式上的。Sukhbaatar et al. 把 FFN 整个删掉，换成注意力里一组可学习的"持久记忆"键值向量，模型效果持平。

### 3.2 训练好的 FFN 里，键和值各是什么

Geva et al. 逐个检查训练好的语言模型里 FFN 的键和值：

- **键在检测输入模式**。取出让某个键激活最强的训练句子，它们往往有人能看懂的共同点。低层的键多对应浅层模式（比如"以某个词结尾"），高层的键多对应语义主题。
- **值在推高某些输出 token**。把 $v_i$ 乘上输出 embedding 矩阵，得到一个词表上的分布。高层里，这个分布常常集中在"键所检测的模式后面最常出现的那个词"上。
- 一层的输出是很多条记忆的叠加，再经过残差流逐层修正。

所以一个合理的心智模型是：**FFN 是一张很大的、按模式寻址的表；命中的条目把各自的"建议"写进残差流**。

### 3.3 一张线性表能存多少？

先看最简单的情形：不要非线性，直接用一个矩阵 $W \in \mathbb{R}^{D\times D}$ 存 $N$ 对 $(k_i, v_i)$，希望 $Wk_i = v_i$。

**赫布式外积**：$W = \sum_i v_i k_i^\top$。注意力里 $V^\top K$ 这样的累加就是这种形式（线性注意力的状态正是它，→ 1.6）。取回第 $j$ 条：

$$
Wk_j = v_j\,\|k_j\|^2 + \sum_{i\ne j} v_i\,(k_i\cdot k_j)
$$

第二项是串扰。$k$ 是随机单位向量时 $\mathbb{E}[(k_i\cdot k_j)^2] = 1/D$（§10 练习 4），串扰的总方差约 $(N-1)/D$，取回的向量与目标的余弦约为 $1/\sqrt{1 + (N-1)/D}$。$N = 16$、$D = 64$ 时已经掉到 0.91。

**最小二乘**：$W = V^\top (K^\top)^{+}$，直接解 $\min_W \|WK^\top - V^\top\|^2$。$N \le D$ 且键线性无关时方程组有精确解；$N > D$ 时，$D$ 维空间里装不下更多独立方向。实测（§8.2，$D = 64$，随机单位键值）：

| 存入条数 $N$ | 16 | 64 | 128 | 256 |
|---|---|---|---|---|
| 赫布外积：平均余弦 | 0.915 | 0.711 | 0.572 | 0.443 |
| 最小二乘：平均余弦 | **1.000** | **1.000** | 0.704 | 0.493 |

线性记忆的硬上限是 $D$ 条：超过之后，再好的解法也只能取回一个被压扁的投影。

### 3.4 非线性隐藏层打破 $D$ 的上限

现在中间加一层宽 $F$ 的非线性：$x \to \sigma(W_{\text{in}}x) \in \mathbb{R}^F$，再线性读出。对读出层来说，"键"变成了 $F$ 维的隐藏特征，而 $\sigma$ 让这些特征不再是 $x$ 的线性函数：$N$ 个键的特征矩阵秩可以到 $\min(N, F)$。**每多一个隐藏单元，就多一个可以独立存东西的维度**。


把存入条数拉过 $D$，最小二乘的线性记忆开始掉，加了 ReLU 隐藏层的记忆要到 $F$ 才开始掉。键随机、隐藏层的输入权重也随机（只训练读出层），这已经是最笨的 FFN；真训练出来的 FFN 会把隐藏单元放在更有用的位置。§8.3 里真正训练了几个 FFN 去背 2048 条随机"事实"（每条答案是 64 类之一）：

| 模型 | 参数 | 背下的比例（3 个种子） |
|---|---|---|
| 线性（无隐藏层） | 4,096 | 21.6%（凸问题，三个种子完全相同） |
| ReLU FFN，$F = 32$ | 4,096 | 64%–68% |
| ReLU FFN，$F = 48$ | 6,144 | 100% |

参数一样多，加了隐藏层的 FFN 背下的事实是线性模型的 3 倍。Allen-Zhu & Li 在受控的合成知识数据上系统测过这件事，结论是：**训练充分时（每条知识见过约 1000 次），语言模型稳定地存下约 2 bit/参数的知识**。只见过 100 次的知识，容量降到约 1 bit/参数；量化到 int8 不损失容量，int4 降到 0.7 bit/参数（→ 7.3）。按这个比例，一个 7B 模型能存约 140 亿 bit。还有一个容易被忽略的结论：把 MLP 层减少甚至删掉，模型在 1000 次曝光下也能接近 2 bit/参数。**知识并不只存在 FFN 里**，注意力的权重同样能存；FFN 只是参数最多的地方。

## 4. 门控：SwiGLU 为什么更好

### 4.1 GLU 家族

Dauphin et al. 提出门控线性单元 GLU：两路线性投影，一路过 sigmoid 当门，与另一路逐元素相乘。Shazeer 把它搬进 Transformer 的 FFN，试了一组变体：

$$
\mathrm{FFN}_{\text{SwiGLU}}(x) = W_2\big(\mathrm{SiLU}(W_1 x) \odot W_3 x\big), \qquad \mathrm{SiLU}(z) = z\cdot\mathrm{sigmoid}(z)
$$

把 SiLU 换成 GELU 是 GEGLU，换成 ReLU 是 ReGLU，**什么激活都不加**、只是两路相乘的叫 Bilinear。

在参数量和计算量都对齐的条件下（T5 的 C4 填空任务，越低越好）：

| FFN 变体 | 65,536 步 | 524,288 步 |
|---|---|---|
| ReLU（基线） | 1.997 | 1.677 |
| GELU | 1.983 | 1.679 |
| GLU（sigmoid 门） | 1.982 | 1.663 |
| **Bilinear（无激活）** | **1.960** | **1.648** |
| ReGLU | 1.953 | 1.645 |
| SwiGLU | 1.944 | 1.636 |
| GEGLU | 1.942 | 1.633 |

最值得看的一行是 Bilinear：它没有任何逐元素的非线性激活，只是两个线性投影相乘，却明显好过 ReLU 和 GELU。**收益主要来自乘法本身**，激活函数是锦上添花。Shazeer 在论文结尾自嘲说，他们把成功归功于 "divine benevolence"（神的眷顾）。下面给出三个比"神的眷顾"更具体的解释。

### 4.2 乘法带来什么

**（1）二次交互是免费的。** Bilinear 的一个隐藏单元算的是

$$
(w_1\cdot x)(w_3\cdot x) = x^\top (w_1 w_3^\top)\, x
$$

一个秩 1 的二次型。$F$ 个单元相加，能表示秩不超过 $F$ 的任意二次型。比如"特征 A 和特征 B 同时出现"这种交互 $x_A x_B$，一个单元就能精确表示（$w_1 = e_A$、$w_3 = e_B$）。ReLU 单元 $\max(0, w\cdot x)$ 是沿一个方向变化的"山脊函数"，要拼出 $x_Ax_B$ 得用很多个单元去分段逼近 $\tfrac14[(x_A + x_B)^2 - (x_A - x_B)^2]$ 里的两个平方。

**（2）"开不开"与"开多少"解耦。** 按键值表的读法，SwiGLU 的第 $i$ 个单元输出 $\mathrm{SiLU}(k_i\cdot x)\,(u_i\cdot x)\, v_i$：门 $\mathrm{SiLU}(k_i\cdot x)$ 决定这条记忆是否被调用，另一路 $u_i\cdot x$ 决定调用时写多少、往哪个符号写。ReLU 单元的激活既是开关又是幅度，只能输出非负系数。

**（3）梯度更顺。** ReLU 单元一旦对所有输入都落在负半轴，梯度永远为 0（死神经元）。SiLU 光滑，负半轴也有小梯度；乘积里的线性支路 $W_3x$ 在门打开时总能拿到梯度。

在 §8.3 的记忆实验里，参数对齐到约 4000 时，SwiGLU（$F = 21$，4,032 参数）背下 93%–95% 的事实，ReLU（$F = 32$，4,096 参数）只有 64%–68%；参数加到约 6000，两者都是 100%。但别急着下结论：Allen-Zhu & Li 发现，在知识只出现 100 次的设置下，带门控 MLP 的 LLaMA 结构存储容量反而比 GPT-2 结构低 1.3 倍，控制变量实验指向的正是门控 MLP；曝光到 1000 次后，各种结构都回到约 2 bit/参数。**SwiGLU 的优势是在标准预训练的 loss 上测出来的，不是"存储容量更大"的普适定律**。

### 4.3 8/3 的由来

经典 FFN 有两个矩阵，参数 $2\times D\times 4D = 8D^2$。SwiGLU 有三个矩阵 $W_1, W_3 \in \mathbb{R}^{F\times D}$、$W_2 \in \mathbb{R}^{D\times F}$，参数 $3DF$。要参数对齐：

$$
3DF = 8D^2 \quad\Longrightarrow\quad F = \tfrac{8}{3}D
$$

Llama 1/2 的 7B：$\tfrac83\times 4096 = 10922.7$，向上取整到 256 的倍数得 **11008**。Llama 3 在这个基础上再乘 1.3，并取整到 1024 的倍数：$1.3\times 10922 = 14198.6$，取整得 **14336** $= 3.5D$。所以 Llama-3-8B 的 FFN 比参数对齐的版本大 31%：它有意把更多参数放进了 FFN。8/3 只是"和经典 FFN 一样大"的换算，不是 SwiGLU 的固定比例。

## 5. 一条事实存在哪里：因果追踪

把一条事实"太空针塔位于西雅图"喂给 GPT-2 XL，问：哪些位置、哪些层的隐藏状态对说出"西雅图"起决定作用？ROME 的作者设计了因果追踪（causal tracing）：

1. **干净运行**：输入 "The Space Needle is in downtown"，记下"Seattle"的概率，并缓存每层、每个位置的隐藏状态。
2. **破坏运行**：给主语 "The Space Needle" 的 token embedding 加大噪声，"Seattle"的概率大幅下降。
3. **逐点恢复**：在破坏运行里，只把某一层、某一个位置的隐藏状态换回干净运行的值，看"Seattle"的概率恢复多少。恢复得越多，这个位置越关键。

结果有清晰的结构：**主语最后一个 token 处、中间层的 MLP** 恢复效应最强；另一个热点是最后一个 token 处、靠后层的注意力。作者的解读是：中间层 MLP 在主语的最后一个 token 上"查表"，把关于这个主语的属性写进残差流；靠后层的注意力再把它搬到要预测的位置。

但要小心"定位"和"编辑"不是一回事。Hase et al. 发现，因果追踪定位出的层，并不能预测在哪一层编辑效果最好：在很多层编辑都能成功，和追踪的结果关系不大。追踪说明的是"信息在哪里流过"，不是"只存在这里"。

## 6. 改写一条事实：ROME 的秩一更新

### 6.1 把一层 FFN 当成线性联想记忆

ROME 只改中间某一层 FFN 的 $W_{\text{out}}$。在主语最后一个 token 上：

- **键** $k$ = FFN 的隐藏激活（过完非线性之后、乘 $W_{\text{out}}$ 之前的向量），它编码"这是哪个主语"；
- **值** $v = W_{\text{out}}k$，写回残差流，后续层据此说出属性。

$W_{\text{out}}$ 已经近似存好了大量旧事实：$W \approx \arg\min_W \|WK - V\|^2$（$K$、$V$ 的列是各条事实的键和值）。要写入新事实时，先用主语的激活得到 $k^*$，再用梯度优化找一个 $v^*$，让模型在这个位置输出 $v^*$ 后说出新答案。剩下的问题是：**怎样改 $W$，使 $\hat W k^* = v^*$，同时尽量不破坏旧事实？**

### 6.2 带约束的最小二乘

$$
\min_{\hat W}\; \|\hat W K - V\|_F^2 \qquad \text{s.t.}\quad \hat W k^* = v^*
$$

引入拉格朗日乘子向量 $\Lambda \in \mathbb{R}^D$：$\mathcal{L} = \|\hat WK - V\|_F^2 - 2\Lambda^\top(\hat Wk^* - v^*)$。对 $\hat W$ 求导置零：

$$
2(\hat WK - V)K^\top - 2\Lambda k^{*\top} = 0 \quad\Longrightarrow\quad \hat W\, KK^\top = VK^\top + \Lambda k^{*\top}
$$

记 $C = KK^\top$（键的二阶矩，非中心化）。原来的 $W$ 满足正规方程 $WC = VK^\top$，所以

$$
\hat W = W + \Lambda\,(C^{-1}k^*)^\top
$$

把约束代回去：$Wk^* + \Lambda\,(C^{-1}k^*)^\top k^* = v^*$，解出

$$
\boxed{\;\hat W = W + \frac{(v^* - Wk^*)\,(C^{-1}k^*)^\top}{(C^{-1}k^*)^\top k^*}\;}
$$

这是一个秩一更新：左边的列向量 $v^* - Wk^*$ 是"输出还差多少"，右边的行向量 $C^{-1}k^*$ 决定"对哪些输入生效"。ROME 用约 10 万个维基百科 token 上的隐藏激活估计 $C$，预先算好。

### 6.3 为什么是 $C^{-1}k^*$，而不是 $k^*$

最朴素的做法是只用新事实去微调这一层。对 $\tfrac12\|Wk^* - v^*\|^2$ 求梯度得 $(Wk^* - v^*)k^{*\top}$：**每一步梯度下降都只往 $W$ 上加一个"行方向为 $k^*$"的秩一矩阵**，收敛后正好是

$$
\hat W_{\text{朴素}} = W + \frac{(v^* - Wk^*)\,k^{*\top}}{k^{*\top}k^*}
$$

（§8.4 用 200 步 SGD 验证了两者相同。）它和 ROME 只差一个 $C^{-1}$。区别出在旧事实上：输入一个旧键 $k_j$，两种更新带来的输出变化分别是

$$
\Delta_{\text{朴素}} = r\,\frac{k^*\cdot k_j}{k^*\cdot k^*}, \qquad
\Delta_{\text{ROME}} = r\,\frac{k^{*\top}C^{-1}k_j}{k^{*\top}C^{-1}k^*}, \qquad r = v^* - Wk^*
$$

真实网络的激活是高度各向异性的：不同 token 的隐藏激活往往共享一个很大的公共分量（均值方向）。若 $k = \mu + \varepsilon$、$\|\mu\|$ 不小，那么任意两个键的点积都约等于 $\|\mu\|^2$，朴素更新会把**每一条**旧事实都往 $r$ 的方向推。$C^{-1}$ 相当于先把键"白化"：在 $C^{-1/2}k$ 的坐标里，键看起来像各向同性的随机向量，两两之间的内积只有 $1/\sqrt{D}$ 量级。

§8.4 在 $D = 64$ 的记忆里精确存好 48 条事实，再写入一条新事实，公共分量的长度取 $s\sqrt{D}$：

| 公共分量 $s$ | 两种方法写入新事实的误差 | 朴素更新：旧事实平均偏移 | ROME：旧事实平均偏移 |
|---|---|---|---|
| 0（各向同性） | $\sim 10^{-6}$ | 26.4% | 26.4% |
| 1 | $\sim 10^{-6}$ | 92.2% | 15.6% |
| 2 | $\sim 10^{-6}$ | 187.4% | 25.1% |

（偏移按目标值的长度归一化。）两点观察：

1. 各向同性时两种写法给出相同的更新。键在某些方向上更集中的时候，$C^{-1}$ 才会改变更新方向。
2. 即便用了 ROME，$D = 64$ 时仍有约 1/4 的偏移，因为 64 维里随机方向的内积并不小。GPT-2 XL 的 FFN 隐藏维度是 6400，$1/\sqrt{6400} = 1/80$。**高维是秩一编辑能做到"局部"的前提**。

先让各个键几乎没有共同方向，再增加公共分量。看写入一条新事实后，旧事实平均偏移了多少。这个读数衡量干扰，和目标事实写得对不对是两项检查。

```academy-lab
1.7-edit
```

实验里 $C$ 用的是精确的 $I + \mu\mu^\top$。默认设置（$D = 32$、公共分量 1）下，朴素更新让旧事实平均偏移 118%，ROME 是 41%；把公共分量拉到 2.5，朴素更新涨到 179%，ROME 纹丝不动，因为 $C^{-1}$ 正好把公共分量整个压掉了；维度换成 64，ROME 降到 26%，这是 $1/\sqrt D$ 在起作用。

### 6.4 编辑的边界

MEMIT 把更新分摊到多层，一次写入上千条事实。但知识编辑有几个公认的问题：改了"A 的首都是 X"，模型未必会同步更新"A 的首都位于哪个大洲"这类推论；同一主语的其他属性可能被连带改动；编辑次数一多，模型整体能力会退化。需要频繁更新的事实，用检索去喂上下文（→ 8.2）通常比改权重可靠。

## 7. 稀疏、百万专家与 MoE

- **ReLU FFN 的激活天然稀疏**。Li et al. 发现，训练好的 T5、ViT 里每个 token 只有很小一部分 FFN 神经元非零，且模型越大越稀疏。推理时可以跳过那些为零的行列。SwiGLU 的输出几乎从不精确为 0，这种加速不再直接可用；Mirzadeh et al. 发现把激活换回 ReLU 再微调，能在很小的精度损失下找回稀疏性。
- **MoE 只替换 FFN**（→ 1.4）。FFN 逐 token、无状态，所以可以切成很多个专家，每个 token 只调用几个；注意力要在 token 之间读写，没法这样切。按键值表的读法，MoE 是"先用路由器粗选一批键，再在里面做查找"。
- **把键值表推到极致**：PEER 用乘积键检索，从一百万个只有一个神经元的"专家"里为每个 token 挑出少数几个。FFN、MoE 和 PEER 处在同一条谱系上：一张越来越大、越来越稀疏地访问的记忆表。

## 8. 从零实现

所有代码可以直接运行（PyTorch 2.x，CPU，约 15 秒），注释里是实际输出。

### 8.1 SwiGLU、隐藏宽度规则与键值分解

```python
import torch, torch.nn as nn, torch.nn.functional as F

def llama_hidden(D, multiple_of=256, mult=None):
    h = int(2 * 4 * D / 3)                 # 参数对齐：3·D·h = 2·D·4D
    if mult: h = int(mult * h)             # Llama 3 再乘一个放大系数
    return multiple_of * ((h + multiple_of - 1) // multiple_of)
print(llama_hidden(4096), llama_hidden(4096, 1024, 1.3))   # 11008 14336

class SwiGLU(nn.Module):
    def __init__(self, D, Fh):
        super().__init__()
        self.w1 = nn.Linear(D, Fh, bias=False)   # 门控支路（过 SiLU）
        self.w3 = nn.Linear(D, Fh, bias=False)   # 线性支路
        self.w2 = nn.Linear(Fh, D, bias=False)   # 写回残差流
    def forward(self, x):
        return self.w2(F.silu(self.w1(x)) * self.w3(x))

torch.manual_seed(0)
ffn, x = SwiGLU(64, 172), torch.randn(64)
a = F.silu(ffn.w1.weight @ x) * (ffn.w3.weight @ x)              # 每个隐藏单元的激活 a_i
manual = sum(a[i] * ffn.w2.weight[:, i] for i in range(172))     # Σ a_i · v_i，v_i 是 W_2 的第 i 列
print(torch.allclose(manual, ffn(x), atol=1e-5))                  # True：输出 = 按激活加权的值向量之和
```

### 8.2 线性联想记忆：赫布外积 vs 最小二乘

```python
torch.manual_seed(0)
D = 64
for N in [16, 64, 128, 256]:
    K = F.normalize(torch.randn(N, D), dim=1)          # N 个随机单位键
    V = F.normalize(torch.randn(N, D), dim=1)          # N 个随机单位值
    W_hebb = V.T @ K                                   # Σ v_i k_iᵀ
    W_ls = V.T @ torch.linalg.pinv(K.T)                # min ‖W Kᵀ − Vᵀ‖
    cos = lambda W: F.cosine_similarity(K @ W.T, V, dim=1).mean().item()
    print(N, round(cos(W_hebb), 3), round(cos(W_ls), 3))
# 16 0.915 1.0
# 64 0.711 1.0      ← 最小二乘精确存到 N = D
# 128 0.572 0.704   ← 超过 D 之后谁也存不精确
# 256 0.443 0.493
```

### 8.3 训练 FFN 背随机事实：隐藏层与门控各值多少

```python
torch.manual_seed(0)
N, C = 2048, 64                                        # 2048 条"事实"，答案是 64 类之一
K = F.normalize(torch.randn(N, D), dim=1)
y = torch.randint(C, (N,))

def memorize(kind, Fh, seed):
    torch.manual_seed(seed)
    W1 = nn.Parameter(torch.randn(Fh, D) / D**0.5)
    W3 = nn.Parameter(torch.randn(Fh, D) / D**0.5)
    W2 = nn.Parameter(torch.randn(C, Fh) / Fh**0.5)
    if kind == "linear":
        W2.data = torch.randn(C, D) * 0.1
        params, fwd = [W2], lambda x: x @ W2.T
    elif kind == "relu":
        params, fwd = [W1, W2], lambda x: F.relu(x @ W1.T) @ W2.T
    else:
        params, fwd = [W1, W3, W2], lambda x: (F.silu(x @ W1.T) * (x @ W3.T)) @ W2.T
    opt = torch.optim.Adam(params, lr=1e-2)
    for _ in range(3000):                              # 全批量训练，每条事实"见过" 3000 次
        loss = F.cross_entropy(fwd(K), y)
        opt.zero_grad(); loss.backward(); opt.step()
    return sum(p.numel() for p in params), (fwd(K).argmax(1) == y).float().mean().item()

for kind, Fh in [("linear", 0), ("relu", 32), ("swiglu", 21), ("relu", 48), ("swiglu", 32)]:
    res = [memorize(kind, Fh, s) for s in range(3)]
    print(kind, Fh, res[0][0], [round(r[1], 3) for r in res])
# linear  0 4096 [0.216, 0.216, 0.216]   ← 凸问题，与初始化无关
# relu   32 4096 [0.638, 0.676, 0.651]
# swiglu 21 4032 [0.95, 0.943, 0.932]    ← 同样的参数，门控多背下约 30 个百分点
# relu   48 6144 [1.0, 1.0, 1.0]
# swiglu 32 6144 [1.0, 1.0, 1.0]
```

### 8.4 ROME 式的秩一编辑，以及"微调 = 朴素更新"

```python
torch.manual_seed(0)
D, N = 64, 48
for shared in [0.0, 1.0, 2.0]:
    mu = torch.randn(D); mu = mu / mu.norm() * shared * D**0.5      # 所有键共享的公共分量
    sample = lambda n: mu + torch.randn(n, D)
    K, V = sample(N), torch.randn(N, D)                              # 已存的 48 条事实
    W = V.T @ torch.linalg.pinv(K.T)                                 # 精确存下（N < D）
    C = (lambda X: X.T @ X / len(X))(sample(20000))                  # 用大量"文本"估计键的二阶矩
    k_new, v_new = sample(1)[0], torch.randn(D)                      # 要写入的新事实
    r = v_new - W @ k_new                                            # 输出还差多少
    ck = torch.linalg.solve(C, k_new)
    for name, u in [("naive", k_new / (k_new @ k_new)), ("rome", ck / (ck @ k_new))]:
        W2 = W + torch.outer(r, u)                                   # 秩一更新
        drift = ((K @ (W2 - W).T).norm(dim=1) / V.norm(dim=1)).mean().item()
        print(shared, name, f"{(W2 @ k_new - v_new).norm().item():.0e}", round(drift * 100, 1))
    Wg = W.clone().requires_grad_(True)                              # 只在新事实上做梯度下降
    opt = torch.optim.SGD([Wg], lr=0.5 / (k_new @ k_new).item())
    for _ in range(200):
        loss = 0.5 * ((Wg @ k_new - v_new) ** 2).sum()
        opt.zero_grad(); loss.backward(); opt.step()
    print("  GD == naive:", torch.allclose(Wg.detach(), W + torch.outer(r, k_new / (k_new @ k_new)), atol=1e-4))
# 0.0 naive 2e-06 26.4 / 0.0 rome 2e-06 26.4
# 1.0 naive 2e-06 92.2 / 1.0 rome 2e-06 15.6
# 2.0 naive 3e-06 187.4 / 2.0 rome 3e-06 25.1
# 每组都输出 GD == naive: True
```

## 9. 实战直觉、避坑与面试深挖

**与工程 / 应用的连接**
- **FFN 是权重字节的大头**：短上下文的 decode 主要在读权重，FFN 占其中七到八成。权重量化的收益也主要来自 FFN（→ 7.3）。
- **SwiGLU 会放大离群值**：Fishman et al. 用 FP8 训练到 2T token 时发现，训练后期 $W_1$ 与 $W_3$ 的对应行会逐渐对齐，让 $\mathrm{SiLU}(w_1\cdot x)(w_3\cdot x)$ 近似变成平方，在 $W_2$ 的输入处造成巨大的离群值，FP8 训练因此发散。这是低精度训练和激活量化要特别照顾 FFN 下投影输入的原因之一（→ 5.3、→ 7.3）。
- **往模型里灌知识**：QLoRA 的实验发现，LoRA 要加在所有线性层上（包括 FFN 的三个矩阵）才能追上全量微调，只加在注意力的投影上明显不够（→ 2.8）。
- **知识编辑不是 RAG 的替代品**：编辑适合修正少量、稳定的错误事实；频繁变化或需要出处的知识，放在检索里（→ 8.2）。

**常见误区 / 反直觉点**
1. **"知识只存在 FFN 里"** ✗：因果追踪显示中间层 FFN 是关键通路，但 Allen-Zhu & Li 发现删掉 MLP 的模型照样能存约 2 bit/参数；Hase et al. 发现编辑的最佳位置与追踪定位关系不大。
2. **"一个神经元对应一个概念"** ✗：特征数远多于神经元数时，模型用叠加（superposition）把多个特征压在同一组神经元上，单个神经元往往是多义的（→ 9.1）。
3. **"SwiGLU 好是因为非线性更强"** ✗：完全没有激活函数的 Bilinear 也明显优于 ReLU，关键是乘法带来的二次交互。
4. **"8/3 是 SwiGLU 的固定比例"** ✗：它只是与经典 FFN 参数对齐的换算。Llama 3 用的是 3.5D。
5. **"在新事实上微调一下就能改知识"** ✗：只在新事实上做梯度下降，收敛到的正是朴素秩一更新，键共享公共分量时会大面积误伤旧事实（§6.3）。

**高频深挖题**
- **Q1：写出 SwiGLU FFN，说明 8/3 和 Llama 的 11008 是怎么来的。**
  思路：$W_2(\mathrm{SiLU}(W_1x)\odot W_3x)$ → 三个矩阵 $3DF$ 对齐 $8D^2$ → $F = 8D/3 = 10922.7$ → 取整到 256 的倍数 11008 → 加分项：Llama 3 再乘 1.3、取整到 1024 → 14336 $= 3.5D$；Bilinear 的结果说明收益来自乘法。
- **Q2：怎样理解"FFN 是键值记忆"？它的容量受什么限制？**
  思路：$\sum_i \sigma(k_i\cdot x)v_i$ → 与注意力对比（固定的键、不归一化）→ 线性记忆最多精确存 $D$ 条 → 非线性隐藏层让容量随 $F$、随参数增长 → 约 2 bit/参数，曝光次数和量化会改变它 → 知识不只在 FFN。
- **Q3：推导 ROME 的闭式更新，并解释为什么它比直接微调好。**
  思路：约束最小二乘 + 拉格朗日乘子 → $\hat W = W + \Lambda(C^{-1}k^*)^\top$，$\Lambda = (v^* - Wk^*)/((C^{-1}k^*)^\top k^*)$ → 单条事实上的梯度下降收敛到 $C = I$ 的朴素版 → 激活各向异性时朴素版误伤所有共享公共分量的键 → $C^{-1}$ 白化 → 高维让误伤降到 $1/\sqrt D$ 量级。
- **Q4：MoE 为什么只替换 FFN，不替换注意力？**
  思路：FFN 逐 token、无状态，切成专家后每个 token 独立路由 → 注意力要读写其他 token 的 K、V，计算依赖整个上下文 → FFN 是参数和"记忆"的大头，稀疏化收益最大 → 加分项：键值表的谱系：FFN → MoE → PEER 百万专家。

## 10. 练习（附解答）

**练习 1**　Llama-3-70B（$D = 8192$、$F = 28672$、80 层）里 FFN 占每层参数和总参数的比例各是多少？

> **解答**：每层 FFN $3\times 8192\times 28672 = 704{,}643{,}072$，每层总参数 855,654,400（1.0 §11 练习 2），占 82.4%。80 层 FFN 共 56.37B，占总参数 70.55B 的 79.9%。

**练习 2**　Mixtral 8×7B 每层有 8 个 SwiGLU 专家（$D = 4096$、$F = 14336$），每个 token 选 2 个。每层 FFN 的总参数和激活参数各是多少？

> **解答**：一个专家 $3\times 4096\times 14336 = 176{,}160{,}768$。总参数 $8\times$ = 1.41B，激活参数 $2\times$ = 352M。显存按 1.41B 算，计算按 352M 算（→ 1.4）。

**练习 3**　用一个 Bilinear 单元精确表示 $f(x) = x_1x_2$；再说明为什么 ReLU 单元做不到"有限个精确表示"。

> **解答**：取 $w_1 = e_1$、$w_3 = e_2$，单元输出 $(e_1\cdot x)(e_2\cdot x) = x_1x_2$，再令 $v = 1$ 即可。有限个 ReLU 单元之和是分段线性函数，而 $x_1x_2$ 的 Hessian 处处不为零（它在任何小区域里都不是线性的），所以分段线性函数只能逼近、不能精确表示，误差随单元数增加而减小。

**练习 4**　$k_i, k_j$ 是 $\mathbb{R}^D$ 里独立的均匀随机单位向量。证明 $\mathbb{E}[(k_i\cdot k_j)^2] = 1/D$。

> **解答**：固定 $k_j$，由对称性可设 $k_j = e_1$，于是 $k_i\cdot k_j = k_{i,1}$。单位向量满足 $\sum_{m=1}^D k_{i,m}^2 = 1$，各分量同分布，所以 $\mathbb{E}[k_{i,1}^2] = 1/D$。赫布记忆取回第 $j$ 条时有 $N-1$ 个串扰项，总方差约 $(N-1)/D$。

**练习 5**　在 ROME 的公式里令 $C = I$，会得到什么？什么情况下 $C$ 应该接近 $I$？

> **解答**：$\hat W = W + (v^* - Wk^*)k^{*\top}/(k^{*\top}k^*)$，正是朴素更新，也就是只在新事实上做梯度下降的极限。只有键的二阶矩各向同性、没有公共分量时 $C \propto I$，两者才等价（§6.3 表的第一行）。真实网络的隐藏激活远非各向同性，所以 $C^{-1}$ 很关键。
