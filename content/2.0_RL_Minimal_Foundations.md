# 2.0 强化学习最小基础

> **一句话核心直觉**：监督学习每一步都有标准答案；强化学习只在事后拿到一个分数，还得自己决定去试什么。把问题写成 MDP 之后，"一个状态有多好"满足一条递推式（贝尔曼方程）：已知环境时，它是一个线性方程组，可以直接解；求最优时，贝尔曼算子是 $\gamma$-压缩，迭代的误差每轮缩小到 $\gamma$ 倍，所以要迭代约 $\ln(1/\varepsilon)/(1-\gamma)$ 轮。不知道环境时，用采样代替期望：蒙特卡洛无偏但方差大，TD 自举、方差小但有偏。大模型后训练选了策略梯度而不是 Q-learning：动作空间是整张词表、状态是所有前缀、预训练模型本身就是一个好策略；而 KL 正则的 RL 目标有一个闭式最优解 $\pi^* \propto \pi_{\text{ref}}\,e^{r/\beta}$，它是 DPO 的起点。
> **唤醒标签**：MDP $(\mathcal S, \mathcal A, P, R, \gamma)$ · 回报 $G_t$ · $V^\pi$、$Q^\pi$、$A^\pi = Q - V$ · $V = (I - \gamma P_\pi)^{-1} r_\pi$ · $\|TV - TU\|_\infty \le \gamma\|V - U\|_\infty$ · 有效视野 $1/(1-\gamma)$ · TD 误差 $\delta = r + \gamma V(s') - V(s)$ · 最大化偏差 · 致命三元组 · $\pi^* \propto \pi_{\text{ref}}e^{r/\beta}$

## 1. 问题：只有事后打分时，怎样学？

SFT 的数据是"输入 → 标准答案"，每个 token 都有监督信号（→ 2.1）。可很多目标给不出标准答案，只能事后评判：

- 一道数学题，模型写了 600 个 token 的推导，判卷器只说"答案对了"或"错了"。
- 一个 Agent 调用了 12 次工具，最后任务成功与否由测试脚本判定（→ 2.6）。
- 两份回答，人只能说哪份更好（→ 2.2）。

这带来两个监督学习里没有的困难：

1. **信用分配**：600 个 token 只拿到一个分数，是哪几步让答案对了？
2. **探索**：数据由模型自己的行为产生。模型从没试过的做法，就不会有关于它的反馈。

强化学习就是处理这两件事的一套语言和工具。这一课把语言（MDP、回报、价值、贝尔曼方程）讲清楚，在一个小网格世界里把几种基本算法都跑一遍，最后说明为什么大模型的后训练走了策略梯度这条路（→ 2.3）。

## 2. MDP：把问题写成"状态 → 动作 → 奖励"

### 2.1 五元组

马尔可夫决策过程 $(\mathcal S, \mathcal A, P, R, \gamma)$：

- 状态 $s \in \mathcal S$，动作 $a \in \mathcal A$；
- 转移 $P(s'\mid s, a)$：在 $s$ 做 $a$ 之后到达 $s'$ 的概率；
- 奖励 $R(s, a)$（或 $R(s, a, s')$）；
- 折扣 $\gamma \in [0, 1]$。

**马尔可夫性**：下一步只取决于当前状态和动作，与更早的历史无关。这不是对世界的限制，而是对"状态"的要求：状态必须包含做决定所需的全部信息。

**策略** $\pi(a\mid s)$ 是在每个状态下选动作的概率分布。智能体与环境交互产生一条轨迹 $s_0, a_0, r_1, s_1, a_1, r_2, \dots$

### 2.2 一个网格世界

本课的实验都用这个 5×5 的网格：

- 左下角出发；右上角是终点（+1），终点正下方是陷阱（−1），到达这两格回合结束；中间有两堵墙。
- 每走一步奖励 −0.04（鼓励尽快到达）。
- 动作是上下左右，但有 10% 的概率"打滑"，各 5% 滑向左右两侧；撞墙则原地不动。

### 2.3 大模型就是一个 MDP 里的策略

| MDP 概念 | 语言模型的后训练 |
|---|---|
| 状态 $s_t$ | 提示词 + 已生成的 token |
| 动作 $a_t$ | 下一个 token（词表里的 12.8 万个选择之一） |
| 转移 $P$ | 确定性的：把选中的 token 接到末尾 |
| 奖励 | 通常只有结尾一个：判卷器、奖励模型或测试结果的分数；InstructGPT 式的 PPO 还给每个 token 加一项 $-\beta\log\frac{\pi_\theta(a_t\mid s_t)}{\pi_{\text{ref}}(a_t\mid s_t)}$ 的 KL 惩罚（当前策略与冻结参考策略的对数似然比） |
| 折扣 $\gamma$ | 一般取 1：回合有限长，以 EOS 结束 |
| 策略 $\pi(a\mid s)$ | 语言模型本身：$\pi_\theta(a_t\mid s_t)$ 就是它输出的下一个 token 分布 |

Agent 场景里，工具返回的结果也是"环境转移"的一部分：它们会被拼进状态，但不是策略选的动作（→ 2.6）。

## 3. 回报、价值与优势

### 3.1 回报

从时刻 $t$ 开始的折扣回报：

$$
G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty}\gamma^k r_{t+k+1}
$$

$\gamma$ 决定"看多远"：$k$ 步之后的奖励打 $\gamma^k$ 折，权重之和 $\sum_k \gamma^k = 1/(1-\gamma)$，所以 $1/(1-\gamma)$ 叫**有效视野**。$\gamma = 0.9$ 约看 10 步，$\gamma = 0.99$ 约看 100 步。

**大模型的特殊情况**：$\gamma = 1$、只有结尾一个标量奖励 $R$ 时，$G_t = R$ 对**每一个** $t$ 都成立：600 个 token 的经验回报完全相同。因为每个 token 拿到的全局分数一模一样，模型无法凭回报本身分辨到底是哪几步关键推理做对了。这就是信用分配问题最赤裸的形态，也是策略梯度必须引入基线与优势估计将全局分数拆解为局部贡献的原因（→ 2.3、→ 2.5）。

### 3.2 价值函数

$$
V^\pi(s) = \mathbb{E}_\pi[G_t\mid s_t = s], \qquad Q^\pi(s, a) = \mathbb{E}_\pi[G_t\mid s_t = s, a_t = a], \qquad A^\pi(s, a) = Q^\pi(s, a) - V^\pi(s)
$$

- $V^\pi(s)$：从 $s$ 出发、按 $\pi$ 行动，平均能拿多少回报。
- $Q^\pi(s, a)$：先做 $a$，之后按 $\pi$ 行动。
- **优势** $A^\pi(s, a)$：做 $a$ 比"按 $\pi$ 的平均水平"好多少。它的均值为零：$\sum_a \pi(a\mid s)A^\pi(s, a) = 0$。策略梯度真正需要的是优势，而不是回报本身：只有"比平均好"的动作才该被加强。

## 4. 贝尔曼方程：价值满足一条递推式

### 4.1 贝尔曼期望方程

把回报拆成"第一步奖励 + 之后的回报"：$G_t = r_{t+1} + \gamma G_{t+1}$。对两边取条件期望，并利用马尔可夫性（$G_{t+1}$ 只依赖 $s_{t+1}$）：

$$
V^\pi(s) = \sum_a \pi(a\mid s)\Big[R(s, a) + \gamma\sum_{s'}P(s'\mid s, a)\,V^\pi(s')\Big]
$$

把所有状态排成向量，记 $r_\pi(s) = \sum_a \pi(a\mid s)R(s,a)$、$P_\pi(s, s') = \sum_a\pi(a\mid s)P(s'\mid s, a)$：

$$
V^\pi = r_\pi + \gamma P_\pi V^\pi \quad\Longrightarrow\quad \boxed{V^\pi = (I - \gamma P_\pi)^{-1}\, r_\pi}
$$

**已知环境时，策略评估就是解一个线性方程组**。$\gamma < 1$ 时 $I - \gamma P_\pi$ 一定可逆（$P_\pi$ 的特征值模长不超过 1）。把逆矩阵展开成级数 $\sum_k \gamma^k P_\pi^k$，它的第 $(s, s')$ 个元素是"从 $s$ 出发，未来折扣后访问 $s'$ 的次数"：价值 = 未来各状态的奖励按折扣访问次数加权求和。§9.1 里，均匀随机策略的价值用线性方程直接解，与迭代 1000 次的结果相差 $10^{-15}$。

### 4.2 贝尔曼最优方程与价值迭代

最优价值 $V^*(s) = \max_\pi V^\pi(s)$ 满足

$$
V^*(s) = \max_a\Big[R(s, a) + \gamma\sum_{s'}P(s'\mid s, a)\,V^*(s')\Big] \;\equiv\; (TV^*)(s)
$$

多了一个 max，不再是线性方程。**价值迭代**就是反复套用这个算子：$V_{k+1} = TV_k$。为什么它一定收敛？

**$T$ 是 $\gamma$-压缩**：对任意两个价值向量 $V, U$，

$$
|(TV)(s) - (TU)(s)| \le \max_a \gamma\sum_{s'}P(s'\mid s, a)\,|V(s') - U(s')| \le \gamma\,\|V - U\|_\infty
$$

第一个不等号用了 $|\max_a f(a) - \max_a g(a)| \le \max_a|f(a) - g(a)|$，第二个用了 $\sum_{s'}P = 1$。取所有 $s$ 的最大值：$\|TV - TU\|_\infty \le \gamma\|V - U\|_\infty$。由压缩映射定理，$T$ 有唯一不动点 $V^*$，并且

$$
\|V_k - V^*\|_\infty \le \gamma^k\,\|V_0 - V^*\|_\infty
$$

误差降到 $\varepsilon$ 倍需要 $k \approx \ln(1/\varepsilon)/(1-\gamma)$ 轮（因为 $\gamma^k = e^{k\ln\gamma} \approx e^{-k(1-\gamma)}$）。**有效视野越长，迭代越慢**。

### 4.3 实测：两种收敛方式

§9.2 把网格改成"持续"版本（到达终点或陷阱后传送回起点，永不结束），这时界是紧的：

| $\gamma$ | 后期每轮误差缩小到 | 误差降到 1/1000 的轮数 | 估算 $\ln 1000/(1-\gamma)$ |
|---|---|---|---|
| 0.9 | 0.9000 倍 | 62 | 69 |
| 0.99 | 0.9900 倍 | 682 | 691 |

回到原来的"有终点"版本（$\gamma = 0.95$），收敛快得多：第 1 轮误差 0.88，第 10 轮 0.093，第 30 轮 $10^{-9}$。原因是第 $k$ 轮的 $V_k$ 恰好是"最多再走 $k$ 步"这个有限视野问题的最优值：终点的信息每轮向外传播一格，离终点最远的格子也只要十步左右，之后的误差只来自打滑造成的小概率长尾。下面的实验能直接看到这道"波"。

- **调节折扣因子 $\gamma$**：默认 $\gamma = 0.95$、打滑 10% 时，陷阱正下方那格的策略箭头朝下——往上一步就是陷阱，左侧是墙，智能体宁愿绕一大圈从左侧安全通道上去；若把 $\gamma$ 降到 0.6，有效视野仅剩 $1/(1-0.6) = 2.5$ 步，起点的估计价值骤降为 −0.08：终点的 +1 奖励经过远距离折扣后几乎不可见，状态价值主要由每一步的移动代价主导。
- **调节单步奖励**：把每步奖励由 −0.04 改成 −1，陷阱正下方那格的箭头会立刻直接反转指向陷阱——因为与其在路上多挨好几步极痛的 −1 惩罚，不如立刻踩进陷阱以 −1 结束回合。

### 4.4 策略迭代：几轮就收敛

另一种做法交替两步：**评估**（解线性方程得到 $V^\pi$）和**改进**（对每个状态取 $\arg\max_a Q^\pi(s, a)$）。

**策略改进定理**：若 $\pi'$ 在每个状态都选 $\arg\max_a Q^\pi(s, a)$，则 $V^{\pi'} \ge V^\pi$。证明是把不等式一路展开：

$$
V^\pi(s) \le Q^\pi(s, \pi'(s)) = \mathbb{E}[r_{t+1} + \gamma V^\pi(s_{t+1})\mid s_t = s, a_t = \pi'(s)] \le \mathbb{E}[r_{t+1} + \gamma Q^\pi(s_{t+1}, \pi'(s_{t+1}))\mid \cdots] \le \cdots \le V^{\pi'}(s)
$$

这里的推导逻辑很直观：第一步由于贪心选择有 $V^\pi(s) \le Q^\pi(s, \pi'(s))$，展开后中间项是后继状态的旧价值 $V^\pi(s_{t+1})$；再把相同的不等式递归代入未来的每一个后继状态 $s_{t+1}, s_{t+2}, \dots$。每一步都把“之后按旧策略 $\pi$ 行动”替换成“再多按新策略 $\pi'$ 走一步”，累积期望回报单调不减，直至无穷步极限收敛到新策略的整体价值 $V^{\pi'}(s)$。确定性策略只有有限个，而每轮严格改进，所以策略迭代在有限轮内停止。网格世界里只要 **3 轮**，结果与价值迭代相同（差 $4\times 10^{-16}$）。这个"评估 → 改进"的循环，就是后面所有 actor-critic 方法（包括 PPO）的骨架：critic 估计价值，actor 朝优势为正的方向改进。

## 5. 不知道环境时：用采样代替期望

真实问题里我们不知道 $P$，只能与环境交互、收集轨迹。贝尔曼方程里的期望要换成样本。

### 5.1 蒙特卡洛与 TD

- **蒙特卡洛（MC）**：跑完整个回合，用真实回报 $G_t$ 更新：$V(s_t) \leftarrow V(s_t) + \alpha[G_t - V(s_t)]$。$G_t$ 是 $V^\pi(s_t)$ 的**无偏**估计，但它累积了之后每一步的随机性，**方差大**；而且必须等回合结束。
- **时序差分 TD(0)**：只走一步，用"一步奖励 + 下一个状态的当前估计"当目标：

$$
V(s_t) \leftarrow V(s_t) + \alpha\,\underbrace{[r_{t+1} + \gamma V(s_{t+1}) - V(s_t)]}_{\text{TD 误差 } \delta_t}
$$

  这叫**自举**（bootstrapping）：用自己的估计去更新自己的估计。目标只含一步的随机性，**方差小**；但 $V(s_{t+1})$ 本身不准，所以**有偏**。

在 Sutton & Barto 的 5 状态随机游走上对比（真值 1/6…5/6，200 次重复取平均，§9.3）：

| 方法 | 步长 $\alpha$ | 第 10 回合 RMS 误差 | 第 100 回合 RMS 误差 |
|---|---|---|---|
| TD(0) | 0.05 | 0.175 | **0.037** |
| TD(0) | 0.15 | **0.097** | 0.072 |
| MC | 0.01 | 0.212 | 0.095 |
| MC | 0.03 | 0.188 | 0.089 |

TD 在这个问题上学得更快、也更准；步长大时前期快，后期在噪声里来回晃。MC 和 TD 之间可以连续插值：$n$ 步回报、$\lambda$-回报，PPO 里的 GAE 正是 TD 误差的指数加权和（→ 2.3）。

### 5.2 Q-learning 与它的两个毛病

不需要模型、直接学最优动作价值：

$$
Q(s, a) \leftarrow Q(s, a) + \alpha\big[r + \gamma\max_{a'}Q(s', a') - Q(s, a)\big]
$$

它是**离策略**的：无论数据由什么策略收集（比如 ε-greedy 探索），目标里的 max 都在估计最优策略的价值。§9.4 让它在网格世界里交互 3000 个回合（约 3.1 万步），结果暴露出两个典型毛病：

1. **最大化偏差**：起点的价值学成 0.41，真值是 0.372。对一组有噪声的估计取 max，期望值偏高：$\mathbb{E}[\max_a \hat Q] \ge \max_a\mathbb{E}[\hat Q]$。Double Q-learning 用两套估计分别负责"选动作"和"估值"来消除它。
2. **很少访问的状态学不准**：21 个非终止格子里，贪心策略只有 15 个与最优策略一致，不一致的多是 ε-greedy 很少走到的角落。没有探索，就没有数据。

## 6. 探索：没试过，就没有反馈

ε-greedy、按 softmax 温度采样、在目标里加熵奖励，都是在"利用已知好的动作"和"尝试可能更好的动作"之间分配。对大模型来说，探索有一个特别的含义：**rollout 的采样分布就是探索策略**。温度、top-p 决定了模型会试出哪些回答（→ 7.1）。

更根本的是，结果奖励只能强化模型**采样得到**的正确回答。一道题如果基础模型采样一千次也做不对一次，结果奖励就永远是 0，梯度为零，RL 学不到任何东西。Yue et al. 的分析发现，在常用的 RLVR 设置下，训练后的模型 pass@1 提高了，但在很大的 $k$ 上，基础模型的 pass@k 反而更高：RL 主要是在已有的能力范围内重新分配概率，把"偶尔做对"变成"经常做对"。探索的边界很大程度上由预训练决定（→ 2.5、→ 2.9）。

## 7. 为什么大模型后训练选了策略梯度

### 7.1 价值方法在这里很难用

- **状态空间是所有 token 前缀**，不可能列表；必须用神经网络近似 $Q$ 或 $V$。
- **函数近似 + 自举 + 离策略 = 致命三元组**。Sutton & Barto 指出三者同时出现时，价值估计可能发散（Baird 的反例就是一个线性近似下 TD 发散的例子）。DQN 用目标网络、经验回放等一系列技巧才把它压住。
- **每一步都要对 12.8 万个动作取 max**，每个动作还需要一个可靠的 $Q$ 值；而 $Q$ 头要从零训练。
- **预训练模型已经是一个很好的策略**。策略梯度直接在它上面微调；Q-learning 则要先学一个准确的价值函数，才能导出好策略。

### 7.2 策略梯度天然适合这个设置

- 转移是确定性的、rollout 只是生成文本，"跑一个回合"相对便宜；
- 奖励稀疏、在结尾，正好用整条轨迹的回报（减去基线）去加权每个 token 的对数概率（→ 2.3）；
- 价值函数并没有消失：PPO 的 critic 就是一个 $V$ 网络；GRPO 用同一题多次采样的平均分代替它（→ 2.5）。

### 7.3 KL 正则的 RL 有闭式最优解

后训练几乎总在目标里加一项 KL，防止策略偏离参考模型太远（→ 2.2）：

$$
\max_\pi\;\mathbb{E}_{a\sim\pi}[r(a)] - \beta\,\mathrm{KL}(\pi\,\|\,\pi_{\text{ref}})
$$

对单步问题（或把整条回答看成一个离散动作），引入拉格朗日乘子 $\lambda$ 约束概率全和为 1：$\mathcal{L}(\pi, \lambda) = \sum_a \pi(a) r(a) - \beta \sum_a \pi(a)\log\frac{\pi(a)}{\pi_{\text{ref}}(a)} - \lambda(\sum_a \pi(a) - 1)$。对每个动作的概率 $\pi(a)$ 求导并令其为 0：

$$
r(a) - \beta\Big[\log\pi(a) - \log\pi_{\text{ref}}(a) + 1\Big] - \lambda = 0 \quad\Longrightarrow\quad \log\frac{\pi(a)}{\pi_{\text{ref}}(a)} = \frac{r(a) - \lambda}{\beta} - 1
$$

两边取指数，并将不依赖动作 $a$ 的常数因子吸收进归一化配分函数 $Z = \sum_a \pi_{\text{ref}}(a)\exp\big(r(a)/\beta\big)$，即解出闭式最优策略：

$$
\boxed{\pi^*(a) = \frac{1}{Z}\,\pi_{\text{ref}}(a)\exp\!\big(r(a)/\beta\big)}
$$

这和 1.0 §2.2 推导 softmax 的过程一模一样：softmax 是“熵正则的 argmax”，这里则是“相对参考分布的熵正则化最优”。最优策略就是参考策略 $\pi_{\text{ref}}$ 经 $e^{r/\beta}$ 指数加权后的重归一化：温度 $\beta$ 越小，概率越极化地流向奖励最高的少数回答；$\beta$ 越大，策略越不敢偏离参考模型。§9.5 用梯度上升直接优化这个目标，收敛到的分布与闭式解逐位一致。更关键的是，反过来解出奖励 $r(a) = \beta\log\frac{\pi^*(a)}{\pi_{\text{ref}}(a)} + \beta\log Z$，就为跳过奖励建模直接优化策略的 DPO 奠定了理论出发点（→ 2.4）。

| 课 | 在 MDP 语言里做了什么 |
|---|---|
| 2.2 RLHF | 用偏好数据学一个奖励函数 $r$；KL 惩罚拴住策略 |
| 2.3 PPO | 策略梯度 + 用 critic 估计优势（GAE = TD 误差的加权和）+ 限制每步更新幅度 |
| 2.4 DPO | 利用 §7.3 的闭式解，把奖励换成对数概率比，跳过 RL 循环 |

| 2.6 Agentic RL | 状态里混进工具返回的观测，变成部分可观测、多轮的 MDP |

## 9. 从零实现

所有代码只依赖 NumPy，几秒内跑完。

### 9.1 网格世界与精确的策略评估

```python
import numpy as np

H, W = 5, 5
GOAL, PIT, WALLS = (0, 4), (1, 4), {(1, 1), (2, 3)}
ACTIONS = [(-1, 0), (0, 1), (1, 0), (0, -1)]            # 上 右 下 左
states = [(r, c) for r in range(H) for c in range(W) if (r, c) not in WALLS]
idx = {s: i for i, s in enumerate(states)}
S, A = len(states), 4
terminal = {GOAL: 1.0, PIT: -1.0}

def build(slip=0.1, step_reward=-0.04, continuing=False, start=(4, 0)):
    """返回 P[s, a, s'] 和期望奖励 R[s, a]。continuing=True 时到达终点/陷阱后传送回起点。"""
    P, R = np.zeros((S, A, S)), np.zeros((S, A))
    for s in states:
        i = idx[s]
        for a in range(A):
            if s in terminal:
                P[i, a, idx[start] if continuing else i] = 1.0   # 吸收（或传送），不再有奖励
                continue
            for b, p in [(a, 1 - slip), ((a + 1) % 4, slip / 2), ((a + 3) % 4, slip / 2)]:
                r, c = s[0] + ACTIONS[b][0], s[1] + ACTIONS[b][1]
                nxt = (r, c) if 0 <= r < H and 0 <= c < W and (r, c) not in WALLS else s
                P[i, a, idx[nxt]] += p
                R[i, a] += p * (step_reward + terminal.get(nxt, 0.0))
    return P, R

P, R = build()
gamma = 0.95
pi = np.full((S, A), 0.25)                                   # 均匀随机策略
P_pi = np.einsum("sa,sat->st", pi, P)
r_pi = (pi * R).sum(1)
V_exact = np.linalg.solve(np.eye(S) - gamma * P_pi, r_pi)   # V = (I − γP_π)⁻¹ r_π
V = np.zeros(S)
for _ in range(1000):
    V = r_pi + gamma * P_pi @ V                              # 反复套用贝尔曼期望方程
print(np.abs(V - V_exact).max())                             # ~1e-15
```

### 9.2 价值迭代、策略迭代与收敛速度

```python
T = lambda V: (R + gamma * P @ V).max(1)                     # 贝尔曼最优算子
V_star = np.zeros(S)
for _ in range(2000): V_star = T(V_star)
V = np.zeros(S)
for k in range(1, 61):
    V = T(V)
    if k in (1, 10, 30, 60): print(k, f"{np.abs(V - V_star).max():.2e}")
# 1 8.79e-01 / 10 9.27e-02 / 30 9.92e-10 / 60 0.00e+00   ← 有终点：信息每轮传播一格，很快精确

pol = np.zeros(S, dtype=int)                                 # 策略迭代
for it in range(1, 50):
    Vp = np.linalg.solve(np.eye(S) - gamma * P[np.arange(S), pol], R[np.arange(S), pol])   # 评估
    new = (R + gamma * P @ Vp).argmax(1)                                                    # 改进
    if (new == pol).all(): break
    pol = new
print(it, np.abs(Vp - V_star).max())                         # 3 轮，误差 ~4e-16
for r in range(H):
    print(" ".join("■" if (r, c) in WALLS else "G" if (r, c) == GOAL else "X" if (r, c) == PIT
                   else "↑→↓←"[pol[idx[(r, c)]]] for c in range(W)))
# → → → → G
# ↑ ■ ↑ ↑ X
# ↑ → ↑ ■ ↓
# ↑ ↑ ↑ ← ←
# ↑ ↑ ↑ ← ←

for g in [0.9, 0.99]:                                        # 持续任务：误差严格按 γ^k 收缩
    Pc, Rc = build(continuing=True)
    Tc = lambda V: (Rc + g * Pc @ V).max(1)
    Vs = np.zeros(S)
    for _ in range(20000): Vs = Tc(Vs)
    V, errs = np.zeros(S), []
    for k in range(3000):
        V = Tc(V); errs.append(np.abs(V - Vs).max())
    need = next(k for k, e in enumerate(errs, 1) if e < 1e-3 * errs[0])
    print(g, round(errs[200] / errs[199], 4), need, round(np.log(1000) / (1 - g)))
# 0.9 0.9 62 69
# 0.99 0.99 682 691
```

### 9.3 蒙特卡洛 vs TD：5 状态随机游走

```python
true = np.arange(1, 6) / 6                                   # 状态 A–E 的真实价值
def episode(rng):
    s, traj = 2, []                                          # 从中间的 C 出发
    while True:
        n = s + (1 if rng.random() < 0.5 else -1)
        traj.append((s, 1.0 if n == 5 else 0.0, n))          # 右端出口奖励 1，左端 0
        if n in (-1, 5): return traj
        s = n

def run(method, alpha, n_ep=100, runs=200, seed=0):
    rng, err = np.random.default_rng(seed), np.zeros(n_ep)
    for _ in range(runs):
        V = np.full(5, 0.5)
        for e in range(n_ep):
            traj = episode(rng)
            if method == "td":
                for s, r, n in traj:
                    V[s] += alpha * (r + (V[n] if 0 <= n <= 4 else 0.0) - V[s])   # 自举
            else:
                G = traj[-1][1]                              # γ = 1、只有结尾奖励：每步回报都等于它
                for s, r, n in traj: V[s] += alpha * (G - V[s])
            err[e] += np.sqrt(((V - true) ** 2).mean())
    return err / runs

for m, a in [("td", 0.05), ("td", 0.15), ("mc", 0.01), ("mc", 0.03)]:
    e = run(m, a)
    print(m, a, round(e[9], 3), round(e[99], 3))
# td 0.05 0.175 0.037 / td 0.15 0.097 0.072 / mc 0.01 0.212 0.095 / mc 0.03 0.188 0.089
```

### 9.4 Q-learning：只靠交互

```python
rng = np.random.default_rng(0)
Q, start, steps = np.zeros((S, A)), idx[(4, 0)], 0
opt = (R + gamma * P @ V_star).argmax(1)
for ep in range(3000):
    s = start
    for t in range(100):
        a = rng.integers(A) if rng.random() < 0.1 else Q[s].argmax()    # ε-greedy
        s2 = rng.choice(S, p=P[s, a])                                    # 环境采样下一个状态
        done = states[s2] in terminal
        Q[s, a] += 0.1 * (R[s, a] + (0 if done else gamma * Q[s2].max()) - Q[s, a])
        s, steps = s2, steps + 1
        if done: break
nonterm = [i for i, st in enumerate(states) if st not in terminal]
print(steps, sum(Q[i].argmax() == opt[i] for i in nonterm), len(nonterm))   # 31046 15 21
print(round(Q[start].max(), 3), round(V_star[start], 3))                    # 0.41 0.372 ← 最大化偏差
```

### 9.5 KL 正则目标的闭式最优解

```python
pi_ref = np.array([0.5, 0.2, 0.15, 0.1, 0.05])      # 参考策略
r = np.array([0.0, 1.0, 0.2, 0.8, 0.0])             # 每个动作（回答）的奖励
beta = 0.5
closed = pi_ref * np.exp(r / beta); closed /= closed.sum()
z = np.log(pi_ref).copy()                           # 从参考策略出发，对 logits 做梯度上升
for _ in range(5000):
    p = np.exp(z - z.max()); p /= p.sum()
    f = r - beta * (np.log(p) - np.log(pi_ref))     # J = E_p[r] − β·KL(p‖π_ref) 对每个动作的"收益"
    z += 0.5 * p * (f - (p * f).sum())              # softmax 参数化下 J 对 z 的梯度
print(np.round(p, 4), np.round(closed, 4))
# [0.182  0.538  0.0815 0.1803 0.0182] [0.182  0.538  0.0815 0.1803 0.0182]   ← 两者逐位一致
```

## 10. 实战直觉、避坑与面试深挖

**与工程 / 应用的连接**
- **奖励设计就是问题定义**：网格里每步 −0.04 让智能体急着走，改成 −1 它会宁可跳进陷阱早点结束（实验里的"每步 −1"）。大模型里，长度惩罚、格式奖励、判卷器的漏洞，都会被策略找到并利用（→ 2.2 的 reward hacking）。
- **$\gamma = 1$ 加结尾奖励**意味着每个 token 拿到同样的回报。PPO 用 critic 给每个位置不同的基线，GRPO 只在序列级别比较；两者对信用分配的处理不同，是 2.3 和 2.5 的核心差别。
- **rollout 参数就是探索策略**：训练时的温度、top-p 改变了模型试出什么，也改变了"策略"本身的定义；计算重要性比率时必须用同一个分布（→ 2.7、→ 7.1）。
- **看 pass@k 判断 RL 有没有可学的信号**：一批题在基础模型上 pass@64 都是 0，结果奖励训练基本学不到东西，要么换更容易的题，要么先用 SFT 或蒸馏把能力带进来。

**常见误区 / 反直觉点**
1. **"价值迭代要迭代到 $\gamma^k$ 足够小"** ✗：这是最坏情况的界。有终点、路径短的问题，信息每轮传播一格，几步就精确了（§4.3）。
2. **"折扣只是为了让级数收敛"** ✗：$\gamma$ 同时定义了任务：它决定智能体愿意为远期奖励付出多少。降低 $\gamma$ 会改变最优策略本身。
3. **"TD 有偏，所以不如 MC"** ✗：TD 的偏差随学习消失，方差小得多，在很多问题上学得更快（§5.1 的表）。
4. **"RL 能让模型学会任何它采样不到的东西"** ✗：结果奖励只能强化采样到的成功。基础模型从不做对的题，奖励恒为 0，梯度也是 0（§6）。
5. **"大模型 RL 里没有价值函数"** ✗：PPO 有 critic，过程奖励模型本质上是价值估计；GRPO 只是用组内平均代替了学出来的 $V$。

**高频深挖题**
- **Q1：写出贝尔曼期望方程和最优方程，证明价值迭代收敛，并估计迭代次数。**
  思路：$G_t = r_{t+1} + \gamma G_{t+1}$ 取期望 → 矩阵形式 $V = (I - \gamma P_\pi)^{-1}r_\pi$ → 最优算子 $T$ 是 $\gamma$-压缩（max 的差不超过差的 max）→ $\|V_k - V^*\| \le \gamma^k\|V_0 - V^*\|$ → $k \approx \ln(1/\varepsilon)/(1-\gamma)$ → 加分项：有终点时实际快得多。
- **Q2：MC 和 TD 的偏差、方差各来自哪里？GAE 怎样在两者之间插值？**
  思路：MC 目标 $G_t$ 无偏、累积整条轨迹的随机性 → TD 目标 $r + \gamma V(s')$ 只含一步随机性、但 $V(s')$ 有误差 → $n$ 步回报 → GAE 是 TD 误差按 $(\gamma\lambda)^k$ 加权求和，$\lambda = 0$ 是 TD、$\lambda = 1$ 是 MC（→ 2.3）。
- **Q3：为什么大模型后训练用策略梯度而不是 Q-learning？**
  思路：状态空间巨大必须函数近似 → 致命三元组 → 每步对 12.8 万个动作取 max → 预训练模型已是好策略，直接微调 → 确定性转移、结尾奖励、rollout 便宜 → 加分项：价值函数以 critic、PRM 的形式仍在。
- **Q4：推导 KL 正则 RL 目标的最优策略，并说明它和 DPO 的关系。**
  思路：$\max E_\pi[r] - \beta\mathrm{KL}(\pi\|\pi_{\text{ref}})$ → 拉格朗日 → $\pi^* \propto \pi_{\text{ref}}e^{r/\beta}$ → 与 softmax 是熵正则 argmax 同构 → 反解 $r = \beta\log(\pi^*/\pi_{\text{ref}}) + \beta\log Z$ → 代入 Bradley–Terry，$Z$ 相消 → DPO（→ 2.4）。

## 11. 练习（附解答）

**练习 1**　一个两状态的 MDP：状态 1 每步奖励 1，以概率 0.9 留在原地、0.1 去状态 2；状态 2 每步奖励 0，以概率 1 留在原地。$\gamma = 0.9$，求 $V(1)$。

> **解答**：$V(2) = 0$。$V(1) = 1 + 0.9\,[0.9\,V(1) + 0.1\times 0]$，即 $V(1) = 1 + 0.81\,V(1)$，解得 $V(1) = 1/0.19 \approx 5.26$。直观上：每步以 0.9 的概率"留下"、再乘折扣 0.9，有效的继续概率是 0.81，期望奖励是几何级数 $1/(1 - 0.81)$。

**练习 2**　价值迭代的误差界是 $\gamma^k\|V_0 - V^*\|_\infty$。$\gamma = 0.999$ 时，误差降到初始的 $10^{-6}$ 大约要多少轮？

> **解答**：$k \approx \ln(10^6)/(1 - 0.999) = 13.8/0.001 \approx 13{,}800$ 轮。有效视野 1000 步的问题，需要上万轮迭代才能在最坏情况下收敛。这也是长视野 RL 难的一个侧面。

**练习 3**　证明优势函数在策略下的期望为零：$\sum_a \pi(a\mid s)\,A^\pi(s, a) = 0$。它对策略梯度意味着什么？

> **解答**：$\sum_a\pi(a\mid s)Q^\pi(s, a) = V^\pi(s)$（按定义，$V$ 就是对动作取期望后的 $Q$），所以 $\sum_a\pi(a\mid s)[Q^\pi(s,a) - V^\pi(s)] = V^\pi(s) - V^\pi(s) = 0$。策略梯度用优势加权时，"高于平均"的动作被加强、"低于平均"的被削弱，正负抵消，平均更新为零。只用回报（全是正数）加权时，所有采样到的动作都被加强，只是程度不同，方差大得多（→ 2.3）。

**练习 4**　在 §7.3 的闭式解里，令 $\beta \to 0$ 和 $\beta \to \infty$，$\pi^*$ 分别趋向什么？$\pi_{\text{ref}}(a) = 0$ 的动作会怎样？

> **解答**：$\beta \to 0$ 时 $e^{r/\beta}$ 被奖励最高的动作主导，$\pi^*$ 集中到 $\pi_{\text{ref}} > 0$ 的动作里奖励最高的那个（若有并列，按 $\pi_{\text{ref}}$ 的比例分配）；$\beta \to \infty$ 时 $e^{r/\beta} \to 1$，$\pi^* \to \pi_{\text{ref}}$。$\pi_{\text{ref}}(a) = 0$ 的动作在 $\pi^*$ 里永远是 0：KL 正则的 RL 只能在参考模型的支撑集里重新分配概率，这与 §6 关于探索边界的结论一致。
