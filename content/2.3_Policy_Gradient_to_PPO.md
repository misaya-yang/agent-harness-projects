# 2.3 从策略梯度到 PPO：后训练的脊柱

> **一句话核心直觉**：策略梯度就是"按'这次比预期好多少'加权的最大似然"；PPO 则是"在旧数据上多走几步，但每个样本一旦已经被推够了，就不再给它激励"。整个后训练（SFT、RLHF、DPO、GRPO）都挂在同一根脊柱上：**KL 正则化的 RL 目标**。
> **唤醒标签**：log-derivative trick · baseline / advantage / GAE · 重要性采样 · clip 与悲观下界 · KL 估计量 k1 / k2 / k3

本篇是 M2 的地基。2.5 / 2.6 是在它上面换零件，2.1 / 2.4 是它的退化形式。

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

SFT 需要示范输出。很多任务更容易给结果打分，例如检查数学题答案、运行代码的单元测试、比较两份对话回复，或者验收一个经过 300 步才完成的 Agent 任务。

这些信号是**整条序列一个标量，且不可微**：采样是离散的，没法对"答对了"求导。这就需要一个把"序列级标量"翻译成"每个 token 的梯度"的机器。

最朴素的翻译器（REINFORCE）能用，但三个问题立刻出现：
1. **方差巨大**：奖励全是正的时候，所有样本都被推高，只有相对大小在起作用，其余都是噪声。
2. **数据太贵**：LLM 生成一批 rollout 要几分钟，用一次就扔，太浪费；可拿旧数据多更新几步，策略又会跑出数据的有效范围，一步崩掉（输出开始重复、乱码）。
3. **信用分配**：500 个 token 的回答最后得了 0 分，到底是哪一步错了？

经典 RLHF 用 baseline 与 GAE 处理方差和信用分配，用 [PPO 的裁剪目标](https://arxiv.org/abs/1707.06347) 在旧样本上做几轮更新。这套配方通常同时运行 **4 个模型**。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 策略梯度 = 加权最大似然

| 更新 | 单个 token 的权重 | 样本提供的更新方向 |
|---|---|---|
| SFT | 示范 token 的权重为 1 | 推高示范 token 的 log 概率 |
| 策略梯度 | 采样 token 的优势 $A_t$ | $A_t > 0$ 推高，$A_t < 0$ 压低 |

**画面**：模型自己采样一批回答，然后"对好于预期的回答做 SFT，对差于预期的回答做反向 SFT"。所有后训练算法的差别，几乎都在**这个权重 A 怎么算**和**能偏离采样分布多远**。

### 2.2 baseline：只看"比预期好多少"

奖励减去与动作无关的基线 $b(s)$，期望梯度不变（证明见 §3 Step 2）。估计好基线可减少梯度方差，常用的选择是状态的预期回报 $V(s)$。用实际回报减去它，就得到样本的**优势估计** $A = R - V(s)$。

### 2.3 GAE：信用分配的偏差-方差旋钮

critic 对每个前缀估计 $V(s_t)$。以有限长回答、折扣 $\gamma=1$ 和终点价值为 0 为例，GAE 有两个端点。

| 设置 | 优势估计 | 取舍 |
|---|---|---|
| $\lambda=0$ | $A_t = r_t + V(s_{t+1}) - V(s_t)$ | 只用一步 TD 残差，方差通常较小，依赖 critic 预测 |
| $\lambda=1$ | $A_t = R_t - V(s_t)$ | 等到序列结束才得出从当前步起的实际回报 $R_t$，方差通常较大 |

中间取值按 $(\gamma\lambda)^l$ 衰减后续残差的权重。回报越远，较小的 $\lambda$ 越早把判断交给 critic。

### 2.4 重要性采样 + clip：橡皮筋

rollout 来自旧策略 $\pi_{\text{old}}$，更新的是 $\pi_\theta$。给定同一个状态，用比率 $\rho = \pi_\theta/\pi_{\text{old}}$ 对旧策略采样的动作重新加权。少量很大的比率会放大估计方差，策略更新多步后，旧样本覆盖的前缀也会逐渐过时。

在右侧固定一个 $\rho > 1+\epsilon$ 的点。把正优势切换成负优势时，平坦的目标会重新带上负斜率。同一个概率比，对好动作表示已推够，对坏动作仍提供向下压的信号。

### 2.5 LLM 作为 token 级 MDP

状态 $s_t$ 是 prompt 加已生成的前缀，动作 $a_t$ 是下一个 token。环境把 token 拼到前缀上，给每步加上 KL 奖励项，并在回答末尾发放 RM 分数。

| 模型 | 职责 | 状态 |
|---|---|---|
| Actor $\pi_\theta$ | 采样并更新策略 | 训练，常按 16 B/参数估算 |
| Critic $V_\phi$ | 预测前缀的预期回报，可从奖励模型初始化 | 训练，常按 16 B/参数估算 |
| Ref $\pi_{\text{ref}}$ | 给 KL 项提供冻结的 SFT 参考策略 | 推理 |
| RM $r_\psi$ | 给整条回答打分 | 推理 |

## 3. 承重墙推导：重新捡起核心数学

### Step 1　log-derivative trick：把不可微的奖励变成可微的目标

$$
\nabla_\theta\, \mathbb{E}_{y\sim\pi_\theta}[R(y)] = \sum_y R(y)\,\nabla\pi_\theta(y) = \mathbb{E}_{y\sim\pi_\theta}\big[R(y)\,\nabla\log\pi_\theta(y)\big],
\quad \log\pi_\theta(y) = \sum_t \log\pi_\theta(y_t\mid y_{<t})
$$

**核心 Trick**：$\nabla\pi = \pi\,\nabla\log\pi$。梯度不需要穿过奖励函数，也不需要穿过采样，只需要对**自己采到的样本**求 log 概率的梯度。奖励可以是单元测试、人类打分、任何黑盒。

### Step 2　baseline 为什么不引入偏差

$$
\mathbb{E}_{y\sim\pi}\big[b\,\nabla\log\pi(y)\big] = b\sum_y \nabla\pi(y) = b\,\nabla\!\sum_y \pi(y) = b\,\nabla 1 = 0
$$

只要 $b$ 与所采样的动作无关，减掉它就保持期望梯度。方差能降多少取决于基线与回报、梯度范数的关系。第 $t$ 步的动作也影响不了已经发放的奖励，因此用从 $t$ 开始的回报计算优势已足够。

### Step 3　GAE

$$
\delta_t = r_t + \gamma V(s_{t+1}) - V(s_t),\qquad
\hat A_t^{\text{GAE}} = \sum_{l\ge 0} (\gamma\lambda)^l\, \delta_{t+l}
$$

LLM 里通常取 γ=1（有限长度，没有理由折扣），λ 取 0.95–1。critic 的回归目标是 $\hat A_t + V(s_t)$。

### Step 4　PPO-clip：悲观下界

代理目标在 $\theta = \theta_{\text{old}}$ 处的梯度就是策略梯度：

$$
L^{\text{IS}}(\theta) = \mathbb{E}_{\pi_{\text{old}}}\big[\rho_t \hat A_t\big],\qquad \rho_t = \frac{\pi_\theta(a_t\mid s_t)}{\pi_{\text{old}}(a_t\mid s_t)}
$$

$$
L^{\text{CLIP}}(\theta) = \mathbb{E}\Big[\min\big(\rho_t \hat A_t,\ \mathrm{clip}(\rho_t, 1-\epsilon, 1+\epsilon)\,\hat A_t\big)\Big]
$$

**逐情况看 min 选了谁**：

| | ρ < 1−ε | 1−ε ≤ ρ ≤ 1+ε | ρ > 1+ε |
|---|---|---|---|
| A > 0 | ρA（有梯度：好动作掉了，拉回来） | ρA | (1+ε)A（**零梯度**：已推够） |
| A < 0 | (1−ε)A（**零梯度**：已压够） | ρA | ρA（有梯度：坏动作涨了，压回去） |

- **设计巧妙之处**：只取 clip（不取 min）的话，A>0 且 ρ<1−ε 时目标变成常数 (1−ε)A，好动作掉下去了也拉不回来。min 保证 clip 只会让目标**变保守**。
- **常被忽略的事实**：clip 限制的是**每个样本的激励**，不是参数的移动幅度。学习率大、epoch 多时策略照样能跑远，所以工程上还要监控 approx-KL 和 clip_frac，必要时提前停止本轮更新。

### Step 5　脊柱：KL 正则化目标与它的闭式最优解

$$
J(\pi) = \mathbb{E}_{y\sim\pi}[r(y)] - \beta\,\mathrm{KL}(\pi\,\|\,\pi_{\text{ref}})
$$

把两项合并（$Z = \sum_y \pi_{\text{ref}}(y)e^{r(y)/\beta}$）：

$$
J(\pi) = -\beta\,\mathrm{KL}\big(\pi\,\big\|\,\pi^*\big) + \beta\log Z,\qquad
\boxed{\pi^*(y) = \frac{1}{Z}\,\pi_{\text{ref}}(y)\,e^{r(y)/\beta}}
$$

最优策略把参考模型按奖励做指数重加权。$\beta$ 趋于 0 时，概率向参考分布支持集内的高奖励回答集中，奖励的偏差也可能被放大。$\beta$ 趋于无穷时，策略回到参考分布。

| 方法 | 与上式的关系 |
|---|---|
| RL（PPO / GRPO） | 使用策略采样近似带 KL 正则的 RL 目标，可写成从 $\pi$ 到 $\pi^*$ 的反向 KL |
| SFT（2.1） | 最小化从 $p_{\text{data}}$ 到 $\pi$ 的前向 KL |
| DPO（2.4） | 从 $\pi^*$ 反解奖励 $r$，代入偏好模型，用固定偏好对估计损失 |

当策略族无法完整拟合多个峰时，前向 KL 往往更重视覆盖，反向 KL 往往偏向某个高密度峰。→ 2.1 的双峰实验给出了一个可观察的例子。

**KL 放在哪、怎么估计，是一个面试级陷阱**。设 $x \sim \pi_\theta$，比率 $u = \pi_{\text{ref}}(x)/\pi_\theta(x)$：

| 估计量 | 式子 | 作为 KL(π‖π_ref) 的值估计 | 直接当 loss 用时的梯度 |
|---|---|---|---|
| k1 | $-\log u$ | 无偏，方差大，可为负 | 期望梯度为 0（采样不求导时） |
| k2 | $\tfrac12(\log u)^2$ | 有偏，低方差 | **= 反向 KL(π‖π_ref) 的梯度** ✓ |
| k3 | $u - 1 - \log u$ | 无偏，低方差，恒非负 | **= 前向 KL(π_ref‖π) 的梯度** ✗ |

本篇代码在一个 6 类分布上数值核对过最后一列（误差 3e-8）。经典 RLHF-PPO 把 k1 放进**奖励**（梯度经优势传播）；GRPO 把 k3 放进 **loss**，于是实际优化的是另一个方向的 KL，而且样本还来自 $\pi_{\text{old}}$ 而非 $\pi_\theta$。DeepSeek-V3.2 用 $\pi_\theta/\pi_{\text{old}}$ 的重要性比率修正 k3，使 KL 估计及其梯度无偏（→ 2.5）。

## 4. 极简代码锚点（PyTorch）

经典 RLHF-PPO 的三块：奖励塑形、GAE、clip 损失。全部张量为 `(B, T)`，右侧 padding，`mask` 标出回答 token。已跑通，padding 位置梯度为 0。

```python
import torch

def shaped_rewards(rm_score, old_logp, ref_logp, mask, beta=0.05):
    r = -beta * (old_logp - ref_logp) * mask                  # 每 token 的 k1 KL 惩罚（进奖励）
    last = mask.sum(1).long() - 1                             # 最后一个有效 token
    r[torch.arange(len(r)), last] += rm_score                 # RM 分只给在末尾：稀疏奖励
    return r                                                  # (B, T)

def gae(rewards, values, mask, gamma=1.0, lam=0.95):
    B, T = rewards.shape
    adv, last = torch.zeros_like(rewards), torch.zeros(B)
    for t in reversed(range(T)):                              # 从后往前累积 TD 残差
        nxt = values[:, t + 1] * mask[:, t + 1] if t + 1 < T else torch.zeros(B)
        delta = rewards[:, t] + gamma * nxt - values[:, t]    # δ_t
        last = (delta + gamma * lam * last) * mask[:, t]      # 越过末尾清零
        adv[:, t] = last
    return adv, adv + values                                  # 优势, critic 的回归目标

def ppo_loss(logp, old_logp, adv, values, old_values, returns, mask, eps=0.2, eps_v=0.2):
    m = mask.bool()
    adv = (adv - adv[m].mean()) / (adv[m].std() + 1e-8)       # batch 内白化
    ratio = torch.exp(logp - old_logp)                        # ρ_t
    pg = -torch.min(ratio * adv, ratio.clamp(1 - eps, 1 + eps) * adv)   # 悲观下界
    v_clip = old_values + (values - old_values).clamp(-eps_v, eps_v)
    vf = torch.max((values - returns) ** 2, (v_clip - returns) ** 2)    # critic 也有信任域
    avg = lambda x: (x * mask).sum() / mask.sum()             # token 级平均
    clip_frac = avg(((ratio - 1).abs() > eps).float())        # 监控：比率超出裁剪带的 token 比例
    return avg(pg) + 0.25 * avg(vf), clip_frac
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **算法 = 少数几个独立旋钮的一种取值**。Prime Intellect 的 RL 术语表把 PPO、GRPO 及其变体统一描述为：用优势加权 token 的 log 概率梯度，每个具名算法只是几个独立设计选择的一种组合。旋钮是：优势怎么算、怎么归一化、比率取 token 级还是序列级、信任域怎么做、要不要参考 KL。读新论文时，先把它放进这张表里。
- **critic 退场，但没有消失**。一份 GRPO 家族综述画出了架构演化：PPO（4 个模型）→ GRPO（3 个）→ DAPO（2 个）→ VAPO（4 个，强化了 critic）。推理 RL 的主流是去掉 critic 的 GRPO 家族（→ 2.5），但长程、多轮的 Agent 任务里，信用分配又在把价值估计请回来（→ 2.6）。
- **前沿配方是"PPO-clip 骨架 + 换零件"**。DeepSeek-V3.2 在 GRPO 上做了四处修补：无偏 KL 估计、off-policy 序列掩码、Keep Routing（训练时强制使用推理采样时的专家路由）、Keep Sampling Mask（对齐 top-p / top-k 截断后的动作空间），后训练算力超过了预训练的 10%。Kimi K3 先按领域 × 推理档位分别做 RL，再用多教师 on-policy 蒸馏合成一个模型；在 K3 上跑 RL 的工程报告专门讲了数值对齐和路由回放（router replay）。共同点：**rollout 端与训练端的一致性，已经和目标函数一样重要**（→ 2.7）。

**与工程 / 应用的连接**
- **RLHF 的账（接 5.1）**：Actor 和 Critic 各 16 B/参数，Ref 和 RM 各 2 B/参数（BF16 推理），合计约 36 B/参数，是 SFT（16）的 2 倍多；更大的成本在时间上，rollout 是 decode，落在屋脊左边，常占一步训练的大头。这就是为什么去掉 critic（GRPO）、去掉 Ref（DAPO）能直接变成钱。
- **训练监控就是可观测性**：reward、KL to ref、clip_frac、entropy、响应长度、value loss 是 RL 的"六条 trace"。reward 涨、KL 平稳、长度暴涨、entropy 骤降 → 先怀疑 hacking 或长度偏置，而不是"模型变聪明了"。

**常见误区 / 反直觉点**
1. **"clip 限制了参数的更新幅度"** ✗：clip 只是让被推够的样本不再提供梯度。参数能走多远由学习率、epoch 数、mini-batch 数决定，所以要看 approx-KL。
2. **"baseline 会让梯度有偏"** ✗：与动作无关的 baseline 永远无偏。GAE 的偏差来自 λ<1 时对 critic 的自举（bootstrap），不是来自 baseline 本身。
3. **"KL 放在奖励里还是放在 loss 里，结果一样"** ✗：放奖励里（k1）走优势、受 GAE 影响；放 loss 里（GRPO 用 k3）的梯度对应的是**前向** KL，与 RLHF 目标中的反向 KL 方向相反。这就是 V3.2 要修正它的原因。

**高频深挖题**
- **Q1：PPO 的目标为什么要取 min？只 clip 不取 min 会怎样？**
  思路：画 §3 Step 4 的表 → 只 clip 时，A>0 且 ρ 掉到 1−ε 以下会被截成常数，好动作的概率掉了也拉不回来 → min 让 clip 只在"目标显得更好"的方向生效，构成悲观下界 → 补一句：clip 不等于约束参数，还要看 approx-KL。
- **Q2：LLM 里 GAE 的 γ、λ 一般怎么取？为什么 critic 在 LLM 上难训？**
  思路：γ=1（有限长度），λ 取 0.95–1 → critic 要从半截文本预测最终得分，奖励稀疏且只在末尾，价值函数和策略同时在变 → 常见现象是 value loss 降不下去、优势噪声大 → 这正是 GRPO 用"同题多采样的组内平均分"替代 critic 的动机（→ 2.5）。
