# 3.1 视觉表征三条路：CLIP / DINO / MAE [熟区：DINO 部分]

> **一句话核心直觉**：视觉表征学习的三条路，区别在于"拿什么当监督信号"。**对比学习**（CLIP / SigLIP）用配对的文本当另一个视角，学到能和语言对齐的全局语义；**自蒸馏**（DINO）让学生在不同裁剪上模仿老师，学到稠密、天然可分割的 patch 特征；**掩码重建**（MAE）补全被遮住的像素，学到低层结构，但通常要微调才好用。下游选哪个，取决于你要全局语义、稠密几何，还是一个好的微调起点。
> **唤醒标签**：InfoNCE 与温度 · sigmoid 损失（SigLIP）· 自蒸馏与防坍塌（centering / sharpening）· Gram anchoring · 掩码比例

**本篇定位**：DINO 部分是熟区，只保留面试表达需要的骨架；重点放在三条路的对比、对比学习的数学，以及它们在 VLM 和生成模型里的位置。

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

一个常见的选型困惑：做 VLM，大家用 CLIP / SigLIP 系的编码器；做分割、深度估计、密集对应，大家用 DINO 系；做需要微调的下游检测任务，MAE 预训练的 ViT 又很常见。**同样是 ViT，换个预训练目标，学到的特征性格完全不同。**

另一个反直觉的事实：编码器的规模不是第一位的。一份 2026 年的视觉编码器综述发现，400M 参数的 SigLIP 2 在大多数 VLM 任务上超过了 5.9B 参数的 InternViT-6B。训练目标和数据，比参数量更决定特征的质量。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 三条路一张表

| | 对比（CLIP / SigLIP） | 自蒸馏（DINO 系列） | 掩码重建（MAE） |
|---|---|---|---|
| 监督信号 | 配对的文本（另一个模态的视角） | 同一张图的另一种裁剪（老师的输出） | 被遮住的像素本身 |
| 学到什么 | 全局语义，和语言对齐 | 稠密的 patch 语义，物体边界清晰 | 低层结构与纹理 |
| 天然擅长 | 零样本分类、图文检索、VLM | 分割、深度、密集对应、以图搜图 | 微调后的检测、分割 |
| 主要短板 | patch 级定位弱（SigLIP 2 有所改善） | 不和语言对齐 | 线性探测弱，要微调 |

### 2.2 对比学习：batch 内的 N 选 1

```
          文本1  文本2  文本3  …  文本N
图片1      ✓     ✗      ✗          ✗      每张图要在 N 段文本里认出自己的那段
图片2      ✗     ✓      ✗          ✗      → N 路分类，正确答案在对角线上
 …
```

- **batch 越大，负样本越多，题越难**，学到的特征越有区分度。这就是 CLIP 要用超大 batch 的原因。
- **温度 τ** 控制"多关注难负样本"：τ 小，softmax 更尖，梯度集中在最像正样本的那几个负样本上。
- **SigLIP** 把 softmax 换成逐对的 sigmoid：每个图文对独立判断"是不是一对"，不需要在整个 batch 上做全局归一化，通信和显存都更友好，batch 也更容易扩大。

### 2.3 自蒸馏：不要标签，也不坍塌

```
同一张图 ─┬─► 大裁剪（全局视角）─► 老师（学生的 EMA）─► 分布 p_t ─┐
          └─► 小裁剪（局部视角）─► 学生 ──────────────► 分布 p_s ─┴─► 交叉熵：学生模仿老师
```

没有负样本的自监督，最大的风险是**坍塌**：所有图片都输出同一个东西，损失也很小。DINO 用两个相反的力量防住两种坍塌：
- **centering**（老师输出减去一个滑动平均的中心）：防止某一维永远占主导；
- **sharpening**（老师用更低的温度）：防止输出变成均匀分布。

DINOv3 把这套方法推到 7B 参数、约 17 亿张图像，并提出 **Gram anchoring**：长时间训练后，稠密特征图会逐渐退化（patch 之间的相似性结构变糊），Gram anchoring 用一个 Gram 矩阵目标，约束学生 patch 特征之间的余弦相似度结构与老师保持一致。

### 2.4 掩码重建：遮掉 75% 再补回来

MAE 随机遮住 75% 的 patch，编码器只处理看得见的 25%（训练很省），轻量解码器负责重建像素。高遮挡比例迫使模型理解整体结构，而不是靠邻近像素插值。但像素级重建的目标偏向低层细节，所以 MAE 特征的线性探测效果一般，微调后才发挥实力。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　InfoNCE 与互信息下界

$$
\mathcal{L}_{\text{InfoNCE}} = -\frac1N\sum_{i=1}^N \log\frac{\exp(\langle z_i, w_i\rangle/\tau)}{\sum_{j=1}^N \exp(\langle z_i, w_j\rangle/\tau)},
\qquad
I(Z;W) \;\ge\; \log N - \mathcal{L}_{\text{InfoNCE}}
$$

- CLIP 对图→文和文→图两个方向各算一次再平均。
- **下界的含义**：InfoNCE 能"证明"的互信息最多是 log N。batch 大小直接限制了对比学习能区分的信息量。本篇代码里，batch=8 时 log N = 2.08；随机初始化的损失是 2.71，正样本对几乎对齐时损失降到 0.0001。

### Step 2　温度的作用

对负样本 j 的梯度权重正比于 $\mathrm{softmax}_j(\langle z_i,w_j\rangle/\tau)$。τ 越小，权重越集中在相似度最高的那几个负样本（难负样本）上。τ 太小训练不稳定，太大则所有负样本被一视同仁、学不到细粒度区分。CLIP 把 τ 设为可学习参数。

### Step 3　SigLIP 的逐对损失

$$
\mathcal{L}_{\text{SigLIP}} = -\frac1N\sum_{i,j}\log\sigma\big(z_{ij}\,(t\,\langle x_i, y_j\rangle + b)\big),\qquad z_{ij} = \begin{cases}+1 & i=j\\ -1 & i\ne j\end{cases}
$$

每个格子是一个独立的二分类。没有分母，就不需要把整个 batch 的相似度矩阵汇总到一起做归一化。可学习的偏置 b 用来抵消"负样本远多于正样本"带来的不平衡。

### Step 4　DINO 的损失与两个防坍塌机制

$$
\mathcal{L} = -\sum_k p_t^{(k)}\log p_s^{(k)},\qquad
p_t = \mathrm{softmax}\Big(\frac{g_t(x_1) - c}{\tau_t}\Big),\quad
p_s = \mathrm{softmax}\Big(\frac{g_s(x_2)}{\tau_s}\Big),\quad \tau_t < \tau_s
$$

$$
c \leftarrow m\,c + (1-m)\,\overline{g_t(x)},\qquad \theta_t \leftarrow \lambda\,\theta_t + (1-\lambda)\,\theta_s
$$

- centering 把老师推向均匀，sharpening（$\tau_t$ 小）把老师推向尖锐，两者平衡才不坍塌。
- 老师不接收梯度，是学生参数的指数滑动平均，相当于一个缓慢演化的"集成模型"，提供稳定的目标。

### Step 5　MAE 的掩码与损失

$$
\mathcal{L}_{\text{MAE}} = \frac{1}{|\mathcal{M}|}\sum_{i\in\mathcal{M}}\|\hat x_i - x_i\|^2
$$

只在被遮住的 patch 集合 $\mathcal{M}$ 上算重建误差。编码器只处理可见的 25%，计算量约为全量的四分之一，这也是 MAE 能高效扩大规模的原因。

## 4. 极简代码锚点（PyTorch）

CLIP 的 InfoNCE、SigLIP 的 sigmoid 损失、带 centering 的 DINO 损失、MAE 的随机掩码。已跑通。

```python
import torch, torch.nn.functional as F

def info_nce(img, txt, tau=0.07):                               # img, txt: (N, D) 配对特征
    img, txt = F.normalize(img, dim=-1), F.normalize(txt, dim=-1)
    logits = img @ txt.T / tau                                  # (N, N)，正确答案在对角线
    y = torch.arange(len(img))
    return (F.cross_entropy(logits, y) + F.cross_entropy(logits.T, y)) / 2   # 图→文、文→图

def siglip_loss(img, txt, t=10.0, b=-10.0):                     # 逐对 sigmoid，无需全局归一化
    img, txt = F.normalize(img, dim=-1), F.normalize(txt, dim=-1)
    z = 2 * torch.eye(len(img)) - 1                             # 对角线 +1，其余 −1
    return -F.logsigmoid(z * (img @ txt.T * t + b)).sum() / len(img)

class DINOLoss:
    def __init__(self, K, t_s=0.1, t_t=0.04, m=0.9):
        self.c, self.t_s, self.t_t, self.m = torch.zeros(K), t_s, t_t, m
    def __call__(self, s_out, t_out):                           # (B, K) 学生 / 老师的投影头输出
        p_t = F.softmax((t_out - self.c) / self.t_t, -1).detach()   # centering + sharpening
        loss = -(p_t * F.log_softmax(s_out / self.t_s, -1)).sum(-1).mean()
        self.c = self.m * self.c + (1 - self.m) * t_out.mean(0).detach()   # 中心的滑动平均
        return loss

def mae_mask(B, N, ratio=0.75):                                 # 返回可见 / 被遮 patch 的下标
    ids = torch.rand(B, N).argsort(1); keep = int(N * (1 - ratio))
    return ids[:, :keep], ids[:, keep:]                         # 编码器只处理前者
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **DINOv3 让自监督像语言模型一样扩展**：7B 参数，在约 16.89 亿张精选图像上预训练，再蒸馏成一族小模型（ViT-S / B / L 和 ConvNeXt 变体）；Gram anchoring 解决了长训练中稠密特征退化的问题，稠密任务上明显超过此前的自监督和弱监督模型。
- **SigLIP 2 补上了对比学习的短板**：在原有的 sigmoid 损失之外，加入了自监督损失和基于解码器的损失，稠密特征和定位能力明显改善；提供保持原始长宽比的 NaFlex 变体；成为 VLM 编码器的常见选择。
- **表示学习与生成模型交汇**：用 DINO 类特征对齐扩散模型的中间表示（REPA）曾是加速生成训练的热门方法，但 Black Forest Labs 2026 年的工作发现，这种外部对齐会在后期停滞，在视频和音频上甚至有害，转而提出在 flow 目标内部做自监督（→ 4.2）。

**与工程 / 应用的连接**
- **检索选 CLIP / SigLIP，密集任务选 DINO**：图文检索、零样本分类要和语言对齐的全局特征；以图搜图里的"同款识别"、局部匹配、密集对应这类任务，DINO 的 patch 特征往往更好用。
- **VLM 编码器的选择**：需要读文字、做定位的应用，优先选在稠密特征上有改进的编码器（如 SigLIP 2），并配合原生分辨率（→ 3.2）。

**常见误区 / 反直觉点**
1. **"CLIP 特征也能直接做好分割"** ✗：对比学习优化的是全局图文匹配，patch 级的定位信号很弱。这正是 SigLIP 2 要额外加入稠密目标的原因。
2. **"自监督就是不需要数据工程"** ✗：DINOv3 的关键贡献之一就是精心的数据准备，从海量图片里筛出 16.89 亿张。自监督省掉的是标注，不是数据工作。
3. **"batch 越大，对比学习就一定越好"** ✗：大 batch 提高了互信息下界 log N，但 softmax 版本要做全局归一化，扩展成本高。SigLIP 用逐对 sigmoid 把"效果"和"batch 规模"部分解耦。

**高频深挖题**
- **Q1：DINO 为什么需要 centering 和 sharpening？只用其中一个会怎样？**
  思路：无负样本的自蒸馏有两种坍塌：所有输出集中到某一维、所有输出变成均匀分布 → centering 防前者但会推向均匀，sharpening 防后者但会推向集中，两者对抗才稳定 → 老师是学生的 EMA，提供缓慢变化的目标 → 加分项：DINOv3 的 Gram anchoring 针对的是另一个问题，即长训练中稠密特征的相似性结构退化。
- **Q2：做一个 VLM 和做一个语义分割系统，视觉编码器分别怎么选？为什么？**
  思路：VLM 要和语言对齐的全局语义，选对比学习系（SigLIP 2，兼顾稠密特征）→ 分割要 patch 级的语义一致性和清晰边界，选自蒸馏系（DINO 系列）→ 背后的原因是监督信号不同：文本配对只约束全局，跨裁剪自蒸馏约束局部 patch → 收尾：两者也可以融合，多编码器拼接能互补。
