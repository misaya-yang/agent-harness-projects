# 3.1 视觉表征三条路：CLIP / DINO / MAE [熟区：DINO 部分]

> **一句话核心直觉**：视觉表征学习的三条路，区别在于"拿什么当监督信号"。**对比学习**（CLIP / SigLIP）用配对的文本当另一个视角，学到能和语言对齐的全局语义；**自蒸馏**（DINO）让学生在不同裁剪上模仿老师，学到稠密、天然可分割的 patch 特征；**掩码重建**（MAE）补全被遮住的像素，学到低层结构，但通常要微调才好用。下游选哪个，取决于你要全局语义、稠密几何，还是一个好的微调起点。
> **唤醒标签**：InfoNCE 与温度 · sigmoid 损失（SigLIP）· 自蒸馏与防坍塌（centering / sharpening）· Gram anchoring · 掩码比例

**本篇定位**：DINO 部分是熟区，只保留面试表达需要的骨架；重点放在三条路的对比、对比学习的数学，以及它们在 VLM 和生成模型里的位置。

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

在计算机视觉与多模态工程中，选型者常面临一个典型困惑：做多模态大模型（VLM）时，业界普遍选用 CLIP 或 SigLIP 系的视觉编码器；做语义分割、单目深度估计或密集几何对应时，首选往往是 DINO 系列；而做需要下游微调的目标检测与实例分割时，MAE 预训练的 ViT 又是极为常见的骨干基座。**即便采用完全相同的 ViT 架构，仅因预训练目标的不同，模型学到的特征空间与表征性格便大相径庭。**

另一个打破直觉的事实是：视觉编码器的参数规模并不直接决定表征优劣。2026 年的一份视觉编码器评测综述指出，仅约 400M 参数的 SigLIP 2 编码器在大多数下游 VLM 综合任务上的表现，反超了 5.9B 参数的 InternViT-6B。预训练的设计目标与清洗后的数据分布，远比单纯堆叠参数量更能决定特征表征的本质质量。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 三条路一张表

| | 对比学习（CLIP / SigLIP） | 自蒸馏（DINO 系列） | 掩码重建（MAE） |
|---|---|---|---|
| 监督信号 | 配对的文本（跨模态自然语言视角） | 同一图像的另一裁剪视图（教师网络的软预测分布） | 被遮挡区域的原始像素本身 |
| 学到什么 | 全局语义表征，与自然语言严格对齐 | 稠密的 patch 级局部语义，具有自发聚类的清晰物体轮廓 | 低层几何拓扑与纹理结构 |
| 天然擅长 | 零样本分类、跨模态图文检索、VLM 图像理解 | 语义分割、深度估计、稠密对应、以图搜图 | 微调后的下游目标检测、精细化分割 |
| 主要短板 | patch 级局部定位能力弱（SigLIP 2 有所改善） | 缺乏与文本的显式映射，无法直接做跨模态图文交互 | 线性探测（Linear Probing）弱，通常必须全面微调才显威力 |

### 2.2 对比学习：batch 内的 N 选 1

CLIP 将同一批次（batch）内配对的 $N$ 张图像与 $N$ 条文本排成相似度矩阵。第 $i$ 张图像与其对应的真实文本位于矩阵第 $i$ 列（对角线位置），其余非对角列均视为负样本候选。图像到文本的检索在每一行计算一次跨所有文本候选的 softmax 分类；文本到图像的检索则在每一列计算一次跨所有图像候选的 softmax 分类。

- **batch 规模越大，负样本池越庞大，分类任务越严苛**：模型被迫在更多相似语义的干扰项中精准锚定正确配对，从而推高表征空间的互信息下界。这正是 CLIP 必须依赖超大 batch 规模分布式训练的根本原因。
- **温度超参数 $\tau$ 调控着对难负样本（hard negatives）的惩罚倾斜度**：$\tau$ 越小，softmax 分布越尖锐，反向传播的梯度越会集中在那些与正样本最相似的极少数混淆样本上。
- **SigLIP 则将全局归一化的 softmax 替换为逐对独立的 sigmoid 二分类**：每个图文对独立判断“是否匹配”，不再需要在全 batch 范围内跨多机通信汇总配分函数的分母。这极大改善了分布式通信与显存开销，使更大规模的 batch 扩展更加平稳顺畅。

### 2.3 自蒸馏：不要标签，也不坍塌

DINO 从同一张输入图像中生成大尺寸的全局裁剪与小尺寸的局部裁剪视图。教师网络仅接收包含全局上下文的裁剪，生成高维概率分布 $p_t$；学生网络则需要根据信息受限的局部裁剪，预测出教师眼中的完整分布 $p_s$，并通过交叉熵损失向教师对齐。教师网络的权重不接收直接梯度，而是通过学生网络参数的指数滑动平均（EMA）稳步演进。

在完全没有负样本排斥的自监督学习中，最大的系统性风险是**表征坍塌（Representation Collapse）**：网络若对所有输入图片均退化输出恒定的相同向量，训练损失同样极小。DINO 引入了两个方向相反的动力学机制来约束表征：
- **中心化（centering）**：将教师网络的未归一化输出减去一个指数滑动平均中心向量，抑制特定维度长期占主导，防止特征全部塌陷至单一极点（推向平坦均匀分布）；
- **尖锐化（sharpening）**：为教师网络设置比学生网络更低的温度参数 $\tau_t < \tau_s$，强制概率分布聚焦，防止输出退化为全维度的平庸均匀分布。

[DINOv3](https://arxiv.org/abs/2508.10104) 进一步将该自监督视觉体系扩展到了 7B 参数与约 17 亿张精选图像，并针对超长训练中的表征退化提出了 **Gram anchoring** 机制。在经历超大规模步数迭代后，稠密 patch 特征彼此间的相对空间几何关系极易变得模糊涣散；Gram anchoring 计算特征 patch 之间的 Gram 相似度矩阵，强制要求学生网络的局部相关性结构时刻锚定在预设的教师先验上。

### 2.4 掩码重建：遮掉 75% 再补回来

MAE 随机掩码遮盖掉图像中 75% 的 patch，并将未被遮挡的 25% 稀疏 patch 送入 ViT 编码器中提取特征，最后由极其轻量的解码器负责把全图被遮盖的像素补全。高达 75% 的极端遮蔽率消除了图像相邻像素间的信息冗余，迫使模型只能依据稀疏且不连续的线索去理解高维整体结构，无法依靠邻近像素平滑插值投机取巧。然而，以还原低层像素为目标的优化使得 MAE 的特征缺乏高级语义抽象，因而其浅层线性探测指标一般，唯有经过下游微调重新适配后才能释放深层结构表征的威力。

### 只把可见 patch 送进编码器，省掉了哪部分计算？

假定单张图像切分为 256 个 patch，在 75% 的遮挡率下，仅剩余 64 个 patch 进入视觉编码器。逐 token 线性变换（如输入 Patch 投影、MLP 前馈网络）的计算量与处理的 token 数量成正比，计算负荷缩减至 $64/256 = 25\%$；而 ViT 自注意力机制中的 Query–Key 点积运算涉及两两配对，计算开销与序列长度呈二次方关系，其计算量急剧缩减至 $(64/256)^2 = 6.25\%$。

若遮蔽比例过低，模型仅需依赖邻近像素的低频纹理即可插值完成修补，无法学到深层表征；若遮挡比例过高，残留的可用线索又不足以恢复物体局部。计算量节省曲线清晰展示了算力削减的理论折扣，但在具体工业实践中，遮蔽比例的最终选型必须在固定训练预算下结合下游精度曲线做权衡。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　InfoNCE 与互信息下界

$$
\mathcal{L}_{\text{InfoNCE}} = -\frac1N\sum_{i=1}^N \log\frac{\exp(\langle z_i, w_i\rangle/\tau)}{\sum_{j=1}^N \exp(\langle z_i, w_j\rangle/\tau)},
\qquad
I(Z;W) \;\ge\; \log N - \mathcal{L}_{\text{InfoNCE}}
$$

- 其中 $z_i$ 与 $w_i$ 分别代表第 $i$ 张图像与对应文本经 $L_2$ 归一化后的特征向量，$\langle z_i, w_j \rangle$ 为其余弦相似度，$\tau$ 为温度超参数。在工程实现中，CLIP 对“图到文”与“文到图”两个检索方向分别计算交叉熵损失，最后取两者的算术平均。
- **互信息下界的本质**：依据从边缘分布独立采样负样本的理论推导，InfoNCE 损失为表征变量 $Z$ 与 $W$ 之间的互信息 $I(Z;W)$ 构筑了一个以 $\log N$ 为上限的变分下界。在 batch 规模 $N=8$ 的算例中，理论最大容量为 $\log 8 \approx 2.08$；随机初始化且未对齐时损失约为 $2.71$，而当正样本对表征几乎完全对齐时，该损失可降至 $0.0001$ 附近。

### Step 2　温度超参数的作用机制

考察特定图像的“图到文”损失：负样本文本 $j$ 所接收到的相似度梯度，正比于其 softmax 预测概率并缩放 $1/\tau$ 倍。由于同批次内的所有负样本共享缩放因子 $1/\tau$，它们分配到的梯度惩罚比例完全由各自的 softmax 概率权重决定。CLIP 在训练中将温度的倒数当作一个可学习标量参数，用来动态缩放相似度矩阵的动态范围。


在上方实验中，正样本相似度固定为 0.80。试着把“最相似的错误文本”（难负样本）相似度滑块停在 0.80 附近，并左右调节“softmax 温度 $\tau$”：当温度降低时，softmax 极化效应加剧，梯度份额近乎全额灌注在最容易混淆的极少数难负样本上；当错误文本相似度偏离 0.80 时，更易观察到低温如何剧烈放大正负样本间的排序差距。

### Step 3　SigLIP 的逐对二分类损失

$$
\mathcal{L}_{\text{SigLIP}} = -\frac1N\sum_{i,j}\log\sigma\big(z_{ij}\,(t\,\langle x_i, y_j\rangle + b)\big),\qquad z_{ij} = \begin{cases}+1 & i=j\\ -1 & i\ne j\end{cases}
$$

将图文矩阵中的每一个格子视作一个完全独立的二分类任务（匹配为 $+1$，不匹配为 $-1$）。因不存在跨样本分母归一化，训练时无需在卡间同步汇总全 batch 的相似度总和。可学习标量 $t$ 充当温度逆系数，而可学习偏置 $b$ 则有效抵消了由于负样本数量（$N^2-N$）远超正样本（$N$）所引发的先验分布失衡。

### Step 4　DINO 的自蒸馏损失与防坍塌机制

$$
\mathcal{L} = -\sum_k p_t^{(k)}\log p_s^{(k)},\qquad
p_t = \mathrm{softmax}\Big(\frac{g_t(x_1) - c}{\tau_t}\Big),\quad
p_s = \mathrm{softmax}\Big(\frac{g_s(x_2)}{\tau_s}\Big),\quad \tau_t < \tau_s
$$

$$
c \leftarrow m\,c + (1-m)\,\overline{g_t(x)},\qquad \theta_t \leftarrow \lambda\,\theta_t + (1-\lambda)\,\theta_s
$$

- 其中 $g_t$ 与 $g_s$ 分别为教师网络与学生网络的非线性投影头，中心向量 $c$ 依据当前批次均值以动量 $m$ 持续更新。
- 中心化（centering）操作剥离了特征均值偏移，将教师分布往均匀方向推拉；尖锐化（sharpening，采用极低的教师温度 $\tau_t$）则强行拉开峰值差距，将分布往尖锐聚焦方向推拉。两者动态制衡，在无需负样本排斥的前提下锁死了表征坍塌通道。
- 教师网络不计算反向梯度，仅通过 EMA 以平滑动量 $\lambda$ 跟随学生更新，实质上扮演了一个缓慢演化的集成模型（Ensemble），输出平稳可靠的软对齐靶标。

### Step 5　MAE 的掩码设计与重建损失

$$
\mathcal{L}_{\text{MAE}} = \frac{1}{|\mathcal{M}|}\sum_{i\in\mathcal{M}}\|\hat x_i - x_i\|^2
$$

仅在被掩码遮蔽的 patch 集合 $\mathcal{M}$ 上计算归一化像素均方误差。由于 ViT 编码器输入端物理剔除了 75% 的遮蔽区域，逐 token 的投影层与 MLP 前馈网络仅需处理 $25\%$ 的 token 序列；而在注意力算子内，自注意力的两两配对交互次数更缩减至全图的十六分之一（$(1/4)^2 = 1/16$）。即便加上末端较浅的轻量级解码器，整体预训练吞吐量依然显著跃升。

## 4. 极简代码锚点（PyTorch）

CLIP 的 InfoNCE、SigLIP 的 sigmoid 损失、带 centering 的 DINO 损失、MAE 的随机掩码。已跑通。

```python
import torch, torch.nn.functional as F

def info_nce(img, txt, tau=0.07):                               # img, txt: (N, D) 配对特征
    img, txt = F.normalize(img, dim=-1), F.normalize(txt, dim=-1)
    logits = img @ txt.T / tau                                  # (N, N)，正确答案在对角线
    y = torch.arange(len(img))
    return (F.cross_entropy(logits, y) + F.cross_entropy(logits.T, y)) / 2   # 图→文、文→图

def siglip_loss(img, txt, t=10.0, b=-10.0):                     # 逐对 sigmoid，无需全局归一化
    img, txt = F.normalize(img, dim=-1), F.normalize(txt, dim=-1)
    z = 2 * torch.eye(len(img)) - 1                             # 对角线 +1，其余 −1
    return -F.logsigmoid(z * (img @ txt.T * t + b)).sum() / len(img)

class DINOLoss:
    def __init__(self, K, t_s=0.1, t_t=0.04, m=0.9):
        self.c, self.t_s, self.t_t, self.m = torch.zeros(K), t_s, t_t, m
    def __call__(self, s_out, t_out):                           # (B, K) 学生 / 老师的投影头输出
        p_t = F.softmax((t_out - self.c) / self.t_t, -1).detach()   # centering + sharpening
        loss = -(p_t * F.log_softmax(s_out / self.t_s, -1)).sum(-1).mean()
        self.c = self.m * self.c + (1 - self.m) * t_out.mean(0).detach()   # 中心的滑动平均
        return loss

def mae_mask(B, N, ratio=0.75):                                 # 返回可见 / 被遮 patch 的下标
    ids = torch.rand(B, N).argsort(1); keep = int(N * (1 - ratio))
    return ids[:, :keep], ids[:, keep:]                         # 编码器只处理前者
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **DINOv3 让自监督像语言模型一样扩展**：7B 参数，在约 16.89 亿张精选图像上预训练，再蒸馏成一族小模型（ViT-S / B / L 和 ConvNeXt 变体）；Gram anchoring 解决了长训练中稠密特征退化的问题，稠密任务上明显超过此前的自监督和弱监督模型。
- **SigLIP 2 补上了对比学习的短板**：在原有的 sigmoid 损失之外，加入了自监督损失和基于解码器的损失，稠密特征和定位能力明显改善；提供保持原始长宽比的 NaFlex 变体；成为 VLM 编码器的常见选择。
- **表示学习与生成模型交汇**：用 DINO 类特征对齐扩散模型的中间表示（REPA）曾是加速生成训练的热门方法，但 Black Forest Labs 2026 年的工作发现，这种外部对齐会在后期停滞，在视频和音频上甚至有害，转而提出在 flow 目标内部做自监督（→ 4.2）。

**与工程 / 应用的连接**
- **跨模态检索选 CLIP / SigLIP，密集几何任务选 DINO**：跨模态图文检索与零样本分类依赖与语言强对齐的高维全局特征；而在以图搜图中的“同款识别”、细粒度局部匹配、点级稠密对应等任务中，DINO 的 patch 特征具备自发语义轮廓聚类能力，表现更为优异。
- **VLM 视觉编码器的选型权衡**：若业务涉及密集文本识别（OCR）、文档图表解析或屏幕细小目标定位，应优先选用在稠密局部特征上有针对性增强的编码器（如 SigLIP 2），并结合支持非固定长宽比的原生分辨率机制（→ 3.2）。

**常见误区 / 反直觉点**
1. **“CLIP 特征也能直接胜任精细分割”** ✗：对比学习的核心是拉近全局图像与文本描述的余弦相似度，对 patch 级别的局部空间定位监督极其微弱。这正是 SigLIP 2 必须在全局损失之外额外融入自监督稠密掩码重建目标的主因。
2. **“自监督训练等于不需要做数据工程”** ✗：DINOv3 能实现规模扩展的底层基石之一是严苛的数据清洗流水线，从海量非结构化图像池中精炼出 16.89 亿张高质量样本。自监督消除的是昂贵的人工标注，而非严谨的数据治理。
3. **“batch 规模越大，对比学习效果就必然无上限提升”** ✗：虽然增大 batch 提升了互信息理论下界 $\log N$，但传统 softmax 依赖跨计算节点的全局配分归一化，显存与通信瓶颈会急剧凸显。SigLIP 引入的逐对独立 sigmoid 机制，正是为了将“对比学习的判别力”与“分布式 batch 扩展上限”有效解耦。

**高频深挖题**
- **Q1：DINO 为什么需要同时引入 centering 和 sharpening？只保留其中一种会发生什么？**
  思路：在无负样本排斥的自蒸馏架构中，存在两类典型坍塌：特征被极少数主导维度统治（局部坍塌），或特征退化为所有维度毫无差异的完全均匀分布（全局平坦）→ Centering 减去均值中心以抵消主导特征，但单独使用会将分布推向纯均匀状态；Sharpening 通过教师极低温度拉开极值差距，但单独使用会快速加剧特定维度霸占概率分布 → 必须由两者在动力学上互相制衡，同时依赖教师网络参数的慢速 EMA 更新作为稳定参照基准 → 加分项：DINOv3 的 Gram anchoring 进一步解决了在长周期极端规模预训练中，局部 patch 相对相似度拓扑逐渐漂移散焦的深层退化问题。
- **Q2：设计一个通用多模态模型（VLM）与一个密集语义分割系统，在视觉编码器上该如何抉择？为什么？**
  思路：VLM 核心需要与文本语言空间紧密对齐的高层语义概念，故首选对比学习系编码器（如 SigLIP 2，兼具全局文本对齐与稠密表征能力）→ 密集分割系统依赖 patch 级高保真局部结构与清晰的物体几何边界，首选自蒸馏系编码器（如 DINO 系列）→ 本质归因于二者预训练监督信号的差异：图文匹配施加的是全局语义约束，多尺度局部裁剪自蒸馏施加的是空间邻域的一致性约束 → 补充：工业前沿亦常采用双编码器特征拼接（Concatenation）或多层特征融合方案互补长短。
