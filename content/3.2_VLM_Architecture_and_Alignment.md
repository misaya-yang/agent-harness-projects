# 3.2 VLM 架构与模态对齐：把图片翻译成"外语单词"

> **一句话核心直觉**：主流 VLM 是"翻译官"结构：视觉编码器把图切成 patch 特征，连接器把它们翻译成 LLM 能读的 token，LLM 把它们当成一种外语单词，和文字一起读。真正的工程难题集中在三处：**分辨率与 token 数的平方关系、视觉位置怎么编码、各训练阶段解冻什么**。
> **唤醒标签**：ViT patch · MLP 连接器 vs Q-Former · 两阶段对齐 · 动态 / 原生分辨率 · M-RoPE 与交错 M-RoPE · DeepStack · 视觉幻觉

前置：1.2（RoPE 频率谱，本篇的位置编码部分直接用到）、1.3（token 数决定 KV 成本）。

## 1. 痛点与钩子：如果没有它，世界会怎样？

在多模态工程落地中，一个最直接的算力痛点是：**一张高分辨率图像到底会吞噬掉多少 token 预算？** 以 Qwen2.5-VL 采用的 14 像素 patch 结合 2×2 邻域特征合并为例，进入语言模型前，一个视觉 token 覆盖的物理面积为 $(14\times 2)\times (14\times 2) = 28\times 28$ 像素。按宽高每边完整分组向下取整计算：

| 分辨率 | 视觉 token 数 |
|---|---:|
| 448 × 448 | 256 |
| 1,344 × 896 | 1,536 |
| 1,920 × 1,080 | 2,584 |
| 2,560 × 1,440 | 4,641 |

在 Computer-Use 或 GUI Agent 场景中，智能体每一步交互都需要截取一张 2K 屏幕（约 2584 个视觉 token）；仅连续执行 50 步操作，累积的视觉上下文就会突破十万 token。视觉 token 数量随输入图像分辨率呈**二次方级**爆发，若简单粗暴地压缩分辨率，微小的按钮、菜单和代码字符又会瞬间模糊不可辨。

多模态大模型的另一个顽疾是**视觉幻觉（Visual Hallucination）**：面对一张仅有一只猫的图片，若用户发问“图里的两只狗在做什么”，模型往往会煞有介事地编造出“两只狗正在玩耍”。这往往不是视觉编码器没有提取到底层特征，而是语言模型主干固有的**强语言文本先验**压倒了来自视觉编码器的微弱特征证据：提示词中一旦触发高频共现词，模型就容易顺着纯文本统计概率脱缰输出。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 数据流架构：模态翻译官

在主流 VLM 架构中，数据流由三个核心组件协同驱动：
1. **视觉编码器（Vision Encoder，通常为 ViT）**：将输入图像均匀切分为空间网格 patch，提取出高维 patch 视觉表征；
2. **跨模态连接器（Projector / Connector）**：将视觉特征映射并对齐到大语言模型的文本嵌入空间，并按需进行空间下采样压缩；
3. **语言模型主干（LLM Backbone）**：将转化后的视觉 token 视为一种“外语单词”，与输入的自然语言 Prompt token 拼接成统一序列，自回归生成文本回复。

| 连接器选型 | 核心实现机制 | 核心工程取舍 |
|---|---|---|
| **MLP 空间投影** | 将相邻 patch（如 2×2 空间网格）沿通道维拼接后，通过两层 MLP 非线性映射 | 结构极简、保留完整二维网格几何拓扑；token 数量直接绑定图像物理分辨率 |
| **Q-Former / 重采样器** | 引入一组固定长度的可学习 Query 向量，通过交叉注意力（Cross-Attention）池化图像特征 | 视觉 token 数量恒定可控、大幅压缩上下文；但细粒度文字与小目标细节极易丢失，训练收敛更难 |

自 2024 年以来，主流开源 VLM（如 LLaVA 系列、Qwen-VL 系列）几乎全面倒向了“MLP 空间投影 + 邻域合并”的极简范式，将 token 序列长度的精细控制解耦交给前端分辨率策略与后置 token 剪枝模块。

### 2.2 渐进式训练：解冻时机的物理考量

| 训练阶段 | 核心训练范围与监督数据 | 核心设计逻辑 |
|---|---|---|
| **阶段 1：模态对齐** | 冻结 ViT 视觉编码器与 LLM 主干，仅训练轻量跨模态连接器（MLP） | 依托大规模粗粒度图文描述对，将视觉特征投影到 LLM 嵌入空间，防止破坏预训练权重先验 |
| **阶段 2：端到端联合训练** | 解冻 LLM 主干，并通常同时解冻 ViT，引入多任务、多分辨率混合数据 | 深度打通视觉特征与逻辑推理，赋予模型细粒度文字识别、物体定位与复杂视觉问答能力 |
| **阶段 3：指令对齐与偏好优化** | 采用多模态指令微调（SFT）、DPO/RL 强化学习 | 矫正输出格式，抑制有害视觉幻觉，确保遵循复杂人类指令 |

前沿技术的演进方向是**原生多模态（Native Multimodal）**：不再将视觉模块作为纯文本 LLM 的后接外挂，而是在预训练最初阶段就将海量图文、视频混合交错流一同喂入同一个主干模型。例如 Kimi K3 原生多模态模型，在统一的主干架构内原生支持文本、图像与视频的多模态联合理解。

### 2.3 分辨率处理机制的三大流派

| 策略范式 | 图像输入处理方式 | 核心工程代价与局限 |
|---|---|---|
| **固定预设尺寸** | 强制双线性插值或缩放到固定几何尺寸（如 448×448） | 严重破坏原始长宽比，细小文字与局部结构在下采样中直接丢失 |
| **动态切块（Tiling）** | 将超大图按固定网格切片（如划分为多个 384×384 局部块），并外加一张全局缩略图 | 保留了局部高清细节，但破坏了全局跨块几何连续性，且 token 数随切块数量倍增 |
| **原生可变分辨率** | 依据原始长宽比切分可变网格 patch，直接由 ViT 提取特征 | 编码输出的 token 数量动态可变，要求 ViT 具备支持任意网格位置编码的能力 |

原生分辨率已成为新一代前沿模型的共识配置：如 SigLIP 2 推出了 NaFlex 变体，单套权重即可直接支持保持原始长宽比的任意可变分辨率图像。但在前沿探索中，“切块 vs 全局编码”的争论仍在延续：LLaVA-UHD v4 实验指出，即便采用针对原生分辨率设计的 MoonViT 编码器，切块编码在细粒度图表基准上的平均分依然压过全局编码，其核心机理在于切块迫使局部注意力集中在微观文字拓扑上，避免了长距离注意力的注意力弥散。

### 2.4 视觉多维位置编码：交错 M-RoPE（接 1.2）

纯文本序列仅具备一维时序拓扑，而图像具备二维空间坐标 $(h, w)$，视频更进一步包含时间轴 $t$。多模态旋转位置编码（M-RoPE）将传统 RoPE 的隐藏通道维度平均分配为三个独立子集，分别承载 $(t, h, w)$ 三个轴的坐标编码；当输入为纯文本时，三个轴统一分配相同的一维标量位置号，自然退化为标准 1D RoPE。

然而，若按维度粗暴分组，每个轴仅能分到一段狭窄且连续的频谱区间。借用第 1.2 讲中的“多针钟表模型”来具象理解：高频旋转的指针对应极短距离内的精细分辨，而在长距离下会发生多次周期性混淆；低频慢速旋转的指针则负责大跨度宏观位置定位，但在微观局部几乎没有转角分辨率。若时间轴仅分得高频通道、空间轴仅分得低频通道，模型在空间轴上将丧失精确定位能力。[Qwen3-VL 技术报告](https://arxiv.org/abs/2511.21631)提出的**交错 M-RoPE（Interleaved M-RoPE）**，将 $t, h, w$ 按照时空坐标通道轮转交错排列，确保每一个物理轴都能完整覆盖从超高频到超低频的全局连续频谱。

### 2.5 DeepStack：多层分级特征直通机制

早期传统 VLM 习惯只提取 ViT 最顶层的特征输入连接器，丢失了丰富的局部低层细节。DeepStack 架构则从 ViT 的多个不同浅层与中层阶段抽取特征，通过分级连接器分别注入大语言模型对应的浅中层 Transformer Block 中：浅层视觉特征专供边缘、纹理与局部字符信息，深层特征则提供高级全局语义，从而显著压低了微小文字识别的错误率。

### 图像压缩四倍，整段输入并不会总是缩短四倍

假定固定输入图像分辨率为 448×448、ViT patch 边长为 14，视觉编码器首先生成 $32\times 32 = 1024$ 个 patch 特征。若采用 2×2 Merger 模块，进入大语言模型的视觉 token 缩减为 $16\times 16 = 256$ 个（压缩至 1/4）。但当用户提问包含 $T$ 个文本 token 时，大语言模型实际承载的序列总长度是从 $T+1024$ 缩减至 $T+256$。在大语言模型标准的双向/全注意力 Prefill 计算中，自注意力计算配对数之比为序列长度比值的平方：$\big(\frac{T+256}{T+1024}\big)^2$。

当文本 Prompt 极短时，视觉 token 的合并压缩对 LLM 首字延迟（Prefill）有极其显著的削减效应；但当上下文包含长篇系统指令或两千个文本 token 时，将视觉 token 压缩 4 倍对 LLM 总注意力的节省比例就会被严重稀释。此外，工业落地中还需将前端视觉编码器的耗时计入端到端关键路径，并核对激进合并后是否会导致 OCR 小字精度损耗。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　视觉 token 计数与跨阶段算力开销

$$
N_{\text{vis}} = \Big\lfloor\frac{H}{p\,m}\Big\rfloor\cdot\Big\lfloor\frac{W}{p\,m}\Big\rfloor
$$

- 其中 $H, W$ 为输入图像物理高宽，$p$ 为 ViT 划分的 patch 边长（如 14），$m$ 为跨模态连接器的空间合并边长（如 2）。当图像宽高各翻倍时，进入语言模型的视觉 token 数量剧增至 4 倍。
- **算力开销的跨阶段分流**：ViT 内部的自注意力两两点积配对数随 ViT 输入 patch 数量呈二次方级暴增（主导前端视觉编码时延）；而大语言模型（LLM）侧的 KV Cache 显存占用以及后续自回归生成的计算量，则直接由进入主干的视觉 token 数量 $N_{\text{vis}}$ 呈线性决定（→ 1.3）。

在上方实验中，调节“截图分辨率”或“宽高同时缩放”会直接改变物理送入 ViT 视觉编码器的原始 patch 总量；而调节“合并边长 $m$”时，ViT 编码器处理的 patch 网格保持不变，跨模态连接器将相邻 $m \times m$ 个特征拼合压缩，仅减少送入下游 LLM 的视觉 token 数量。观察左右矩阵对比，即可直观厘清两阶段算力负荷的解耦机制。

### Step 2　2×2 空间合并（像素反洗牌）

$$
\underbrace{(H/p)\times(W/p)\times C}_{\text{patch 网格}} \;\longrightarrow\; \underbrace{(H/2p)\times(W/2p)\times 4C}_{\text{拼接相邻 4 个}} \;\xrightarrow{\text{MLP}}\; (H/2p)\times(W/2p)\times d_{\text{LLM}}
$$

该过程类似于卷积神经网络中的 Pixel-Unshuffle（像素反洗牌）：将局部相邻的 4 个 patch 特征在通道维度拼接，token 序列物理长度直接压减至 1/4。原始高频几何信息并未因空间池化而丢弃，而是全部转移至通道维度，交由后续的两层 MLP 映射并重构出适配 LLM 的语义嵌入。

### Step 3　M-RoPE 的多轴位置编码

在图像块内，位于第 $(i, j)$ 网格的 token 拥有三维时空坐标 $(t_0,\ t_0 + i,\ t_0 + j)$；紧随图像块之后的后续文本 token 则统一从标量位置 $t_0 + \max(H', W')$ 开始顺序编号，以维持全局因果连续性。各轴在分得的通道频段上独立执行旋转：

$$
\text{score} = \sum_{a\in\{t,h,w\}}\ \big\langle R^{(a)}_{p_a}\,q^{(a)},\ R^{(a)}_{p'_a}\,k^{(a)}\big\rangle
= \sum_a q^{(a)\top} R^{(a)}_{p'_a - p_a}\,k^{(a)}
$$

每个物理轴仅感知其自身坐标方向上的**相对**位移。传统“分块连续分组”与“交错排列分配”的关键差异，就在于每个轴所分配到的旋转矩阵 $R^{(a)}$ 是仅涵盖一段窄频带，还是均衡覆盖从高到低的完整连续频谱。

### Step 4　自回归训练目标：只对文本计算监督损失

$$
\mathcal{L} = -\sum_{t\in\text{文本回答}}\log p_\theta(y_t\mid \text{视觉 token},\ y_{<t})
$$

在标准 VLM 训练中，视觉 token 仅作为多模态因果上下文的条件输入，模型并不计算针对视觉 token 自身的重构或预测损失（像素或特征的直接预测属于 3.3 节统一生成模型的范畴）。

### Step 5　视觉幻觉的极简动力学模型

我们将模型最终回答的条件对数概率粗略解构为“纯文本先验”与“视觉特征证据”的加权融合：

$$
\log p(y\mid v, x) \approx \log p(y\mid x) + \lambda(v)\cdot\text{视觉证据}
$$

当图像输入分辨率不足、目标尺度极小、经过过度激进的 token 剪枝或跨模态对齐较弱时，视觉信号置信度 $\lambda(v) \to 0$。此时输出几乎完全被纯语言先验分布 $p(y\mid x)$ 挟制，若提问中包含诱导性高频词（如“有几只狗”），模型便会依循语言统计模式顺水推舟地编造幻觉。工业界前沿的对比解码（Contrastive Decoding）与多模态强化学习，正是通过显式对比“有图输入”与“空图输入”的输出 logits 差值，强行放大视觉证据项的影响力。

## 4. 极简代码锚点（PyTorch）

视觉 token 计数、2×2 合并的 MLP 连接器、图像块的 M-RoPE 位置号。已跑通，§1 的表格来自 `n_visual_tokens`。

```python
import torch, torch.nn as nn

def n_visual_tokens(H, W, patch=14, merge=2):
    return (H // patch // merge) * (W // patch // merge)       # 1920×1080 → 2584

class Merger(nn.Module):
    """把相邻 m×m 个 patch 拼到通道维，再用 MLP 投影到 LLM 宽度"""
    def __init__(self, d_vit, d_llm, m=2):
        super().__init__(); self.m = m
        self.mlp = nn.Sequential(nn.LayerNorm(d_vit * m * m), nn.Linear(d_vit * m * m, d_llm),
                                 nn.GELU(), nn.Linear(d_llm, d_llm))
    def forward(self, x, gh, gw):                               # x: (B, gh·gw, C) 行优先的 patch 网格
        B, N, C = x.shape; m = self.m
        x = x.view(B, gh // m, m, gw // m, m, C).permute(0, 1, 3, 2, 4, 5)
        x = x.reshape(B, (gh // m) * (gw // m), m * m * C)      # token 数降为 1/m²，信息只是挪到通道维
        return self.mlp(x)                                      # (B, N/m², d_llm)

def mrope_ids(start, gh, gw, t=0):
    """图像块的 (t, h, w) 三轴位置号；文本 token 三轴取同一个值即退化为 1D RoPE"""
    tt = torch.full((gh * gw,), t)
    hh = torch.arange(gh).repeat_interleave(gw)
    ww = torch.arange(gw).repeat(gh)
    return torch.stack([tt, hh, ww]) + start                    # (3, gh·gw)
```

### 数值复算 · 图像压缩四倍，整段输入并不会总是缩短四倍

在同一个 Python 会话中先运行本节上方的实现，再运行以下算例。

```python
import torch
grid = torch.ones(1, 32*32, 2)
with torch.no_grad():
    count = Merger(2, 4, m=2)(grid, 32, 32).shape[1]
assert count == n_visual_tokens(448, 448) == 256
for text in [0, 256, 1024]:
    ratio = (text + count) / (text + grid.shape[1])
    print(f"文本={text:4d}  点积比例={ratio**2:.3f}  投影比例={ratio:.3f}")
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **Qwen3-VL 的三处架构升级**：交错 M-RoPE（每个时空轴覆盖完整频谱）、DeepStack（多层 ViT 特征注入 LLM 对应层）、用文本时间戳 token 做视频的时间对齐；原生支持 256K token 的图文交错上下文。旗舰 Qwen3-VL-235B-A22B 是 MoE，总参数 235B、每 token 激活 22B。
- **原生多模态成为前沿模型的标配**：Kimi K3 是原生多模态模型，视觉编码器 MoonViT-V2 约 4 亿参数，输入支持文本和图像。
- **编码器：方法比规模重要**：一份 2026 年的视觉编码器综述指出，训练方法上的改进胜过参数规模，400M 参数的 SigLIP 2 在多数 VLM 任务上超过 5.9B 的 InternViT-6B。token 压缩也在快速进步：LLaVA-UHD v3 的渐进式压缩在 SigLIP2 上把视觉 token 从 1024 降到 256，平均分反而从 61.94 升到 64.71。

**与工程 / 应用的连接**
- **GUI / 截图 Agent 的 token 成本控制**：在搭建 Agent 前，必须先核算视觉编码器的 patch 尺寸与连接器的合并倍率，进而逆推单图输入 token 预算；对全局长上下文仅保留低分辨率缩略图，仅对鼠标交互焦点或高频操作区域裁剪高分辨率局部（Dynamic Crop）。§1 的公式可直接用于每步 token 预算评估。
- **“模型频繁点错坐标”不一定是语义理解失败**：GUI Agent 在屏幕坐标上的定位能力深度绑定了视觉位置编码的几何连续性与输入缩放比例。若图像在送入视觉编码器前经历了非等比拉伸或坐标未归一化映射，模型推理出的 $(x, y)$ 坐标必然与真实屏幕产生物理错位。排查时应优先核对多分辨率坐标系的一致性。
- **密集 OCR 场景对物理分辨率存在硬门槛**：文档、数据报表、复杂代码截图等场景对有效分辨率高度敏感。在前端粗暴压低分辨率省下的 token 算力，通常会全额以关键字符 OCR 识别率暴跌的惨重代价反噬。

**常见误区 / 反直觉点**
1. **“输入视觉 token 数量越多，多模态理解就必然越准”** ✗：冗余的低频背景 token 只会挤占注意力显存；优秀的特征压缩算法能够利用 1/4 的 token 维持甚至提升基准精度。压缩的精髓在于保留哪些关键结构信息，而非盲目保留 token 数量。
2. **“预训练全程冻结视觉编码器一定更稳定可靠”** ✗：在第一阶段对齐时冻结 ViT 是为了防止脆弱的跨模态映射破坏成熟的视觉先验；但进入端到端联合训练阶段后，适度解冻 ViT 权重往往能大幅突破微小文字识别与目标定位的精度天花板。
3. **“VLM 出现幻觉纯粹是视觉编码器‘没看清’”** ✗：许多经典视觉幻觉实质上是大语言模型内部纯文本先验对弱视觉特征证据的强势碾压。通过对比同一 Query 在“有图输入”与“全黑/纯噪声输入”下的模型 logits 分布，通常就能精准归因出文本先验的主导作用。

**高频深挖题**
- **Q1：针对 4K 高清文档截图解析场景，在总 token 预算严苛受限的条件下，VLM 架构该如何系统化设计？**
  思路：先算账：4K 截图按 28×28 像素一个 token 会暴增至上万 token，严重挤占上下文 → 采用原生动态分辨率保持长宽比，结合局部切块（Tiling）捕捉超高频局部文字拓扑 → 引入 2×2 Merger 结合渐进式 token 压缩（如 LLaVA-UHD v3），将 token 规模削减数倍 → 引入 DeepStack 将 ViT 浅层字符特征直通注入语言模型对应中浅层 → 位置编码选用交错 M-RoPE 保证二维空间连续几何定位 → 评测指标重点观测 OCR 与 DocVQA 类端到端表现。
- **Q2：为什么 Qwen3-VL 等前沿模型要将 M-RoPE 从“分组划分”升级为“交错划分”？**
  思路：类比 1.2 讲的 RoPE 多针钟表模型：不同特征维度对代表不同旋转速率的时钟 → 若简单粗暴地将通道划分为连续的三大块分别分配给 $(t, h, w)$，则每个物理轴仅能获得极窄的频带（如某一轴全为快钟，在远距离发生高频混叠；另一轴全为慢钟，在近距离难以分辨角度）→ 交错排列使时空各轴轮流采样高频、中频与低频通道，让每一个轴都能在完整频谱跨度内兼顾宏观定位与微观近邻分辨 → 核心洞察：这本质上是在有限的嵌入维度预算内，实现多物理维度频率资源的帕累托最优配置。
