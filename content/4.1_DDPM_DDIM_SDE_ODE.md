# 4.1 DDPM → DDIM → SDE / ODE：从一千步去噪到一条确定性的路

> **一句话核心直觉**：DDPM 把"生成"拆成一千次"去掉一点噪声"，网络只需学会预测加进去的噪声，而**预测噪声等价于估计 score**（对数密度的梯度）。DDIM 发现同一个网络可以走一条确定性的路径，所以能跳步。SDE 视角把这一切统一起来：前向是加噪的随机微分方程，反向既有一个随机版本，也有一个确定性的 ODE（概率流），两者的边际分布完全相同。Flow Matching（4.2）只是换了一条更直的路径。
> **唤醒标签**：前向闭式 $q(x_t\mid x_0)$ · ε-prediction 与 score · 简化 ELBO · DDIM 确定性采样 · 概率流 ODE · v-prediction

**本篇定位**：4.2 是更短的入门路径，本篇是"回看"。它的价值在于把扩散模型的数学语言补齐：面试里的推导题、2025 年以后 RL 微调扩散模型的工作，都建立在这套语言上。记号：t=0 为数据，t 越大噪声越多（与 4.2 方向一致）。

## 1. 痛点与钩子：如果没有它，世界会怎样？

GAN 生成质量高，但训练不稳定、容易模式坍塌。DDPM 训练极其稳定（就是一个回归损失），代价是采样要走 1000 步。

本篇代码用一个**有精确 score** 的玩具做对照：数据是 8 个高斯组成的环（每簇标准差 0.15），由于高斯混合加噪后仍是高斯混合，可以写出每个噪声水平下的精确 score，不需要训练网络，排除了模型误差，只看采样器本身。指标是样本相对最近簇中心的残差标准差，目标值 0.15：

| 采样步数 | 确定性 DDIM（η=0） | 随机更新（η=1） |
| --- | --- | --- |
| 5 | 0.540 | 0.567 |
| 10 | 0.163 | 0.141 |
| 20 | 0.121 | 0.093 |
| 50 | 0.134 | 0.114 |
| 200 | 0.146 | 0.136 |
| 1000 | 0.147 | 0.148 |

5 步时两种更新的样本都散得太开。20 到 200 步的三组读数则都低于目标值，随机更新的样本在各簇中心附近更集中。衡量采样效果时，可以先指出误差方向，再和真实分布的标准差比较。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 前向加噪、反向去噪

前向过程从数据 $x_0$ 出发，按预设调度逐步加噪，到 $x_T$ 时几乎成为纯噪声。反向生成从 $x_T$ 出发，由网络用当前带噪样本预测去噪方向，最终生成 $x_0$。

关键事实：前向过程有**闭式解**，可以从 $x_0$ 一步跳到任意 $x_t$，训练时不需要真的模拟一千步。

### 2.2 去噪器就是 score 估计器

网络看到一个带噪样本 $x_t$，猜"加进去的噪声是什么"。猜得准，就等于知道"往哪个方向走，样本会变得更像数据"，而这个方向正是对数密度的梯度 $\nabla\log p_t(x)$，也就是 score（§3 Step 3）。

### 2.3 同一个网络，两种走法

DDPM 的反向更新包含一个新抽取的高斯噪声。DDIM 把更新写成可以跳到任意较早时刻的形式，并用 η 控制新噪声的尺度。η=0 时，给定初始噪声和去噪网络，每次都走同一条轨迹。

DDIM 不需要重新训练：用的是同一个 ε 预测网络，只是换了更新公式。确定性还带来一个好处：给定一张图，可以反向积分得到它对应的噪声（**反演**），这是很多图像编辑方法的基础。

下面把八簇简化为单个一维高斯，这样可以沿每次有限步更新直接计算方差。读图时沿横轴从高噪声端向左走，到 $t=0$ 读出采样器最终保留了多少散布。

### 2.4 SDE 视角：一个随机方程，一个确定性方程

| 连续时间方程 | 漂移项 | 随机项 |
| --- | --- | --- |
| 前向 SDE | $f(x,t)\,dt$ | $g(t)\,dW$ |
| 反向 SDE | $[f-g^2\nabla\log p_t]\,dt$ | $g(t)\,d\bar W$ |
| 概率流 ODE | $[f-\tfrac12 g^2\nabla\log p_t]\,dt$ | 无 |

精确的 score 和连续积分下，反向 SDE 和概率流 ODE 在任一时刻共享边际分布 $p_t$。离散实践里，DDPM 对应随机反向过程，确定性 DDIM 与概率流 ODE 相联系。边际相等的推导见 [Score SDE 论文 §4.3](https://arxiv.org/abs/2011.13456)。

所有方法都需要同一个东西：每个噪声水平下的 score。区别只在于用随机方程还是确定性方程去积分。Flow Matching 则直接学 ODE 的速度场，并选择了一条直线路径。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　前向过程的闭式解

$$
q(x_t\mid x_{t-1}) = \mathcal{N}\big(\sqrt{1-\beta_t}\,x_{t-1},\ \beta_t I\big)
\;\Longrightarrow\;
q(x_t\mid x_0) = \mathcal{N}\big(\sqrt{\bar\alpha_t}\,x_0,\ (1-\bar\alpha_t)I\big),\quad \bar\alpha_t = \prod_{s\le t}(1-\beta_s)
$$

即 $x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon$。**核心 Trick**：高斯的复合仍是高斯，所以训练时随机抽一个 t、一步构造出 $x_t$ 即可。

### Step 2　训练目标：预测噪声

变分下界（ELBO）展开后，每一项都是两个高斯之间的 KL，最终可以化简为（去掉与 t 有关的加权）：

$$
\mathcal{L}_{\text{simple}} = \mathbb{E}_{t,x_0,\varepsilon}\big\|\varepsilon - \varepsilon_\theta\big(\sqrt{\bar\alpha_t}x_0 + \sqrt{1-\bar\alpha_t}\,\varepsilon,\ t\big)\big\|^2
$$

一个看起来很复杂的概率模型，训练时就是一个回归问题，这是它比 GAN 稳定的根本原因。

### Step 3　ε 预测 = score 估计（Tweedie 公式）

对高斯加噪，有 Tweedie 公式：

$$
\mathbb{E}[x_0\mid x_t] = \frac{x_t + (1-\bar\alpha_t)\nabla\log p_t(x_t)}{\sqrt{\bar\alpha_t}}
$$

与 $x_0 = \big(x_t - \sqrt{1-\bar\alpha_t}\,\varepsilon\big)/\sqrt{\bar\alpha_t}$ 对比，最优的噪声预测满足：

$$
\varepsilon^*(x_t,t) = -\sqrt{1-\bar\alpha_t}\;\nabla\log p_t(x_t)
$$

**物理含义**：预测噪声和估计 score 只差一个已知的缩放系数。本篇代码正是用这个关系，把高斯混合的精确 score 换算成精确的 ε，直接驱动采样器。

### Step 4　DDIM 的更新公式

先由当前预测还原干净样本 $\hat x_0 = \big(x_t - \sqrt{1-\bar\alpha_t}\,\varepsilon_\theta\big)/\sqrt{\bar\alpha_t}$，再"重新加噪"到下一个时刻 s<t：

$$
x_s = \sqrt{\bar\alpha_s}\,\hat x_0 + \sqrt{1-\bar\alpha_s-\sigma^2}\;\varepsilon_\theta + \sigma z,\qquad
\sigma = \eta\sqrt{\frac{1-\bar\alpha_s}{1-\bar\alpha_t}\Big(1-\frac{\bar\alpha_t}{\bar\alpha_s}\Big)}
$$

- η=0：σ=0，完全确定性，即 DDIM。
- η=1：在相邻时间步和相同方差设定下对应 DDPM 的随机更新。跳步时，使用的是同一个公式得到的跨步方差。
- s 可以是任意更早的时刻，不必是 t−1，所以能跳步。这正是 §1 表格里两条曲线的来源。

### Step 5　三种参数化的换算

在高斯路径下，预测噪声 ε、预测干净样本 $x_0$、预测速度 v 可以线性互换。4.2 的直线路径中 $v = \varepsilon - x_0$；扩散模型常用的 v-prediction 是同一思想在 $\sqrt{\bar\alpha}$ 系数下的版本。选择哪一种影响的是不同噪声水平下的数值稳定性和损失加权：高噪声时预测 ε 信息量小，低噪声时预测 $x_0$ 的误差被放大，速度预测在两端都比较均衡。

## 4. 极简代码锚点（PyTorch）

噪声调度、前向加噪、训练损失和 DDIM 更新（η 控制随机性）。§1 的表格就是把 `ddim_step` 接上高斯混合的精确 ε 得到的。

```python
import torch

T = 1000
betas = torch.linspace(1e-4, 0.02, T)
abar = torch.cumprod(1 - betas, 0)                              # ᾱ_t

def q_sample(x0, t, eps):                                       # 一步跳到任意 t：x_t = √ᾱ x0 + √(1−ᾱ) ε
    a = abar[t].view(-1, *[1] * (x0.dim() - 1))
    return a.sqrt() * x0 + (1 - a).sqrt() * eps

def ddpm_loss(eps_model, x0):
    t = torch.randint(0, T, (len(x0),)); eps = torch.randn_like(x0)
    return (eps_model(q_sample(x0, t, eps), t) - eps).pow(2).mean()   # 就是一个回归

@torch.no_grad()
def ddim_step(x, eps, t, s, eta=0.0):
    """从时刻 t 走到更早的时刻 s（可以跳步）。eta=0 为 DDIM，eta=1 为 DDPM。"""
    a_t, a_s = abar[t], abar[s]
    x0 = (x - (1 - a_t).sqrt() * eps) / a_t.sqrt()              # 先还原干净样本
    sigma = eta * ((1 - a_s) / (1 - a_t) * (1 - a_t / a_s)).sqrt()
    return a_s.sqrt() * x0 + (1 - a_s - sigma ** 2).clamp(min=0).sqrt() * eps + sigma * torch.randn_like(x)

def eps_from_score(score, t):                                   # ε* = −√(1−ᾱ_t) · ∇log p_t
    return -(1 - abar[t]).sqrt() * score
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **新一代图像、视频模型的主干已经是 Flow Matching**（→ 4.2），但扩散模型的数学仍是这个领域的通用语言：噪声调度、score、概率流 ODE、各种求解器，都在 flow 模型上继续使用。
- **RL 微调生成模型需要随机性**：2025 年以来用 GRPO 类方法微调 flow 模型的工作（如 Flow-GRPO），会把确定性的 ODE 采样改写成边际分布相同的 SDE 采样，让每一步都有随机性，从而可以像 2.5 那样对同一提示采样一组结果、做组内比较。这正是本篇"同一边际分布、两种积分方式"的直接应用，也把 M4 和 M2 连了起来。

**与工程 / 应用的连接**
- **采样器是独立于模型的旋钮**：同一个模型可以换 DDIM、DPM-Solver 等不同的求解器，步数和质量的权衡由求解器决定。产品里的"采样步数""采样器"选项，改的就是这一层。
- **确定性带来可复现和可编辑**：DDIM 类确定性采样下，同一个种子总得到同一张图；把一张真实图像反演回噪声，再在噪声上修改条件重新生成，是很多图像编辑功能的基础。

**常见误区 / 反直觉点**
1. **"DDPM 必须走 1000 步"** ✗：训练用 1000 个噪声水平，采样完全可以跳步。DDIM 用同一个网络、几十步甚至十几步就能得到可用的样本。
2. **"预测噪声和预测图像是两种不同的模型"** ✗：在高斯路径下，ε、$x_0$、v 三种预测可以线性互换，差别只在数值稳定性和损失加权。
3. **"随机采样一定比确定性采样好（或差）"** ✗：随机项能修正之前步骤累积的误差，但步数少时会引入更多方差；确定性采样步数少时更稳，还支持反演。要按步数预算和用途选。

**高频深挖题**
- **Q1：证明（或说明）预测噪声等价于估计 score。**
  思路：写出 $q(x_t\mid x_0)$ 的闭式 → Tweedie 公式给出 $\mathbb{E}[x_0\mid x_t]$ 与 score 的关系 → 与"用噪声预测还原 $x_0$"对比，得到 $\varepsilon^* = -\sqrt{1-\bar\alpha_t}\nabla\log p_t$ → 收尾：所以 DDPM、score SDE、概率流 ODE 用的都是同一个东西，区别只在怎么积分。
- **Q2：DDIM 为什么能跳步？为什么 η=0 时是确定性的？这有什么用？**
  思路：DDIM 的更新先还原 $\hat x_0$ 再重新加噪到任意更早的时刻，没有要求相邻步 → η=0 时去掉了随机项，对应概率流 ODE 的离散化，边际分布与随机版本相同 → 用处：少步采样、同种子可复现、图像反演与编辑；RL 微调时反过来要把 ODE 改回 SDE 以获得探索所需的随机性。
