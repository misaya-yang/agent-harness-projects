# 4.2 Flow Matching / Rectified Flow：学一个搬运的速度场

> **一句话核心直觉**：不去学"怎么一步步去噪"，而是直接学一个**速度场**：在任意时刻 t、任意位置 x，告诉粒子该往哪走，才能把噪声分布整体搬成数据分布。训练只需要回归"数据点和噪声点之间那条直线的速度"，而这个条件目标的期望，恰好就是我们要的边际速度场。路径越直，需要的步数越少。
> **唤醒标签**：概率路径 · 条件流匹配（CFM）· 速度预测 · 直线插值 · Reflow · 一步生成为何坍塌 · MeanFlow

**记号**：全套资料统一用 **t=0 为数据、t=1 为噪声**（与 SD3 / Rectified Flow 一致）。本篇可以跳过 4.1 直接读。

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

扩散模型（→ 4.1）效果好，但数学包袱重（随机微分方程、噪声调度、ELBO），采样也慢。Flow Matching 把同样的事情说得简单得多：**数据和噪声之间连一条直线，让网络学这条直线的速度**。

本篇代码在一个二维玩具上训练了一个小网络：数据是 8 个高斯组成的环（半径 4，每个簇标准差 0.15），指标是样本到最近簇中心的平均距离（理想值约 0.19）和覆盖的簇数：

| Euler 步数 | Flow Matching 距离 / 簇数 | 一次 Reflow 后距离 / 簇数 |
| --- | --- | --- |
| 1 | 3.51 / 0 | 0.61 / 8 |
| 2 | 1.47 / 8 | 0.50 / 8 |
| 4 | 0.55 / 8 | 0.42 / 8 |
| 8 | 0.35 / 8 | — |
| 32 | 0.28 / 8 | — |

两个现象值得解释：**一步采样时，所有样本都塌缩到了环的中心**（到最近簇中心的距离 3.51，接近半径 4），一个簇都没覆盖；做一次 Reflow 之后，**一步就能生成覆盖全部 8 个簇的样本**。§3 Step 4 和 Step 5 分别给出原因。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 粒子与速度场

从 $t=1$ 的噪声分布采一个点。每一刻用当前位置和时刻查询速度 $v(x,t)$，沿着这个速度场反向积分到 $t=0$。许多这样的粒子一起移动，最终形成数据分布。

### 2.2 条件路径是直线，边际路径是弯的

每一对数据点 $x_0$ 和噪声点 $\varepsilon$ 都给出一条直线 $x_t=(1-t)x_0+t\varepsilon$，其条件速度恒为 $\varepsilon-x_0$。在同一时刻经过同一位置的配对可能给出不同速度，网络在那里学到的是这些速度的条件平均值。沿着平均速度走时，速度会随当前位置和时刻改变，边际轨迹因此可能弯曲。

### 2.3 Reflow：把交叉的直线解开

第一次训练时，数据点和噪声点是**随机**配对的。Reflow 用训练好的模型把每个噪声点送到它对应的生成样本，得到一组新的配对，再用这些端点训练。减少相互冲突的条件速度，可以得到更直的边际轨迹，降低一步 Euler 采样的误差，见 [Rectified Flow 原论文](https://arxiv.org/abs/2209.03003)。

在下面的一维高斯实验里，可以直接控制两端样本的配对相关性。数据端的标准差始终为 2，噪声端始终为 1。两端分布固定，改变的是同一个噪声点被配给哪个数据点。

在 $t=1$，独立配对使数据点的条件均值为 0，一步更新把所有起点送到数据均值。在同向配对下，从噪声点就能确定对应的数据点，起点速度携带了终点信息。八簇实验中的同一现象出现在环中心。§1 的 Reflow 结果可以和此处的落点对照。

### 2.4 和扩散模型是同一件事

高斯概率路径下，Flow Matching 和扩散模型只是同一个生成过程的不同参数化。三种预测目标之间是线性换算关系（§3 Step 1）。扩散模型里常用的 v-prediction，本质上就是在预测速度。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　路径与三种预测目标的换算

$$
x_t = (1-t)\,x_0 + t\,\varepsilon,\qquad u = \frac{dx_t}{dt} = \varepsilon - x_0
$$

已知 $x_t$ 和速度 v，就能还原另外两者：

$$
\hat x_0 = x_t - t\,v,\qquad \hat\varepsilon = x_t + (1-t)\,v
$$

预测速度、预测噪声、预测干净数据，在信息上是等价的，差别只在于数值条件和损失加权。

### Step 2　条件流匹配：为什么回归条件速度就够了

我们想要的是**边际速度场**：

$$
v^*(x,t) = \mathbb{E}\big[\varepsilon - x_0 \,\big|\, x_t = x\big]
$$

它算不出来（要对所有经过 x 的配对求平均）。条件流匹配直接回归每一对的条件速度：

$$
\mathcal{L}_{\text{CFM}} = \mathbb{E}_{t,\,x_0,\,\varepsilon}\big\|v_\theta(x_t,t) - (\varepsilon - x_0)\big\|^2
$$

展开平方项，对固定的 $x_t$：

$$
\mathbb{E}\|v_\theta - u\|^2 = \|v_\theta - v^*\|^2 + \underbrace{\mathbb{E}\|v^* - u\|^2}_{\text{与 }\theta\text{ 无关}}
$$

- **核心 Trick**：平方损失的最优解是条件期望。回归一个**算得出**的条件目标，得到的最优解恰好是那个**算不出**的边际目标；两个损失对 θ 的梯度完全相同。
- **去掉它会怎样**：就得先估计边际速度场才能训练，回到了扩散模型需要的那套 score 估计。

### Step 3　采样：解一个 ODE

$$
\frac{dx}{dt} = v_\theta(x,t),\quad x_1\sim\mathcal{N}(0,I)\ \text{从 } t=1 \text{ 积分到 } t=0
$$

最简单的 Euler 法：$x_{t-\Delta t} = x_t - v_\theta(x_t,t)\,\Delta t$。步数越少，离散化误差越大，误差的大小取决于轨迹有多弯。

### Step 4　一步采样为什么坍塌到均值

在 t=1 处，$x_1 = \varepsilon$ 与 $x_0$ 独立，所以：

$$
v^*(x,1) = \mathbb{E}[\varepsilon - x_0 \mid x_1 = x] = x - \mathbb{E}[x_0]
\quad\Rightarrow\quad
x_1 - 1\cdot v^*(x_1, 1) = \mathbb{E}[x_0]
$$

**一步走完，任何起点都落在数据的均值上。** 环形数据的均值在圆心，这正是 §1 里一步采样"到最近簇中心 3.51、零个簇被覆盖"的原因。这不是模型容量的问题，而是边际速度场本身的性质：在出发点，模型对"要去哪个簇"毫无信息，只能指向平均。

### Step 5　让一步可行的几条路

- **Reflow**：用模型生成的配对 $(\varepsilon, \Phi(\varepsilon))$ 重新训练。配对不再随机，t=1 处的速度不再是"指向均值"，而是"指向这个噪声点对应的那个样本"。§1 里一步采样从 3.51 降到 0.61。
- **MeanFlow**：不学某一时刻的瞬时速度，而是学一段时间区间上的**平均速度**，用两者之间的关系构造训练目标，不需要预训练、蒸馏或课程学习。它在 ImageNet 256×256 上从零训练，一步生成（1-NFE）的 FID 达到 3.43。
- **蒸馏 / 一致性模型**：用多步的教师训练少步的学生（→ 4.3）。

## 4. 极简代码锚点（PyTorch）

训练循环、Euler 采样器和 Reflow，§1 的表格就是这段代码的输出（二维玩具，CPU 上几秒钟）。

```python
import torch, torch.nn as nn

class VNet(nn.Module):                                          # v_θ(x, t)
    def __init__(self, D=2, H=256):
        super().__init__()
        self.net = nn.Sequential(nn.Linear(D + 1, H), nn.SiLU(), nn.Linear(H, H), nn.SiLU(), nn.Linear(H, D))
    def forward(self, x, t):                                    # x: (B, D)，t: (B,)
        return self.net(torch.cat([x, t[:, None]], -1))

def train_fm(sample_data, steps=3000, pairs=None, B=512):
    net = VNet(); opt = torch.optim.Adam(net.parameters(), lr=2e-3)
    for _ in range(steps):
        if pairs is None:                                       # 第一次：数据与噪声随机配对
            x0 = sample_data(B); eps = torch.randn_like(x0)
        else:                                                   # Reflow：用模型生成的配对
            i = torch.randint(0, len(pairs[0]), (B,)); x0, eps = pairs[0][i], pairs[1][i]
        t = torch.rand(B)
        xt = (1 - t[:, None]) * x0 + t[:, None] * eps           # 直线插值（t=0 数据，t=1 噪声）
        loss = (net(xt, t) - (eps - x0)).pow(2).mean()          # 回归条件速度 ε − x₀
        opt.zero_grad(); loss.backward(); opt.step()
    return net

@torch.no_grad()
def sample(net, z, steps=8):                                    # z: (B, D) 起点噪声
    x, dt = z.clone(), 1.0 / steps
    for i in range(steps):
        t = torch.full((len(x),), 1 - i * dt)
        x = x - net(x, t) * dt                                  # Euler：从 t=1 积分到 t=0
    return x

# Reflow：z = torch.randn(N, D); x0 = sample(net, z, steps=64); net2 = train_fm(None, pairs=(x0, z))
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **Flow Matching 已是图像生成的主干**：FLUX 用 Rectified Flow 加 MMDiT（图文 token 联合注意力）和多维 RoPE；微软 2026 年 7 月发布的 Mage-Flow 是一个 4B 规模的生成栈，由轻量 VAE 和原生分辨率的 MMDiT 组成，同样用 Rectified Flow 训练。语音、视频转音频、动作生成也在用同一套方法。
- **表示学习进入生成训练**：Black Forest Labs 2026 年 3 月的 Self-Flow 指出，标准的 flow 目标是一个去噪任务，几乎没有学习语义表示的动力；而借助外部视觉编码器做表示对齐（如 REPA）会在训练后期停滞，在视频和音频生成上与外部编码器对齐甚至有害。他们改用自监督的 flow matching，按预期的扩展规律提升了图像、视频和音频生成。
- **一步生成持续推进**：MeanFlow 之后，2026 年有大量工作在研究它的训练动力学、在大模型上的蒸馏稳定性，以及用 Reflow 拉直轨迹来改善优化地形。

**与工程 / 应用的连接**
- **步数就是延迟**：生成服务的每张图要过 N 次网络前向，CFG 还要再翻倍（→ 4.3）。产品里的 "Turbo"、"Lightning" 版本，一般是蒸馏或 Reflow 过的少步模型。
- **机器人和语音也在用**：Flow Matching 的动作头能从多模态分布里采样连续动作，比直接回归平均动作更不容易"取中间值撞墙"。这和 §3 Step 4 是同一个道理：回归会塌缩到均值，生成模型不会。

**常见误区 / 反直觉点**
1. **"Flow Matching 和扩散模型是完全不同的方法"** ✗：高斯路径下二者是同一生成过程的不同参数化，速度、噪声、干净数据三种预测可以线性互换。
2. **"训练用直线插值，所以采样轨迹也是直线"** ✗：条件路径是直线，边际路径是所有条件速度的平均，一般是弯的。要变直得做 Reflow。
3. **"一步生成效果差是因为模型不够大"** ✗：在 t=1 处，边际速度场本身就指向数据均值。这是数学性质，换大模型也没用，得改目标（Reflow、MeanFlow、蒸馏）。

**高频深挖题**
- **Q1：为什么条件流匹配的损失能学到边际速度场？**
  思路：写出边际速度 $v^* = \mathbb{E}[\varepsilon - x_0\mid x_t]$ → 展开平方损失，分解为 $\|v_\theta - v^*\|^2$ 加一个与 θ 无关的项 → 平方损失的最优解就是条件期望，两个损失梯度相同 → 一句话：回归一个算得出的条件目标，得到一个算不出的边际目标。
- **Q2：为什么少步采样效果差？有哪些办法把步数降到 1–4 步？**
  思路：边际轨迹是弯的，Euler 步长大时误差大；t=1 处一步走完会落在数据均值（写出推导）→ 办法：Reflow（换配对、拉直轨迹）、MeanFlow（学区间平均速度）、蒸馏与一致性模型（让学生直接学多步教师的终点）→ 代价：Reflow 要额外生成配对并重训，蒸馏要老师，且一步模型的多样性和细节通常略差。
