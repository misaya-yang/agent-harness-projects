# 4.3 CFG 与少步采样：放大"条件带来的偏移"

> **一句话核心直觉**：CFG 用同一个模型做两次前向（有条件、无条件），两者之差就是"条件让方向偏了多少"，再把这个偏移放大 w 倍。从贝叶斯的角度看，它相当于把 $p(c\mid x)$ 的梯度放大，于是样本更贴合条件、更集中；代价是多样性下降，w 太大则直接冲出数据流形。少步采样是另一条线：把几十步的 ODE 压成几步甚至一步。
> **唤醒标签**：classifier guidance → CFG · 条件 dropout · guidance scale · 过饱和 · APG · 蒸馏 / 一致性模型 / 分布匹配

前置：4.2（速度场与采样）。记号：t=0 为数据、t=1 为噪声。

---

## 1. 痛点与钩子：如果没有它，世界会怎样？

不加引导的条件生成模型，样本和条件的贴合度往往很弱：给它"一只猫"，生成的东西有时只是模糊地像猫。CFG 几乎是所有文生图、文生视频模型的标配旋钮。

本篇代码在 4.2 的环形玩具上训练了一个按"簇编号"条件化的流模型（训练时 10% 概率丢弃条件），然后用不同的 guidance scale w 生成第 2 号簇的样本。数据本身每个簇的标准差是 0.15：

| 引导强度 $w$ | 目标簇命中率 | 样本标准差 |
| --- | --- | --- |
| 0 | 8% | 2.824 |
| 1 | 100% | 0.135 |
| 2 | 100% | 0.059 |
| 4 | 99% | 0.082 |
| 8 | 2% | 0.824 |

从 $w=1$ 增大到 $w=2$ 后，命中率维持在 100%，簇内散布已经不足原来的一半。到 $w=8$，命中率降到 2%。把命中率和散布一同报告，才能看到引导的两个代价：样本可以在有效区域内过度集中，也可以因为外推太远而离开有效区域。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 从分类器引导到 CFG

分类器引导直接训练带噪分类器来提供 $\nabla_x\log p(c\mid x)$，再把它加到无条件 score 上。由贝叶斯公式，这个梯度也等于有条件 score 减去无条件 score。CFG 在训练时随机把条件换成空条件，让同一个网络学会这两种预测，推理时用它们的差来计算引导。

### 2.2 沿什么方向外推

把无条件预测看作起点、有条件预测看作方向上的第一个刻度。$w=0$ 留在起点，$w=1$ 到达有条件预测，$w>1$ 则沿两点之差继续往前。这个额外延伸的方向既可以改变预测的位置，也可以放大预测向量的长度。

### 2.3 过饱和从哪来：APG 的分解

APG（ICLR 2025）把 CFG 的更新项分解成与条件预测**平行**和**正交**的两个分量。作者的实验把过饱和主要归因于平行分量。降低这一分量的权重，再配合重缩放和动量，可以更好地使用较高的 guidance scale。方法与对照图见 [APG 原论文](https://arxiv.org/abs/2410.02416)。

实验固定一对二维去噪预测。左右两个坐标系采用相同尺度，普通 CFG 和 APG 都以同一个条件预测为基准。调节 η 后，对比引导后向量的长度和方向，再用读数检查平行、正交两部分各占了多少。

在本例里，平行更新沿着有条件预测的方向继续拉长向量，正交更新让向量偏转。只减小 η 时，引导保留了同样大小的正交更新，同时减少了沿原方向的放大。

### 2.4 少步采样的三条路

| 路线 | 做法 | 代表 |
|---|---|---|
| **拉直轨迹** | 换配对，让边际轨迹接近直线 | Reflow（→ 4.2） |
| **学终点 / 区间** | 直接学从任意 t 到终点的映射，或区间上的平均速度 | 一致性模型、flow map、MeanFlow |
| **分布蒸馏** | 让少步学生的输出分布匹配多步教师 | DMD 等分布匹配蒸馏 |

## 3. 承重墙推导：重新捡起核心数学

### Step 1　贝叶斯分解与"倾斜分布"

$$
\nabla\log p(x) + w\,\nabla\log p(c\mid x) = \nabla\log\Big[p(x)\,p(c\mid x)^{w}\Big]
$$

$$
p_w(x\mid c) \;\propto\; p(x)\,p(c\mid x)^w \;=\; p(x)^{1-w}\,p(x\mid c)^{w}
$$

**物理含义**：w=1 时就是条件分布本身；w>1 时，对"分类器越确信的区域"给予指数级更高的权重，分布被锐化。多样性下降是这个指数的直接后果。

### Step 2　速度（或噪声）形式

$$
v_{\text{cfg}} = v_\theta(x,t,\varnothing) + w\,\big(v_\theta(x,t,c) - v_\theta(x,t,\varnothing)\big)
$$

噪声预测同理：$\tilde\varepsilon = \varepsilon_u + w(\varepsilon_c - \varepsilon_u)$。每一步要两次前向，采样成本翻倍。

### Step 3　为什么大 w 会出问题

Step 1 的倾斜分布在 t=0 处是良定义的，但**不同噪声水平下的边际分布并不按同样的方式组合**：把每个时刻的有条件 / 无条件预测做线性外推，并不等于"对倾斜分布做精确采样"。w 小时这个偏差可以接受，w 大时外推出的速度会把样本推到数据流形之外，这就是 §1 表格里 w=8 时样本跑到簇外的原因。CFG 本质上是一个好用的启发式，而不是精确的采样方法。

### Step 4　APG 的分解

记更新项 $\Delta = \hat x_c - \hat x_u$（用去噪后的预测表示），把它投影到条件预测 $\hat x_c$ 上：

$$
\Delta_\parallel = \frac{\langle\Delta,\hat x_c\rangle}{\|\hat x_c\|^2}\,\hat x_c,\qquad
\Delta_\perp = \Delta - \Delta_\parallel,\qquad
\hat x = \hat x_c + (w-1)\big(\Delta_\perp + \eta\,\Delta_\parallel\big),\ \ \eta<1
$$

平行分量会沿着 $\hat x_c$ 本身的方向放大它的幅度，表现为颜色过饱和；正交分量改变内容和细节。压低 η 就保留了 CFG 提升质量的部分，去掉了导致过饱和的部分。

### Step 5　为什么少步会损失多样性

少步方法要求学生在一步之内从噪声走到样本。如果只是回归多步教师的终点，学生会倾向于学到"平均终点"（和 4.2 §3 Step 4 一样的均值坍塌）；分布匹配类方法改为匹配**分布**而不是逐点回归，能缓解这一点，但通常需要额外的判别器或分数估计。2025–2026 年的 MeanFlow 系列则试图在不蒸馏的前提下直接学出一步生成的模型，并且在使用引导时不增加采样成本。

## 4. 极简代码锚点（PyTorch）

条件 dropout 训练、CFG 速度、APG 式分解。§1 的表格来自同一套代码（4.2 的 `VNet` 加一个条件嵌入）。

```python
import torch

NULL = 8                                                        # 空条件的类别编号

def drop_condition(c, p=0.1):                                   # 训练时以概率 p 把条件换成"空"
    return torch.where(torch.rand(len(c)) < p, torch.full_like(c, NULL), c)

@torch.no_grad()
def cfg_velocity(net, x, t, c, w):
    v_u = net(x, t, torch.full_like(c, NULL))                   # 无条件
    v_c = net(x, t, c)                                          # 有条件
    return v_u + w * (v_c - v_u)                                # 沿"条件 − 无条件"方向外推

@torch.no_grad()
def apg_x0(x0_c, x0_u, w, eta=0.0):
    """x0_c / x0_u：有 / 无条件的去噪预测 (B, D)。压低与 x0_c 平行的分量以抑制过饱和。"""
    d = x0_c - x0_u
    par = (d * x0_c).sum(-1, keepdim=True) / (x0_c.pow(2).sum(-1, keepdim=True) + 1e-8) * x0_c
    return x0_c + (w - 1) * ((d - par) + eta * par)

@torch.no_grad()
def sample_cfg(net, z, c, w, steps=32):                         # t 从 1（噪声）积分到 0（数据）
    x, dt = z.clone(), 1.0 / steps
    for i in range(steps):
        t = torch.full((len(x),), 1 - i * dt)
        x = x - cfg_velocity(net, x, t, c, w) * dt
    return x
```

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **让 CFG 对 guidance scale 不那么敏感**：ICML 2026 的 CFG-MP 指出 CFG 的 guidance scale 缺少客观的选择依据，提出一种无需训练的流形投影，使 CFG 对 scale 不那么敏感；同期还有曲率感知的 CACFG，把引导与最优控制联系起来。APG 已成为常见的对照基线。
- **少步生成的路线在收敛**：一份 2025 年底的文生图少步蒸馏实践指南，把主流方法分为分布蒸馏（如 DMD）等几大范式并做了对比；2026 年的 Mean Flow Distillation 用时间积分的平均速度作为对齐目标，报告在文生图上优于基于分数和基于一致性的流蒸馏方法。

**与工程 / 应用的连接**
- **guidance scale 就是产品里的"贴合度"滑块**：太低像素糊、不听话，太高过饱和、千篇一律。不同模型的最佳区间不同，蒸馏过的少步模型往往已经把引导"烧"进了权重，再加 CFG 反而会坏。
- **负向提示**：把无条件预测换成"负向条件"的预测，CFG 就变成了"远离负向描述"。它不是精确地减去一个概念，而是沿着"正向 − 负向"的方向外推，所以负向提示写得太强同样会出伪影。
- **成本**：CFG 让每步前向翻倍。生产里常用 CFG 蒸馏（把引导后的输出蒸馏进单次前向）或只在部分步数上开启 CFG 来省一半算力。

**常见误区 / 反直觉点**
1. **"w 越大，越贴合提示，效果越好"** ✗：贴合度提升的同时多样性下降，超过某个值之后样本冲出流形，出现过饱和和伪影（§1 表格的 w=8）。
2. **"CFG 需要训练一个额外的分类器"** ✗：那是 classifier guidance。CFG 用同一个网络的有条件和无条件预测之差充当隐式分类器的梯度，训练时只需要随机丢弃条件。
3. **"CFG 是在对倾斜分布做精确采样"** ✗：线性外推在各个噪声水平上并不精确对应倾斜分布的 score，它是一个效果很好的启发式。

**高频深挖题**
- **Q1：从贝叶斯公式推导 CFG，并解释为什么 w>1 会降低多样性。**
  思路：$\nabla\log p(x|c) = \nabla\log p(x) + \nabla\log p(c|x)$ → 用"有条件 − 无条件"得到隐式分类器的梯度 → 放大 w 倍得到 $p(x)p(c|x)^w$ 的 score → 指数 w 锐化分布 → 收尾：大 w 时线性外推在中间噪声水平上不精确，样本会离开流形，APG 通过压低平行分量缓解过饱和。
- **Q2：要把一个 30 步的模型压到 4 步，你有哪些选择？各自的代价是什么？**
  思路：Reflow（拉直轨迹，要额外生成配对并重训）；一致性模型 / MeanFlow（学终点或区间平均速度，训练更难调）；分布匹配蒸馏（匹配分布而非逐点回归，多样性更好，但要额外的分数估计或判别器）→ 再补一句：少步模型通常已内化引导，需要重新标定 guidance scale。
