# 4.4 DiT 与 MM-DiT：让条件和图像 token 在哪里相遇

> **一句话核心直觉**：生成模型不必在数以百万计的高维原始像素上笨重运转；它先通过图像编码器将图片无损压缩为紧凑的潜空间特征网格（latent），再将其切分为规整的特征补丁（patch token）序列，交由 Transformer 骨干网络反复去噪或演化。DiT 利用自适应归一化（adaLN-Zero）将时间步与文本条件逐层注入每个残差块，初始时将残差门控置零，使整个深层网络天然从平稳的恒等映射出发。MM-DiT 则进一步为文本与图像分别保留专属的参数变换空间，同时在联合注意力矩阵中让两种模态充分互读。当图像分辨率翻倍时，图像 token 数量变为 4 倍，稠密注意力配对激增至 16 倍；但由于逐 token 线性投影仍占主导，整个模型的实际运算量远非粗暴翻上 16 倍。
> **唤醒标签**：$N=(H/fp)(W/fp)$ · $\operatorname{adaLN}=(1+\gamma)\operatorname{LN}(x)+\beta$ · $y=x+gF(\operatorname{adaLN}(x))$ · 图文 QKV 分开、注意力联合 · $(N+M)^2=N^2+2NM+M^2$ · 视频另乘 latent 时间片数

## 1. 任务：同一张画，怎样既听懂提示又能放大？

设想你需要生成一张「小狗戴着一顶红色帽子，乖巧坐在蓝色椅子上」的复杂场景图片，并希望将输出画布由 512×512 升级到 1024×1024。在此过程中，生成系统面临着双重严峻考验：既要在语义上让“红色”精准绑定到“帽子”而非“椅子”，又要在空间上处理暴增的像素计算量。这两个工程问题在架构设计中往往容易混为一谈：**模型究竟在网络的哪一层、以何种形式融合外部条件？**以及**当画布放大时，每次去噪迭代到底多增加了多少真实计算负担？**

前几课已经从动力学角度阐释了去噪器与速度场的训练法则（→ 4.1、4.2），以及推理阶段如何组合有条件与无条件预测（→ 4.3）。本课则深入解剖神经网络主干（Backbone）的微观生理结构：张量以何种几何形状输入，扩散时间步与文本嵌入如何逐层穿透，图像与文本 token 如何在注意力层高效互读。模型的训练目标可以是噪声预测、速度预测或条件流匹配；而 DiT 骨干网络自身的设计，完全独立于具体采用何种采样与优化目标。

## 2. 从像素到 latent patch，再回到图像

### 2.1 为什么先压缩

对于高维 RGB 图像 $x\in\mathbb R^{H\times W\times3}$，如果直接在其原始像素空间运行自注意力机制，庞大的序列长度会让计算开销迅速爆炸。现代架构通过预训练的自编码器（VAE，详见 4.5 节）将其映射到紧凑的连续潜空间 $z=E(x)\in\mathbb R^{H/f\times W/f\times C}$。

这里的 $f$ 称为**空间下采样因子**：$f=8$ 意味着图像在**宽度和高度上各缩小 8 倍**，空间特征位置数缩减为原来的 $1/f^2 = 1/64$。需要明确的是，标量总数并不会等比例缩小到 1/64，因为潜空间的通道数已由原本的 RGB 3 通道扩展为潜通道数 $C$。例如一张 512×512 的 RGB 图像共包含 $512\times512\times3 = 786,432$ 个标量；经过 $f=8, C=4$ 的编码压缩后，潜变量张量尺寸为 64×64×4，总标量数仅为 16,384 个，体积压缩了近 48 倍。

在训练阶段，算法由真实图片的干净潜变量 $z_0$ 出发，按照加噪或插值公式构造出特定时刻的带噪中间状态 $z_t$；DiT 主干网络接收输入元组 $(z_t, t, \text{condition})$，预测对应的去噪目标向量。在推理阶段，采样器从纯噪声潜变量出发逐步反向迭代演化出预测的干净潜变量 $\hat z_0$，最后由潜空间解码器 $D(\hat z_0)$ 一次性还原为高清晰度真实像素图片。在整个链路中，**自编码器负责紧凑的感知表征，而 Transformer 负责在潜空间中建模分布动力学**；两者的重建保真度与生成泛化力应在工程中分别进行独立测试。

### 2.2 patchify 是把网格变成序列

为了让标准 Transformer 处理二维连续特征图，系统执行 **patchify（切块序列化）** 操作：将潜空间网格按 $p\times p$ 的局部邻域划分，把每个小方块展平为维度为 $p^2C$ 的一维特征向量，再通过一个可学习的线性投影矩阵 $W_{\rm in}$ 映射为隐藏宽度为 $D$ 的输入 token。在假设潜空间宽高能被 $p$ 整除的前提下：

$$
N=\frac H{fp}\frac W{fp},\qquad
\text{patch}\in\mathbb R^{p^2C}\xrightarrow{W_{\rm in}}\mathbb R^D
$$

在为序列中的每个 token 叠加二维空间位置编码后，token 序列被送入多层 Transformer 深度迭代。在最后一层，输出预测头将每个 $D$ 维 token 线性投影回 $p^2C$ 个标量，最后通过 **unpatchify** 逆操作，严丝合缝地重组回 $H/f\times W/f\times C$ 的潜变量几何网格。若输入分辨率无法被 $fp$ 整除，工程上必须明确约定规范的居中裁切或边缘填充策略。

以 $C=4, p=2, D=1152$ 为例：每一个 patch 包含 $2\times2\times4=16$ 个潜标量；不计偏置的线性输入投影层拥有 $16\times1152=18,432$ 个权重参数，序列中所有 patch 均共享这一套权重。类似地，输出头负责将 $D$ 维特征投影回 16 维并按空间坐标填回。值得注意的是，提升图像分辨率并不会增加这两个投影层的参数量，但会成倍增加前向调用频次；而增大 patch 边长 $p$ 则会同时改变输入投影矩阵的几何尺寸与总序列长度。若 Transformer 缺少显式的位置编码注入，自注意力机制将无法区分「红帽子在小狗头上」与「将图像 patch 随机乱序拼贴」的空间拓扑差异（→ 1.0）。

| 设置 | latent 网格 | 图像 patch 数 $N$ | 有序图—图配对 $N^2$ |
|---|---:|---:|---:|
| 512×512，$f=8,p=2$ | 64×64 | 1,024 | 1,048,576 |
| 1024×1024，同 $f,p$ | 128×128 | 4,096 | 16,777,216 |
| 1024×1024，$f=8,p=4$ | 128×128 | 1,024 | 1,048,576 |

表格最后一行清晰表明：通过把 patch 尺寸从 2 扩大到 4，我们可以把 1024 分辨率下的 token 总数强行拉回 1024 个；但此时每一个 token 内被强行塞入了 4 倍的局部细节信息，不可想当然地假定微观画质保持不变，必须在算力与画质之间进行严格实测。当扩展至视频生成时，空间 token 数还要进一步乘上时域潜切片数（详见 4.6 节）。

### 2.3 配对数不是完整 FLOPs

假设仅考虑图像 token 序列、Transformer 隐藏层宽度为 $D$、前馈全连接网络（FFN）中间隐藏层扩展比为 $4D$。按一次乘加运算计为 2 FLOPs、忽略归一化与偏置项，单层 Transformer 的主干计算量可严谨拆解为：

$$
\underbrace{24ND^2}_{\text{QKV 投影、输出投影与 FFN 线性项}}+
\underbrace{4N^2D}_{\text{自注意力 } QK^\top\text{ 与 }AV\text{ 配对项}}\quad\text{FLOPs}
$$

式中第一项包含 Q、K、V 及输出四个投影矩阵贡献的 $8ND^2$ FLOPs，加上 FFN 两层线性变换贡献的 $16ND^2$ FLOPs；第二项则是注意力矩阵生成与特征加权的两次稠密矩阵乘法。

**核心洞见**：只有当序列长度 $N = 6D$ 时，两部分的计算量才恰好打平。在常规图像生成中，隐藏维度 $D$ 通常在 1000 以上（如 $D=1152$），此时临界长度高达 $6D \approx 6912$。在 $N=1024$ 乃至 $N=4096$ 的常见分辨率区间内，逐 token 计算的线性投影与 FFN 始终占据总算力的半壁江山甚至主导地位！

因此，尽管图像边长翻倍让稠密注意力配对数激增 16 倍，但只要 $N$ 尚未超越临界点，单层前向的综合运算量远远没有达到 16 倍。FlashAttention 等内存优化算法能够避免在显存中实体化庞大的注意力矩阵、显著降低访存开销，但并没有消除这两个矩阵乘法的理论浮点计算量（→ 1.5）。此外，单次去噪的计算量还要乘以推理总步数；若开启 CFG 引导，实际计算量还要乘以分支数 2。

我们来测算一次完整的推理账本：沿用 $N=1024, D=1152$、28 个同宽层、30 次去噪迭代，假设每步 CFG 计算条件与无条件两个分支。单张图像仅 Transformer 主干部分的浮点开销约为 $(32.61 + 4.83) \times 28 \times 30 \times 2 / 1000 \approx 62.91$ TFLOPs。这尚未计入文本编码器、最终输出头、VAE 解码器及其他开销。不可将理论 FLOPs 简单除以 GPU 标称算力来冒充实测延迟。

在下面的交互实验中，我们刻意固定基准为 512×512、$p=2$（对应基准 $N=1024$），直观观察画布放大与 patch 切换对工作量的重塑：

```academy-lab

```

**实验操作指南**：
1. **拖动输入图像边长（side）滑块**：从 512 像素连续滑动至 1024 像素。对比两条折线的增长斜率：观察“图像 token 数（代表线性项工作量）”从 1 倍线性上升至 4 倍，而“图—图稠密注意力配对”则呈二次方曲线陡峭攀升至 16 倍；

### 2.4 换宽度和换分辨率，不是同一种扩容

只看标准 Transformer 主体结构，一层模型的参数量约为注意力层 $4D^2$ 加上 FFN 层 $8D^2$，共计 $12D^2$；$L$ 层参数量约为 $12LD^2$。
- **增大输入图像分辨率**：仅改变序列长度 $N$，而模型核心参数量保持完全不变；
- **增大模型宽度 $D$**：参数量随宽度的平方急剧膨胀，且逐 token 投影项随 $D^2$ 增长；
- **增大网络层数 $L$**：参数量与计算量均保持严格的线性增长。

| 固定其他量，只改一项 | 参数量近似 | 逐 token 投影 FLOPs | 注意力配对 FLOPs |
|---|---:|---:|---:|
| 图像边长 ×2，$N$ ×4 | 不变 | ×4 | ×16 |
| 宽度 $D$ ×2 | ×4 | ×4 | ×2 |
| 层数 $L$ ×2 | ×2 | ×2 | ×2 |

这一对照清晰地指明了算力扩展的瓶颈演变方向：当图像分辨率极大时，注意力配对是吞噬计算的主要推手；而在处理常规尺寸时，模型宽度与层数深度则构成了参数吞吐的核心承重墙。

### 2.5 同一个网络输出，如何接到采样器

设扩散加噪状态为 $z_t=\alpha_t z_0+\sigma_t\epsilon$，其中 $\epsilon\sim\mathcal N(0,I)$。DiT 网络的职责是将输入 $(z_t, t, c)$ 映射为与 $z_t$ 严格同形的输出张量。
- 若模型训练目标设定为噪声预测 $\epsilon$，在 $\alpha_t>0$ 时，采样器通过代数反解计算对干净样本的估计：

$$
\hat z_0=\frac{z_t-\sigma_t\hat\epsilon_\theta(z_t,t,c)}{\alpha_t}
$$

- 若模型采用满足 $\alpha_t^2+\sigma_t^2=1$ 旋转约束的速度参数化 $v=\alpha_t\epsilon-\sigma_tz_0$，反解关系式则为 $\hat z_0=\alpha_tz_t-\sigma_t\hat v$ 与 $\hat\epsilon=\sigma_tz_t+\alpha_t\hat v$；
- 若在 Flow Matching 线性插值路径 $z_t=(1-t)z_0+t\epsilon$ 下，模型预测的目标速度为 $\epsilon - z_0$（→ 4.2），采样器在反向积分时必须遵循对应的线性微分法则。

**网络架构、预测目标定义、时间流向约定与外部采样求解器必须做到严格闭环匹配**：如果错误地将噪声预测输出直接当作流匹配速度场喂给 Euler 求解器，即便两者的张量形状完全吻合，数值积分也会立刻走向彻底发散的荒谬终点。

## 3. 为什么用 Transformer，条件从哪里进入？

经典扩散模型（如 SD 1.5）以卷积 U-Net 为骨干，通过多尺度下采样、残差卷积块与跨注意力（Cross-Attention）融合图文特征。U-Net 至今依然是高效稳健的选择；而 DiT 将生成任务抽象为规范的 token 序列建模，使得视觉生成模型能够直接复用语言大模型在规模扩展（Scaling Laws）上的工程基础设施与前沿算子。

仅仅输入带噪 latent 是不够的：相同的加噪图像在不同的扩散时刻所需要的去噪策略截然不同；文本提示词也必须精准调控每一个空间实体的属性。DiT 系统对比了三种条件注入路径：

| 注入方式 | 一层里信息怎么到达图像 token | 优势与适用场景 | 局限性 |
|---|---|---|---|
| **全局条件调制（adaLN）** | 一个全局向量经 MLP 映射，产生逐通道的平移 $\beta$、缩放 $\gamma$ 与门控 $g$ | 结构轻巧，让所有空间位置感知当前的噪声阶段与全局类别 | 若仅输入单个池化向量，难以直接实现细粒度的局部图文位置绑定 |
| **Cross-Attention（跨注意力）** | 图像 token 作为 Query，检索文本编码器输出的 Key/Value | 允许图像各空间位置按需寻址特定的提示词短语 | 文本 Key/Value 通常固定不更新，文本模态无法反向感知图像结构 |
| **Joint Attention（联合注意力）** | 文本与图像的 Q、K、V 拼接为统一长序列共同注意 | 实现图文双向无障碍信息交互与深度语义对齐 | 文本序列长度直接计入二次方注意力计算账本 |

### 3.1 先归一化，再按条件调节

对图像 token 的隐藏特征执行层归一化（LayerNorm），条件向量 $c$（通常由时间步嵌入与文本全局池化向量拼接而成）送入轻量 MLP 生成逐通道缩放向量 $\gamma(c)$、偏置向量 $\beta(c)$ 以及残差门控标量 $g(c)$：

$$
h=(1+\gamma(c))\odot\operatorname{LN}(x)+\beta(c),
\qquad y=x+g(c)\odot F(h)
$$

在实际的 DiT 架构中，自注意力子层与 FFN 子层各自拥有独立的一套调制参数与门控。通过这种机制，网络能够在不同的去噪时刻动态重塑各层的特征坐标系与激活幅度。

### 3.2 零初始化的精确含义

在 DiT 架构设计中，**adaLN-Zero 的精髓在于将生成调制参数的最后一层线性权重初始化为全零**。这意味着在模型初始化的第 0 步，恒有 $\gamma=\beta=g=0$。

代入残差公式可知：残差分支的输出贡献被门控 $g=0$ 彻底截断，整个 **Transformer 残差块在初始时刻严格退化为一个恒等映射（$y=x$）**。

这一设计极其关键：它使得即便堆叠多达几十层的深度 Transformer，初始信号与梯度也能毫无阻碍地纵向穿透整个主干，彻底避免了深度网络在初始阶段常发生的数值剧烈振荡与梯度爆炸。

针对局部导数，对残差公式 $y = x + g F(h)$ 求偏导：
- 对分支特征的梯度为 $\partial y / \partial h = g F'(h)$：当 $g=0$ 时，该梯度为零，残差分支内部参数在初始瞬间暂时不接收更新；
- 对门控自身的梯度为 $\partial y / \partial g = F(h)$：该项在初始时为非零常数！这意味着门控自身能够率先接收到有效的反向传播梯度，并随着优化器迭代迅速“推开大门”，随后平滑引导内部特征分支融入训练。

在下面的交互实验中，我们设定输入标量 $x=1$，分支映射 $F(h)=2h$；条件 A 与条件 B 分别激活 $h=1$ 与 $h=2$：

```academy-lab
4.4-adaln
```

**实验操作指南**：
1. **观察 $g=0$ 处的初始点**：无论输入条件 A 还是条件 B，残差块输出均严格恒等于 1.00，残差分支完全隐身；此时对 $h$ 的导数为 0.00，但对门自身导数恒为 2.00；
2. **滑动调节残差门 $g$（gate）**：将门从 0.00 逐渐拉大至 0.25、1.00。观察条件 A 与条件 B 的输出如何迅速拉开差距（$g=0.25$ 时输出分别为 1.50 和 2.00），同时对分支的导数线性恢复。这形象证明了零初始化门控“恒等起步、平滑解冻”的深层稳定性优势。

## 4. MM-DiT：图文各算投影，但共同做注意力

### 4.1 为什么不是把两种 token 简单当成一样

文本编码器输出 $M$ 个文本 token，图像潜变量切出 $N$ 个图像 token。文本与图像属于异构模态：文本语义高度稠密抽象，而图像像素特征具有强烈的空间局部平滑性与不同的数值分布。

SD3 与 FLUX 采用的 **MM-DiT（Multimodal Diffusion Transformer）** 给出了巧妙的模态处理范式：**让文本流与图像流各自保留专属的权重矩阵来计算 $Q, K, V$，随后将两者拼接并送入统一的注意力矩阵中联合运算**：

$$
Q=\begin{bmatrix}Q_T\\Q_I\end{bmatrix},\quad
K=\begin{bmatrix}K_T\\K_I\end{bmatrix},\quad
V=\begin{bmatrix}V_T\\V_I\end{bmatrix},\quad
O=\operatorname{softmax}(QK^\top/\sqrt{d_h})V
$$

注意力计算完成后，输出张量再次拆分回文本流与图像流，各自经过专属的输出投影层与 FFN。在联合注意力内部，整个分数矩阵自然划分为四个功能分明的大象限：

| Query → Key | 文本 Key（$M$ 个） | 图像 Key（$N$ 个） |
|---|---|---|
| **文本 Query（$M$ 个）** | **文—文交互（$M^2$）**：上下文理解与语法消歧 | **文—图交互（$MN$）**：文本动态感知当前画面演化 |
| **图像 Query（$N$ 个）** | **图—文交互（$NM$）**：空间位置精确寻址提示词属性 | **图—图交互（$N^2$）**：空间全局连续性与纹理构图 |

这一机制赋予了模型真正的双向深度交互能力。需要特别警惕的是：**在每一行 Softmax 归一化中，文本 Key 与图像 Key 必须共同竞争总和为 1.0 的注意力概率质量**。例如当图像分辨率显著提高、引入海量有竞争力的图像 Key 时，分摊给文本 Key 的平均注意力权重可能被稀释。网络需要学习自适应的模态缩放因子以维持图文绑定的稳固性。

### 4.2 成本怎样随文本长度变化

在联合注意力中，总配对数由单模态的 $N^2$ 扩展为完全展开的二项式：

$$
(N+M)^2 = N^2 + 2NM + M^2
$$

以典型的 $M=77, N=1024$ 为例：全注意力矩阵共包含 $(1024+77)^2 = 1,212,201$ 对计算；其中图—图内部占 1,048,576 对，双向跨模态交互占 157,696 对，文—文仅占 5,929 对。当图像扩大至 $N=4096$ 时，总数激增至 17,413,929 对。

**工程反例警示**：「只要搭建了图文注意力通道，模型就必定绝对服从文本指令」并不成立。在训练数据不足或缺乏解耦约束时，模型仍可能发生“属性错误绑定（Attribute Binding）”的典型幻觉：比如把提示词中的“红色”错误附着在椅子上、把“蓝色”涂在帽子上。注意力连通仅仅提供了信息交互的物理通路，精准的语义绑定依赖高质量数据对齐与充分的训练优化。

## 5. 走到视频：多了时间轴，模型选择仍需实验

当从二维图像跨入三维视频时，潜变量在宽高之外新增了时间切片维度 $T_z$。若每个时间切片包含 $S$ 个空间 patch，则全局时空序列总长度将剧烈扩张为 $N_v = T_z S$。

若直接采用未分解的时空全注意力机制，其注意力配对数将按总长度的二次方狂飙至 $(T_z S)^2$。正如在 4.6 节中将要深入展开的，实际系统往往需要借助时空分解注意力（Factorized Attention）等架构创新来遏制算力爆炸，但长时一致性与物理逻辑的保真度依然面临深刻的工程挑战。

### 数值复算 · 零门控输出和梯度

```python
# y = x + g * F(h); x=1, F(h)=2h, h_A=1, h_B=2.
def block(g, h):
    return 1 + g * 2 * h

eps = 1e-6
for g in (0, 0.25, 1):
    a, b = block(g, 1), block(g, 2)
    dh = (block(g, 1 + eps) - block(g, 1 - eps)) / (2 * eps)
    dg = (block(g + eps, 1) - block(g - eps, 1)) / (2 * eps)
    print(f"g={g:.2f}: A={a:.2f}, B={b:.2f}, "
          f"对h的导数={dh:.2f}, A对门导数={dg:.2f}")
```

## 7. 常见误区与诊断

| 常见误区或现象 | 深度排查与诊断方向 |
|---|---|
| **“换用 DiT 之后，所有外部条件都是通过 Attention 注入的”** ✗ | 时间步与全局类别嵌入通常经由 adaLN 逐层调制；文本既可走 Cross-Attention，也可走 MM-DiT 联合注意力，应依据具体模型拓扑核实。 |
| **“零初始化意味着整个模型在第一步没有任何梯度更新”** ✗ | 门控权重自身享有非零的直接局部导数 $\partial y / \partial g = F(h)$，它能率先接收梯度开启门扉，保护的是深层主干不被剧烈扰动。 |
| **“1024×1024 图像的生成推理延迟一定比 512×512 慢 16 倍”** ✗ | 16 倍仅对应纯图—图注意力配对项；在常规尺寸下，线性投影与 FFN 开销依然占据显著份额，整体延迟倍数通常远低于 16 倍。 |
| **画面清晰逼真，但提示词中的颜色与实体屡屡绑定错误** | 固定随机种子，排查文本编码器输出是否丢失细节，检查训练集中相关属性共现偏差与 CFG 引导强度，而非盲目归因于图像分辨率不足。 |
| **生成图中的小字与招牌始终模糊不可辨认** | 先执行原图→VAE 编码→VAE 解码的无损重建测试（4.5 节），精准定位是自编码器的空间瓶颈还是主干生成器未学会。 |

## 8. 练习（附解答）

1. **切块尺寸换算**：输入 512×512 图像，设定 $f=8, p=4$，计算序列长度 $N$ 与图—图配对数。若改为 $p=2$，两者各变化为多少倍？

   **答**：$N = (512/8/4)^2 = 16^2 = 256$，图—图配对数为 $256^2 = 65,536$；若切换为 $p=2$，则 $N = (512/8/2)^2 = 32^2 = 1024$（增大为 4 倍），配对数变为 $1024^2 = 1,048,576$（激增为 16 倍）。
2. **多模态配对统计**：图像序列 $N=256$ token，文本序列 $M=64$ token，在完整的 MM-DiT 联合注意力矩阵中，跨模态双向有序配对为多少？总配对数为多少？

   **答**：双向跨模态配对包含文—图与图—文两个象限，共计 $2 \times 256 \times 64 = 32,768$ 对；全矩阵配对数为 $(256 + 64)^2 = 320^2 = 102,400$ 对。
3. **门控梯度判定**：对于残差块 $y = x + g F(h)$，若当前门控 $g=0$ 且分支当前计算值为 $F(h)=3$，输入 $x=2$，输出值及对门控的局部偏导数 $\partial y / \partial g$ 分别是多少？

   **答**：输出严格等于输入 $x=2$；对门的局部导数为 $\partial y / \partial g = F(h) = 3$。
4. **性能调优诊断**：将模型 patch 从 $p=2$ 扩大到 $p=4$ 后，推理耗时显著降低，但图像微小细节出现明显模糊，能断定注意力机制是算力瓶颈吗？

   **答**：不能。必须先测试 VAE 自编码器在相应 patch 展平下的表征损失，并在相同训练与采样预算下分别度量线性投影、稠密注意力的实际内核耗时。增大 patch 同时改变了输入特征表示与感受野。
