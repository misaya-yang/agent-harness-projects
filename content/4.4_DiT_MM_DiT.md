# 4.4 DiT 与 MM-DiT：让条件和图像 token 在哪里相遇

> **一句话核心直觉**：生成器不必在每个像素上运行；先把图像压成 latent，再把 latent 切成 patch，Transformer 反复预测去噪量或速度。DiT 用时间等条件逐层调节特征；adaLN-Zero 的残差门从零开始，使每个残差块初始为恒等映射。MM-DiT 则让文本与图像保留各自的投影参数，同时在联合注意力里交换信息。分辨率翻倍时，图像 token 通常变成 4 倍，稠密注意力配对变成 16 倍；这不是整个生成流程的 16 倍延迟。
> **唤醒标签**：$N=(H/fp)(W/fp)$ · $\operatorname{adaLN}=(1+\gamma)\operatorname{LN}(x)+\beta$ · $y=x+gF(\operatorname{adaLN}(x))$ · 图文 QKV 分开、注意力联合 · $(N+M)^2=N^2+2NM+M^2$ · 视频另乘 latent 时间片数

---

## 1. 任务：同一张画，怎样既听懂提示又能放大？

假设你要生成一张「小狗戴红帽，坐在蓝色椅子上」的图片，并从 512×512 升级到 1024×1024。系统既要让文本里的颜色与对象对应，又要在每次去噪时处理更多空间位置。两个问题容易混为一谈：**模型在哪里融合条件**，以及**每次去噪到底多算了多少**。

前几课讨论怎样训练去噪器或速度场（→ 4.1、4.2），以及推理时怎样组合有条件和无条件的预测（→ 4.3）。这节课沿着张量走一遍：图像怎样变成 token，时间和文本条件在哪里进入，图像与文本又怎样在注意力层中交换信息。这个骨干可以搭配不同训练目标，例如噪声预测、速度预测或条件流匹配。

## 2. 从像素到 latent patch，再回到图像

### 2.1 为什么先压缩

对 RGB 图像 $x\in\mathbb R^{H\times W\times3}$，编码器产生 $z=E(x)\in\mathbb R^{H/f\times W/f\times C}$。$f=8$ 指**宽和高各缩小 8 倍**，面积是 1/64；它不是指全部标量数量一定是 1/64，因为通道从 3 变成了 $C$。例如 512×512 RGB 共 786,432 个标量，$f=8,C=4$ 的 latent 是 64×64×4，共 16,384 个标量（→ 4.5）。

在训练中，从真实图的 $z_0$ 构造噪声状态 $z_t$，模型接收 $(z_t,t,\text{condition})$，预测训练目标；采样时从噪声 latent 逐步更新到 $\hat z_0$，最后由解码器 $D(\hat z_0)$ 得到图片。压缩器负责表示，Transformer 负责该表示里的分布建模；重建能力与生成能力要分别评估。

### 2.2 patchify 是把网格变成序列

每个 $p\times p$ latent 邻域拉直为 $p^2C$ 维向量，经共享线性投影变成宽度 $D$ 的 token。设宽高能被 $fp$ 整除：

$$
N=\frac H{fp}\frac W{fp},\qquad
\text{patch}\in\mathbb R^{p^2C}\xrightarrow{W_{\rm in}}\mathbb R^D.
$$

给 token 加空间位置信息，再送进多层 Transformer；输出头预测每个 patch 对应的 $p^2C$ 个数，unpatchify 回 $H/f\times W/f\times C$ 网格。对不整除的尺寸，必须约定裁切、填充或可变尺寸处理，不能直接取整声称 token 数正确。

例如 $C=4,p=2,D=1152$ 时，一个 patch 含 $2\times2\times4=16$ 个 latent 标量；不计偏置的输入投影有 $16\times1152=18,432$ 个权重，所有 patch 共用它。输出头反过来把每个 $D$ 维 token 投影到 16 维，再按原顺序拼回网格。增加图像分辨率不增加这两个投影的参数数目，却会增加调用次数；增加 $p$ 则同时改变输入输出投影的尺寸与序列长度。Transformer 若没有任何位置编码，也无法仅凭自注意力区分「红帽在狗头上」和将 patch 打乱后的空间排列（→ 1.0）。

| 设置 | latent 网格 | 图像 patch 数 $N$ | 有序图—图配对 $N^2$ |
|---|---:|---:|---:|
| 512×512，$f=8,p=2$ | 64×64 | 1,024 | 1,048,576 |
| 1024×1024，同 $f,p$ | 128×128 | 4,096 | 16,777,216 |
| 1024×1024，$f=8,p=4$ | 128×128 | 1,024 | 1,048,576 |

最后一行说明可以用大 patch 把 token 数拉回来，但一个 token 内压进更多局部信息，不能假定画面细节不变；需要在固定训练数据、模型和预算下实测。换成视频后，空间 token 数还要乘 latent 时间片数，见 4.6。

### 2.3 配对数不是完整 FLOPs

假设仅计算图像序列、宽度 $D$、FFN 中间宽度 $4D$，乘加算 2 FLOPs，忽略归一化和偏置，一层近似为

$$
\underbrace{24ND^2}_{\text{QKV、输出投影与 FFN}}+
\underbrace{4N^2D}_{QK^\top\text{ 与 }AV}\quad\text{FLOPs}.
$$

第一项来自四个注意力投影 $8ND^2$ 和两个 FFN 矩阵 $16ND^2$；第二项是两个稠密矩阵乘法。只有 $N=6D$ 时两项相等。因此当 $N$ 尚小，即使配对数大幅增长，逐 token 的投影也可能占主导。FlashAttention 可以避免物化完整注意力矩阵、减少访存，但精确稠密注意力的两两乘法并没有自动变成线性复杂度（→ 1.5）。此外，整个生成成本还要乘采样步数；CFG 若算两条分支，也增加预测工作量，即便它们被打包到同一次批处理中。

把预算接到一次完整采样上：沿用 $N=1024,D=1152$，28 个同宽层、30 个去噪步骤，假设每步 CFG 计算条件与无条件两次，则仅上式的 Transformer 主项约为 $(32.61+4.83)\times28\times30\times2/1000\approx62.9$ TFLOPs/张图。这里按十进制 $10^{12}$ FLOPs 计；没有包含文本流、输出头、VAE 和其他操作，也没有假设硬件利用率。只用理论峰值除以 FLOPs 会给出理想下界，不能冒充测得延迟。如果只算一步、或把批量化误认为算了一条分支，会少算整个采样的主要工作。

先预测固定 512×512 时把 patch 从 2 改到 4 的后果，再改变 patch 和边长观察曲线。图中的基准始终是 512×512、$p=2$；这里刻意只画相对工作量，图上的值不是 GPU 延迟。

### 2.4 换宽度和换分辨率，不是同一种扩容

只看标准 Transformer 主体、忽略调制和偏置，一层参数约为注意力 $4D^2$ 加 FFN $8D^2$，共 $12D^2$；$L$ 层约 $12LD^2$。图像分辨率增大改变 $N$，但这部分参数数量不变；模型宽度 $D$ 增大，则参数近似按平方增长。对应前向 FLOPs 的两个主项：

| 固定其他量，只改一项 | 参数量近似 | 逐 token 投影 FLOPs | 注意力配对 FLOPs |
|---|---:|---:|---:|
| 图像边长 ×2，$N$ ×4 | 不变 | ×4 | ×16 |
| 宽度 $D$ ×2 | ×4 | ×4 | ×2 |
| 层数 $L$ ×2 | ×2 | ×2 | ×2 |

表中 FFN 的扩张比固定，参数估算不包括条件嵌入、输入输出头和 adaLN 参数。真实设计通常同时改变深度、宽度、head 数和训练预算；这里的目的是预测瓶颈往哪里移动，而不是比较不同模型的质量。

### 2.5 同一个网络输出，如何接到采样器

令加噪状态为 $z_t=\alpha_t z_0+\sigma_t\epsilon$，$\epsilon\sim\mathcal N(0,I)$，网络先只负责把 $(z_t,t,c)$ 映射为与 $z_t$ 同形的预测。若训练目标是 $\epsilon$，在 $\alpha_t>0$ 时可计算

$$
\hat z_0=\frac{z_t-\sigma_t\hat\epsilon_\theta(z_t,t,c)}{\alpha_t}.
$$

若使用一种满足 $\alpha_t^2+\sigma_t^2=1$ 的**旋转式**速度参数化 $v=\alpha_t\epsilon-\sigma_tz_0$，则反解得到 $\hat z_0=\alpha_tz_t-\sigma_t\hat v$、$\hat\epsilon=\sigma_tz_t+\alpha_t\hat v$。这两个变换的前提是同一组 $\alpha_t,\sigma_t$，不要直接套在任意路径上。Flow Matching 也常把网络目标称为速度，但它指所选概率路径的时间导数（→ 4.2），不一定等于这里旋转式的 $v$。

例如把干净 latent 和噪声连成 $z_t=(1-t)z_0+t\epsilon$，则条件路径的导数为 $\epsilon-z_0$；模型回归该方向，采样时从对应噪声端按所选时间方向数值积分。**网络结构、目标参数化、噪声/时间约定与数值采样器要匹配**：把预测噪声的输出直接当作这个路径的速度，哪怕张量形状完全相同，也会走错方向。最终解码的是采样器产生的近似干净 latent，而不是任意时刻的带噪 $z_t$。

## 3. 为什么用 Transformer，条件从哪里进入？

经典 U-Net 通过多尺度卷积、跳连和跨注意力把局部与全局信息结合起来；它仍是有效选择。DiT 将较规则的 token 序列交给 Transformer，便于研究模型规模、token 数与计算预算的关系。原论文在其评测设置下观察到，增大前向计算量的 DiT 获得更低的 FID；这不是对所有 U-Net 或所有部署约束的普遍替代定理。

仅有 latent 不够：相同的 $z_t$ 在不同噪声时间应采取不同更新；提示或类别也要改变输出。最简单的方法是把时间、类别等嵌入作为额外 token，或者用 cross-attention 查询条件。DiT 还比较了在每层使用条件自适应归一化的做法，尤其是 adaLN-Zero。

### 3.1 先归一化，再按条件调节

对每个 token 的通道做 LayerNorm，条件向量 $c$（如时间嵌入与类别嵌入的组合）经网络产生向量 $\gamma(c),\beta(c),g(c)$：

$$
h=(1+\gamma(c))\odot\operatorname{LN}(x)+\beta(c),
\qquad y=x+g(c)\odot F(h).
$$

$\gamma$、$\beta$、$g$ 与模型宽度同维，广播到同一条件下的图像 token；$F$ 代表注意力或 MLP 分支。真实 DiT 中两条分支各有一套平移、缩放与残差门，而不是只有上面一条。对时间条件，网络可以按时间改变每层的特征坐标和更新强度。

这几种注入方式回答的是不同问题：

| 注入方式 | 一层里信息怎么到图像 token | 适合解释什么 | 局限 |
|---|---|---|---|
| 全局条件调制（如 adaLN） | 一个条件向量产生逐通道缩放、平移和门 | 所有位置随噪声时间调整处理方式 | 若只输入一个汇总向量，不能直接对应每个词的位置 |
| 图像查询文本的 cross-attention | 图像 query 读取文本 key/value | 每个图像位置按内容选读提示词 | 文本 key/value 若不更新，文本不会通过这条路径读回图像 |
| 联合注意力 | 文本和图像 query、key、value 拼接后共同注意 | 两个方向都能交换信息 | 图像与文本总长度都进入联合配对预算 |

这些方式可以组合。例如时间通过 adaLN 注入，词序列通过 cross-attention 或联合注意力进入；不能把「用了 adaLN」推断成「没有文本注意力」。

### 3.2 零初始化的精确含义

让生成调制参数的最后线性层初始输出为零，就有 $\gamma=\beta=g=0$，因此每条残差分支开始都不改变输入，整个 **Transformer 残差块**是恒等映射。它并不意味着输入 patch 投影、输出头和整个模型都是恒等映射；也不意味着不同时间的预测一开始已经不同。

对 $y=x+gF(h)$，若把 $g$ 看成独立标量，$\partial y/\partial h=gF'(h)$，而 $\partial y/\partial g=F(h)$。当 $g=0$ 时，该分支内部与调制参数从这条路径收到的梯度为零，但门可以先收到梯度并打开；具体训练中还受最终输出头、损失和上游梯度影响。恒等起步是初始化方式，不是网络永远无法学习条件。

例如，若完整网络的最终预测头也被初始化为零，其第一步可能先只更新输出头：此时传回残差块的上游梯度也为零。输出头之后变为非零，门才可能通过非零上游梯度更新，随后门打开使分支参数得到梯度。这个顺序依赖实现、损失以及优化器；只凭局部 $\partial y/\partial g$ 非零，不能断言网络在第一步就一定打开门。

先预测两种条件在 $g=0$ 时是否产生不同输出，再拖动残差门。示例固定归一化后的标量为 1，条件 A、B 分别使 $h=1,2$，$F(h)=2h$。

```academy-lab

```

$g=0$ 时输出均为 1；$g=0.25$ 时分别为 1.5 和 2。玩具计算只演示门与梯度的关系，并未训练真实 DiT。[复算这组结果](#worked-example-2)。

## 4. MM-DiT：图文各算投影，但共同做注意力

### 4.1 为什么不是把两种 token 简单当成一样

文本编码器产生 $M$ 个文本 token $T$，图像 latent 产生 $N$ 个图像 token $I$。两者数值分布、目标和所需特征不同。MM-DiT 对文本流和图像流各用各自的参数生成 $Q,K,V$，然后沿序列维拼接：

$$
Q=\begin{bmatrix}Q_T\\Q_I\end{bmatrix},\quad
K=\begin{bmatrix}K_T\\K_I\end{bmatrix},\quad
V=\begin{bmatrix}V_T\\V_I\end{bmatrix},\quad
O=\operatorname{softmax}(QK^\top/\sqrt{d_h})V.
$$

把结果再按模态分开，经各自的输出投影和后续处理。以文本在前为例，分数矩阵分成四块：

| query → key | 文本 $M$ 个 key | 图像 $N$ 个 key |
|---|---|---|
| 文本 $M$ 个 query | 文—文 $M^2$ | 文—图 $MN$ |
| 图像 $N$ 个 query | 图—文 $NM$ | 图—图 $N^2$ |

联合注意力允许两种方向的信息交互；每一行仍只在该 query 的可见 key 上做一次 softmax。与只让图像 query 读取固定文本 key/value 的常见 cross-attention 相比，文本流也可以随图像更新。具体实现可能对某些层、输出或掩码做特殊处理，不能把这张图当成所有多模态 Transformer 的源码。

注意文本和图像 key 在同一行 softmax 中**竞争同一份概率质量**。若某个图像 query 看见一个文本 key 和两个图像 key，其 logits 分别为 $(2,1,0)$，得到权重约 $(0.665,0.245,0.090)$。这里 0.665 是分给文本的总质量；新增大量有竞争力的图像 key 或改变 logits 后，它可能下降。网络可以学习投影、归一化和注意力模式来适应不同模态长度，不能由 token 数单独预测最终绑定能力；但这个算例解释了为什么直接比较两个模态各自内部归一化的权重会误读联合注意力。

### 4.2 成本怎样随文本长度变化

以 $M=77,N=1024$ 为例，完整分数矩阵有 $(1024+77)^2=1,212,201$ 对，其中图—图 1,048,576，两个跨模态方向共 157,696，文—文 5,929。$N=4096$ 时，总数为 17,413,929 对。仅仅报告图—图的 16 倍会漏掉文本部分；但也不能把联合注意力整个开销都归因于跨模态交换。掩码、稀疏连接和不同 token 数会改变这些数字。

**反例**：「加进文本 token 就一定遵循指令」不成立。模型可能把“红”连到了椅子，把“蓝”连到了帽子，虽然图文之间存在注意力路径。连接使交互成为可能，绑定关系仍须靠训练数据、目标和评测建立；注意力权重也不能单独证明模型理解了提示。

## 5. 走到视频：多了时间轴，模型选择仍需实验

假设 latent 有 $T_z$ 个时间片，每片 $S$ 个空间 patch，则序列长度 $N_v=T_zS$；若再用时间 patch $p_t$ 合并相邻片段，则按实际 padding 规则计算 $\lceil T_z/p_t\rceil S$。图像时空信息进入同一序列后，简单的全时空注意力配对为 $N_v^2$。实际视频编码器常在时间上压缩，$T_z$ 不能未经换算就当作原始视频帧数（→ 4.6）。

DiT 对变量长度序列自然适配，但长视频的计算与一致性不是光靠换一个骨干就解决。下一课分别分析 codec 与潜空间，4.6 再比较全时空注意力、分解注意力与长时间滚动。

### 数值复算 · 零门控输出和梯度

```python
# y = x + g * F(h); x=1, F(h)=2h, h_A=1, h_B=2.
def block(g, h):
    return 1 + g * 2 * h

eps = 1e-6
for g in (0, 0.25, 1):
    a, b = block(g, 1), block(g, 2)
    dh = (block(g, 1 + eps) - block(g, 1 - eps)) / (2 * eps)
    dg = (block(g + eps, 1) - block(g - eps, 1)) / (2 * eps)
    print(f"g={g:.2f}: A={a:.2f}, B={b:.2f}, "
          f"对h的导数={dh:.2f}, A对门导数={dg:.2f}")
```

## 7. 常见误区与诊断

| 现象或说法 | 应该核对什么 |
|---|---|
| 「用了 DiT，所有条件都在 attention 里」 | 时间、类别可以通过 adaLN 注入；文本可走 cross-attention 或联合注意力，依具体架构而定。 |
| 「零初始化意味着所有权重永远没有梯度」 | 区分门自身与被门挡住的分支；真实输出头的初始化也影响第一步。 |
| 「1024 图像一定比 512 慢 16 倍」 | 16 倍仅对应这里固定 patch 下的图—图配对；检查线性项、采样次数、实现与实测。 |
| 图片清晰但提示绑定错误 | 固定 seed 比较对象、属性及空间关系；同时检查文本编码、数据和 CFG，不要只看分辨率。 |
| 图片中的小字始终模糊 | 先做原图→codec→重建诊断，区分表征瓶颈和生成器没学会；不能单凭生成图归因。 |

## 8. 练习（附解答）

1. **换 patch**：512×512 图、$f=8$、$p=4$，算 $N$ 与图—图配对。若改为 $p=2$，各变多少倍？

   **答**：$N=16^2=256$，配对 $65,536$；改 $p=2$ 后 $N=1024$ 是 4 倍，配对是 16 倍。
2. **区分模态**：图像 256 token，文本 64 token，完整联合注意力的跨模态有序配对多少？全部配对多少？

   **答**：两个方向共 $2\times256\times64=32,768$；全部 $(256+64)^2=102,400$。不能只计一个方向。
3. **判断初始化**：若 $g=0$ 而 $F(h)=3$，输入 $x=2$，输出及对门的局部导数是什么？

   **答**：输出为 2；局部导数 $\partial y/\partial g=3$。损失对门的梯度还要乘 $\partial L/\partial y$。
4. **设计排查**：换成更大的 patch 后，速度提高但细字变差，能直接认定注意力是瓶颈吗？

   **答**：不能。先单独检查 VAE 重建，再在相同训练与采样预算下比较不同 patch 大小。记录投影和注意力的实测耗时，也比较输出质量：patch 大小还改变了每个 token 表示的区域。
