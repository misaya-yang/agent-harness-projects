# 4.6 视频生成与世界模型：从时空 token 到可检验的行动后果

> **一句话核心直觉**：视频的 latent 同时有时间和空间轴；在其他设置固定时，加长视频会线性增加 token 数，而稠密全时空注意力的配对数按总长度平方增长。时空分解把一次全注意力改成空间和时间两次注意力，在时空规模足够大时减少配对，同时改变模型类。长视频还要维持遮挡前后的状态；逐段滚动可能累积误差。把动作接入生成器可以提出可交互的未来预测，但仅有动作输入或逼真画面还不足以证明它能可靠模拟行动后果。
> **唤醒标签**：$N=T_zS$ · 全注意力 $(T_zS)^2$ · 分解 $T_zS^2+ST_z^2$ · $p(z_t|z_{<t},a_{<t})$ · $e_{t+1}\le Le_t+\delta$ · 开环 / 闭环 · 干预动作

---

## 1. 场景：生成一个可交互的机器人练习场

设想机器人看见桌上一只红杯子，计划伸手将它推向右边。你希望生成 5 秒视频，让研究者看到手、杯子和桌面如何运动；进一步，希望改变施力方向后，杯子的结果也随之改变。

这实际上有三道不同的题：

1. **计算题**：5 秒视频要喂给模型多少时空 token？加到 10 秒会增加多少注意力工作？
2. **记忆题**：杯子被手挡住后再次出现，颜色、位置和运动状态能不能延续？
3. **行动题**：同样的初始画面，向左推和向右推是否产生对应的可验证结果？

一段视频帧帧清晰不等于跨时间一致；跨时间看起来一致也不等于对行动的物理后果预测正确。先算账，再讨论建模与评估。

## 2. 原始帧不等于 latent 时间片

设视频长 $d$ 秒、帧率 $r$ 帧/秒，若恰好采样整帧，则原始帧数 $F=dr$。一个时空 codec 将视频压成 $T_z\times H_z\times W_z\times C$ 的 latent 网格；每时间片再用 $p\times p$ 空间 patch 切分，得到

$$
S=\frac{H_z}{p}\frac{W_z}{p},\qquad N=T_zS.
$$

若近似空间压缩 $f_s$，且无填充并整除，则 $H_z=H/f_s,W_z=W/f_s$。时间压缩 $f_t$ 后有多少片取决于 codec 的时域卷积、首帧和 padding；不能机械地对所有模型使用 $T_z=F/f_t$。也有视频模型在 latent 上继续做时间 patch，这时要按实际 patch 布局再计算。

为了有可复算的数，**本节假设** 24 fps、512×512、每 4 帧恰好产生 1 个 latent 时间片、$f_s=8,p=2$，无边界损失。一个时间片是 $(512/8/2)^2=1024$ 个 patch：

| 时长 | 原始帧 $F$ | latent 时间片 $T_z$ | token $N$ | 全注意力有序配对 $N^2$ |
|---|---:|---:|---:|---:|
| 5 秒 | 120 | 30 | 30,720 | 943,718,400 |
| 10 秒 | 240 | 60 | 61,440 | 3,774,873,600 |

固定帧率与空间分辨率时，时间翻倍，token 翻倍，配对变 4 倍。若**每边**图像分辨率翻倍，$S$ 变 4 倍，配对变 16 倍；时间和边长都翻倍则配对变 64 倍。这只是单层的稠密配对项，不是完整系统必然慢 64 倍。[用 Python 复算](#worked-example)。

若真的物化上表 5 秒视频单个样本、**单个头**的 BF16 分数矩阵，仅分数就占 $943,718,400\times2/2^{30}=1.76$ GiB；10 秒为 7.03 GiB。还没计算多头、激活、模型参数与反向传播。FlashAttention 一类算法能避免存下完整矩阵，因此这个数是物化时的内存账，不是所有实现都必须分配的显存（→ 1.5）。

## 3. 3D 全注意力与时空分解

### 3.1 为什么需要跨空间、跨时间读取

一帧内，杯子和手相距很远时也可能相互影响，需要空间交互；相邻或相隔较远的帧中，模型要把杯子的外观和位置对应起来，需要时间交互。把所有 $TS$ 个 token 放在一起，所有 query 对所有 key 做注意力，有序配对数为

$$
C_{\rm full}=(TS)^2=T^2S^2.
$$

这里 $T$ 指 latent 时间片数，包含自身配对；实际 FLOPs 还要乘头维度、层数并加投影与 MLP。全注意力的好处是一步可直接连接任意两个时空位置；代价是配对迅速增长。

### 3.2 先在帧内看，再沿时间看

一种分解方式在每个时间片内对 $S$ 个位置做空间注意力，再在每个空间位置沿 $T$ 个时间片做时间注意力：

$$
C_{\rm factor}=TS^2+ST^2,\qquad
\frac{C_{\rm full}}{C_{\rm factor}}=\frac{TS}{T+S}.
$$

两次注意力都有自己的投影和计算，不应只拿配对比宣称等比例的 GPU 加速。先空间后时间时，信息可通过「同一时间片中的空间位置 → 另一时间片的相同位置」两跳到达远处；但这不是单层全注意力能表达的任意加权关系。也可采用时间后空间、局部窗口、稀疏注意力等其他结构，各有连接路径和代价。

先预测 $T$ 从 8 变 16 的结果，再调整下面实验。输入为 512×512、空间压缩 8 倍，默认 patch $p=4$，所以每时间片 $S=256$；也可以切换为 $p=2$，此时 $S=1024$。含自身配对，不包括投影、归一化和其他网络开销。这里用的 $T$ 是 latent 时间片，按本节假设 24 fps × 秒数得到原帧、每 4 帧得到 1 个 latent 时间片，例如 5 秒为 30 片。

```academy-lab
4.6
```

$p=4,T=8$ 时，全注意力有 4,194,304 对，分解注意力有 540,672 对；$T=16$ 时分别为 16,777,216 和 1,114,112 对。后者约 2.06 倍而不是 2 倍，因为时间注意力项本身仍随 $T^2$ 增长。固定 $T=8$ 改为 $p=2$，$S=1024$，两种配对分别变为 67,108,864 和 8,454,144。回到 §2 的 5 秒例子，分解是 32,378,880 对，相比全注意力约少 29.15 倍的配对；这不是已经测得 29.15 倍的运行加速。

### 3.3 两次注意力的投影也要算

一个宽度 $D$ 的标准注意力层，如果 Q、K、V 和输出都为 $D\times D$ 投影，乘加算 2 FLOPs，投影约 $8TSD^2$；$QK^\top$ 与 $AV$ 再合计 $4CD$，$C$ 是配对数。若分解结构用两套独立注意力投影，且其他 FFN 等开销相同，比较的是

$$
\text{全}=8TSD^2+4(TS)^2D,\qquad
\text{分解}=16TSD^2+4(TS^2+ST^2)D.
$$

例如 $T=8,S=256,D=1152$，全注意力约 41.07 GFLOPs，分解约 45.98 GFLOPs：虽然配对少了约 7.76 倍，第二套投影让总注意力主项反而更大。$T=16$ 时两者分别约 120.80 和 92.11 GFLOPs。这些仍只是算子量，不含 FFN、激活、带宽、实现与额外模块；可作为测量前的预判，不能代替实测。

### 3.4 减少 token 也可能损失时间信息

降低帧率或扩大时间压缩比会让 $T$ 下降，但快速运动、短接触和遮挡状态可能消失；同一组稀疏帧也可能对应多种运动。插帧模型能生成一种合理轨迹，不一定恢复真实发生的细节。实验要在目标任务的动作速度、时长和相机设置下检查接触、位移及时间一致性；画面流畅本身不能证明原始运动被保留。

## 4. 一次生成与自回归滚动有什么不同

### 4.1 联合去噪：整段一起更新

一种视频扩散或 flow 模型先采样整段时空噪声，在每个采样步骤同时更新所有时间片。若使用双向时间注意力，任一时间位置可以参考未来位置；这有助于整段协调，但要求一次预定生成长度，不能把它当成天然逐帧、实时因果模型。模型仍可通过窗口、条件续写等方式扩展，不同实现的延迟和上下文安排并不一样。

### 4.2 因果 / 自回归：用已知历史产生下一段

如果有初始观察 $z_0$ 和预先固定、外生指定的动作序列 $a_0,\dots,a_{T-1}$，且状态生成不依赖尚未发生的动作，一个因果模型可以写成

$$
p_\theta(z_{1:T}\mid z_0,a_{0:T-1},c)
=\prod_{t=1}^T p_\theta(z_t\mid z_{0:t-1},a_{0:t-1},c).
$$

$z_t$ 可以表示一帧、一个 latent 时间片或一个分块；每个条件项只使用已发生的状态与动作。实际系统也可能一次自回归地产生一段、并用段内扩散联合采样；「视频扩散」与「自回归」并非只能二选一。因果掩码、缓存和块边界都必须与生成顺序一致，避免训练时偷看未来。

假设一个时间片内所有 $S$ 个 token 可以互相读取，但第 $t$ 片只能读取前 $t$ 片，那么全时空注意力的有序配对数不再是 $(TS)^2$，而是

$$
S^2\sum_{t=1}^{T}t=\frac{S^2T(T+1)}2.
$$

若空间注意力仍在每片内部全连接、时间注意力只读相同空间位置的过去，分解的配对数为 $TS^2+ST(T+1)/2$。例如 $T=8,S=256$，两者分别为 2,359,296 和 533,504 对。这里允许同一片内所有 token 相互看见；若帧内也要逐 token 自回归，掩码与数字还会改变。[复算掩码的配对数](#worked-example)。

还有一个隐蔽的未来泄漏：即使 Transformer 上了因果掩码，如果训练时的时空编码器对 $t$ 时刻的输入使用了未来帧，那么当前 latent 本身就可能含未来信息。部署要求严格实时预测时，应检查编码器的时间感受野、首帧 padding、条件帧边界与目标对齐，而不只看 Transformer 掩码。允许整段离线生成的任务则可以使用双向编码；关键是训练输入和部署时可用的信息必须一致。

训练时常用真实历史作条件（teacher forcing）；部署滚动时只能用自己以前的预测。模型即便一步误差小，也可能进入训练里很少出现的状态区域，随后误差继续传播。视频里表现为物体遮挡后消失、手部形状漂移、场景布局改变或物体穿过桌面；这不是必然会在某个固定秒数发生的定律，取决于模型、场景和反馈机制。

### 4.3 遮挡是对状态记忆的测试

仅凭当前帧无法看到被手挡住的杯子：模型需要从历史推断它在哪里、是什么颜色以及是否受到力。重现一个外观上类似的杯子还不够；如果杯子从左侧被推到右侧，遮挡结束后却出现在原地，单帧可能真实、轨迹却不一致。

可以构造成对测试：同一初始状态、一组可控遮挡时长，隐藏对象后再露出，记录对象 ID、颜色、位置和速度误差。要固定提示、采样设置、分辨率和计算预算，并区分预测分布有多种合理未来与模型忘记了已知状态。

## 5. 误差是怎样沿时间传递的

设真实状态按 $s_{t+1}=f(s_t,a_t)$ 演化，预测器使用 $\hat f$。固定相同动作序列，若在考虑区域内 $f$ 关于状态的 Lipschitz 常数至多为 $L$，并且每一步的模型误差至多 $\delta$，则由三角不等式：

$$
e_{t+1}=\|\hat s_{t+1}-s_{t+1}\|
\le L e_t+\delta.
$$

若 $e_0=0$，则 $L=1$ 时上界为 $t\delta$；$L\ne1$ 时上界为 $\delta(1-L^t)/(1-L)$。它是给定条件下的**上界**，不是说真实误差必定以该速率增长；不同误差可能抵消，状态约束也可能使界变松。若策略会根据预测状态改变动作，额外的动作误差和环境反馈还要进入分析。

也可以用概率理解为什么长轨迹的「全程不出错」会比单步准确率更苛刻。作为假设，每一步独立地以 2% 概率出现一次不可接受错误，则前 $t$ 步均未出错的概率为 $(0.98)^t$：10 步约 0.817，50 步约 0.364。这里的「错误」必须事先定义，且独立同分布是假设；真实错误常因同一物体、同一隐藏状态或一次严重偏移而强相关，不能把 2% 直接外推成任何产品的崩溃概率。

用一个可视化玩具例子：每步偏差固定 $+0.1$ m，初始误差为 0。第一种完全保留已有误差，$e_{t+1}=e_t+0.1$；第二种假设每步有效修正 20% 的已有误差，$e_{t+1}=0.8e_t+0.1$。这只是规定的误差动力学，不代表所有闭环模型都能校正，步数也不自动等于秒数。

让两条轨迹从同样的起点出发，逐步增加滚动步数。先问每一步新增的偏差有多大，再问上一步留下的偏差有多少会传到这一步。

```academy-lab
4.6-rollout
```

20 步后两者分别为 2.000 m 与 0.494 m；第二条趋向 $0.5$ m。它展示了可用观测和有效反馈为何可能抑制漂移，也提醒我们：错误的观测、错误的动作或不稳定的控制器可能放大误差。[复算滚动递推](#worked-example-2)。

## 6. 从视频先验到世界模型：必须回答「改变动作会怎样」

### 6.1 观测与状态不是一回事

视频 $o_t$ 是环境状态 $s_t$ 经相机或传感器产生的观测：$o_t\sim p(o_t|s_t)$。真实状态还可能包括物体质量、速度、机器人关节、相机外未见物体等；单张图未必能确定这些信息。可交互的世界模型试图在历史或隐状态 $h_t$、动作 $a_t$ 条件下预测下一状态或观测，例如

$$
h_{t+1}\sim p_\theta(h_{t+1}\mid h_t,a_t),\qquad
\hat o_{t+1}\sim p_\theta(o_{t+1}\mid h_{t+1}).
$$

隐状态可以是显式几何、离散符号、连续向量或视频 latent；并非每个世界模型都要生成像素。对于规划，还可能预测奖励、碰撞、终止或任务成功概率。接入动作使模型**能够表示**不同的行动后果，但并不自动保证它学到了可干预的真实动力学。

当动作由策略即时决定时，要把策略也放进过程：当前历史 $h_t$ 给出动作 $a_t\sim\pi(\cdot\mid h_t)$，环境再按 $p(s_{t+1}\mid s_t,a_t)$ 转移，模型据此预测。把整条未来动作序列作为普通观测条件可能泄露信息：未来动作本身是看到中间状态后才选出的。§4 的分解因此明确采用预先指定的外生动作；做闭环评估时则应逐步运行策略、观察和环境转移，不从录像里提前透露未来动作。

### 6.2 一个反例：只会猜数据集的默认动作

数据集中大部分示范都向右推杯子。一个模型忽略动作，只凭当前图像预测杯子向右移动：在原始数据的平均指标上，它可能表现不错。但在相同初始条件下改成「向左推」，它仍输出向右的杯子，说明画面预测未正确响应动作。

诊断时，对同一个初始状态分别输入向左、向右和不施力，在真实环境或可信模拟器中执行，再比较位移方向、大小和接触时序。注意实际动作要有可比较的力度、持续时间和坐标系；如果离线数据中的动作选择与不可见状态相关，单纯的相关性不能保证反事实准确。只把动作标签拼入 Transformer 并画出合理的视频，不构成因果有效性的证明。

### 6.3 对机器人有什么用，也如何限制误用

模型可以作为规划器的候选轨迹模拟器：比较不同动作下的可能结果、估计任务成功概率，再选动作执行。机器人接收新的真实观察后更新状态，重新规划；与无限期开环播放预测相比，这提供了纠正状态估计的机会。规划器也可能利用模型误差，选出在模拟器里成功、真实环境里失败的动作，因此要在保留场景、动作扰动和真实执行中评估。视觉逼真、物理一致与任务成功应分别报告，不可互相替代。

## 7. 评估方案：把一步预测、长时一致和行动结果分开

| 要回答的问题 | 对照与度量 | 只看这一项会漏掉什么 |
|---|---|---|
| codec 保留了什么？ | 同视频直接编码→解码；测重建、文字、运动与时间一致性 | 重建好不等于从噪声能生成好 |
| 模型一步预测得怎样？ | 用真实历史和相同动作评估一步位置、碰撞和条件似然等 | teacher forcing 不暴露滚动误差 |
| 长时间能否维持状态？ | 关闭真实帧反馈、从相同初始条件滚动，按时间画位置/对象一致性；固定采样预算 | 多模态未来不应只按唯一像素参考惩罚所有合理轨迹 |
| 改变动作能否改变后果？ | 同初始状态做左 / 右 / 停止干预，与环境中的方向、接触及轨迹比较 | 一种动作下的拟合不足以证明新动作也有效 |
| 对控制是否有用？ | 保留场景与动作范围，闭环执行并报告成功率、碰撞率和重规划开销 | 漂亮视频或单步误差不等于实际任务成功 |

基于分布的整段视频指标可用于补充整体观感，但数值受数据集、特征提取器、帧率、采样量影响，不能单独证明物理规律正确。若未来本来具有随机性，应该评估概率校准、覆盖和任务相关量，而不是要求所有生成都和唯一录制轨迹逐像素一致。

## 8. 数值复算

两组代码可单独用 Python 标准库运行。第一段的时间压缩是为了教学明确假设的整除版本，计算的是有序配对，不是实测运行时间。

### 数值复算 · 视频 token 和分数矩阵

```python
for patch in (4, 2):
    s, t, d = (512 // 8 // patch) ** 2, 8, 1152
    n = t * s
    full, factor = n**2, t*s**2 + s*t**2
    full_flops = (8*n*d**2 + 4*full*d) / 1e9
    factor_flops = (16*n*d**2 + 4*factor*d) / 1e9
    print(f"T={t}, p={patch}, S={s}: 全={full:,} 对, 分解={factor:,} 对, "
          f"注意力={full_flops:.2f}/{factor_flops:.2f} GFLOPs")

s, t = 256, 8
past_pairs = t * (t + 1) // 2
print(f"T={t}, S={s}：因果全注意力={s*s*past_pairs:,} 对, "
      f"因果时空分解={t*s*s+s*past_pairs:,} 对")
spatial_tokens = (512 // 8 // 2) ** 2
for seconds in (5, 10):
    frames = seconds * 24
    t = frames // 4  # 仅在本节假设的整除 codec 下成立
    n = t * spatial_tokens
    full = n * n
    factor = t * spatial_tokens**2 + spatial_tokens * t**2
    score_gib = full * 2 / 2**30  # 单头、单样本、BF16，物化分数
    print(f"{seconds}s: 原帧={frames}, latent时间片={t}, token={n:,}")
    print(f"  全注意力={full:,} 对, 分解={factor:,} 对, "
          f"倍数={full/factor:.2f}, 单头分数={score_gib:.2f} GiB")
```

## 9. 练习（附解答）

1. **数 token**：每时间片 $S=256$，$T=8$，全注意力和空间后时间分解各有多少有序配对？

   **答**：全注意力 $(8\times256)^2=4,194,304$；分解 $8\times256^2+256\times8^2=540,672$。
2. **推断代价**：在前题中 $T$ 翻倍时，分解配对为何不是恰好 2 倍？

   **答**：空间项随 $T$ 线性增长，但时间项 $ST^2$ 变为 4 倍；总数从 540,672 变到 1,114,112，约 2.06 倍。
3. **排除训练泄漏**：用自回归模型在训练中输入未来真帧，验证分数很好。部署后仍能得到这个分数吗？

   **答**：不能保证；部署时未来真帧不可用。应按实际预测顺序做因果遮挡，并报告真实历史的一步误差和自生成历史的滚动误差。
4. **动作反事实**：一个画面逼真的杯子视频模型，向左、向右推都输出同一段向右运动。它能否作为可靠的动作模型？

   **答**：不能。它对动作缺乏正确敏感性；需在相同初始状态下对不同动作进行环境干预，并检验方向、大小与接触。
5. **递推**：从 $e_0=0$ 开始，每步 $e_{t+1}=0.8e_t+0.1$，稳定值是多少？若第二步仅获得错误观测，能否保证实际误差收敛？

   **答**：理想递推的稳定值为 0.5 m；错误观测改变有效递推，不能由这个玩具计算保证收敛。
