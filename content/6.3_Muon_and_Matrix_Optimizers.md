# 6.3 Muon 与矩阵优化器：把动量正交化

> **一句话核心直觉**：Adam 把一个权重矩阵当成几百万个互不相干的数，逐个缩放；Muon 把它当成一个线性算子，只保留更新的"方向结构" $UV^\top$，把所有奇异值都拉到 1。这样，被少数大方向淹没的"稀有方向"也能迈出同样大的一步。SVD 太贵，Muon 用几步只含矩阵乘法的 Newton–Schulz 迭代去近似它。
> **唤醒标签**：谱范数下的最速下降 · 极分解 $UV^\top$ · 奇矩阵多项式只改奇异值 · 系数 (3.4445, −4.7750, 2.0315) · 更新 RMS 对齐 0.2 · QK-Clip

前置：0.1（SVD 与谱范数）、0.6（动量与 AdamW）、5.1 §3（每参数显存账）。记号：$W, G, M \in \mathbb{R}^{m\times n}$ 分别是权重、梯度与动量，默认 $m \le n$（否则先转置）；$G = U\Sigma V^\top$ 是奇异值分解。

## 1. 痛点与钩子：如果没有它，世界会怎样？

训练一个 Transformer 到中途，取出某一层 FFN 权重的动量矩阵，做一次奇异值分解。Muon 的作者在手工检查中发现：SGD-momentum 和 Adam 给 2D 参数算出的更新，**条件数都极高**，几乎是低秩矩阵。几千个神经元的更新，被少数几个方向主导。

```academy-figure
6.3-spectrum
```

SGD 在第 i 个奇异方向上走的步长正比于 $\sigma_i$，Adam 的逐元素归一化也不会改变"矩阵整体近似低秩"这件事。于是那些幅度小、但对学习同样重要的方向，几乎永远轮不到。

另一笔账在显存上：AdamW 每个参数要存一阶矩、二阶矩两个状态；Muon 只存一份动量（→ 5.1 §3）。

结果是：Moonlight 在算力最优的设定下报告 Muon 的计算效率约为 AdamW 的 2 倍；Kimi K2（1T 参数）用 MuonClip 训完 15.5T token，**全程没有一次 loss spike**；DeepSeek-V4 系列的大部分模块也换成了 Muon。

**反直觉现象**：Muon 把每个方向的奇异值都改成 1，等于丢掉了"这个方向的梯度有多大"的信息。这听上去是在扔信号，可它比保留全部幅度信息的 Adam 训得更快。

## 2. 第一性原理：看透它的几何 / 物理直觉

### 2.1 权重是算子，不是一袋数

一层线性变换算的是 $y = Wx$。我们真正关心的不是 $W$ 里每个数变了多少，而是**输出会变多少**：

$$
\|\Delta W\,x\| \;\le\; \|\Delta W\|_2\,\|x\|
$$

谱范数 $\|\Delta W\|_2$（最大奇异值）就是"这次更新最多能把输入拉长多少倍"。把它当作步长预算，是对一个线性层最自然的约束。三种优化器的差别，可以归结为它们各自用什么范数来量"一步有多大"：

| 优化器 | 把更新看成 | 用什么量步长 | 最速下降方向 |
|---|---|---|---|
| SGD | 一个长向量 | Frobenius 范数 | $G$ 本身 |
| Adam（去掉动量与 ε） | 一堆独立的数 | 每个元素的绝对值（ℓ∞） | $\operatorname{sign}(G)$ |
| Muon | 一个线性算子 | 谱范数（最大拉伸倍数） | $UV^\top$ |

### 2.2 椭圆变成圆

把单位圆送进一个矩阵，得到一个椭圆，两个半轴的长度就是两个奇异值，朝向由 $U$、$V$ 决定。动量矩阵是一个被拉得极扁的椭圆；Muon 保留椭圆的朝向，把所有半轴都改成 1，于是得到一个圆。

先动手看看：从"常规失衡"出发，把迭代步数从 0 拖到 5，再切换三组系数。

### 2.3 为什么不直接做 SVD：奇多项式只动奇异值

SVD 能精确给出 $UV^\top$，但它是迭代算法，难以在 GPU 上高效并行，放进每一步训练太慢。Newton–Schulz 只用矩阵乘法，而且在 bf16 下也稳定。它能工作，全靠一个恒等式：

```
X = U Σ Vᵀ
X Xᵀ X = U Σ Vᵀ · V Σ Uᵀ · U Σ Vᵀ = U Σ³ Vᵀ
                  └ VᵀV = I ┘ └ UᵀU = I ┘

a·X + b·(XXᵀ)X + c·(XXᵀ)²X = U · (aΣ + bΣ³ + cΣ⁵) · Vᵀ
                                  └──── φ(σ) 逐个作用在奇异值上 ────┘
```

任何**奇次**矩阵多项式都只改奇异值，不碰 $U$ 和 $V$。于是"把矩阵正交化"这个高维问题，被压缩成一个一维问题：**设计一个标量多项式 φ，让它把 (0, 1] 里的每个数都送到 1 附近**。

### 2.4 和 Shampoo 的关系

Shampoo 用左右两个预条件子 $L = GG^\top$、$R = G^\top G$ 把梯度改造成 $L^{-1/4}\,G\,R^{-1/4}$。如果不做跨步累积，只看当前这一步：

$$
L^{-1/4} G R^{-1/4} = U\Sigma^{-1/2}U^\top \cdot U\Sigma V^\top \cdot V\Sigma^{-1/2}V^\top = UV^\top
$$

所以 Muon 可以看成"去掉预条件子累积的 Shampoo"，再把昂贵的逆四次方根换成几步 Newton–Schulz。它也不必存 $L$、$R$ 两个矩阵。

## 3. 承重墙推导：重新捡起核心数学

### Step 1　谱范数约束下的最速下降

在谱范数预算内，找让一阶下降量最大的方向（$\langle A, B\rangle = \operatorname{tr}(A^\top B)$）：

$$
\max_{\|\Delta W\|_2 \le 1} \; \langle G, \Delta W \rangle
$$

由 von Neumann 迹不等式，$\operatorname{tr}(G^\top \Delta W) \le \sum_i \sigma_i(G)\,\sigma_i(\Delta W)$。约束要求每个 $\sigma_i(\Delta W) \le 1$，所以上界是 $\sum_i \sigma_i(G) = \|G\|_*$（核范数）。取 $\Delta W = UV^\top$ 时：

$$
\operatorname{tr}\big(V\Sigma U^\top \cdot UV^\top\big) = \operatorname{tr}(\Sigma) = \|G\|_*
$$

上界被取到。因此步长预算为 η 的最速下降一步是 $\Delta W = -\eta\, UV^\top$。

- **核心 Trick**："最陡"永远是相对某个范数而言的。换成谱范数，最陡方向就从 $G$ 变成了 $UV^\top$。
- **对比 SGD**：在 Frobenius 范数下，第 i 个奇异方向的步长正比于 $\sigma_i$；在谱范数下，**所有方向的步长都是 η**。这就是"稀有方向被放大"的数学版本。

### Step 2　Frobenius 归一化与极分解

$UV^\top$ 是 $G$ 的极分解 $G = (UV^\top)(V\Sigma V^\top)$ 里的正交因子，也可以写成 $G(G^\top G)^{-1/2}$。Newton–Schulz 迭代前先做一次归一化：

$$
X_0 = \frac{M}{\|M\|_F}, \qquad \sigma_{\max}(X_0) \le \|X_0\|_F = 1
$$

保证所有奇异值落在 (0, 1]，即多项式的工作区间内。代价是：矩阵秩越高，$\|M\|_F$ 比 $\sigma_{\max}$ 大得越多，归一化后的奇异值越小。在 §4 的验证里，一个 1024×4096、奇异值跨 3 个数量级的矩阵，归一化后 $\sigma_{\max}$ 只有 0.116，最小的奇异值约 1.2e-4。多项式要把它拉高四个数量级。

### Step 3　系数设计：斜率与精度的取舍

每一步做 $X \leftarrow aX + b(XX^\top)X + c(XX^\top)^2X$，即在奇异值上作用 $\varphi(\sigma) = a\sigma + b\sigma^3 + c\sigma^5$。三组系数代表三种取舍：

- **经典三次** $(1.5, -0.5, 0)$：$\varphi(1) = 1$、$\varphi'(1) = 0$，在 1 附近二次收敛，结果精确；但 $\varphi'(0) = 1.5$，小奇异值每步只放大 1.5 倍。
- **Muon 五次** $(3.4445, -4.7750, 2.0315)$：设计目标是在"迭代结果始终留在约 [0.7, 1.3]"的约束下，把 $\varphi'(0) = a$ 尽量做大。代价是 $\varphi(1) = 3.4445 - 4.7750 + 2.0315 \approx 0.70$，它**不收敛到 1**，而是在一个带里摆动（我们按公式迭代算出的极限带约为 [0.68, 1.13]）。
- **DeepSeek-V4 混合**：前 8 步用 Muon 五次快速拉起，最后 2 步换成 $(2, -1.5, 0.5)$。这组系数满足 $\varphi(1) = 2 - 1.5 + 0.5 = 1$，$\varphi'(1) = 2 - 4.5 + 2.5 = 0$，把奇异值钉在 1 上。

用 §4 的代码在上面那个 1024×4096 矩阵上实测：

| 方案 | 步数 | 输出奇异值范围（fp32） | 输出奇异值范围（bf16） |
|---|---|---|---|
| 经典三次 | 5 | [0.0009, 0.73] | [0.0014, 0.73] |
| Muon 五次 | 5 | [0.056, 1.20] | [0.076, 1.20] |
| V4 混合 | 8 + 2 | [1.0000, 1.0009] | [0.994, 1.006] |

五次系数 5 步之后，最小的那些方向仍只被拉到 0.06 左右。这正是 V4 愿意多花一倍步数的原因。下面的实验把整条 φ 曲线画出来：

### Step 4　更新尺度：对齐 AdamW

$UV^\top$ 的秩为 m、每个奇异值都是 1，所以：

$$
\|UV^\top\|_F^2 = m,\qquad \operatorname{RMS}(UV^\top) = \sqrt{\frac{m}{mn}} = \frac{1}{\sqrt{\max(m,n)}}
$$

原始 Muon 更新的逐元素幅度随矩阵形状变化：矩阵越大，每个元素的更新越小。Moonlight 与 Kimi K2 的做法是乘上 $0.2\sqrt{\max(m,n)}$，把更新 RMS 固定在 0.2，与 AdamW 的典型更新幅度对齐，从而**直接复用 AdamW 的学习率和权重衰减**；DeepSeek-V4 把这个目标值设为 0.18。再加上解耦权重衰减，完整一步是：

$$
W_t = W_{t-1}(1 - \eta\lambda) - \eta \cdot 0.2\sqrt{\max(m,n)}\;\operatorname{NS}(M_t)
$$

Moonlight 把"加权重衰减"和"调整逐参数的更新尺度"列为 Muon 能扩展到大模型训练的两项关键改动。

### Step 5　成本：为什么几乎免费

对 n×m 的矩阵（m ≤ n），每步迭代约 $2(2nm^2 + m^3) \le 6nm^2$ FLOPs，T 步共 $6Tnm^2$；而这一层一次前向 + 反向是 $6nmB$（B 为每个优化步的 token 数）。相除：

$$
\text{额外开销} \;\le\; \frac{T\,m}{B}
$$

NanoGPT 速通的设定是 m = 768、B = 524,288，开销 ≈ 5 × 768 / 524,288 ≈ 0.7%；一个宽 16,384、每步 16M token 的稠密大模型约为 0.5%。

## 4. 极简代码锚点（PyTorch）

Muon 的一步、可换系数的 Newton–Schulz，以及 MHA 版的 QK-Clip。下面的代码已在 1024×4096、奇异值跨 3 个数量级的矩阵上与 SVD 对拍：V4 混合方案的输出奇异值在 fp32 下落在 [1.0000, 1.0009]，bf16 下落在 [0.994, 1.006]；`muon_step` 的更新 RMS 为 0.200；`qk_clip` 之后，每个头的最大 logit 恰好缩放为原来的 γ 倍。

```python
import torch

MUON_QUINTIC = (3.4445, -4.7750, 2.0315)   # 最大化 φ'(0)，结果在 0.7–1.2 间摆动
STABILIZE    = (2.0, -1.5, 0.5)            # φ(1)=1, φ'(1)=0：把奇异值钉在 1

def newton_schulz(G, schedule=(MUON_QUINTIC,) * 8 + (STABILIZE,) * 2, eps=1e-7):
    """把 G 近似正交化为 U Vᵀ。schedule 是每一步的 (a, b, c)，默认取 DeepSeek-V4 的 8+2。"""
    X = G.bfloat16()
    X = X / (X.norm() + eps)                    # Frobenius 归一化 → σ_max ≤ 1
    tall = X.size(0) > X.size(1)
    if tall: X = X.T                            # 保证 X Xᵀ 是较小的 (m, m) 方阵
    for a, b, c in schedule:
        A = X @ X.T                             # (m, m)
        X = a * X + (b * A + c * A @ A) @ X     # 奇多项式：只改奇异值，不动 U、V
    return X.T if tall else X

@torch.no_grad()
def muon_step(W, grad, buf, lr, momentum=0.95, wd=0.1, rms=0.2):
    """只用于 2D 隐藏层矩阵；embedding、输出头和 1D 参数交给 AdamW。"""
    buf.mul_(momentum).add_(grad)               # M_t = μ M_{t-1} + G_t：唯一的优化器状态
    update = grad + momentum * buf              # Nesterov
    O = newton_schulz(update).to(W.dtype)       # ≈ U Vᵀ，RMS = 1/√max(m, n)
    O *= rms * max(W.shape) ** 0.5              # 对齐 AdamW 的更新 RMS，复用其学习率
    W.mul_(1 - lr * wd).sub_(lr * O)            # 解耦权重衰减 + 更新

@torch.no_grad()
def qk_clip(W_q, W_k, max_logits, d_head, tau=100.0):
    """W_q, W_k: (H·d_head, D)；max_logits: (H,) 本步前向记录的各头最大注意力 logit。"""
    gamma = (tau / max_logits).clamp(max=1.0)   # 只有超过阈值的头 γ < 1
    s = gamma.sqrt().repeat_interleave(d_head)[:, None]
    W_q.mul_(s); W_k.mul_(s)                    # 两边各乘 √γ，该头的 logit 恰好乘 γ
```

**对照看维度**：`newton_schulz` 里所有乘法都发生在 (m, m) 的小方阵和 (m, n) 的矩阵之间，这就是开销 ≤ $Tm/B$ 的来源。`muon_step` 里只有一个 `buf`，这就是 Muon 比 AdamW 少一份优化器状态的地方。`qk_clip` 在前向和反向都结束之后才修改权重，不影响当前这一步的梯度。

## 5. 实战直觉、避坑与面试深挖

**2026 前沿现状**
- **Kimi K2：MuonClip**。K2 报告观察到，用原版 Muon 训一个 9B 激活 / 53B 总参数的 MoE 时，最大注意力 logit 很快超过 1000，伴随 loss spike 甚至发散。它的架构是 MLA，推理时不显式构造完整的 Key，无法使用 QK-Norm。于是提出 QK-Clip：每步之后检查每个头的最大 logit $S^h_{\max}$，取 $\gamma_h = \min(1, \tau / S^h_{\max})$，**只缩放超阈值的头**。在 MLA 上，头独有的 $q^C$、$k^C$ 各乘 $\sqrt{\gamma_h}$，头独有的 $q^R$ 乘 $\gamma_h$，所有头共享的 $k^R$ 不动。K2 取 τ = 100：最大 logit 很快涨到 100 被截住，约 30% 训练步之后才自然回落到稳定区间。
- **DeepSeek-V4：混合 Newton–Schulz，不用 QK-Clip**。V4 对大部分模块用 Muon，embedding、预测头、mHC 的静态偏置与门控因子、所有 RMSNorm 权重用 AdamW；Muon 用 Nesterov、动量 0.95、权重衰减 0.1，更新 RMS 缩放到 0.18。正交化用 10 步混合迭代（8 步 Muon 五次 + 2 步 (2, −1.5, 0.5)）。它的注意力结构允许直接对 query 和 KV 条目做 RMSNorm（→ 1.3 §5），足以压住 logit，所以没有用 QK-Clip。
- **系统层面：为整矩阵重新设计 ZeRO**。Newton–Schulz 需要完整的梯度矩阵，而 ZeRO 是为逐元素优化器设计的切分方式。V4 对稠密参数限制 ZeRO 并行规模，用背包算法把整块矩阵均衡分配到各 rank（每个 rank 不超过 5 个矩阵，额外显存 < 10%）；MoE 专家则逐个独立优化。它还发现 Newton–Schulz 在 BF16 矩阵乘下保持稳定，于是把 MoE 梯度用随机舍入量化到 BF16 再同步，通信量减半。
- **系数仍在演进**。Polar Express（ICLR 2026）为每一步求解极小极大最优的多项式系数，在 GPT-2 训练上一致优于固定系数，并处理了 bf16 下的数值问题。V4 的"8 步拉起 + 2 步精修"可以看成同一思路的手工两段版。GLM-5 则把 MLA 的上投影按头拆开分别正交化（Muon Split，→ 1.3 §5），说明架构和优化器会互相牵制。

**与工程 / 应用的连接**
- **换优化器就是换一套超参**。RMS 对齐让 AdamW 的学习率和权重衰减可以直接复用，但 warmup、调度和 batch size 仍要重新验证。V4 依然用"线性 warmup + 恒定学习率 + 末段衰减"的调度。
- **把最大 attention logit 加进监控面板**。换成 Muon 之后，最值得新增的一条曲线就是每个头的最大 logit（→ 5.3）。它先于 loss spike 出现，是最早的预警信号。
- **省下的显存要和通信放在一起算**。少一份优化器状态是实打实的（→ 5.1），但整矩阵正交化会改变参数怎么切、梯度怎么同步（→ 5.2）。小集群上收益明显，超大规模时取决于 ZeRO 方案设计得好不好。

**常见误区 / 反直觉点**
1. **"Muon 用于所有参数"** ✗：只用于 2D 隐藏层矩阵。embedding 的输入是 one-hot，"算子"视角不成立；输出头改用 AdamW 主要出于经验；norm 增益、偏置等 1D 参数没有矩阵结构，都交给 AdamW。
2. **"Newton–Schulz 得到的是精确正交矩阵"** ✗：5 步 Muon 五次的输出奇异值在约 0.7–1.2 之间摆动；矩阵秩很高时，最小的方向甚至拉不起来（§3 Step 3 实测只有 0.06）。这种近似是设计上接受的，V4 才额外加了精修步。
3. **"Muon 丢掉了梯度幅度，所以对学习率不敏感"** ✗：每个方向的幅度被抹平了，但整体步长仍由 η 和 RMS 缩放决定。学习率、warmup 和退火照样要调。
4. **"QK-Clip 是 Muon 的一部分"** ✗：它是给无法使用 QK-Norm 的架构（如 MLA）打的稳定性补丁。能直接归一化 query 和 key 时，V4 选择了更简单的 RMSNorm。

**高频深挖题**
- **Q1：Muon 为什么要正交化？它的更新方向在什么意义下最优？**
  思路：最速下降的方向取决于用什么范数量步长 → 谱范数控制 $\|\Delta W x\|$ 的最大变化，是线性层最自然的预算 → von Neumann 迹不等式给出解 $UV^\top$ → 对比 Frobenius（SGD，方向 G）与 ℓ∞（Adam 近似 sign）→ 经验动机：2D 参数的更新近似低秩，正交化放大了"稀有方向"。加分项：Shampoo 去掉预条件子累积，正好也是 $UV^\top$。
- **Q2：为什么用 Newton–Schulz 而不是 SVD？系数是怎么来的？**
  思路：SVD 难并行、慢；Newton–Schulz 只用矩阵乘法，bf16 下稳定 → 奇多项式只作用于奇异值（$XX^\top X = U\Sigma^3V^\top$），问题降成一维多项式设计 → 三次精确但慢；五次把零点斜率提到 3.4445，代价是 0.7–1.2 的摆动；V4 最后两步用 $\varphi(1)=1, \varphi'(1)=0$ 的系数精修；Polar Express 为每步求最优系数。
- **Q3：用 Muon 训一个上千亿参数的 MoE，attention logit 开始爆炸，你怎么处理？**
  思路：先看每个头的最大 logit 曲线确认 → 架构允许就上 QK-Norm（V4：对 query 和 KV 条目做 RMSNorm）→ MLA 这类无法 QK-Norm 的架构用 QK-Clip：按头算 $\gamma_h = \min(1, \tau/S^h_{\max})$，只缩放超阈值的头，共享的 RoPE key 不动 → 预期代价：训练前段频繁触发，对 loss 几乎没有影响（K2 在小规模上用更激进的 τ = 30 做过验证）。
