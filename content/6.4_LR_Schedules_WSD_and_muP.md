# 6.4 学习率调度与超参迁移

> **一句话核心直觉**：长跑时，学习率决定每一步迈多大：warmup 让训练从小步进入工作区；余弦衰减预先安排终点；WSD 在平台上保留可继续训练的起点，确定交付点后再付出额外计算退火。退火降低更新噪声，可能让验证 loss 更快下降，但不保证骤降。模型变宽时，直接照搬一个学习率数值不一定保留相同的函数变化；μP 通过指定初始化、层的尺度和优化器规则，使某些超参有机会跨宽度迁移，仍需在目标设置验证。
> **唤醒标签**：warmup → 稳定 → decay · 同预算比较 · 噪声底 · 平台 checkpoint + 独立退火 · 函数步长 · μP / μTransfer · 宽度而非任意架构迁移

前置：0.6 的 AdamW 与动量，6.1 的算力最优，6.3 的矩阵优化器。

---

## 1. 工程问题：不知道训练什么时候结束，怎么留一个好模型？

你正在训练基座模型：训练可能因为新增数据继续三个月，也可能下周就要交付 checkpoint。把余弦衰减排到三个月后，下一周的模型还在较高学习率；把终点排在下一周，则学完这一轮后继续训练必须重新设计学习率。每次都提前决定结束日期，会让实验和交付绑在同一条时间线上。

第二个问题是成本：7B 模型的学习率网格搜索很贵，能否在 0.5B 上找到一个数，再迁移过去？两个问题实际上都在问**如何控制参数更新对模型行为的影响**：调度改变时间方向上的步长；参数化改变不同宽度下同一个步长代表什么。

我们依次比较调度、建立一个可计算的退火模型，再看 μP 的适用范围。所有数值示例都是说明机制的玩具模型，不是某个基座模型的实测结果。

## 2. 同样 120 步，两种学习率路线

记 $t$ 为当前步数，$T$ 为训练总步数，$w$ 为 warmup 步数，$\eta_{\max}$ 为峰值学习率。同样跑一步，两组实验可能用了不同数量的 token。比较调度时请同时写出步数、每步的 token 数和累计训练量。

### Step 1　warmup：先走小步再进入工作区

一个简单的线性 warmup 是 $\eta_t=\eta_{\max}t/w$，$1\le t\le w$。初始的参数和梯度统计可能尚未进入稳定区，激活尺度、曲率以及动量、二阶矩的估计都会影响更新；较小的早期步长给模型和优化器状态一个适应过程。Adam 的偏差校正已处理零初始化带来的部分统计偏差，因此**不能把所有 warmup 的作用归为“二阶矩未校正”**。它不是理论上处处必需的：长度过大也会浪费有限预算，应在目标架构和 batch 上测稳定性与 loss。

### Step 2　余弦：围绕已知终点降温

warmup 后，一种不带重启、末值为零的余弦调度是

$$
\eta_t=\frac{\eta_{\max}}2\left[1+\cos\left(\pi\frac{t-w}{T-w}\right)\right],\quad w<t\le T.
$$

学习率从峰值连续降到终点。若 $T$ 已知，这是一条完整的预定路线；突然提前停止时，尚未经历完整的尾段。实际训练常设置非零最低学习率，其终值和形状也要一起报告。

### Step 3　WSD：把平台与退火分开

Warmup–Stable–Decay（WSD）先 warmup，随后保持平台；需要交付时，从平台状态再跑一个长度为 $d$ 的衰减段。下面举**线性**衰减的例子，并非 WSD 唯一形状：

$$
\eta_t = \begin{cases}
\eta_{\max}t/w,&t\le w,\\
\eta_{\max},&w<t\le T-d,\\
\eta_{\max}(T-t)/d,&T-d<t\le T.
\end{cases}
$$

例如先训练到平台第 100 步，保存完整状态；可以从它分叉跑 20 步退火，得到第 120 步的交付模型，同时保留平台分支继续训练。另一个平台点也能分叉出自己的模型。[MiniCPM](https://arxiv.org/abs/2404.06395) 使用了 WSD 思路，让一个持续训练的主干支持多个退火分支。

“可以随时停”是指**可以在合适的平台点启动退火**，不是平台模型一停就拥有退火收益。每个分支都需要额外 token、时间和算力。保存模型权重之外，还要保存优化器状态、学习率调度器位置、数据游标和随机数状态；否则分叉可能因状态突变或数据改变而无法与原轨迹比较。实际系统还要记录精度缩放器和并行训练状态（如适用）。

## 3. 退火时 loss 为什么有时下降很快？

从一个可求解的例子开始。令真实目标 $L(x)=x^2/2$，随机梯度为 $x+\xi_t$，其中 $\mathbb E[\xi_t\mid x_{t-1}]=0$、$\mathbb E[\xi_t^2\mid x_{t-1}]=\sigma^2$。第 $t$ 步更新为

$$
x_t=(1-\eta_t)x_{t-1}-\eta_t\xi_t.
$$

令 $M_t=\mathbb E[x_t^2]$，交叉项期望为零，便得到

$$
M_t=(1-\eta_t)^2M_{t-1}+\eta_t^2\sigma^2,\qquad \mathbb E[L_t]=M_t/2.
$$

第一项是离最优点的误差衰减；第二项是每步重新注入的噪声。固定 $0<\eta<2$ 且运行足够久时，$M$ 达到 $\eta\sigma^2/(2-\eta)$：步子越大，稳态噪声底越高。**降低学习率可以降低噪声底，但也会减慢向最优点移动。** 因此退火长度有取舍，甚至可能没有明显下降。

真实训练还可能随时间改变数据配比、batch 或损失组成，loss 的变化不能全部归因于学习率。判断退火效果：从相同平台状态分别续训恒定学习率与退火，控制同样的新 token、数据顺序和总算力，在**固定验证集**上记录 loss，并重复种子；训练 loss 的短期下滑和下游能力的提升也要分开看。训练 loss 噪声大、衰减时统计窗口变了、验证集变了，都可能制造“骤降”。

**迁移练习 1。** 已有 100B token 的 WSD 平台 checkpoint，两个团队分别再训练 5B token：A 继续平台学习率，B 退火。B 的验证 loss 更低。能否说 B 的总预算只有 5B？不能；两个模型从头累计都用了 105B token，比较额外阶段时才是各 5B。还要确认数据、状态与验证口径一致。

## 4. μP：小模型的学习率为什么能迁移？

### Step 1　一个逐项求导的宽度例子

令玩具模型宽度为 $n$，参数 $a_1,\ldots,a_n$ 的平均是输出 $f_n=\frac1n\sum_i a_i$，目标 $y=1$，损失 $L=\frac12(f_n-1)^2$，初始 $a_i=0$。用普通 SGD：

$$
\frac{\partial L}{\partial a_i}=\frac{f_n-1}{n},\qquad
\Delta f_n=\frac1n\sum_i\left(-\eta_n\frac{f_n-1}{n}\right)
=-\frac{\eta_n}{n}(f_n-1).
$$

因此这里的**输出有效步长**是 $\eta_n/n$。在 $n=16$ 调出 $\eta=8$，每步收缩误差一半；若宽度扩成 128，却仍用 $\eta=8$，输出步长变为 $1/16$，4 步输出只有 0.2275。若在这个特定模型里选 $\eta_n=8n/16$，有效步长仍为 0.5，4 步输出 0.9375。


这个例子只说明：**参数名相同的学习率数值，不等于相同的函数步长**。这里采用输出平均和 SGD，换成求和、换初始化或换优化器，缩放规律都会变；不能把示例中的“学习率乘宽度”照抄到 Transformer。

### Step 2　μP 不只是改一个全局学习率

最大更新参数化（maximal update parameterization，μP）为一族不同宽度的网络规定相互配套的**初始化尺度、前向乘子与各类参数的更新尺度**，使宽度增大时隐藏特征仍能发生合适量级的学习，同时网络的行为不会因宽度而无控制地漂移。μTransfer 的目标是在较小代理模型上搜索诸如学习率等超参，再迁移到较宽模型；论文在其规定的模型族与实验范围内观察到较好的迁移。

实施时先定义模型族和基准宽度；区分输入 embedding、隐藏矩阵、输出头、偏置/归一化等参数类型；采用与 SGD、Adam 类优化器相匹配的 μP 实现，再在至少几个宽度上检查激活、更新尺度以及最优学习率是否稳定。**规则依赖前向具体参数化和优化器实现**：不能从这个玩具例子推导一张通用的 Transformer 学习率表。把 AdamW 换成 Muon（→ 6.3）也需要对应规则和重新验证。

迁移最可信的是**其余关键条件尽量一致、只改变宽度**的同一模型族。改深度、注意力结构、tokenizer、数据分布、batch、优化器或训练时长都可能改变最佳值；例如宽度稳定不代表不同 batch 的梯度噪声相同。小代理应覆盖多个宽度和候选学习率，大模型上留少量验证点；“零样本迁移”指免除对每个目标规模重新完整搜索，并非保证任意任务零调参。

**迁移练习 2。** 在上面的平均模型中，$n=256$ 时把学习率从 8 提高到 128，为什么 4 步输出与 $n=16,\eta=8$ 一样？两者 $\eta/n$ 都为 0.5，误差每步乘 0.5，输出是 $1-0.5^4=0.9375$。这只在这个模型和更新规则下成立。

## 5. 从头复算两组结果

### 数值复算 · 调度噪声底与宽度有效步长

第一组按上面的递推同时计算学习率和期望 loss。$\sigma=0.6$ 表示玩具梯度噪声；输出来自确定性的期望计算，而非单次抽样轨迹。

```python
import math
T, warmup, peak, decay, noise = 120, 10, 0.3, 20, 0.6

def rate(mode, t):
    if t <= warmup:
        return peak * t / warmup
    if mode == "cosine":
        return peak * (1 + math.cos(math.pi * (t - warmup) / (T - warmup))) / 2
    return peak if t <= T - decay else peak * (T - t) / decay

def run(mode, sigma):
    second = 1.0
    result = {}
    for t in range(1, T + 1):
        eta = rate(mode, t)
        second = (1 - eta) ** 2 * second + eta ** 2 * sigma ** 2
        if t in (10, 100, 110, 120):
            result[t] = (eta, second / 2)
    return result

c, w = run("cosine", noise), run("wsd", noise)
for t in (10, 100, 110, 120):
    print(f"{t:3d}  cosine η={c[t][0]:.3f} loss={c[t][1]:.4f}  WSD η={w[t][0]:.3f} loss={w[t][1]:.4f}")
print(f"无噪声的 WSD: 第 100 步 loss={run('wsd', 0)[100][1]:.10f}，第 120 步 loss={run('wsd', 0)[120][1]:.10f}")
```

**运行结果**

```text
100  cosine η=0.024 loss=0.0051  WSD η=0.300 loss=0.0318
110  cosine η=0.006 loss=0.0042  WSD η=0.150 loss=0.0180
120  cosine η=0.000 loss=0.0041  WSD η=0.000 loss=0.0103
无噪声的 WSD: 第 100 步 loss=0.0000000000，第 120 步 loss=0.0000000000
```

第二组复算平均模型的 4 步输出；固定 8 和按 $n/16$ 缩放各算一次。

```python
for n in (16, 128, 256):
    eta_fixed, eta_scaled = 8.0, 8.0 * n / 16
    def output(eta):
        return 1 - (1 - eta / n) ** 4
    print(f"n={n:3d}  固定 η: f={output(eta_fixed):.4f}  缩放 η: f={output(eta_scaled):.4f}")
```

## 6. 训练时怎么用

- **先确定交付策略**：有明确固定预算，可对照完整余弦；终点可能改变、需要多个模型时，可保留 WSD 平台并为每个交付点单独预算退火。比较时算上所有分支的计算，不只算主干。
- **同时监控训练与验证**：每次切换记录学习率、累计 token、梯度/更新范数、数据配方及固定验证集；遇到 loss spike 按 5.3 检查，而不是仅凭一条平滑曲线判优。
- **小模型先做迁移实验**：维持架构族、优化器和数据配方，扫多个宽度与学习率，核对激活与相对更新。目标大模型上用少数点复核，遇到架构或 batch 改动重新校准。
- **别混淆能力与 loss**：降低平均验证 loss 是有价值的信号，但任务能力和长上下文效果还需要各自评估（→ 5.4、6.5）。
