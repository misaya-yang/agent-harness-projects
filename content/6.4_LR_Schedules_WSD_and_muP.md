# 6.4 学习率调度与超参迁移

> **一句话核心直觉**：在长周期的基础模型预训练中，学习率调度决定了优化器在不同阶段如何权衡“全局探索”与“局部降噪收敛”：Warmup 引导初始动量与二阶统计量平稳进入有效工作区；经典余弦衰减强制将整个研发节奏死锁在预先设定的单一终点；而 WSD（Warmup-Stable-Decay）则通过将学习率长久冻结在平坦的高位平台，维持了一条可无限持续扩展的主干轨迹，并在任意阶段按需独立分叉出退火分支交付模型。退火阶段测试 loss 的断崖式暴跌，本质上是学习率压低扼杀了随机小批量梯度带来的稳态“噪声底”，而非模型突然参透了知识。当模型规模跨尺度扩张时，直接照搬小模型的学习率数值会因为维度稀释导致函数步长急剧萎缩；$\mu\text{P}$（Maximal Update Parameterization）通过协同重构不同层级的初始化尺度、前向乘子与参数级学习率，实现了超参数跨宽度的零样本迁移。
> **唤醒标签**：Warmup 初始校准 · 余弦衰减单一终点死锁 · WSD 平台主干与分叉退火 · 随机梯度稳态噪声底 $M_\infty \approx \frac{\eta\sigma^2}{2-\eta}$ · 函数步长稀释 · $\mu\text{P}$ / $\mu\text{Transfer}$ · 仅限宽度跨尺度迁移
>
> 前置知识：0.6（AdamW 与动量机制）、6.1（算力最优规划与 Scaling Law）、6.3（Muon 矩阵优化器与 RMS 对齐）。

## 1. 工程问题：不知道训练什么时候结束，怎么留一个好模型？

在真实的大规模前沿模型工业研发中，技术团队几乎每天都在面对两难的调度抉择：
当前正在运行的万卡集群预训练任务，可能因为下周突然洗出了一批 5T token 的高质量教科书代码语料而决定继续狂训三个月；但也可能因为下周需要向产品团队紧急交付一个可供下游对齐评测的 Baseline 检查点。

如果一开始选择经典的**余弦衰减调度（Cosine Decay）**：
- 若将终点设定在三个月之后，那么下周所拿到的中间检查点依然漂浮在极高学习率的平台震荡区，模型未经历温度冷却，下游测试 loss 极差，无法作为交付产品；
- 若为了迁就下周的交付而将余弦终点强行设定在下周，一旦后续拿到新语料想继续训练，衰减至零的学习率已经丧失了继续更新的能力，重新拉高学习率（Cosine with Restarts）会引发灾难性的训练震荡。

这种“必须提前预知死亡日期”的调度僵局，将科学探索与工程交付深度捆绑在了一条不可逆的脆弱时间线上。

与此同时，团队面临的第二个算力痛点是**超参数搜索的天价成本**：
对于一个 70B 或 405B 的旗舰大模型，执行网格搜索（Grid Search）以寻找最佳学习率与 Batch Size 的算力成本动辄需要数百万美元。我们能否在仅有 0.5B 或 1.5B 参数的“玩具小模型”上，廉价地扫出最优学习率，然后直接一键无缝“拷贝”给 70B 模型使用？

这两个关键命题，本质上都在探索**如何精准控制参数更新对整个深度神经网络函数输出行为的微观扰动量**：
- **学习率调度（Schedule）**：是在时间轴上调控单步更新步长的收缩节奏；
- **参数化表征（Parameterization, 如 $\mu\text{P}$）**：是在空间维度上调控模型宽度膨胀时，同一个标量学习率代表的真实函数更新幅度。

## 2. 同样 120 步，两种学习率路线

设 $t$ 为当前优化步数，$T$ 为本次既定交付的总预算步数，$w$ 为 Warmup 步数，$\eta_{\max}$ 为设定的峰值学习率。需明确：当分布式训练的全局 Batch Size 发生变动时，单步 $t$ 所消耗的物理 token 数将等比例变动。在规范的工业报告中，**对比调度策略必须同步锚定步数、每步 token 吞吐以及累计 token 总量**。

### Step 1　Warmup：平稳建立动量与二阶统计量

最基础的线性 Warmup 表达为：

$$
\eta_t = \eta_{\max}\,\frac{t}{w}, \qquad 1 \le t \le w
$$

在网络初始化的前几十步中，各层激活值的数值尺度尚未收敛至稳态流形，局部损失曲面的曲率极其险峻；更关键的是，AdamW 优化器的一阶动量 $M_t$ 与二阶平方矩 $V_t$ 均从全零状态启动。虽然 AdamW 内建的偏差校正机制（Bias Correction）能够在统计期望上修正零初值，但早期的二阶矩样本极少、方差极大。如果第一步就冒然施加全额学习率 $\eta_{\max}$，极易在脆弱方向上直接迈出灾难性的过大步长，诱发不可逆的梯度爆炸。小步起跑的 Warmup 阶段为网络状态与优化器二阶矩估计提供了至关重要的适应期。

### Step 2　余弦衰减：围绕已知终点的闭环降温

完成 Warmup 之后，标准的不带重启的单周期余弦衰减将学习率平滑引导至 0：

$$
\eta_t = \frac{\eta_{\max}}{2}\left[1 + \cos\left(\pi\,\frac{t - w}{T - w}\right)\right], \qquad w < t \le T
$$

余弦调度是一条在数学上连续且处处可导的封闭曲线，其优势在于没有剧烈的突变拐点，在固定训练预算 $T$ 到达的瞬间，刚好完成温度冷却。但其代价正如前文所述：**它是一张单程票**，一旦中途被迫提前停机，模型尚未经历尾部退火；一旦到达终点，主干寿命即告终结。

### Step 3　WSD 调度：主干平台长青，退火分支按需分叉

Warmup–Stable–Decay（WSD）调度在架构思路上实现了根本性的解耦：在 Warmup 结束后，将学习率**无限期恒定锁定在峰值平台 $\eta_{\max}$ 上**（Stable 阶段）。只有当团队收到确定的交付需求时，才从该平台状态独立分叉（Fork），执行一段相对较短的退火衰减段（Decay 阶段，衰减步长记为 $d$）。

以工业界常见的线性退火为例：

$$
\eta_t = \begin{cases}
\eta_{\max}\,\frac{t}{w}, & t \le w \\
\eta_{\max}, & w < t \le T - d \\
\eta_{\max}\,\frac{T - t}{d}, & T - d < t \le T
\end{cases}
$$

**主干与分支的工程分离机制**：
MiniCPM 等现代开源模型全面拥抱了 WSD 调度。其核心工作流如下：
1. **主干长青（Mainline Training）**：万卡集群始终在 Stable 恒定高学习率平台上稳定推进，只要持续有清洗好的新语料入库，主干就可以不设终点地一直跑下去；
2. **按需分叉退火（Fork & Anneal）**：当需要发布一个 100B token 的检查点时，保存第 100B 步的完整集群状态（包含模型权重、优化器动量、学习率位置、数据游标与 RNG 种子）；
3. **独立算力结算**：从该保存点拉出一条分支，额外追加例如 10B token 的独立算力预算执行 Decay 退火，交付最终模型；而与此同时，原本的 100B 平台主干依然不受任何干扰地继续向前推进，并在 200B、300B 节点随时可以再次拉出新的退火分支。

必须纠正一个常见误区：“**WSD 能够随时停机直接交付**”。这是对该技术的严重误解。**停留在 Stable 平台的检查点依然处于高噪声震荡态，必须额外投入 $d$ 步的计算量执行退火，才能兑现最终的性能收益**。

## 3. 退火时 loss 为什么有时下降很快？

很多初涉大模型预训练的工程师会对一个现象感到困惑：在 WSD 平台期推进数百步，测试 loss 下降十分缓慢；然而一旦启动退火，在短短几十步内，验证 loss 就会像坐过山车一样发生戏剧性的断崖式暴跌。这是因为模型突然在最后几十步“顿悟”了大量知识吗？

我们通过一个严密的解析随机梯度下降玩具模型彻底解密其物理机制。

设一维最小化目标损失为标量二次函数 $L(x) = \frac{1}{2}x^2$（真实最优解位于 $x^* = 0$）。在实际训练中，每个小批量计算出的随机梯度带有一个零均值、方差为 $\sigma^2$ 的随机采样噪声 $\xi_t$：

$$
g_t = x_{t-1} + \xi_t, \qquad \mathbb{E}[\xi_t \mid x_{t-1}] = 0, \quad \operatorname{Var}[\xi_t \mid x_{t-1}] = \sigma^2
$$

参数按步长 $\eta_t$ 执行更新：

$$
x_t = x_{t-1} - \eta_t g_t = (1 - \eta_t)x_{t-1} - \eta_t \xi_t
$$

考察参数平方的数学期望 $M_t = \mathbb{E}[x_t^2]$。由于随机梯度噪声 $\xi_t$ 与上一时刻状态 $x_{t-1}$ 相互独立，交叉项期望归零：

$$
\mathbb{E}[(1 - \eta_t)x_{t-1} \cdot (-\eta_t \xi_t)] = 0
$$

展开平方可得精妙的期望二阶矩递推状态方程：

$$
M_t = (1 - \eta_t)^2 M_{t-1} + \eta_t^2 \sigma^2, \qquad \mathbb{E}[L(x_t)] = \frac{1}{2}M_t
$$

这个方程揭示了参数震荡的两个对立力量：
1. **收缩项 $(1 - \eta_t)^2 M_{t-1}$**：代表确定性梯度引导参数向真实极优点 $x^* = 0$ 的指数衰减收敛；
2. **方差注入项 $\eta_t^2 \sigma^2$**：代表每次随机采样不可避免地向系统注入的布朗运动能量。

当长期保持固定学习率 $\eta$（Stable 平台期）且 $0 < \eta < 2$ 时，系统迅速达到动态平衡（令 $M_t = M_{t-1} = M_\infty$）：

$$
M_\infty = (1 - \eta)^2 M_\infty + \eta^2 \sigma^2 = (1 - 2\eta + \eta^2)M_\infty + \eta^2 \sigma^2
$$

$$
(2\eta - \eta^2)M_\infty = \eta^2 \sigma^2 \quad\Longrightarrow\quad \boxed{M_\infty = \frac{\eta \sigma^2}{2 - \eta} \approx \frac{\eta \sigma^2}{2}}
$$

**这就是震撼的“稳态噪声底”（Noise Floor）定理**：
在高学习率平台上，参数并不可能收敛到单点，而是在极值点周围做方差为 $M_\infty$ 的高维热运动！**平台的期望测试 loss 存在一个物理下界，该下界直接正比于当前学习率 $\eta$ 与梯度噪声方差 $\sigma^2$**。

## 4. μP：小模型的学习率为什么能迁移？

### Step 1　一个均值网络的维度稀释灾难

为什么在 0.5B 小模型上调出的最佳学习率，直接照搬到 70B 大模型上往往导致训练发散或完全学不动？

我们通过一个可逐项求导的均值玩具网络揭开其数学机制。
设模型包含 $n$ 个权重标量参数 $a_1, a_2, \ldots, a_n$，其网络前向输出为全参数的算术平均值：

$$
f_n = \frac{1}{n}\sum_{i=1}^n a_i
$$

设定监督目标为 $y = 1$，损失函数定义为平方误差 $L = \frac{1}{2}(f_n - 1)^2$。所有参数初始全为 0（$a_i = 0 \implies f_n = 0$）。
采用标准 SGD 计算每个独立参数的梯度：

$$
\frac{\partial L}{\partial a_i} = \frac{\partial L}{\partial f_n} \cdot \frac{\partial f_n}{\partial a_i} = (f_n - 1) \cdot \frac{1}{n}
$$

参数执行单步梯度下降：$a_i \leftarrow a_i - \eta_n \frac{f_n - 1}{n}$。
现在考察这一步更新所引起的**网络最终输出函数值的实际变化量 $\Delta f_n$**：

$$
\Delta f_n = \frac{1}{n}\sum_{i=1}^n \left(-\eta_n \frac{f_n - 1}{n}\right) = -\frac{\eta_n}{n}\,(f_n - 1)
$$

这个简洁的代数结果揭示了一个冷酷的物理现实：
**网络在函数输出层面的有效步长，根本不是标量数字 $\eta_n$，而是被模型宽度稀释后的比值 $\frac{\eta_n}{n}$**！

> **交互实验引导 · 细看宽度扩张时的步长塌陷**：
> 在宽度迁移实验室中，调节【宽度 n】（16、128、256）与【训练步数】：
> 1. **固定学习率的悲剧**：
>    在基准小网络 $n=16$ 时，技术团队精调出的最优学习率为 $\eta = 8$。此时有效步长为 $\frac{8}{16} = 0.5$，每步将残差减半，仅用 4 步输出便迅速收敛至 $1 - (1 - 0.5)^4 = \mathbf{0.9375}$；
>    当将网络宽度盲目扩充 8 倍至 $n=128$，但依然照搬原封不动的 $\eta = 8$ 时：有效函数步长瞬间被稀释为 $\frac{8}{128} = 0.0625$。观察灰色曲线【$\eta$ 固定为 8】：训练 4 步后，网络输出仅仅挪动到 **0.2275**，更新几乎陷入停滞！当 $n=256$ 时，4 步输出进一步跌落至 **0.1193**。
> 2. **按宽度协同缩放的威力**：
>    观察蓝色曲线【$\eta$ 随宽度缩放】：如果遵循参数化规则，令学习率按宽度联动缩放 $\eta_n = 8 \times \frac{n}{16}$（即 $n=128$ 时取 $\eta = 64$，$n=256$ 时取 $\eta = 128$），有效步长恒定保持在 0.5，所有不同宽度的模型在第 4 步的输出完全无缝重合在 **0.9375**！

### Step 2　μP：跨尺度的完整参数化重构

上面的玩具均值模型揭示了核心启示：**在深度学习中，参数名相同的标量学习率，绝不代表相等的函数更新步长**。

在现代真实多层 Transformer 中，情况比简单的平均更为错综复杂：
- 隐藏层注意力与 FFN 涉及大量的矩阵乘法 $W \in \mathbb{R}^{d \times d}$；
- 矩阵乘法在前向传播中会导致激活值方差以 $d$ 倍扩张；
- 反向传播中由于链式法则，梯度的幅值又以特定指数随 $d$ 衰减。

由 Greg Yang 等人提出的**最大更新参数化（Maximal Update Parameterization, $\mu\text{P}$ / Tensor Programs V）**，给出了在宽度极限 $d \to \infty$ 下唯一能够让网络每一层的隐藏特征更新幅度均保持为 $\Theta(1)$ 的完备解：

1. **协同重构初始化标准差**：
   - 输入 Embedding 矩阵：权重初始化方差设为 $\Theta(1)$；
   - 内部隐藏层投影矩阵（Attention $W_q, W_k, W_v, W_o$ 及 FFN $W_1, W_2$）：权重初始化方差必须从标准参数化的 $\Theta(1/\sqrt{d})$ 压缩至 $\Theta(1/d)$；
   - 最终语言模型输出预测分类头（Unembedding Head）：权重初始化方差设为 $\Theta(1/d)$。
2. **重构前向乘子（Forward Multipliers）**：
   - 自注意力中的缩放因子由经典的 $1/\sqrt{d_{\text{head}}}$ 重构为 $1/d_{\text{head}}$；
   - 并在各层前向显式引入与宽度 $1/d$ 关联的常数乘子，以稳定特征向量的范数。
3. **分层分化学习率（Layer-wise Learning Rates）**：
   - 内部隐藏层矩阵的学习率必须按 $\eta \propto 1/d$ 缩放；
   - 输入 Embedding 与输出分类头的学习率则保持不同维度的独立缩放。

**$\mu\text{Transfer}$ 的终极工程收益与严格边界**：
在严格部署了 $\mu\text{P}$ 体系后，大模型团队获得了令人惊叹的超能力：**在数张 GPU 上对 0.5B 的代理模型做详尽的网格搜索，扫出的最优学习率、Weight Decay 与初始化超参数，可以直接零样本无缝套用到 70B 甚至更大参数的模型上，且实测几乎完美命中大模型的最优收敛点**。

**牢记 $\mu\text{Transfer}$ 的不可逾越边界**：
1. **它只管宽度跨尺度（Width Scaling）**：$\mu\text{P}$ 严格建立在宽度 $d_{\text{model}} \to \infty$ 的张量极限理论上。如果盲目改变**网络深度（层数）、改变注意力架构（如从 MHA 换为 MLA）、或更换优化器（从 AdamW 换为 6.3 的 Muon）**，超参数迁移规律将彻底失效；
2. **它无法抹平数据与 Batch Size 的梯度噪声变动**：小模型试验如果 Batch Size 过小，其最优学习率受梯度噪声主导；必须在代理小模型与目标大模型上保持相同的临界批大小拓扑结构。

## 5. 从头复算两组结果

### 数值复算 · 调度噪声底与宽度有效步长

第一组按上面的递推同时计算学习率和期望 loss。$\sigma=0.6$ 表示玩具梯度噪声；输出来自确定性的期望计算，而非单次抽样轨迹。

```python
import math
T, warmup, peak, decay, noise = 120, 10, 0.3, 20, 0.6

def rate(mode, t):
    if t <= warmup:
        return peak * t / warmup
    if mode == "cosine":
        return peak * (1 + math.cos(math.pi * (t - warmup) / (T - warmup))) / 2
    return peak if t <= T - decay else peak * (T - t) / decay

def run(mode, sigma):
    second = 1.0
    result = {}
    for t in range(1, T + 1):
        eta = rate(mode, t)
        second = (1 - eta) ** 2 * second + eta ** 2 * sigma ** 2
        if t in (10, 100, 110, 120):
            result[t] = (eta, second / 2)
    return result

c, w = run("cosine", noise), run("wsd", noise)
for t in (10, 100, 110, 120):
    print(f"{t:3d}  cosine η={c[t][0]:.3f} loss={c[t][1]:.4f}  WSD η={w[t][0]:.3f} loss={w[t][1]:.4f}")
print(f"无噪声的 WSD: 第 100 步 loss={run('wsd', 0)[100][1]:.10f}，第 120 步 loss={run('wsd', 0)[120][1]:.10f}")
```

第二组复算平均模型的 4 步输出；固定 8 和按 $n/16$ 缩放各算一次。

```python
for n in (16, 128, 256):
    eta_fixed, eta_scaled = 8.0, 8.0 * n / 16
    def output(eta):
        return 1 - (1 - eta / n) ** 4
    print(f"n={n:3d}  固定 η: f={output(eta_fixed):.4f}  缩放 η: f={output(eta_scaled):.4f}")
```

## 6. 训练时怎么用

**工业实战决策 SOP**：
- **根据商业交付形态确定调度策略**：对于训练预算严格锁死、仅需产出单一最终版本的基线对比试验，直接采用无重启的经典余弦衰减（Cosine）；对于长期进行语料扩展、未来需要衍生出多个不同阶段权重版本的基座工程，果断采用 WSD 架构。在结算研发投入时，必须将每次退火分支所消耗的算力全部独立计入成本总账。
- **全方位监控优化健康状态**：在训练看板中除了记录训练 loss 外，必须实时监控更新量均方根（RMS）、参数梯度范数、一阶与二阶动量范数以及固定独立验证集的 PPL 走势。遇到 Loss Spike 时，切忌仅凭平滑曲线误判，按照 5.3 检查数值溢出。
- **构建科学的代理模型超参搜索流**：采用 $\mu\text{P}$ 框架构建小模型体系。在 0.5B 代理模型上保持与目标 70B 模型相同的分词器、注意力拓扑、数据分布与优化器规则，密集体检特征更新量的 $\Theta(1)$ 稳定性，随后在大模型上仅需保留极少数锚点进行置信度确认。

1. 简述经典余弦衰减在持续预训练场景下面临的核心工程困境，以及 WSD 调度是如何通过解耦“主干平台”与“独立退火分支”解决这一问题的。
2. 写出随机梯度下降在二次目标下的二阶矩递推方程 $M_t = (1 - \eta_t)^2 M_{t-1} + \eta_t^2 \sigma^2$。结合稳态噪声底公式解释：为什么退火阶段测试 loss 会出现断崖式下跌？如果梯度没有采样噪声（$\sigma = 0$），退火还会产生额外收益吗？
