# 7.5 测试时计算扩展：多想、多试与何时停下

> **一句话核心直觉**：不改模型权重，也可以在回答时增加计算：并行采样多个候选再投票或验证，或者让模型沿一条轨迹继续推理、检查和修正。候选里有正确答案只是第一步，能否选出来取决于验证器与候选的错误相关性；继续思考也可能修错或改错。判断预算是否值得，要在同一质量指标下同时比较正确率、总 token 成本与实际延迟。
>
> **唤醒标签**：Best-of-N · 理想上界与可选解率 · 多数票 · 假阳性与验证器 · PRM / 搜索 · 并行采样 vs 顺序修正 · 关键路径 · 早停 · overthinking

前置：2.5（推理模型与可验证奖励）、5.4（评测）、7.1（采样）。

## 1. 为什么同一个模型能用更多计算解题

给一道数学题采样一次，模型可能选错思路；换一个采样轨迹，或许就走对了。测试时计算扩展指**固定模型权重**，增加生成、检查、搜索或工具调用的推理计算。并行扩展让多条候选同时探索不同答案；顺序扩展让后续计算读到之前的步骤或反馈，再继续搜索、修订。这两种方法花费计算的方式不同，无法仅凭“多生成了多少 token”断定哪一种更强。

实际产品的“推理模式”可能还换了模型、提示词、工具或训练方式，不能把所有提升都归因于测试时计算。比较时应固定或注明权重、提示词、工具、采样温度和最大预算，并把验证器及工具的成本也算进去。更多思考**有可能**改善准确率，并不保证每题或每个预算点都改善。

## 2. 并行扩展：先生成候选，再选一个

### 2.1 候选存在率只是上界

假设对**同一道题**独立采样 $N$ 次，每次正确概率为 $p$。至少一个答案正确的概率，即理想验证器总能选对时的上界，是

$$
P(\text{至少一个正确})=1-(1-p)^N.
$$

$p=0.6$、$N=5$ 时，上界 $1-0.4^5=0.98976$。上界说明正确答案有没有出现在候选里；它不告诉我们怎样识别那个答案。真实题目的难度不同：若每题成功率为 $p_i$，总体的理想成功率应平均 $1-(1-p_i)^N$，而不是把平均 $p$ 直接代入。共享错误思路、温度过低或共同误解题意也会使候选相关；独立公式因此只是明确假设下的参照。

### 2.2 多数投票：不需要知道标准答案

对一个只有两种答案的任务，假设每次独立正确的概率均为 $p$，严格多数正确就选对；偶数次平票时随机选一个。若 $X\sim\operatorname{Binom}(N,p)$，则

$$
P_{\mathrm{vote}}=P(X>N/2)+\tfrac12 P(X=N/2).
$$

对于奇数 $N=5$、$p=0.6$，这个概率是 0.68256，远低于 0.98976 的理想上界。若 $p<0.5$ 且假设成立，多数投票反而会放大错误；$p=0.5$ 时没有提升。自一致性（self-consistency）先采多条推理轨迹，再按最终答案聚合，可避免直接比较每一步。但开放题通常有许多种不同的错误答案：**最高票（plurality）不等于二元正确 / 错误多数票**，答案归一化与等价判定也会影响统计。

### 2.3 验证器：通过的不一定都对

构造一个可算清的 Best-of-N 选择器。每个候选正确概率 $p$，验证器对正确候选的通过率为 $t$（TPR），对错误候选的通过率为 $f$（FPR）。假设候选及其验证结果独立同分布。规则是：有通过的候选时，在通过者中**均匀随机**选一个；没有通过者时，从所有候选中随机选一个。设

$$
a=pt+(1-p)f,\qquad q_+=\frac{pt}{a},\qquad q_-=\frac{p(1-t)}{1-a}.
$$

$a$ 是单个候选通过率；$q_+$ 是通过者中正确的比例；$q_-$ 是不通过者中正确的比例。没有任何候选通过的概率为 $(1-a)^N$，所以

$$
P_{\mathrm{verify}}(N)=\big[1-(1-a)^N\big]q_+ +(1-a)^N q_-.
$$

当 $a=0$ 时总是回退随机选择，正确率为 $p$；$a=1$ 时总是从全部候选选择，正确率同样为 $p$。$0<a<1$ 且 $N\to\infty$ 时，本规则的正确率趋于 $q_+$，因为几乎一定有通过者，但通过者中依然混杂着假阳性的错误答案。取 $p=0.6,t=0.8,f=0.2$：$a=0.56$，通过者正确比例 $q_+=0.48/0.56\approx0.8571$。$N=5$ 时最终正确率约 0.8475；盲目增大 $N$ 会逐渐逼近并受制于 0.8571 的饱和上限。

在下方交互实验中，深入体验验证器精度如何划定测试时计算扩展的收益天花板：
- **调节参数**：调节**候选采样数 $N$**（从 1 扫到 31）、**单次采样正确率 $p$**、**验证器真阳性率 TPR ($t$)** 与 **假阳性率 FPR ($f$)**；
- **观察指标**：对比“理想选解上界”（绿）、“二元多数票”（橙）与“二值验证器”（蓝）三条随 $N$ 扩展的正确率曲线，重点观察验证器在 $N \to \infty$ 时的渐近饱和极限 $q_+ = \frac{pt}{pt + (1-p)f}$；
- **核心因果**：理想上界假设存在全知神谕（只要候选池里有至少一个对的就能挑出），因此随 $N$ 迅速趋于 100%；但现实中的验证器存在假阳性（FPR $f > 0$），当候选池极度膨胀时，大量被误判为“通过”的错误答案会涌入候选池，导致均匀选解的正确率饱和在 85.7% 无法寸进；若将 FPR 调高与 TPR 相等，验证器完全丧失区分度，正确率死死钉在基准 $p$。

## 3. 顺序扩展：搜索、过程奖励与修正

### 3.1 最终奖励与过程奖励

结果奖励模型（ORM）看整条解答，为最终结果打分；过程奖励模型（PRM）评估中间步骤或部分解。训练过程评分器可以给步骤标对错，或用后续多次 rollout 的成功率估计从某个前缀继续解对的机会；两种标签含义不同。正确的局部步骤也不保证最终能解出来，错误步骤有时可能碰巧得到正确结果。

搜索时可以把部分解视为树节点：从一个前缀生成若干下一步，用 PRM 给候选前缀评分，保留高分分支继续展开，达到预算后选最终解。这样可以不必把相同预算花在所有分支上；早期剪枝错了也可能把唯一可解的路径丢掉。过程监督和结果监督的比较见 Let's Verify Step by Step；“PRM 得分高”始终只是代理信号，并不自动等于数学证明。

有些实现把各步得分相乘、取最小或取最后一步分数。各自引入不同假设：未经校准的局部概率连乘会偏好短轨迹，彼此相关的错误评分也会叠加。先说明评分是“此步正确”还是“从前缀最终可成功”，再在独立标注数据上检验排序和校准，不能把任意分数当作可相乘的条件概率。还要防范模型学会迎合验证器表面偏好，而不是真的解决问题。

### 3.2 并行探索与顺序思考怎样比较

并行 Best-of-N 的每条轨迹彼此独立，善于覆盖多条不同路径；顺序思考的后续步骤能读取前文、执行测试、修复错误，但可能沿错误前提越走越远。将总 token 预算固定时，$N$ 条短轨迹与一条长轨迹并不等价：候选分布、上下文复用、检查质量和停止策略都不同。最优分配随题目难度和验证器能力改变，测试时计算研究因此强调按问题选择预算。

延迟也要单列：假设每条候选的生成需 $T$ 秒、硬件可同时运行 $P$ 条且不互相拖慢，$N$ 条候选约需 $\lceil N/P\rceil T$ 秒，再加验证时间；顺序的 $N$ 轮每轮 $T$ 秒则约 $NT$ 秒。但并行仍消耗大致 $N$ 份生成计算和更高瞬时资源，真实服务中 batch 竞争、轨迹长短不同、排队、KV 内存及工具延迟会打破理想模型。汇报总 token、GPU 时间 / 调用费用和端到端 p50/p95 延迟，比只报一条“加速倍数”更有意义。

## 4. 预算控制与 overthinking

继续思考可能发现漏洞，也可能改掉正确答案、引入多余假设或在无效循环中耗费预算。用一个能算清的群体模型说明这种**可能性**：开始时正确率为 $p_0$；第 $t$ 轮里，原来错误的答案以 $u_t$ 的概率被修正，原来正确的答案以 $v$ 的概率被改错，设修错机会随轮数递减 $u_t=u_0e^{-dt}$，则

$$
p_{t+1}=p_t(1-v)+(1-p_t)u_t,
\qquad p_{t+1}-p_t=(1-p_t)u_t-p_tv.
$$

前一项是这一轮修对的比例，后一项是改错的比例。后期修错机会变少，若改错占上风，继续推理就降低群体正确率。这个模型只是将两类转移明确量化，**不是说所有真实模型都会如此**；真实改错率和修错率随题目、轮数、提示词和工具变化，需要实测。

把每轮代价换算为 $\lambda$ 个正确率单位，定义 $U(t)=p_t-\lambda t$。例如 $p_0=0.6$、$u_0=0.3$、$d=0.35$、$v=0.04$、$\lambda=0.005$：第 3 轮正确率 0.742992，效用 0.727992；第 12 轮正确率降到 0.589656，效用为 0.529656。这里 0.005 意味着每轮的代价被设为 **0.5 个百分点**，不是通过概率推导出来的市场价格，而是任务方给质量和成本设置的换算尺度。

在下方交互实验中，直观探查思考轮数与过度思考（Overthinking）的收益转折点：
- **调节参数**：调节**顺序思考轮数**（0 到 20 轮）、**初始修错率 $u_0$**、**衰减系数 $d$**、**每轮改错率 $v$** 以及**单轮 token 算力成本 $\lambda$**；
- **观察指标**：观察“群体正确率”曲线（先升后降的单峰走势）与扣除累积计算成本后的“净效用”曲线 $U(t)$，捕获效用最高的最优固定停止轮数（如第 3 轮）；
- **核心因果**：在推理初期，模型通过反思修正粗心错误（修错率占上风），正确率快速提升；但随着思考轮数推移，容易修正的漏洞逐渐耗尽（修错率指数衰减），而原本正确的思路却在漫长自问自答中以固定概率 $v$ 被带偏、引入过度假设（改错率占上风），导致群体正确率掉头向下（Overthinking 现象）；叠加上昂贵的 token 推理成本，盲目拉长思考链条反而会导致收益严重亏损。

## 5. 怎样设计一场公平实验

1. **定义质量与成本。** 固定题集、答案判定与超时策略；记准确率，以及 prompt、思考、候选、验证和工具的总 token、费用、GPU 时间、延迟。若有模型与验证器分离，要把二者都计入。
2. **匹配预算画曲线。** 比较单次回答、多个候选多数票、Best-of-N 验证、单条长思考、PRM 搜索；在多个总预算点比较，而不是只拿“最贵方案”对比“最便宜方案”。同时报告等墙钟延迟的比较，因为并行资源有代价。
3. **识别瓶颈。** 用有标准答案的离线数据同时报告“候选中至少一个正确”的理想上界和最终选解率，测验证器 TPR、FPR、按难度分层的错误相关；这样才能分清是生成不出正确答案，还是生成后挑错。
4. **验证动态策略。** 在开发集选停止阈值，在测试集固定并报告准确率与预算分布；记录“本来对、后来改错”和“本来错、后来修对”的比例。比较延长思考时，保持上下文与工具条件一致。
5. **给不确定性。** 题目应配对比较，并报告置信区间（→ 5.4）；不同题型分别报告，避免简单题的大幅过度计算掩盖困难题收益。训练 / 验证器标签与测试题泄漏会让曲线虚高。

## 6. 数值复算

### 数值复算 · 候选选择

第一段直接求二项分布，并使用上面的二值验证器公式；它对应交互实验中的 $p=0.6,t=0.8,f=0.2$，无需外部依赖。

```python
import math

p, t, f = 0.6, 0.8, 0.2
a = p*t + (1-p)*f
for n in [1, 3, 5, 9]:
    oracle = 1 - (1-p)**n
    majority = sum(math.comb(n, k)*p**k*(1-p)**(n-k)
                   for k in range(n//2+1, n+1))
    none = (1-a)**n
    verified = (1-none)*p*t/a + none*p*(1-t)/(1-a)
    print(f"N={n:2d} 理想={oracle:.6f} 多数={majority:.6f} 验证={verified:.6f}")
print(f"验证器极限={p*t/a:.6f}")
```

**运行结果**

```text
N= 1 理想=0.600000 多数=0.600000 验证=0.600000
N= 3 理想=0.936000 多数=0.648000 验证=0.807360
N= 5 理想=0.989760 多数=0.682560 验证=0.847505
N= 9 理想=0.999738 多数=0.733432 验证=0.856782
验证器极限=0.857143
```

### 数值复算 · 停止预算

第二段逐轮计算修错与改错；最佳轮数只在枚举的 0–12 轮中比较，不是逐题读取真值。实验图覆盖 0–20 轮，在这组参数下也选第 3 轮。

```python
import math

p, u, d, v, cost = 0.6, 0.3, 0.35, 0.04, 0.005
rows = []
for step in range(13):
    rows.append((step, p, p - cost*step))
    p = p*(1-v) + (1-p)*u*math.exp(-d*step)
for step in [0, 1, 2, 4, 8, 12]:
    print(f"轮={step:2d} 正确率={rows[step][1]:.6f} 效用={rows[step][2]:.6f}")
best = max(rows, key=lambda row: row[2])
print(f"效用最优轮={best[0]} 正确率={best[1]:.6f} 效用={best[2]:.6f}")
```

轮= 4 正确率=0.740254 效用=0.720254

## 7. 练习（附解答）

**练习 1。** 每次采样正确率为 0.6，彼此独立。3 次里至少一条正确的概率是多少？如果二元答案严格多数正确才获胜，又是多少？

**解。** 理想上界为 $1-0.4^3=0.936$；多数票为 $3(0.6)^2(0.4)+(0.6)^3=0.648$。两者相差来自只有一条正确的情况：理想选择器能找到它，多数票会选错。

**练习 2。** 对上面的验证器，若 TPR 和 FPR 都为 0.8，无论 $N$ 是多少，最终正确率是多少？

**解。** 通过与否不携带正确性信息，通过者与不通过者的正确比例都为 $p=0.6$；按题中随机选择规则，最终正确率始终是 0.6。

**练习 3。** 初始正确率 0.6，下一轮的修错率是 0.1、改错率是 0.05。增加一轮是否提高正确率？每轮成本为 0.015 个正确率单位时，效用是否提高？

**解。** 净正确率变化 $0.4\times0.1-0.6\times0.05=0.01$，所以正确率从 0.6 升至 0.61；效用变化 $0.01-0.015=-0.005$，因此按此成本尺度不值得继续。
