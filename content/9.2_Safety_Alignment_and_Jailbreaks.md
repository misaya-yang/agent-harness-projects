# 9.2 安全对齐与越狱：评估拒答边界

> **一句话核心直觉**：安全对齐把行为规范写进训练和评估；面对超出训练覆盖的输入，系统既可能放过本应拒绝的请求，也可能拒绝本应回答的请求。要用固定标准、两类错误、分层统计和独立盲审共同判断边界，而不是只追求一个总体通过率。
> **唤醒标签**：规范 → 标注 → 后训练 → 拒答边界 · 漏过率 · 过度拒答 · 混淆矩阵 · 分层 · 盲审 · 不确定性

---

## 1. 问题：拒得越多就越安全吗？

团队要上线一个答疑系统：规范规定哪些请求应拒绝，哪些应正常回答。现在系统对两类请求都可能出错。把拒答阈值调低可以挡住更多「需拒绝」类别，但也可能误拒正常问题；把阈值调高又可能漏过更多。**怎样同时量化两种错误，并确认看似改善的总体结果并未隐藏某个场景的退化？**

本课只使用虚构的「需拒绝 / 应回答」固定类别标签和数值评分，不展示请求内容。数字是教学数据，不代表真实模型性能；[数值复算](#worked-example)可核对阈值与区间。

## 2. 对齐是目标、数据与评估共同决定的边界

预训练学习预测数据中的下一个 token（→ 1.0 §6.1），本身不等同于遵循部署方的行为规范。后训练将可接受行为变成示范、偏好或其他训练信号，但标注不完备、标准不一致、训练目标和部署输入的差异都会留下边界误差。所谓越狱是系统在某些输入条件下未遵循既定规范的行为；它不等于能证明所有失效都由单一机制或一个训练步骤造成。评测要覆盖不同场景和请求边界，也要覆盖**规范允许的相邻请求**，否则只测漏过就会把无差别拒答误判为改进。

[Constitutional AI](https://arxiv.org/abs/2212.08073) 使用明确原则指导模型生成批评和修订，并用 AI 反馈训练偏好模型，是把原则接入训练的一种方法。[Deliberative Alignment](https://arxiv.org/abs/2412.16339) 研究让模型学习并运用安全规范。两者都不能使规范覆盖无限输入，更不能替代部署环境下的独立评测；规范质量、标注质量、效用与边界都有各自的误差。

## 3. 用混淆矩阵建立可比较的评估

### 3.1 两类错误的分母不同

本例把「需拒绝」视为正类，模型输出是拒答或回答：

| 人工参考类别 | 模型拒答 | 模型回答 |
|---|---:|---:|
| 需拒绝（10） | 正确拒答 TP = 8 | 漏过 FN = 2 |
| 应回答（10） | 过度拒答 FP = 2 | 正常回答 TN = 8 |

阈值 0.5，评分 $s\ge0.5$ 才拒答。于是

$$
\text{漏过率}=\frac{FN}{TP+FN}=\frac2{10}=20\%,\qquad
\text{过度拒答率}=\frac{FP}{FP+TN}=\frac2{10}=20\%.
$$

拒答率 $(TP+FP)/N=50\%$ 无法单独区分这两种错误。这里把「回答了需拒绝类别」作为代理漏过；实际系统还需独立评定答复内容是否违反规范，不能由形式上回答/拒答推断所有安全结果。[XSTest](https://arxiv.org/abs/2308.01263) 专门设计允许与不允许类别相邻的评估，说明要测过度拒答。

```academy-lab
9.2
```

评分固定时，把阈值从 0.5 提到 0.7：漏过由 2/10 升到 4/10，误拒由 2/10 降到 0/10；这只是该组评分的阈值路径。实验的「评分」不必是经过校准的概率。基率变化会改变总错误数和预测值，类别条件率未必改变；实际阈值需要结合错误代价与业务场景确定，不能把所有模型、策略或训练改动都压成同一条固定 ROC 曲线。

**选择一个部署阈值**：假设部署中「需拒绝」占 1%，其余 99% 应回答；每次漏过代价 1000 单位，每次误拒代价 1 单位，并假定两类条件错误率从评测集转移到部署分布。每 10000 次请求，0.5 阈值的预期代价是 $10000(0.01\times0.2\times1000+0.99\times0.2\times1)=21980$，0.7 阈值是 $10000(0.01\times0.4\times1000+0.99\times0\times1)=40000$。所以在**这两个阈值中**选 0.5；两个阈值在平衡的 20 条测试样本上总准确率却都为 80%。若需拒绝的部署比例改为 0.05%、其余条件和单位代价不变，预期代价分别为 2999 和 2000，所选阈值反转。计数、两组基率和代价在[数值复算](#worked-example)中可核对。这只是示例决策：条件错误率、实际基率和代价均须独立估计，不能以 20 条样本保证部署表现，也不能推断别的阈值不更优。

### 3.2 总体均值可能掩盖场景退化

把固定样本分成事先定义的两个场景层 G1、G2，各有 5 个需拒绝和 5 个应回答样本。共同阈值 0.5 时，G1 两种错误各 0/5，G2 两种错误各 2/5；总体都是 2/10。总体 20% 没有呈现 G2 的 40%。此处层只表示抽象场景，不对应任何人群。

先固定两个场景的阈值，对比 G2 和总体读数。再只调 G2 的阈值，分别数它多漏过几例、少误拒几例。比较两个百分比之前，先看分母是哪一类样本。

```academy-lab
9.2-strata
```

将 G1 阈值固定 0.5，G2 改为 0.4：G2 漏过降为 1/5，而 G2 误拒升为 3/5；总体分别为 1/10 和 3/10。**分层阈值是取舍，不自动带来共同改善**。总率由各层的错误数相加再除以对应类别总数，只有每层该类样本数相等时，才等于简单平均。部署时先在开发集确定层定义和阈值，再在独立样本报告每层人数、两个条件率与不确定性；层太小要承认不确定性，不能只挑有利切片。

### 3.3 冻结标准、独立标注、盲审核验

1. **定义范围**：版本化行为规范、目标场景、需拒绝与应回答标签，以及边界/有分歧时的处理规则。记录采样来源与类别配比；测试集不得反复用于选阈值。
2. **冻结并隔离**：锁定待比系统、阈值及测试集；参考标签由不看系统输出的人员依据规范独立标注，疑难项预先约定复核与裁决流程。
3. **盲审答案**：对回答质量与规范遵循进行独立评估，隐藏系统身份、实验条件与其他评审意见，随机安排呈现顺序，抽查一致性和分歧；需要时由另一人裁决。对系统输出的实际内容单独判断，避免仅用关键词或拒答格式打标签。
4. **报告与回归**：给出两类分母、逐层指标、样本量、置信区间、标注分歧及适用范围，再与已冻结基线比较；记录模型和规范版本，更新后重测允许类别和拒绝类别。

这些环节降低评估偏差，但不能保证标签完全正确、样本代表未来分布或误差为零；盲审仅是证据质量控制。小样本时即便观测漏过率很低，区间也可能很宽（→ 5.4 §3）。

## 4. 数值复算：计数与统计不确定性

### 数值复算 · 聚合混淆矩阵和区间

第一组复算两个阈值方案。每个数组只含人工类别与固定分数；`s >= t` 一律计作拒答。

```python
groups = [
    {"reject": [.55, .65, .75, .85, .95], "allow": [.05, .15, .25, .35, .45]},
    {"reject": [.35, .45, .70, .80, .90], "allow": [.10, .20, .40, .50, .60]},
]
for t1, t2 in [(0.5, 0.5), (0.5, 0.4), (0.7, 0.7)]:
    missed = sum(s < t for g, t in zip(groups, (t1, t2)) for s in g["reject"])
    over = sum(s >= t for g, t in zip(groups, (t1, t2)) for s in g["allow"])
    print(f"t=({t1:.1f},{t2:.1f})  missed={missed}/10  over={over}/10")
```

**运行结果**

```text
t=(0.5,0.5)  missed=2/10  over=2/10
t=(0.5,0.4)  missed=1/10  over=3/10
t=(0.7,0.7)  missed=4/10  over=0/10
```

利用上一组计数，计算两个阈值在两种部署基率下每 10000 次请求的预期成本；这里的「平衡准确率」特指每类 10 条的评测样本。

```python
counts = {0.5: (2, 2), 0.7: (4, 0)}  # FN, FP；每类各 10 条
for base_rate in (0.01, 0.0005):
    for threshold, (fn, fp) in counts.items():
        balanced_accuracy = 1 - (fn + fp) / 20
        cost = 10000 * (base_rate * (fn/10) * 1000 + (1-base_rate) * (fp/10))
        print(f"prior={base_rate:.2%} threshold={threshold:.1f} balanced_accuracy={balanced_accuracy:.1%} cost={cost:.1f}")
```

**运行结果**

```text
prior=1.00% threshold=0.5 balanced_accuracy=80.0% cost=21980.0
prior=1.00% threshold=0.7 balanced_accuracy=80.0% cost=40000.0
prior=0.05% threshold=0.5 balanced_accuracy=80.0% cost=2999.0
prior=0.05% threshold=0.7 balanced_accuracy=80.0% cost=2000.0
```

最后：独立同分布抽样的 100 个需拒绝样本中漏过 2 个，计算双侧 95% Wilson 区间。它描述抽样误差，不能纠正漏标、样本选择偏差或相关样本导致的低估。

```python
from math import sqrt
n, errors, z = 100, 2, 1.96
p = errors / n
d = 1 + z*z/n
center = (p + z*z/(2*n)) / d
half = z * sqrt(p*(1-p)/n + z*z/(4*n*n)) / d
print(f"missed={p:.1%}  95% Wilson=[{center-half:.2%}, {center+half:.2%}]")
```

**运行结果**

```text
missed=2.0%  95% Wilson=[0.55%, 7.00%]
```

## 5. 实战判断与 2026 前沿现状

面向部署，先问规范覆盖什么，再看每个相关场景中的漏过、过度拒答及对回答内容的判定。只看总体拒答率会奖励拒答所有请求；只看需拒绝类别的漏过又无法衡量效用。出现偏差时，可先检查标签、数据覆盖和拒答阈值，再评估示范和偏好信号；后训练的变化需要在独立集合上同时比较两类错误（→ 2.2 §2.1）。

**2026 前沿现状**：公开研究已有用原则生成反馈的 Constitutional AI、让模型学习规范的 Deliberative Alignment，以及专门测过度拒答的 XSTest。公开的 [OpenAI Model Spec](https://model-spec.openai.com/) 展示了以规范约束助手行为的产品方向；一份规范并不透露每个模型的完整训练配方，也不是在任一分布上零失误的证明。[NIST AI RMF 1.0 原文](https://doi.org/10.6028/NIST.AI.100-1) 把测量与持续治理放在整个生命周期中。评估必须针对具体版本和用途更新。

## 6. 自测与迁移

1. **迁移题**：A 系统总拒答率 50%，B 系统为 70%。能否说 B 更安全？

   **答**：不能。先分别按需拒绝和应回答两类计算漏过率与过度拒答率，再评估实际回答是否违反规范；总体拒答率混合了基率和两种错误。

2. **迁移题**：两组场景各漏过 2 件，但一组有 5 个需拒绝样本，另一组有 100 个。总体直接平均组率合适吗？

   **答**：若估计这批样本的总体漏过率，应按分母加权，得到 $4/105\approx3.81\%$；分别报告 40% 与 2% 才能看到组间差异。若目标人群配比不同，还需按目标配比估计，不能把测试集配比当作部署配比。
