# 9.3 幻觉与校准：什么时候应该相信答案？

> **一句话核心直觉**：答案正确率、置信度校准和选择性回答的覆盖率是三个不同问题。校准关注「说 80% 时是否约有 80% 正确」，覆盖率关注回答了多少，选择性风险关注已回答部分错了多少；三者必须在相同任务定义和独立数据上一起报告。
> **唤醒标签**：流畅 ≠ 真实 · 答案正确性 · ECE · Brier · 语义熵 · 自洽性 · 风险—覆盖率 · 弃答

---

## 1. 问题：模型说自己有 90% 把握，能直接信吗？

同一个问答系统答 100 题，能给出流畅回答，但其中一部分事实不实、证据不支持或来源被编造。预训练预测文本中的下一 token，语言上常见和事实正确并不等价；后训练奖励有用与符合偏好，也可能在某些设置下鼓励给出答案而不是准确表达不确定性，但不能断言所有后训练都必然提高过度自信。

本课把同一系统的问题拆成三问：**答案到底对不对？90% 置信度对应的题是否约 90% 答对？设一个答题门槛后留下多少题、又错了多少？** 两个实验和[数值复算](#worked-example)用固定答案、固定真值展示它们的区别。若是开放题，须先明确什么算正确、何时可判定、标注如何处理多种正确表达。

## 2. 事实正确、证据支持和不确定性不是同一件事

一次回答可能刚好答对但没有证据，也可能忠实转述了一份过期来源而事实错误。对检索问答，应分开测**召回**、答案是否被给定证据支持（忠实度），以及独立外部标准下的**事实正确性**（→ 8.2 §3）。实体、日期和证据范围决定评测单位；「未能验证」不能直接计作「已证伪」。

模型分配给下一个 token 的概率，是在给定前缀和模型分布下的预测概率，不直接等于完整答案事实正确的概率。整段 logprob 受长度、措辞与分词影响；自报的置信度同样需要用独立数据校验。哪怕所有答案看起来很自信，系统仍可能对了很多或错了很多：**准确率** $\frac1N\sum_i y_i$ 只用到答案的正确性 $y_i\in\{0,1\}$，没有检查报出的概率 $p_i$。

## 3. 从校准到选择性回答

### 3.1 校准：按置信度分组比实际正确率

理想校准的定义是 $P(Y=1\mid P=p)=p$。例如所有报告 0.8 的题中，长期约 80% 答对。这个条件针对指定任务、答案生成方式和数据分布，不表示每一道题「80% 正确」，也不代表系统准确率就是 80%。

有限数据中常把置信度分为 $B$ 个箱 $I_b$，分别计算非空箱的平均置信度 $\mathrm{conf}(b)$ 和准确率 $\mathrm{acc}(b)$（空箱不计入 ECE）：

$$
\mathrm{ECE}=\sum_{b=1}^{B}\frac{|I_b|}{N}\left|\mathrm{acc}(b)-\mathrm{conf}(b)\right|,\qquad
\mathrm{Brier}=\frac1N\sum_{i=1}^N(p_i-y_i)^2.
$$

本课中的 $p_i$ 是系统对**固定待评答案正确**的概率，即使低于 0.5 也合法，不是一定取最大类的 top-1 置信度。ECE 依赖箱数、边界与样本量，同箱正负误差可抵消；Brier 是概率预测的平方误差，除了校准也反映分辨能力。二者都要配箱内数量、置信区间与子群检查，不能仅凭单一汇总分数判断。[Guo et al.](https://arxiv.org/abs/1706.04599) 是神经网络校准与温度缩放的经典来源。

```academy-lab
9.3
```

固定 30 个回答：原置信度 0.2、0.6、0.9 的三组各 10 个，正确数分别为 2、6、7，正确率是 50%。用 5 个等宽箱，原 ECE 为 0.067、Brier 为 0.217。将所有置信度压为 0.5 后，答案和正确数没有变化，总体恰好 50% 正确，所以单箱 ECE 变为 0；但 Brier 恶化到 0.250，原来各组的差异也被隐藏。实验中的映射只是说明分箱与分辨能力，**不是推荐的校准器**。

### 3.2 不确定性信号怎么取

| 信号 | 怎样读 | 限制 |
|---|---|---|
| token / 序列 logprob | 模型对生成序列的偏好 | 不直接等于事实正确概率，跨长度和措辞比较有偏 |
| 自评置信度 | 让系统报告答案正确性的概率 | 需独立校准，表达出来不代表可靠 |
| 语义熵 | 多次抽样后将等义答案归并，计算意义分布的熵 | 依赖采样、语义归并与问题范围，低熵也可能共同答错 |
| 自洽性 | 比较多次答案是否归为同一意义或取多数 | 样本共享偏差、错误可高度相关，一致不是正确 |

例如问「法国首都是哪座城市？」；在同一采样策略下，10 次答案中「巴黎」4 次、「法国巴黎」4 次、「伦敦」2 次。以完整字符串为类别的**经验答案字符串熵**是 $H_{\rm str}=-[0.4\ln0.4+0.4\ln0.4+0.2\ln0.2]=1.055$ nats；将前两种表达归到同一个意思后，**经验语义组熵**是 $H_{\rm sem}=-[0.8\ln0.8+0.2\ln0.2]=0.500$ nats。这里统计完整答案的经验频率，不是逐 token 的熵；分组与计算可在[数值复算](#worked-example)中核对。这个已知真值的例子里 8/10 次采样正确，但 0.500 nats 是分布的熵，不是 80% 正确概率；即使十次都说同一个答案、语义熵为零，也可能一致答错。真实问题中的分组错误、样本太少和温度选择都会改变估计。[Farquhar et al.](https://www.nature.com/articles/s41586-024-07421-0) 研究语义熵作为事实生成中的不确定性信号；具体效果应在自己的分布和成本约束下测，不能从低熵推出事实正确。

### 3.3 弃答：正确率、校准和覆盖率各管什么

令 $a_i=\mathbf1[p_i\ge\tau]$，达到门槛才回答。定义

$$
\text{覆盖率}=\frac{\sum_i a_i}{N},\qquad
\text{选择性风险}=\frac{\sum_i a_i(1-y_i)}{\sum_i a_i}.
$$

分母为零时没有回答，选择性风险未定义，不能记为零。通常希望在满足风险目标的同时保留尽可能多的覆盖，但有限样本下，提高阈值不保证观测风险处处下降；置信度排序错时，风险甚至会升高。不同门槛画出风险—覆盖率曲线（[Selective Classification](https://arxiv.org/abs/1705.08500)），而不只是汇报最漂亮的一个点。

```academy-lab
9.3-coverage
```

10 个固定答案中 6 个正确。门槛 0.75 时回答 5 个，其中错 1 个：覆盖 50%，选择性风险 20%；门槛 0.90 时回答 2 个且都对：覆盖 20%，观察风险 0%。后者不是部署时风险为零的保证。要将校准或门槛选取与评测分离，在冻结模型与数据处理后使用独立测试集，再随真实反馈和分布漂移监控。弃答有机会成本：对不同错误代价、人工复核容量和任务人群，合理工作点可能不同。

## 4. 数值复算：校准与风险—覆盖率

### 数值复算 · 固定答案上的两种比较

第一组计算 5 个等宽箱的 ECE 与 Brier；三组正确数和置信度都固定，变换只改置信度读数。

```python
groups = [(0.2, 10, 2), (0.6, 10, 6), (0.9, 10, 7)]
for scale in (1.0, 0.0):
    bins = [[0, 0, 0.0] for _ in range(5)]  # n, correct, sum of probabilities
    brier = 0.0
    for original_p, n, correct in groups:
        p = 0.5 + scale * (original_p - 0.5)
        b = bins[min(4, int(p * 5))]
        b[0] += n
        b[1] += correct
        b[2] += n * p
        brier += correct * (1-p)**2 + (n-correct) * p**2
    ece = sum(abs(correct - sum_p) / 30 for n, correct, sum_p in bins if n)
    print(f"scale={scale:.1f}  accuracy={15/30:.3f}  ECE={ece:.3f}  Brier={brier/30:.3f}")
```

**运行结果**

```text
scale=1.0  accuracy=0.500  ECE=0.067  Brier=0.217
scale=0.0  accuracy=0.500  ECE=0.000  Brier=0.250
```

第二组计算完整字符串与语义组的经验熵，使用自然对数、单位 nats。

```python
from collections import Counter
from math import log
answers = ["巴黎"] * 4 + ["法国巴黎"] * 4 + ["伦敦"] * 2
meaning = {"巴黎": "巴黎", "法国巴黎": "巴黎", "伦敦": "伦敦"}
for name, counts in [("strings", Counter(answers)),
                     ("meanings", Counter(meaning[x] for x in answers))]:
    entropy = -sum((count/len(answers)) * log(count/len(answers))
                   for count in counts.values())
    print(f"{name}: {entropy:.3f} nats")
```

**运行结果**

```text
strings: 1.055 nats
meanings: 0.500 nats
```

第三组计算门槛改变后的回答覆盖率与条件错误率；比较使用同一组固定答案。

```python
answers = [(.95, 1), (.90, 1), (.85, 0), (.80, 1), (.75, 1),
           (.70, 0), (.65, 1), (.60, 0), (.55, 1), (.50, 0)]
for threshold in (0.50, 0.75, 0.90):
    answered = [correct for p, correct in answers if p >= threshold]
    coverage = len(answered) / len(answers)
    risk = sum(1-correct for correct in answered) / len(answered)
    print(f"threshold={threshold:.2f}  coverage={coverage:.1%}  risk={risk:.1%}")
```

**运行结果**

```text
threshold=0.50  coverage=100.0%  risk=40.0%
threshold=0.75  coverage=50.0%  risk=20.0%
threshold=0.90  coverage=20.0%  risk=0.0%
```

## 5. 实战判断与 2026 前沿现状

部署时先定义答案正确与证据支持的标注，再测总体准确率；把答案固定，用留出数据校准其正确性概率，报告可靠性图、箱数和 Brier；最后在**另一份**评测数据上报告完整风险—覆盖率曲线及分层样本量。校准可以改变概率读数而不改变答案；只改变门槛可以改变回答子集，但不能声称提高了原始全部答案的准确率。模型重训、提示、工具、问题难度或用户群变化都可能使原校准失效，应重新评测。

**2026 前沿现状**：公开研究已把多次采样和语义归并用于检测部分事实性错误，工具调用或检索也能提供外部证据；它们都依赖验证器、来源与任务。OpenAI 的 [Why language models hallucinate](https://openai.com/index/why-language-models-hallucinate/) 讨论了评测中猜测比承认不确定更易得分的激励。相关方法提供改进方向，不保证模型自评、检索结果或一致答案必然正确；用独立事实依据和实际分布检验。

## 6. 自测与迁移

1. **迁移题**：两个模型答对率都为 70%；A 的 0.9 置信箱实际正确率 90%，B 的同箱正确率 60%。能说 A 全面优于 B 吗？

   **答**：不能。只知 A 在这个箱中更接近校准；还需看其他箱、样本数与置信区间、整体正确率的任务构成、Brier，以及选择性风险和覆盖率。单箱结果不能推出全面排序。

2. **迁移题**：新校准器让 ECE 从 0.07 降到 0，却把所有置信度设为数据集总体正确率。应立即上线吗？

   **答**：不能只根据 ECE。常数预测能在总体上校准却丢失题目间区分能力；应在独立数据比较 Brier、可靠性图及风险—覆盖率，并检查分层和数据漂移。是否上线还取决于业务对错误和弃答的代价。
